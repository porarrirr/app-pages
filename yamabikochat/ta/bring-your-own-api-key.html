முதன்மை / உங்கள் API விசையைப் பயன்படுத்துங்கள்

உங்கள் விசையைக் கொண்டு வாருங்கள்

iPhone மற்றும் iPad-ல் AI அரட்டைக்கு உங்கள் சொந்த API விசையைப் பயன்படுத்துங்கள்

YamabikoChat ஒரு பிரிங்-யுவர்-ஓன்-கீ (BYOK) கிளையண்ட். நீங்கள் ஒரு API விசையைச் சேர்க்கிறீர்கள் — அல்லது ஆதரவு பெறும் கணக்கில் உள்நுழைகிறீர்கள் — செயலி உங்கள் கேள்விகளை நேரடியாக அந்த வழங்குநருக்கு அனுப்புகிறது. இடையில் YamabikoChat சந்தாவோ டோக்கன் விற்பனையாளரோ இல்லை.

கடைசியாகப் புதுப்பிக்கப்பட்டது: 2026-11-17

“உங்கள் சொந்த விசையைப் பயன்படுத்துங்கள்” என்றால் என்ன

OpenAI, Google, Anthropic, OpenRouter போன்ற AI வழங்குநர்கள் API விசைகள் மூலம் தங்கள் மாடல்களுக்கான அணுகலை விற்கிறார்கள்; பொதுவாகப் பயன்பாட்டுக்கு ஏற்பக் கட்டணம் வசூலிக்கிறார்கள். BYOK செயலி அந்த விசைகளுக்கான ஒரு கிளையண்ட்: உங்கள் வழங்குநர் கணக்கில் விசையை உருவாக்கி, அதைச் செயலியில் சேர்த்தால், நீங்கள் பயன்படுத்துவதற்கான கட்டணத்தை வழங்குநரே நேரடியாக வசூலிப்பார்.

உங்கள் சொந்த விசையை ஏன் பயன்படுத்த வேண்டும்

  • பயன்படுத்தியதற்கு மட்டும் செலுத்துங்கள். குறைவாகப் பயன்படுத்துபவர்கள் பெரும்பாலும் மாதாந்திர AI சந்தாவை விடக் குறைவாகச் செலவிடுகிறார்கள்; அதிகம் பயன்படுத்துபவர்கள் செலவு எங்கிருந்து வருகிறது என்பதைத் துல்லியமாகப் பார்க்கிறார்கள்.
  • மாடலைத் தேர்ந்தெடுங்கள். செயலி தேர்ந்தெடுத்த நிலையான பட்டியலுக்குப் பதிலாக உங்கள் வழங்குநர் வழங்கும் மாடல்களைப் பயன்படுத்துங்கள்.
  • ஒரு செயலி, பல வழங்குநர்கள். Gemini, OpenRouter, OpenAI, Anthropic ஆகியவற்றைப் பக்கம் பக்கமாக வைத்து, இரட்டைப் பயன்முறையில் ஒப்பிடுங்கள்.
  • உங்கள் பயன்பாட்டைப் பாருங்கள். டோக்கன் பயன்பாட்டுப் புள்ளிவிவரங்கள் எவ்வளவு பயன்படுத்துகிறீர்கள் என்பதைக் காட்டும்.

எப்படி அமைப்பது

  1. API விசையை உருவாக்குங்கள் உங்கள் வழங்குநரின் கன்சோலில் — உதாரணமாக Gemini-க்கு Google AI Studio, OpenAI தளம், Anthropic கன்சோல் அல்லது OpenRouter.
  2. YamabikoChat-ன் அமைப்புகளைத் திறந்து இணைப்பு அமைப்புகளில் வழங்குநரைத் தேர்ந்தெடுக்கவும்.
  3. விசையை ஒட்டவும். அது உங்கள் சாதனத்தின் iOS கீச்செயினில் சேமிக்கப்படும்.
  4. மாடலைத் தேர்ந்தெடுத்து அரட்டையைத் தொடங்குங்கள். செயலி பாதுகாப்பாக இயக்க முடியாத மாடல்கள் ஊகிக்கப்படாமல், காரணத்துடன் கிடைக்காதவை எனக் காட்டப்படும்.

API விசை இல்லையா? உள்நுழையுங்கள்

  • ChatGPT திட்டம் — உங்கள் ChatGPT கணக்கில் உள்நுழைந்து உங்கள் திட்டத்தில் அடங்கிய மாடல்களைப் பயன்படுத்துங்கள்.
  • xAI — உங்கள் xAI கணக்கில் உள்நுழையுங்கள்.
  • Apple Intelligence — ஆதரவு உள்ள சாதனங்களில் உள்ளமைந்தது; சாதனத்திலேயே அல்லது Private Cloud Compute மூலம், விசை இல்லாமல் இயங்கும்.

தனிப்பயன் எண்ட்பாயிண்ட்கள்

உங்கள் சேவை பட்டியலில் இல்லையெனில், அதன் அடிப்படை URL மற்றும் விசையுடன் தனிப்பயன் எண்ட்பாயிண்டைச் சேர்த்து, ஆதரவு பெறும் API வடிவங்களில் ஒன்றைத் தேர்ந்தெடுக்கவும்: OpenAI Chat Completions, OpenAI Responses, Anthropic Messages, Gemini (Google Generative AI) அல்லது Mistral.

செலவு எவ்வளவு

செயலி இலவசம்; செயலிக்குள் வாங்குதல்கள் இல்லை. உங்கள் வழங்குநர் தனது சொந்த விலை, வரம்புகள் மற்றும் விதிமுறைகளின்படி பயன்பாட்டுக்குக் கட்டணம் வசூலிப்பார். இரட்டைப் பயன்முறையும் தானியங்கி உரையாடலும் இரண்டு மாடல்களுக்குக் கோரிக்கைகளை அனுப்புவதால் இரண்டிலும் பயன்பாடு உருவாகும்.

பாதுகாப்பும் தனியுரிமையும்

  • API விசைகளும் அணுகல் டோக்கன்களும் iOS கீச்செயினில் சேமிக்கப்படும்; அவற்றைத் தனது கண்டறிதல் பதிவுகளில் எழுதாத வகையில் செயலி வடிவமைக்கப்பட்டுள்ளது.
  • கேள்விகள், உரையாடல் சூழல் மற்றும் நீங்கள் தேர்ந்தெடுத்த இணைப்புகள் நீங்கள் தேர்ந்தெடுத்த வழங்குநருக்கு நேரடியாக அனுப்பப்படும்.
  • உரையாடல்கள் உங்கள் சாதனத்தில் சேமிக்கப்படும். செயலி ஆப்களுக்கு இடையேயான கண்காணிப்பைப் பயன்படுத்துவதில்லை. தனியுரிமைக் கொள்கையைப் பார்க்கவும்.

தொடர்புடைய வழிகாட்டிகள்

AI மாடல்களை ஒப்பிடுங்கள் ஒரே கேள்வியை இரண்டு மாடல்களுக்கு அனுப்பி, இரண்டு பதில்களையும் பக்கம் பக்கமாகப் படியுங்கள். ஆதரவு பெறும் வழங்குநர்கள் Gemini, OpenRouter, ChatGPT திட்டம், xAI, OpenAI, Anthropic மற்றும் பல. கேள்விகள் விலை, தேவைகள், தனியுரிமை மற்றும் ஆதரவு பெறும் மாடல்கள்.
