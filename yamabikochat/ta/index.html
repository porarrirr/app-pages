உங்கள் சொந்த AI · iPhone & iPad

உங்கள் சொந்த API விசையில் AI அரட்டை. பதில்களை ஒப்பிடுங்கள்.

YamabikoChat என்பது iPhone மற்றும் iPad-க்கான இலவச AI சாட் செயலி. நீங்கள் ஏற்கனவே பயன்படுத்தும் AI சேவைகளை API விசை அல்லது ஆதரவு பெறும் கணக்கு மூலம் இணைத்து, ஒரு மாடலுடன் அரட்டை அடியுங்கள், இரண்டு மாடல்களைப் பக்கம் பக்கமாக ஒப்பிடுங்கள் அல்லது இரண்டு மாடல்கள் ஒன்றோடொன்று பேசட்டும்.

YamabikoChat என்றால் என்ன

வகை
உங்கள் சொந்த API விசை அல்லது கணக்கைப் பயன்படுத்தும் iPhone, iPad-க்கான நேட்டிவ் AI சாட் கிளையண்ட் (BYOK)
விலை
இலவசம். விளம்பரங்கள் இல்லை, பதிவு இல்லை, செயலிக்குள் சந்தா அல்லது டோக்கன் வாங்குதல் இல்லை. வழங்குநர் பயன்பாட்டுக்கான கட்டணத்தை வழங்குநரே வசூலிக்கிறார்.
AI சேவைகள்
Google Gemini, OpenRouter, ChatGPT திட்டம், xAI, Apple Intelligence, OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq, Sarashina, PLaMo, தனிப்பயன் எண்ட்பாயிண்ட்கள் மற்றும் பல — அனைத்து வழங்குநர்களையும் பார்க்கவும்
பயன்முறைகள்
சாட், இரட்டை (இரண்டு மாடல்கள் பக்கம் பக்கமாக) மற்றும் தானியங்கி உரையாடல் (இரண்டு மாடல்கள் ஒன்றோடொன்று பேசும்), மேலும் பணியின் பகுதிகளை ஏற்கும் துணை முகவர்கள்
தனியுரிமை
உரையாடல்கள் உங்கள் சாதனத்திலேயே இருக்கும், விசைகள் iOS கீச்செயினில் சேமிக்கப்படும், கேள்விகள் நீங்கள் தேர்ந்தெடுத்த வழங்குநருக்கு மட்டுமே செல்லும்
தேவைகள்

பயன்முறைகள்

மூன்று உரையாடல் பயன்முறைகள், மேலும் துணை முகவர்கள்

கேள்விக்கு ஏற்ற பயன்முறையைத் தேர்ந்தெடுங்கள், அதற்கு மாறாக அல்ல.

01 / சாட்

ஒரு மாடலுடன் பேசுங்கள்

Markdown, குறியீடு சிறப்பம்சம், கணிதம் மற்றும் பட இணைப்புகளுடன் ஸ்ட்ரீமிங் பதில்கள். திருத்தி, மீண்டும் உருவாக்கி, பதிலின் மாறுபாடுகளை வைத்திருங்கள்.

02 / இரட்டை

இரண்டு பதில்களை ஒப்பிடுங்கள்

ஒரே கேள்வியை இரண்டு மாடல்களுக்கு அனுப்பி, இரண்டு பதில்களையும் பக்கம் பக்கமாகப் படியுங்கள். இரட்டைப் பயன்முறை எப்படி வேலை செய்கிறது

03 / தானியங்கி

இரண்டு மாடல்கள் பேசட்டும்

இரண்டு மாடல்கள், ஒரு தலைப்பு மற்றும் சுற்றுகளின் எண்ணிக்கையைத் தேர்ந்தெடுத்து, அவை ஒன்றோடொன்று விவாதிப்பதைப் பாருங்கள்.

+ / துணை முகவர்கள்

வேலையை ஒப்படையுங்கள்

கோரிக்கையின் பகுதிகளை மாடல் துணை முகவர்களுக்கு ஒப்படைக்கட்டும் — ஒவ்வொன்றும் தனி மாடலைப் பயன்படுத்தலாம் — அவற்றின் முன்னேற்றத்தை அரட்டையில் பின்தொடருங்கள்.

அம்சங்கள்

அன்றாட வேலைக்காக உருவாக்கப்பட்டது

எழுத்து, சுருக்கம், மொழிபெயர்ப்பு, குறியீடு மற்றும் கணிதம் — உண்மையான உதவியாளருக்குத் தேவையான கருவிகளுடன்.

  • படங்கள், PDF மற்றும் உரைக் கோப்புகளை இணைக்கவும் (ஒவ்வொன்றும் 10 MB வரை)
  • இணையத் தேடல், லோக்கல் Python மற்றும் ஊடாடும் வரைபடங்கள் (GenUI) கருவிகளாக
  • குரல் டிக்டேஷன் மற்றும் Safari உள்ளிட்ட செயலிகளுக்கான பங்கீட்டு நீட்டிப்பு
  • Shortcuts செயல்கள், Spotlight தேடல் மற்றும் ரகசிய உரையாடல்கள்
  • திட்டங்கள், வரலாற்றுத் தேடல், மாடல் முன்னமைவுகள் மற்றும் டோக்கன் பயன்பாட்டுப் புள்ளிவிவரங்கள்
  • iPad பிளவுப் பார்வை மற்றும் இருண்ட பயன்முறை

யாருக்கானது

இது யாருக்கானது

  • நீங்கள் ஏற்கனவே API விசைக்கோ ChatGPT திட்டத்துக்கோ பணம் செலுத்தி, அதற்கான நேட்டிவ் iPhone மற்றும் iPad செயலியை விரும்புகிறீர்கள்.
  • ஒரு மாடலின் பதிலை நம்புவதற்கு முன், மற்றொரு மாடலுடன் அதைச் சரிபார்க்க விரும்புகிறீர்கள்.
  • பல AI சந்தாக்களைச் சேர்ப்பதை விட, பயன்படுத்தியதற்கு மட்டும் செலுத்த விரும்புகிறீர்கள்.
  • OpenRouter அல்லது பல வழங்குநர்களைப் பயன்படுத்தி, அவற்றை ஒரே இடத்தில் வைத்திருக்க விரும்புகிறீர்கள்.
  • உங்கள் அரட்டை வரலாறு உங்கள் சொந்தச் சாதனத்திலேயே இருக்க வேண்டும் என விரும்புகிறீர்கள்.

மேலும் அறிக

AI மாடல்களை ஒப்பிடுங்கள் ஒரே கேள்வியை இரண்டு மாடல்களுக்கு அனுப்பி, இரண்டு பதில்களையும் பக்கம் பக்கமாகப் படியுங்கள். உங்கள் சொந்த API விசையைப் பயன்படுத்துங்கள் BYOK எப்படி வேலை செய்கிறது, எவ்வளவு செலவாகும், உங்கள் விசை எங்கே சேமிக்கப்படுகிறது. ஆதரவு பெறும் வழங்குநர்கள் Gemini, OpenRouter, ChatGPT திட்டம், xAI, OpenAI, Anthropic மற்றும் பல. கேள்விகள் விலை, தேவைகள், தனியுரிமை மற்றும் ஆதரவு பெறும் மாடல்கள்.

நீங்கள் ஏற்கனவே பயன்படுத்தும் AI உடன் இதை முயற்சியுங்கள்.
