YamabikoChat இலவசமா?

ஆம். YamabikoChat பதிவிறக்கம் இலவசம்; விளம்பரங்கள் இல்லை, பதிவு இல்லை, செயலிக்குள் சந்தா அல்லது டோக்கன் வாங்குதல் இல்லை. நீங்கள் உருவாக்கும் பயன்பாட்டுக்கான கட்டணத்தை அந்த வழங்குநரின் விலை மற்றும் விதிமுறைகளின்படி நேரடியாக உங்கள் AI வழங்குநருக்குச் செலுத்துகிறீர்கள்.

எனக்கு API விசை தேவையா?

ஆதரவு பெறும் AI வழங்குநரின் API விசை அல்லது ChatGPT திட்டம், xAI போன்ற ஆதரவு பெறும் கணக்கில் உள்நுழைவு தேவை. Apple Intelligence ஆதரவு உள்ள சாதனங்களில் விசை இல்லாமல் வேலை செய்கிறது.

API விசைக்குப் பதிலாக எனது ChatGPT சந்தாவைப் பயன்படுத்தலாமா?

ஆம். ChatGPT திட்ட இணைப்பு மூலம் உங்கள் ChatGPT கணக்கில் உள்நுழைந்து, OpenAI API விசை இல்லாமல் உங்கள் திட்டத்தில் அடங்கிய மாடல்களைப் பயன்படுத்தலாம்.

எந்த AI மாடல்களைப் பயன்படுத்தலாம்?

Google Gemini, OpenRouter, ChatGPT திட்டம், xAI, Apple Intelligence, Sarashina மற்றும் PLaMo ஆகியவை உள்ளமைந்தவை. OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq மற்றும் பல API வழங்குநர்கள் models.dev பட்டியல் மூலம் கிடைக்கின்றன; ஆதரவு பெறும் API வடிவத்தைப் பயன்படுத்தும் தனிப்பயன் எண்ட்பாயிண்டையும் சேர்க்கலாம். கிடைக்கும் மாடல்கள் ஒவ்வொரு வழங்குநரைப் பொறுத்தவை.

எனது Anthropic API விசையுடன் Claude-ஐப் பயன்படுத்தலாமா?

ஆம். வழங்குநர் பட்டியலில் இருந்து உங்கள் API விசையுடன் Anthropic-ஐச் சேர்க்கவும், அல்லது Anthropic Messages API-ஐப் பயன்படுத்தும் தனிப்பயன் எண்ட்பாயிண்டை அமைக்கவும்.

ChatGPT, Gemini, Claude ஆகியவற்றின் பதில்களைப் பக்கம் பக்கமாக ஒப்பிடலாமா?

ஆம். இரட்டைப் பயன்முறை ஒரே கேள்வியை இரண்டு மாடல்களுக்கு அனுப்பி, இரண்டு பதில்களையும் பக்கம் பக்கமாகக் காட்டும். நீங்கள் இணைத்த வழங்குநர்களில் இருந்து ஏதேனும் இரண்டு மாடல்களைத் தேர்ந்தெடுக்கவும்.

எனது உரையாடல்களும் API விசைகளும் எங்கே சேமிக்கப்படுகின்றன?

உரையாடல்களும் அமைப்புகளும் உங்கள் சாதனத்தில் சேமிக்கப்படும். API விசைகளும் அணுகல் டோக்கன்களும் iOS கீச்செயினில் சேமிக்கப்படும். உங்கள் கேள்விகள், உரையாடல் சூழல் மற்றும் நீங்கள் தேர்ந்தெடுத்த இணைப்புகள் நீங்கள் தேர்ந்தெடுத்த வழங்குநருக்கு மட்டுமே அனுப்பப்படும்.

YamabikoChat iPad-ல் வேலை செய்யுமா?

ஆம். இது iPhone மற்றும் iPad-க்கான நேட்டிவ் செயலி; iPad-ல் பிளவுப் பார்வை உங்கள் உரையாடல் பட்டியலையும் அரட்டையையும் பக்கம் பக்கமாகக் காட்டும்.
