ஆதரவு பெறும் AI வழங்குநர்கள்

YamabikoChat கீழே உள்ள AI சேவைகளுடன் உங்கள் சொந்த API விசை அல்லது கணக்கு மூலம் இணைகிறது. உள்ளமைந்த வழங்குநர்கள் செயலியில் நேரடியாக அமைக்கப்படுகின்றன; மேலும் பல API வழங்குநர்கள் models.dev பட்டியலில் இருந்து வருகின்றன.

கடைசியாகப் புதுப்பிக்கப்பட்டது: 2026-11-17

உள்ளமைந்த வழங்குநர்கள்

வழங்குநர்எப்படி இணைப்பதுகுறிப்புகள்
Google GeminiAPI விசைGoogle AI Studio-வின் Gemini மாடல்கள்
OpenRouterAPI விசைசெயலியில் OpenRouter-ன் மாடல் பட்டியலைப் பாருங்கள்
ChatGPT திட்டம்ChatGPT மூலம் உள்நுழையுங்கள்உங்கள் ChatGPT திட்டத்தில் அடங்கிய மாடல்களைப் பயன்படுத்துகிறது
xAIஉங்கள் xAI கணக்கில் உள்நுழையுங்கள்உங்கள் கணக்குக்குக் கிடைக்கும் Grok மாடல்கள்
Apple Intelligenceஉள்ளமைந்தது, விசை தேவையில்லைஆதரவு உள்ள சாதனங்களில், சாதனத்திலேயே மற்றும் Private Cloud Compute மூலம்
SarashinaAPI விசைSB Intuitions-ன் ஜப்பானிய மொழி மாடல்கள்
PLaMoAPI விசைPreferred Networks-ன் ஜப்பானிய மொழி மாடல்கள்; PLaMo 3.1 Prime-ல் இணையத் தேடல்
தனிப்பயன் எண்ட்பாயிண்ட்அடிப்படை URL + API விசைOpenAI Chat Completions, OpenAI Responses, Anthropic Messages, Gemini அல்லது Mistral வடிவம்

models.dev பட்டியலில் இருந்து மேலும் API வழங்குநர்கள்

மேலும் பல API வழங்குநர்களை வழங்க, YamabikoChat பொதுப் models.dev பட்டியலைப் படிக்கிறது; அதில் OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq, xAI API, Moonshot AI (Kimi), MiniMax, Z.ai (GLM), Fireworks AI, Together AI மற்றும் Hugging Face போன்ற வழங்குநர்கள் அடங்குவர். அமைப்புகளில் உங்கள் API விசையுடன் வழங்குநரைச் சேர்த்து ஒரு மாடலைத் தேர்ந்தெடுக்கவும்.

ஒவ்வொரு மாடலும் அதன் API ஒப்பந்தம் சரிபார்க்கப்பட்ட பிறகே இயங்கும். பாதுகாப்பாக இயக்க முடியாத மாடல்கள் துல்லியமான காரணத்துடன் முடக்கப்பட்டதாகத் தெரியும் — ஆனால் செயலி உங்களை அறியாமல் வேறு மாடல், எண்ட்பாயிண்ட் அல்லது வழங்குநருக்கு மாற்றாது.

மாடல்களை ஒன்றாகப் பயன்படுத்துதல்

இணைக்கப்பட்ட ஒவ்வொரு மாடலையும் அரட்டையில், இரண்டு பதில்களை ஒப்பிடும் இரட்டைப் பயன்முறையில், மற்றும் இரண்டு மாடல்கள் பேசும் தானியங்கி உரையாடலில் பயன்படுத்தலாம். பட உள்ளீடு, பகுத்தறிவு அமைப்புகள், கருவிகள் மற்றும் சூழல் நீளம் மாடலைப் பொறுத்தது.

மாடல் பட்டியல்கள் அடிக்கடி மாறும். செயலி எப்போதும் ஒவ்வொரு வழங்குநரின் தற்போதைய பட்டியலைக் காட்டும். வழங்குநர் மற்றும் தயாரிப்புப் பெயர்கள் அவற்றின் உரிமையாளர்களின் வர்த்தக முத்திரைகள்; YamabikoChat அவர்களுடன் இணைக்கப்படவில்லை.

தொடர்புடைய வழிகாட்டிகள்

AI மாடல்களை ஒப்பிடுங்கள்ஒரே கேள்வியை இரண்டு மாடல்களுக்கு அனுப்பி, இரண்டு பதில்களையும் பக்கம் பக்கமாகப் படியுங்கள்.உங்கள் சொந்த API விசையைப் பயன்படுத்துங்கள்BYOK எப்படி வேலை செய்கிறது, எவ்வளவு செலவாகும், உங்கள் விசை எங்கே சேமிக்கப்படுகிறது.கேள்விகள்விலை, தேவைகள், தனியுரிமை மற்றும் ஆதரவு பெறும் மாடல்கள்.
