FAQ

Frequently asked questions

Short answers about price, API keys, supported models, privacy and requirements.

Last updated: 2026-11-17

Is YamabikoChat free?

Yes. YamabikoChat is free to download, with no ads, no sign-up, and no subscriptions or token purchases inside the app. You pay your AI provider directly for the usage you create, under that provider's pricing and terms.

Do I need an API key?

You need either an API key from a supported AI provider or a supported account sign-in, such as ChatGPT plan or xAI. Apple Intelligence works without a key on devices that support it.

Can I use my ChatGPT subscription instead of an API key?

Yes. The ChatGPT plan connection lets you sign in with your ChatGPT account and use the models included in your plan, without an OpenAI API key.

Which AI models can I use?

Google Gemini, OpenRouter, ChatGPT plan, xAI, Apple Intelligence, Sarashina and PLaMo are built in. OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq and many other API providers are available through the models.dev catalog, and you can add a custom endpoint that uses a supported API format. Available models depend on each provider.

Can I use Claude with my Anthropic API key?

Yes. Add Anthropic from the provider catalog with your API key, or set up a custom endpoint that uses the Anthropic Messages API.

Can I compare ChatGPT, Gemini and Claude answers side by side?

Yes. Dual mode sends the same prompt to two models and shows both answers next to each other. Pick any two models from the providers you have connected.

Where are my conversations and API keys stored?

Conversations and settings are stored on your device. API keys and access tokens are stored in the iOS Keychain. Your prompts, the conversation context and the attachments you choose are sent only to the provider you selected.

Does YamabikoChat work on iPad?

Yes. It is a native app for iPhone and iPad, with a split view on iPad that shows your conversation list and chat side by side.

What are the system requirements?

iOS 17 or later on iPhone, and iPadOS 17 or later on iPad. Apple Intelligence requires a device and OS version that support it.

Is YamabikoChat open source?

Yes. The source code is published on GitHub under the MIT License. Bundled third-party software keeps its own licenses.
