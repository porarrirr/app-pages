지원하는 AI 제공업체

YamabikoChat은 내 API 키나 계정으로 아래 AI 서비스에 연결합니다. 내장 제공업체는 앱에서 바로 설정할 수 있고, 더 많은 API 제공업체는 models.dev 카탈로그에서 가져옵니다.

models.dev 카탈로그의 더 많은 API 제공업체

YamabikoChat은 공개 models.dev 카탈로그를 읽어 OpenAI, Anthropic(Claude), DeepSeek, Mistral, Groq, xAI API, Moonshot AI(Kimi), MiniMax, Z.ai(GLM), Fireworks AI, Together AI, Hugging Face 등 더 많은 API 제공업체를 지원합니다. 설정에서 API 키로 제공업체를 추가하고 모델을 고르면 됩니다.

각 모델은 API 계약이 검증된 경우에만 실행됩니다. 안전하게 실행할 수 없는 모델은 정확한 이유와 함께 표시되지만 비활성화되며, 앱이 다른 모델, 엔드포인트, 제공업체로 몰래 전환하는 일은 없습니다.

모델 함께 사용하기

연결한 모든 모델은 채팅, 두 답변을 비교하는 듀얼 모드, 두 모델이 대화하는 자동 대화에서 사용할 수 있습니다. 이미지 입력, 추론 설정, 도구, 컨텍스트 길이는 모델에 따라 다릅니다.

모델 목록은 자주 바뀝니다. 앱은 항상 각 제공업체의 최신 목록을 보여 줍니다. 제공업체 및 제품 이름은 각 소유자의 상표이며, YamabikoChat은 이들과 제휴하지 않습니다.
