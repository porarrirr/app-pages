내 API 키로 쓰는 AI 채팅. 답변을 나란히 비교하세요.

YamabikoChat은 iPhone과 iPad를 위한 무료 AI 채팅 앱입니다. 이미 쓰고 있는 AI 서비스를 API 키나 지원되는 계정으로 연결한 뒤, 한 모델과 대화하거나 두 모델의 답변을 나란히 비교하고, 두 모델끼리 대화하게 할 수 있습니다.

YamabikoChat이란?

유형
내 API 키나 계정으로 쓰는 iPhone·iPad용 네이티브 AI 채팅 클라이언트(BYOK)
가격
무료. 광고, 회원가입, 앱 내 구독이나 토큰 구매가 없습니다. AI 사용료는 각 제공업체가 직접 청구합니다.
AI 서비스
Google Gemini, OpenRouter, ChatGPT 요금제, xAI, Apple Intelligence, OpenAI, Anthropic(Claude), DeepSeek, Mistral, Groq, Sarashina, PLaMo, 사용자 지정 엔드포인트 등 — 모든 제공업체 보기
모드
채팅, 듀얼(두 모델을 나란히 비교), 자동 대화(두 모델이 서로 대화), 작업의 일부를 맡는 서브에이전트
개인정보
대화는 기기에 저장되고 키는 iOS 키체인에 보관되며, 프롬프트는 선택한 제공업체에만 전송됩니다
요구 사항
iOS 17 이상(iPhone), iPadOS 17 이상(iPad)
개발자
개인 개발자 porarrirr · MIT License로 배포되는 오픈소스

모드

세 가지 대화 모드와 서브에이전트

질문에 맞는 모드를 고르면 됩니다. 모드에 질문을 맞출 필요는 없습니다.

01 / 채팅

한 모델과 대화하기

Markdown, 코드 하이라이트, 수식, 이미지 첨부를 지원하는 스트리밍 답변. 편집, 다시 생성, 답변 버전 보관도 가능합니다.

02 / 듀얼

두 답변 비교하기

같은 프롬프트를 두 모델에 보내고 두 답변을 나란히 확인하세요. 듀얼 모드 사용법

03 / 자동

두 모델끼리 대화하게 하기

두 모델, 주제, 턴 수를 정하면 두 모델이 서로 대화를 이어 갑니다.

+ / 서브에이전트

작업 맡기기

모델이 요청의 일부를 서브에이전트에게 넘기게 하세요. 서브에이전트마다 다른 모델을 쓸 수 있고, 진행 상황은 채팅에서 확인할 수 있습니다.

기능

매일의 작업을 위해 만들었습니다

글쓰기, 요약, 번역, 코드, 수학까지 — 실제 어시스턴트에 필요한 도구를 갖췄습니다.

  • 이미지, PDF, 텍스트 파일 첨부(파일당 최대 10 MB)
  • 웹 검색, 로컬 Python, 인터랙티브 차트(GenUI)를 도구로 사용
  • 음성 받아쓰기와 Safari 및 다른 앱을 위한 공유 확장 기능
  • 단축어 액션, Spotlight 검색, 비밀 대화
  • 프로젝트, 기록 검색, 모델 프리셋, 토큰 사용량 통계
  • iPad 스플릿 뷰와 다크 모드

이런 분께

이런 분께 추천합니다

  • 이미 API 키나 ChatGPT 요금제를 쓰고 있고, 이를 위한 네이티브 iPhone·iPad 앱을 원하는 분.
  • 한 모델의 답변을 그대로 믿기 전에 다른 모델과 비교해 확인하고 싶은 분.
  • 여러 AI 구독을 겹쳐 쓰기보다 사용한 만큼만 지불하고 싶은 분.
  • OpenRouter나 여러 제공업체를 한곳에서 쓰고 싶은 분.
  • 대화 기록을 내 기기에 보관하고 싶은 분.

가이드

자세히 알아보기

AI 모델 비교 같은 프롬프트를 두 모델에 보내고 두 답변을 나란히 비교하세요. 내 API 키로 사용하기 BYOK 작동 방식, 비용, 키 보관 방법을 알아보세요. 지원하는 AI 제공업체 Gemini, OpenRouter, ChatGPT 요금제, xAI, OpenAI, Anthropic 등. 자주 묻는 질문 요금, 시스템 요구 사항, 개인정보, 지원 모델.
