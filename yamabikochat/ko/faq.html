자주 묻는 질문

요금, API 키, 지원 모델, 개인정보, 요구 사항에 대한 짧은 답변.

마지막 업데이트: 2026-11-17

YamabikoChat은 무료인가요?

네. YamabikoChat은 무료로 다운로드할 수 있으며 광고, 회원가입, 앱 내 구독이나 토큰 구매가 없습니다. AI 사용료는 각 제공업체의 요금과 약관에 따라 제공업체에 직접 지불합니다.

API 키가 필요한가요?

지원되는 AI 제공업체의 API 키나 ChatGPT 요금제, xAI 같은 지원 계정 로그인 중 하나가 필요합니다. Apple Intelligence는 지원 기기에서 키 없이 작동합니다.

API 키 대신 ChatGPT 구독을 쓸 수 있나요?

네. ChatGPT 요금제 연결을 사용하면 ChatGPT 계정으로 로그인해 OpenAI API 키 없이 요금제에 포함된 모델을 사용할 수 있습니다.

어떤 AI 모델을 쓸 수 있나요?

Google Gemini, OpenRouter, ChatGPT 요금제, xAI, Apple Intelligence, Sarashina, PLaMo가 내장되어 있습니다. OpenAI, Anthropic(Claude), DeepSeek, Mistral, Groq 등 많은 API 제공업체는 models.dev 카탈로그를 통해 사용할 수 있고, 지원되는 API 형식을 쓰는 사용자 지정 엔드포인트도 추가할 수 있습니다. 사용 가능한 모델은 제공업체마다 다릅니다.

Anthropic API 키로 Claude를 쓸 수 있나요?

네. 제공업체 카탈로그에서 Anthropic을 선택하고 API 키를 추가하거나, Anthropic Messages API를 쓰는 사용자 지정 엔드포인트를 설정하세요.

ChatGPT, Gemini, Claude의 답변을 나란히 비교할 수 있나요?

네. 듀얼 모드는 같은 프롬프트를 두 모델에 보내고 두 답변을 나란히 보여 줍니다. 연결한 제공업체의 모델 중 원하는 두 개를 고르면 됩니다.

대화와 API 키는 어디에 저장되나요?

대화와 설정은 기기에 저장되고, API 키와 액세스 토큰은 iOS 키체인에 저장됩니다. 프롬프트, 대화 컨텍스트, 선택한 첨부 파일은 선택한 제공업체에만 전송됩니다.

iPad에서도 쓸 수 있나요?

네. iPhone과 iPad를 위한 네이티브 앱이며, iPad에서는 대화 목록과 채팅을 나란히 보여 주는 스플릿 뷰를 지원합니다.

시스템 요구 사항은 무엇인가요?

iPhone은 iOS 17 이상, iPad는 iPadOS 17 이상입니다. Apple Intelligence는 이를 지원하는 기기와 OS 버전이 필요합니다.

YamabikoChat은 오픈소스인가요?

네. 소스 코드는 MIT License로 GitHub에 공개되어 있습니다. 함께 포함된 타사 소프트웨어에는 각자의 라이선스가 적용됩니다.

궁금한 점이 더 있나요? 고객 지원을 확인하세요.

관련 가이드
