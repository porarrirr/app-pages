내 키로 시작하기

iPhone·iPad에서 내 API 키로 AI 채팅하기

YamabikoChat은 BYOK(Bring Your Own Key) 클라이언트입니다. API 키를 추가하거나 지원되는 계정으로 로그인하면 앱이 프롬프트를 해당 제공업체로 곧바로 보냅니다. 중간에 YamabikoChat 구독이나 토큰 재판매는 없습니다.

마지막 업데이트: 2026-11-17

BYOK(내 키 사용)란?

OpenAI, Google, Anthropic, OpenRouter 같은 AI 제공업체는 API 키를 통해 모델 이용 권한을 판매하며, 보통 사용한 만큼 과금합니다. BYOK 앱은 그 키로 쓰는 클라이언트입니다. 제공업체 계정에서 키를 만들고 앱에 추가하면, 사용한 만큼의 요금은 제공업체가 직접 청구합니다.

내 키를 쓰는 이유

  • 쓴 만큼만 지불. 가볍게 쓰는 사용자는 월 구독형 AI 서비스보다 적게 쓰는 경우가 많고, 많이 쓰는 사용자는 비용이 어디서 발생하는지 정확히 알 수 있습니다.
  • 모델 선택. 앱이 정한 고정 목록이 아니라 제공업체가 제공하는 모델을 쓸 수 있습니다.
  • 하나의 앱, 여러 제공업체. Gemini, OpenRouter, OpenAI, Anthropic 등을 나란히 두고 듀얼 모드에서 비교하세요.
  • 사용량 확인. 토큰 사용량 통계로 얼마나 쓰는지 확인할 수 있습니다.

설정 방법

  1. API 키 만들기 — 제공업체 콘솔에서 만듭니다. 예: Gemini는 Google AI Studio, OpenAI 플랫폼, Anthropic 콘솔, OpenRouter.
  2. YamabikoChat 설정 열기 — 연결 설정에서 제공업체를 선택합니다.
  3. 키 붙여 넣기. 키는 기기의 iOS 키체인에 저장됩니다.
  4. 모델을 고르고 채팅 시작하기. 앱이 안전하게 실행할 수 없는 모델은 추측하지 않고 이유와 함께 사용 불가로 표시합니다.

API 키가 없다면? 계정으로 로그인

  • ChatGPT 요금제 — ChatGPT 계정으로 로그인해 요금제에 포함된 모델을 사용합니다.
  • xAI — xAI 계정으로 로그인합니다.
  • Apple Intelligence — 지원 기기에 내장되어 온디바이스 또는 Private Cloud Compute로 동작하며 키가 전혀 필요 없습니다.

사용자 지정 엔드포인트

사용하는 서비스가 목록에 없다면 베이스 URL과 키를 넣어 사용자 지정 엔드포인트를 추가하고, 지원되는 API 형식 중 하나를 선택하세요. OpenAI Chat Completions, OpenAI Responses, Anthropic Messages, Gemini(Google Generative AI), Mistral.

비용

앱은 무료이며 앱 내 구매가 없습니다. 사용료, 한도, 약관에 따라 제공업체가 요금을 청구합니다. 듀얼 모드와 자동 대화는 두 모델에 요청을 보내므로 양쪽 모두 사용량이 발생합니다.

보안과 개인정보

  • API 키와 액세스 토큰은 iOS 키체인에 저장되며, 앱은 이를 진단 로그에 기록하지 않도록 설계되었습니다.
  • 프롬프트, 대화 컨텍스트, 선택한 첨부 파일은 선택한 제공업체로 직접 전송됩니다.
  • 대화는 기기에 저장됩니다. 앱은 앱 간 추적을 사용하지 않습니다. 자세한 내용은 개인정보 처리방침을 참고하세요.
