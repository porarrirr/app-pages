নিজের কী আনুন

iPhone ও iPad-এ নিজের API কী দিয়ে AI চ্যাট করুন

YamabikoChat একটি নিজের কী আনার (BYOK) ক্লায়েন্ট। আপনি একটি API কী যোগ করেন — বা সমর্থিত কোনো অ্যাকাউন্টে সাইন ইন করেন — আর অ্যাপ আপনার প্রম্পট সরাসরি সেই প্রোভাইডারের কাছে পাঠায়। মাঝখানে YamabikoChat-এর কোনো সাবস্ক্রিপশন বা টোকেন বিক্রেতা নেই।

সর্বশেষ হালনাগাদ: 2026-11-17

“নিজের কী আনুন” মানে কী

OpenAI, Google, Anthropic ও OpenRouter-এর মতো AI প্রোভাইডাররা API কী-এর মাধ্যমে নিজেদের মডেলের ব্যবহার বিক্রি করে, সাধারণত ব্যবহার অনুযায়ী বিল নেয়। BYOK অ্যাপ হলো সেই কী-গুলোর ক্লায়েন্ট: আপনি প্রোভাইডার অ্যাকাউন্টে একটি কী তৈরি করেন, অ্যাপে যোগ করেন, আর আপনি যা ব্যবহার করেন তার বিল প্রোভাইডার সরাসরি আপনার কাছে পাঠায়।

নিজের কী কেন ব্যবহার করবেন

  • যতটুকু ব্যবহার, ততটুকু খরচ। কম ব্যবহারকারীদের খরচ প্রায়ই মাসিক AI সাবস্ক্রিপশনের চেয়ে কম হয়; বেশি ব্যবহার করলে খরচ কোথা থেকে আসছে তা স্পষ্ট দেখা যায়।
  • মডেল বেছে নিন। কোনো অ্যাপের বেঁধে দেওয়া তালিকা নয়, আপনার প্রোভাইডার যে মডেল দেয় সেগুলোই ব্যবহার করুন।
  • এক অ্যাপে অনেক প্রোভাইডার। Gemini, OpenRouter, OpenAI, Anthropic ও অন্যগুলো পাশাপাশি রাখুন, আর ডুয়াল মোড-এ তুলনা করুন।
  • নিজের ব্যবহার দেখুন। টোকেন ব্যবহারের পরিসংখ্যানে দেখা যায় আপনি কতটা ব্যবহার করছেন।

কীভাবে সেট করবেন

  1. একটি API কী তৈরি করুন আপনার প্রোভাইডারের কনসোলে — যেমন Gemini-র জন্য Google AI Studio, OpenAI প্ল্যাটফর্ম, Anthropic কনসোল বা OpenRouter।
  2. YamabikoChat-এর সেটিংস খুলুন এবং কানেকশন সেটিংসে প্রোভাইডার বেছে নিন।
  3. কী-টি পেস্ট করুন। এটি আপনার ডিভাইসের iOS Keychain-এ সংরক্ষিত হয়।
  4. একটি মডেল বেছে চ্যাট শুরু করুন। অ্যাপ যে মডেল নিরাপদে চালাতে পারে না, সেগুলো অনুমান না করে কারণসহ অনুপলব্ধ হিসেবে দেখায়।

API কী নেই? সাইন ইন করুন

  • ChatGPT প্ল্যান — আপনার ChatGPT অ্যাকাউন্টে সাইন ইন করে প্ল্যানে অন্তর্ভুক্ত মডেলগুলো ব্যবহার করুন।
  • xAI — আপনার xAI অ্যাকাউন্টে সাইন ইন করুন।
  • Apple Intelligence — সমর্থিত ডিভাইসে, ডিভাইসেই বা Private Cloud Compute-এর মাধ্যমে, কোনো কী ছাড়াই।

কাস্টম এন্ডপয়েন্ট

আপনার সেবা তালিকায় না থাকলে তার বেস URL ও কী দিয়ে একটি কাস্টম এন্ডপয়েন্ট যোগ করুন, এবং সমর্থিত API ফরম্যাটগুলোর একটি বেছে নিন: OpenAI Chat Completions, OpenAI Responses, Anthropic Messages, Gemini (Google Generative AI) বা Mistral.

খরচ কত

অ্যাপটি ফ্রি, অ্যাপের ভেতরে কোনো কেনাকাটা নেই। আপনার প্রোভাইডার নিজের দাম, সীমা ও শর্ত অনুযায়ী ব্যবহারের বিল নেয়। ডুয়াল মোড ও অটো কথোপকথন দুটি মডেলে অনুরোধ পাঠায়, তাই দুটিতেই ব্যবহার তৈরি হয়।

নিরাপত্তা ও গোপনীয়তা

  • API কী ও অ্যাক্সেস টোকেন iOS Keychain-এ সংরক্ষিত হয়, আর অ্যাপটি এগুলো তার ডায়াগনস্টিক লগে না লেখার ভাবেই তৈরি।
  • প্রম্পট, কথোপকথনের কনটেক্সট ও আপনার বেছে নেওয়া সংযুক্তি সরাসরি আপনার নির্বাচিত প্রোভাইডারের কাছে পাঠানো হয়।
  • কথোপকথন আপনার ডিভাইসে সংরক্ষিত থাকে। অ্যাপটি ক্রস-অ্যাপ ট্র্যাকিং করে না। গোপনীয়তা নীতি দেখুন।

সংশ্লিষ্ট গাইড

AI মডেল তুলনা করুনএকই প্রম্পট দুটি মডেলে পাঠান এবং দুটি উত্তর পাশাপাশি পড়ুন।সমর্থিত প্রোভাইডারGemini, OpenRouter, ChatGPT প্ল্যান, xAI, OpenAI, Anthropic এবং আরও।সচরাচর জিজ্ঞাসাদাম, প্রয়োজনীয়তা, গোপনীয়তা ও সমর্থিত মডেল।

আপনি যে AI আগে থেকেই ব্যবহার করেন, সেটি দিয়েই চেষ্টা করুন।
