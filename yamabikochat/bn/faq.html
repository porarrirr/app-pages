দাম, API কী, সমর্থিত মডেল, গোপনীয়তা ও প্রয়োজনীয়তা নিয়ে সংক্ষিপ্ত উত্তর।

সর্বশেষ হালনাগাদ: 2026-11-17

YamabikoChat কি ফ্রি?

হ্যাঁ। YamabikoChat ডাউনলোড করা ফ্রি; কোনো বিজ্ঞাপন নেই, সাইন-আপ নেই, অ্যাপের ভেতরে সাবস্ক্রিপশন বা টোকেন কেনা নেই। আপনি যে ব্যবহার তৈরি করেন, তার জন্য সংশ্লিষ্ট প্রোভাইডারের দাম ও শর্ত অনুযায়ী সরাসরি সেই প্রোভাইডারকে টাকা দেন।

আমার কি API কী দরকার?

আপনার একটি সমর্থিত AI প্রোভাইডারের API কী, অথবা ChatGPT প্ল্যান বা xAI-এর মতো সমর্থিত অ্যাকাউন্টে সাইন ইন — দুটির একটি দরকার। Apple Intelligence সমর্থিত ডিভাইসে কোনো কী ছাড়াই কাজ করে।

API কী-এর বদলে আমি কি আমার ChatGPT সাবস্ক্রিপশন ব্যবহার করতে পারি?

হ্যাঁ। ChatGPT প্ল্যান সংযোগে আপনি ChatGPT অ্যাকাউন্টে সাইন ইন করে আপনার প্ল্যানে অন্তর্ভুক্ত মডেলগুলো OpenAI API কী ছাড়াই ব্যবহার করতে পারেন।

কোন AI মডেল ব্যবহার করতে পারি?

Google Gemini, OpenRouter, ChatGPT প্ল্যান, xAI, Apple Intelligence, Sarashina ও PLaMo বিল্ট-ইন। OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq এবং আরও অনেক API প্রোভাইডার models.dev ক্যাটালগে পাওয়া যায়, আর আপনি সমর্থিত API ফরম্যাট ব্যবহার করা একটি কাস্টম এন্ডপয়েন্টও যোগ করতে পারেন। কোন মডেল পাওয়া যাবে তা প্রোভাইডারভেদে আলাদা।

আমার Anthropic API কী দিয়ে Claude ব্যবহার করতে পারি?

হ্যাঁ। প্রোভাইডার ক্যাটালগ থেকে Anthropic যোগ করে আপনার API কী দিন, অথবা Anthropic Messages API ব্যবহার করা একটি কাস্টম এন্ডপয়েন্ট সেট করুন।

ChatGPT, Gemini ও Claude-এর উত্তর কি পাশাপাশি তুলনা করা যায়?

হ্যাঁ। ডুয়াল মোড একই প্রম্পট দুটি মডেলে পাঠায় এবং দুটি উত্তর পাশাপাশি দেখায়। আপনি যে প্রোভাইডারগুলো যুক্ত করেছেন সেখান থেকে যেকোনো দুটি মডেল বেছে নিন।

আমার কথোপকথন ও API কী কোথায় সংরক্ষিত থাকে?

কথোপকথন ও সেটিংস আপনার ডিভাইসে সংরক্ষিত থাকে। API কী ও অ্যাক্সেস টোকেন iOS Keychain-এ সংরক্ষিত থাকে। আপনার প্রম্পট, কথোপকথনের কনটেক্সট এবং আপনার বেছে নেওয়া সংযুক্তি কেবল আপনার নির্বাচিত প্রোভাইডারের কাছেই পাঠানো হয়।

YamabikoChat কি iPad-এ চলে?

হ্যাঁ। এটি iPhone ও iPad-এর জন্য একটি নেটিভ অ্যাপ, আর iPad-এ স্প্লিট ভিউতে কথোপকথনের তালিকা ও চ্যাট পাশাপাশি দেখা যায়।

সিস্টেমের প্রয়োজনীয়তা কী?

iPhone-এ iOS 17 বা তার পরের সংস্করণ, আর iPad-এ iPadOS 17 বা তার পরের সংস্করণ। Apple Intelligence-এর জন্য এমন ডিভাইস ও OS সংস্করণ দরকার যা এটি সমর্থন করে।

YamabikoChat কি ওপেন সোর্স?

হ্যাঁ। সোর্স কোড MIT License-এর অধীনে GitHub-এ প্রকাশিত। সঙ্গে দেওয়া তৃতীয় পক্ষের সফটওয়্যারের নিজস্ব লাইসেন্স বহাল থাকে।

আরও প্রশ্ন আছে? সহায়তা দেখুন।

সংশ্লিষ্ট গাইড

AI মডেল তুলনা করুন একই প্রম্পট দুটি মডেলে পাঠান এবং দুটি উত্তর পাশাপাশি পড়ুন। নিজের API কী ব্যবহার করুন BYOK কীভাবে কাজ করে, খরচ কত, এবং আপনার কী কোথায় সংরক্ষিত থাকে। সমর্থিত প্রোভাইডার Gemini, OpenRouter, ChatGPT প্ল্যান, xAI, OpenAI, Anthropic এবং আরও।

আপনি যে AI আগে থেকেই ব্যবহার করেন, সেটি দিয়েই চেষ্টা করুন।
