সমর্থিত AI প্রোভাইডার

YamabikoChat নিচের AI সেবাগুলোর সঙ্গে আপনার নিজের API কী বা অ্যাকাউন্ট দিয়ে যুক্ত হয়। বিল্ট-ইন প্রোভাইডার অ্যাপেই সরাসরি সেট করা যায়; আরও অনেক API প্রোভাইডার আসে models.dev ক্যাটালগ থেকে।

models.dev ক্যাটালগ থেকে আরও API প্রোভাইডার

YamabikoChat সর্বজনীন models.dev ক্যাটালগ পড়ে আরও অনেক API প্রোভাইডার দেয়, যার মধ্যে OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq, xAI API, Moonshot AI (Kimi), MiniMax, Z.ai (GLM), Fireworks AI, Together AI ও Hugging Face আছে। সেটিংসে প্রোভাইডার যোগ করুন, আপনার API কী দিন এবং একটি মডেল বেছে নিন।

প্রতিটি মডেল কেবল তখনই চলে যখন তার API চুক্তি যাচাই করা থাকে। যেসব মডেল নিরাপদে চালানো যায় না সেগুলো সঠিক কারণসহ দেখা যায় কিন্তু নিষ্ক্রিয় থাকে — অ্যাপ কখনোই চুপচাপ আপনাকে অন্য মডেল, এন্ডপয়েন্ট বা প্রোভাইডারে সরিয়ে দেয় না।

মডেলগুলো একসঙ্গে ব্যবহার

যুক্ত প্রতিটি মডেল চ্যাটে, দুটি উত্তর তুলনার জন্য ডুয়াল মোড-এ, এবং দুটি মডেলকে কথা বলানোর অটো কথোপকথনে ব্যবহার করা যায়। ছবি ইনপুট, রিজনিং সেটিংস, টুল ও কনটেক্সট দৈর্ঘ্য মডেলভেদে আলাদা।

মডেলের তালিকা প্রায়ই বদলায়। অ্যাপ প্রতিটি প্রোভাইডারের বর্তমান তালিকা সবসময় দেখায়। প্রোভাইডার ও পণ্যের নাম তাদের মালিকদের ট্রেডমার্ক; YamabikoChat তাদের সঙ্গে সম্পর্কিত নয়।

সংশ্লিষ্ট গাইড

AI মডেল তুলনা করুনএকই প্রম্পট দুটি মডেলে পাঠান এবং দুটি উত্তর পাশাপাশি পড়ুন।নিজের API কী ব্যবহার করুনBYOK কীভাবে কাজ করে, খরচ কত, এবং আপনার কী কোথায় সংরক্ষিত থাকে।সচরাচর জিজ্ঞাসাদাম, প্রয়োজনীয়তা, গোপনীয়তা ও সমর্থিত মডেল।

আপনি যে AI আগে থেকেই ব্যবহার করেন, সেটি দিয়েই চেষ্টা করুন।
