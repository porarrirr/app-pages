Provedores de IA compatíveis

O YamabikoChat se conecta aos serviços de IA abaixo com a sua própria chave de API ou conta. Os provedores integrados são configurados direto no app; muitos outros provedores de API vêm do catálogo models.dev.

Mais provedores de API do catálogo models.dev

O YamabikoChat lê o catálogo público models.dev para oferecer muitos outros provedores de API, incluindo OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq, xAI API, Moonshot AI (Kimi), MiniMax, Z.ai (GLM), Fireworks AI, Together AI e Hugging Face. Adicione o provedor nos Ajustes com a sua chave de API e escolha um modelo.

Cada modelo só é executado quando o contrato da sua API está verificado. Modelos que não podem ser executados com segurança continuam visíveis, mas desativados, com o motivo exato — o app nunca troca você silenciosamente por outro modelo, endpoint ou provedor.

Usando os modelos em conjunto

Todo modelo conectado pode ser usado no Chat, no modo Dual para comparar duas respostas e na conversa automática para deixar dois modelos conversarem. Entrada de imagem, configurações de raciocínio, ferramentas e tamanho do contexto dependem do modelo.

As listas de modelos mudam com frequência. O app sempre mostra a lista atual de cada provedor. Nomes de provedores e produtos são marcas registradas de seus proprietários; o YamabikoChat não tem vínculo com eles.
