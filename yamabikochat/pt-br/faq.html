FAQ

Perguntas frequentes

Respostas curtas sobre preço, chaves de API, modelos compatíveis, privacidade e requisitos.

Última atualização: 2026-11-17

O YamabikoChat é grátis?

Sim. O YamabikoChat é grátis para baixar, sem anúncios, sem cadastro e sem assinaturas ou compra de tokens dentro do app. Você paga diretamente ao seu provedor de IA pelo uso que gerar, conforme os preços e termos desse provedor.

Preciso de uma chave de API?

Você precisa de uma chave de API de um provedor de IA compatível ou de entrar com uma conta compatível, como o plano ChatGPT ou a xAI. O Apple Intelligence funciona sem chave nos dispositivos compatíveis.

Posso usar minha assinatura do ChatGPT em vez de uma chave de API?

Sim. A conexão do plano ChatGPT permite entrar com sua conta ChatGPT e usar os modelos incluídos no seu plano, sem uma chave de API da OpenAI.

Quais modelos de IA posso usar?

Google Gemini, OpenRouter, plano ChatGPT, xAI, Apple Intelligence, Sarashina e PLaMo já vêm integrados. OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq e muitos outros provedores de API estão disponíveis pelo catálogo models.dev, e você pode adicionar um endpoint personalizado que use um formato de API compatível. Os modelos disponíveis dependem de cada provedor.

Posso usar o Claude com minha chave de API da Anthropic?

Sim. Adicione a Anthropic pelo catálogo de provedores com sua chave de API, ou configure um endpoint personalizado que use a API Anthropic Messages.

Posso comparar as respostas do ChatGPT, do Gemini e do Claude lado a lado?

Sim. O modo Dual envia o mesmo prompt para dois modelos e mostra as duas respostas uma ao lado da outra. Escolha quaisquer dois modelos dos provedores que você conectou.

Onde ficam minhas conversas e chaves de API?

As conversas e configurações ficam no seu dispositivo. As chaves de API e os tokens de acesso ficam no Keychain do iOS. Seus prompts, o contexto da conversa e os anexos que você escolher são enviados apenas ao provedor selecionado.

O YamabikoChat funciona no iPad?

Sim. É um app nativo para iPhone e iPad, com Split View no iPad que mostra a lista de conversas e o chat lado a lado.

Quais são os requisitos do sistema?

iOS 17 ou posterior no iPhone e iPadOS 17 ou posterior no iPad. O Apple Intelligence exige um dispositivo e uma versão do sistema compatíveis.

O YamabikoChat é de código aberto?

Sim. O código-fonte é publicado no GitHub sob a licença MIT. Os softwares de terceiros incluídos mantêm as próprias licenças.
