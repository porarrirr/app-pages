Apportez votre clé

Utilisez votre propre clé API pour le chat IA sur iPhone et iPad

YamabikoChat est un client BYOK (apportez votre propre clé). Vous ajoutez une clé API — ou vous vous connectez à un compte compatible — et l'app envoie vos prompts directement à ce fournisseur. Aucun abonnement YamabikoChat ni revendeur de tokens ne s'interpose.

Dernière mise à jour : 2026-11-17

Que signifie « apporter sa propre clé » ?

Les fournisseurs d'IA comme OpenAI, Google, Anthropic et OpenRouter vendent l'accès à leurs modèles par clé API, généralement facturé à l'usage. Une app BYOK est un client pour ces clés : vous créez une clé dans votre compte fournisseur, l'ajoutez à l'app, et le fournisseur vous facture directement ce que vous consommez.

Pourquoi utiliser votre propre clé

  • Payez ce que vous consommez. Les petits usages coûtent souvent moins qu'un abonnement IA mensuel ; les gros usages voient exactement d'où vient le coût.
  • Choisissez le modèle. Utilisez les modèles proposés par votre fournisseur, pas une liste figée choisie par une app.
  • Une app, plusieurs fournisseurs. Gardez Gemini, OpenRouter, OpenAI, Anthropic et d'autres côte à côte, et comparez-les en mode Double.
  • Suivez votre usage. Les statistiques de tokens montrent ce que vous consommez.

Comment la configurer

  1. Créez une clé API dans la console de votre fournisseur — par exemple Google AI Studio pour Gemini, la plateforme OpenAI, la console Anthropic ou OpenRouter.
  2. Ouvrez les Réglages de YamabikoChat et choisissez le fournisseur dans les réglages de connexion.
  3. Collez la clé. Elle est enregistrée dans le Trousseau iOS de votre appareil.
  4. Choisissez un modèle et discutez. Les modèles que l'app ne peut pas exécuter en toute sécurité s'affichent comme indisponibles, avec la raison, au lieu d'être devinés.

Pas de clé API ? Connectez-vous plutôt

  • Offre ChatGPT — connectez-vous avec votre compte ChatGPT pour utiliser les modèles inclus dans votre offre.
  • xAI — connectez-vous avec votre compte xAI.
  • Apple Intelligence — intégré aux appareils compatibles, sur l'appareil ou via Private Cloud Compute, sans aucune clé.

Points de terminaison personnalisés

Si votre service n'est pas dans la liste, ajoutez un point de terminaison personnalisé avec son URL de base et sa clé, puis choisissez l'un des formats d'API pris en charge : OpenAI Chat Completions, OpenAI Responses, Anthropic Messages, Gemini (Google Generative AI) ou Mistral.

Combien ça coûte

L'app est gratuite, sans achats intégrés. Votre fournisseur facture l'usage selon ses propres tarifs, limites et conditions. Le mode Double et la conversation Auto envoient des requêtes à deux modèles : ils génèrent donc un usage sur les deux.

Sécurité et confidentialité

  • Les clés API et les jetons d'accès sont stockés dans le Trousseau iOS, et l'app est conçue pour ne pas les écrire dans ses journaux de diagnostic.
  • Les prompts, le contexte de la conversation et les pièces jointes choisies sont envoyés directement au fournisseur sélectionné.
  • Les conversations sont stockées sur votre appareil. L'app n'utilise pas de suivi entre apps. Voir la politique de confidentialité.
