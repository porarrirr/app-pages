Περισσότεροι πάροχοι API από τον κατάλογο models.dev

Το YamabikoChat διαβάζει τον δημόσιο κατάλογο models.dev για να προσφέρει πολλούς περισσότερους παρόχους API, όπως OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq, xAI API, Moonshot AI (Kimi), MiniMax, Z.ai (GLM), Fireworks AI, Together AI και Hugging Face. Προσθέστε τον πάροχο στις Ρυθμίσεις με το κλειδί API σας και επιλέξτε ένα μοντέλο.

Κάθε μοντέλο εκτελείται μόνο όταν το συμβόλαιο API του έχει επαληθευτεί. Τα μοντέλα που δεν μπορούν να εκτελεστούν με ασφάλεια παραμένουν ορατά αλλά απενεργοποιημένα, με τον ακριβή λόγο — η εφαρμογή δεν σας αλλάζει ποτέ σιωπηλά σε άλλο μοντέλο, endpoint ή πάροχο.

Χρήση των μοντέλων μαζί

Κάθε συνδεδεμένο μοντέλο μπορεί να χρησιμοποιηθεί στο Chat, στη λειτουργία Dual για σύγκριση δύο απαντήσεων και στην αυτόματη συνομιλία όπου δύο μοντέλα μιλούν μεταξύ τους. Η εισαγωγή εικόνας, οι ρυθμίσεις συλλογισμού, τα εργαλεία και το μήκος πλαισίου εξαρτώνται από το μοντέλο.

Οι λίστες μοντέλων αλλάζουν συχνά. Η εφαρμογή εμφανίζει πάντα την τρέχουσα λίστα για κάθε πάροχο. Τα ονόματα παρόχων και προϊόντων είναι εμπορικά σήματα των κατόχων τους· το YamabikoChat δεν συνδέεται μαζί τους.
