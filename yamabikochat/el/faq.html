Συχνές ερωτήσεις

Σύντομες απαντήσεις για την τιμή, τα κλειδιά API, τα υποστηριζόμενα μοντέλα, το απόρρητο και τις απαιτήσεις.

Τελευταία ενημέρωση: 2026-11-17

Είναι δωρεάν το YamabikoChat;

Ναι. Το YamabikoChat είναι δωρεάν για λήψη, χωρίς διαφημίσεις, χωρίς εγγραφή και χωρίς συνδρομές ή αγορές token μέσα στην εφαρμογή. Πληρώνετε απευθείας τον πάροχο AI για τη χρήση που δημιουργείτε, με τους όρους και τις τιμές του παρόχου.

Χρειάζομαι κλειδί API;

Χρειάζεστε είτε κλειδί API από υποστηριζόμενο πάροχο AI είτε σύνδεση με υποστηριζόμενο λογαριασμό, όπως το πακέτο ChatGPT ή το xAI. Το Apple Intelligence λειτουργεί χωρίς κλειδί σε συσκευές που το υποστηρίζουν.

Μπορώ να χρησιμοποιήσω τη συνδρομή ChatGPT αντί για κλειδί API;

Ναι. Η σύνδεση με το πακέτο ChatGPT σάς επιτρέπει να συνδεθείτε με τον λογαριασμό σας ChatGPT και να χρησιμοποιήσετε τα μοντέλα που περιλαμβάνει το πακέτο σας, χωρίς κλειδί API του OpenAI.

Ποια μοντέλα AI μπορώ να χρησιμοποιήσω;

Είναι ενσωματωμένα: Google Gemini, OpenRouter, πακέτο ChatGPT, xAI, Apple Intelligence, Sarashina και PLaMo. Πάροχοι όπως OpenAI, Anthropic (Claude), DeepSeek, Mistral και Groq είναι διαθέσιμοι μέσω του καταλόγου models.dev, και μπορείτε να προσθέσετε προσαρμοσμένο endpoint που χρησιμοποιεί υποστηριζόμενη μορφή API. Τα διαθέσιμα μοντέλα εξαρτώνται από τον πάροχο.

Μπορώ να χρησιμοποιήσω το Claude με το κλειδί API του Anthropic;

Ναι. Προσθέστε το Anthropic από τον κατάλογο παρόχων με το κλειδί API σας ή ρυθμίστε προσαρμοσμένο endpoint που χρησιμοποιεί το Anthropic Messages API.

Μπορώ να συγκρίνω τις απαντήσεις του ChatGPT, του Gemini και του Claude δίπλα-δίπλα;

Ναι. Η λειτουργία Dual στέλνει το ίδιο ερώτημα σε δύο μοντέλα και εμφανίζει και τις δύο απαντήσεις δίπλα-δίπλα. Επιλέξτε οποιαδήποτε δύο μοντέλα από τους παρόχους που έχετε συνδέσει.

Πού αποθηκεύονται οι συνομιλίες και τα κλειδιά API μου;

Οι συνομιλίες και οι ρυθμίσεις αποθηκεύονται στη συσκευή σας. Τα κλειδιά API και τα token πρόσβασης αποθηκεύονται στην Κλειδοθήκη του iOS. Τα ερωτήματά σας, το πλαίσιο της συνομιλίας και τα συνημμένα που επιλέγετε στέλνονται μόνο στον πάροχο που επιλέξατε.

Λειτουργεί το YamabikoChat σε iPad;

Ναι. Είναι εγγενής εφαρμογή για iPhone και iPad, με διαχωρισμένη προβολή στο iPad που δείχνει τη λίστα συνομιλιών και τη συνομιλία δίπλα-δίπλα.

Ποιες είναι οι απαιτήσεις συστήματος;

iOS 17 ή νεότερο σε iPhone και iPadOS 17 ή νεότερο σε iPad. Το Apple Intelligence απαιτεί συσκευή και έκδοση λειτουργικού συστήματος που το υποστηρίζουν.

Είναι το YamabikoChat ανοιχτού κώδικα;

Ναι. Ο πηγαίος κώδικας δημοσιεύεται στο GitHub υπό την άδεια MIT. Το λογισμικό τρίτων που περιλαμβάνεται διατηρεί τις δικές του άδειες.
