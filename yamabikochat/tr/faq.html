Sık sorulan sorular

Fiyat, API anahtarları, desteklenen modeller, gizlilik ve gereksinimler hakkında kısa yanıtlar.

Son güncelleme: 2026-11-17

YamabikoChat ücretsiz mi?

Evet. YamabikoChat'i indirmek ücretsizdir; reklam, kayıt, abonelik veya uygulama içi token satın alımı yoktur. Oluşturduğunuz kullanımın ücretini, sağlayıcının fiyatlandırma ve koşullarına göre doğrudan AI sağlayıcınıza ödersiniz.

API anahtarı gerekli mi?

Desteklenen bir AI sağlayıcısından API anahtarı ya da ChatGPT planı veya xAI gibi desteklenen bir hesaba giriş gerekir. Apple Intelligence, destekleyen cihazlarda anahtar olmadan çalışır.

API anahtarı yerine ChatGPT aboneliğimi kullanabilir miyim?

Evet. ChatGPT planı bağlantısı, ChatGPT hesabınızla giriş yapıp planınıza dahil modelleri OpenAI API anahtarı olmadan kullanmanızı sağlar.

Hangi AI modellerini kullanabilirim?

Google Gemini, OpenRouter, ChatGPT planı, xAI, Apple Intelligence, Sarashina ve PLaMo yerleşiktir. OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq ve daha birçok API sağlayıcısına models.dev kataloğu üzerinden ulaşabilir, ayrıca desteklenen bir API biçimi kullanan özel bir uç nokta ekleyebilirsiniz. Kullanılabilir modeller sağlayıcıya göre değişir.

Anthropic API anahtarım ile Claude kullanabilir miyim?

Evet. Sağlayıcı kataloğundan Anthropic'i API anahtarınızla ekleyin veya Anthropic Messages API'sini kullanan özel bir uç nokta ayarlayın.

ChatGPT, Gemini ve Claude yanıtlarını yan yana karşılaştırabilir miyim?

Evet. İkili mod aynı istemi iki modele gönderir ve iki yanıtı yan yana gösterir. Bağladığınız sağlayıcılardan istediğiniz iki modeli seçin.

Sohbetlerim ve API anahtarlarım nerede saklanıyor?

Sohbetler ve ayarlar cihazınızda saklanır. API anahtarları ve erişim tokenları iOS Anahtar Zinciri'nde tutulur. İstemleriniz, sohbet bağlamı ve seçtiğiniz ekler yalnızca seçtiğiniz sağlayıcıya gönderilir.

YamabikoChat iPad'de çalışır mı?

Evet. iPhone ve iPad için yerel bir uygulamadır; iPad'de sohbet listenizi ve sohbeti yan yana gösteren bölünmüş görünüm sunar.

Sistem gereksinimleri neler?

iPhone'da iOS 17 veya üzeri, iPad'de iPadOS 17 veya üzeri. Apple Intelligence için onu destekleyen bir cihaz ve işletim sistemi sürümü gerekir.

YamabikoChat açık kaynak mı?

Evet. Kaynak kodu GitHub'da MIT License kapsamında yayımlanır. Pakete dahil üçüncü taraf yazılımlar kendi lisanslarını korur.
