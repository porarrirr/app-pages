మద్దతు ఉన్న AI ప్రొవైడర్లు

YamabikoChat మీ సొంత API కీ లేదా ఖాతాతో కింది AI సేవలకు కనెక్ట్ అవుతుంది. బిల్ట్-ఇన్ ప్రొవైడర్లు యాప్‌లోనే సెటప్ అవుతాయి; మరిన్ని API ప్రొవైడర్లు models.dev క్యాటలాగ్ నుండి వస్తాయి.

చివరిగా నవీకరించబడింది: 2026-11-17

models.dev క్యాటలాగ్ నుండి మరిన్ని API ప్రొవైడర్లు

YamabikoChat మరిన్ని API ప్రొవైడర్లను అందించడానికి పబ్లిక్ models.dev క్యాటలాగ్‌ను చదువుతుంది — OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq, xAI API, Moonshot AI (Kimi), MiniMax, Z.ai (GLM), Fireworks AI, Together AI మరియు Hugging Face వంటివి. సెట్టింగ్స్‌లో ప్రొవైడర్‌ను మీ API కీతో జోడించి, ఒక మోడల్‌ను ఎంచుకోండి.

ప్రతి మోడల్ దాని API ఒప్పందం ధృవీకరించబడినప్పుడే నడుస్తుంది. సురక్షితంగా నడపలేని మోడళ్లు కనిపిస్తాయి కానీ నిష్క్రియంగా ఉంటాయి, ఖచ్చితమైన కారణంతో — యాప్ ఎప్పుడూ మీకు తెలియకుండా వేరే మోడల్, ఎండ్‌పాయింట్ లేదా ప్రొవైడర్‌కు మార్చదు.

మోడళ్లను కలిసి వాడడం

కనెక్ట్ చేసిన ప్రతి మోడల్‌ను చాట్‌లో, రెండు సమాధానాలను పోల్చడానికి డ్యూయల్ మోడ్‌లో, మరియు రెండు మోడళ్లు మాట్లాడుకునే ఆటో సంభాషణలో వాడవచ్చు. చిత్ర ఇన్‌పుట్, రీజనింగ్ సెట్టింగ్స్, సాధనాలు మరియు కాంటెక్స్ట్ పొడవు మోడల్‌ను బట్టి ఉంటాయి.

మోడల్ జాబితాలు తరచుగా మారుతుంటాయి. యాప్ ఎప్పుడూ ప్రతి ప్రొవైడర్‌కు ప్రస్తుత జాబితాను చూపిస్తుంది. ప్రొవైడర్ మరియు ఉత్పత్తి పేర్లు వాటి యజమానుల ట్రేడ్‌మార్కులు; YamabikoChat వాటితో అనుబంధించబడదు.

సంబంధిత గైడ్లు

AI మోడళ్లను పోల్చండి ఒకే ప్రాంప్ట్‌ను రెండు మోడళ్లకు పంపి, రెండు సమాధానాలను పక్కపక్కనే చదవండి. మీ సొంత API కీతో వాడండి BYOK ఎలా పనిచేస్తుంది, ఖర్చు ఎంత, మీ కీ ఎలా నిల్వ ఉంటుంది. ప్రశ్నోత్తరాలు ధర, అవసరాలు, గోప్యత మరియు మద్దతు ఉన్న మోడళ్లు.

మీరు ఇప్పటికే వాడుతున్న AI తో ప్రయత్నించండి.
