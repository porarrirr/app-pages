Bawa API key sendiri

Gunakan API key Anda sendiri untuk chat AI di iPhone dan iPad

YamabikoChat adalah klien bring-your-own-key (BYOK). Anda menambahkan API key — atau masuk ke akun yang didukung — dan aplikasi mengirim prompt Anda langsung ke penyedia tersebut. Tidak ada langganan YamabikoChat atau perantara penjual token.

Terakhir diperbarui: 2026-11-17

Apa arti “bring your own key”

Penyedia AI seperti OpenAI, Google, Anthropic, dan OpenRouter menjual akses ke model mereka melalui API key, biasanya ditagih per pemakaian. Aplikasi BYOK adalah klien untuk key tersebut: Anda membuat key di akun penyedia, menambahkannya ke aplikasi, dan penyedia menagih Anda langsung atas pemakaian Anda.

Mengapa memakai key sendiri

  • Bayar sesuai pemakaian. Pengguna ringan sering mengeluarkan lebih sedikit daripada langganan AI bulanan; pengguna berat melihat persis dari mana biayanya berasal.
  • Pilih modelnya. Gunakan model yang ditawarkan penyedia Anda, bukan daftar tetap yang dipilih aplikasi.
  • Satu aplikasi, banyak penyedia. Simpan Gemini, OpenRouter, OpenAI, Anthropic, dan lainnya berdampingan, lalu bandingkan di mode Dual.
  • Lihat pemakaian Anda. Statistik penggunaan token menunjukkan seberapa banyak Anda memakai.

Cara menyiapkannya

  1. Buat API key di konsol penyedia Anda — misalnya Google AI Studio untuk Gemini, platform OpenAI, konsol Anthropic, atau OpenRouter.
  2. Buka Pengaturan di YamabikoChat dan pilih penyedia di pengaturan koneksi.
  3. Tempel key. Key disimpan di Keychain iOS di perangkat Anda.
  4. Pilih model dan mulai chat. Model yang tidak dapat dijalankan dengan aman oleh aplikasi ditampilkan sebagai tidak tersedia, beserta alasannya, bukan hasil tebakan.

Tidak punya API key? Masuk saja

  • Paket ChatGPT — masuk dengan akun ChatGPT Anda untuk memakai model yang termasuk dalam paket Anda.
  • xAI — masuk dengan akun xAI Anda.
  • Apple Intelligence — tersedia bawaan di perangkat yang mendukung, di perangkat atau melalui Private Cloud Compute, tanpa key sama sekali.

Endpoint kustom

Jika layanan Anda tidak ada dalam daftar, tambahkan endpoint kustom dengan base URL dan key-nya, lalu pilih salah satu format API yang didukung: OpenAI Chat Completions, OpenAI Responses, Anthropic Messages, Gemini (Google Generative AI), atau Mistral.

Berapa biayanya

Aplikasi ini gratis, tanpa pembelian dalam aplikasi. Penyedia Anda menagih pemakaian sesuai harga, batas, dan ketentuan mereka sendiri. Mode Dual dan Percakapan otomatis mengirim permintaan ke dua model, sehingga menimbulkan pemakaian pada keduanya.

Keamanan dan privasi

  • API key dan token akses disimpan di Keychain iOS, dan aplikasi dirancang untuk tidak menuliskannya ke log diagnostiknya.
  • Prompt, konteks percakapan, dan lampiran yang Anda pilih dikirim langsung ke penyedia yang Anda pilih.
  • Percakapan disimpan di perangkat Anda. Aplikasi tidak menggunakan pelacakan antar-aplikasi. Lihat kebijakan privasi.
