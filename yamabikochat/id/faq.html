FAQ

Pertanyaan yang sering diajukan

Jawaban singkat tentang harga, API key, model yang didukung, privasi, dan persyaratan.

Terakhir diperbarui: 2026-11-17

Apakah YamabikoChat gratis?

Ya. YamabikoChat gratis untuk diunduh, tanpa iklan, tanpa pendaftaran, dan tanpa langganan atau pembelian token di dalam aplikasi. Anda membayar langsung kepada penyedia AI atas pemakaian yang Anda buat, sesuai harga dan ketentuan penyedia tersebut.

Apakah saya perlu API key?

Anda memerlukan API key dari penyedia AI yang didukung atau masuk dengan akun yang didukung, seperti paket ChatGPT atau xAI. Apple Intelligence berfungsi tanpa key di perangkat yang mendukungnya.

Bisakah saya memakai langganan ChatGPT, bukan API key?

Bisa. Koneksi paket ChatGPT memungkinkan Anda masuk dengan akun ChatGPT dan memakai model yang termasuk dalam paket Anda, tanpa API key OpenAI.

Model AI apa saja yang bisa saya gunakan?

Google Gemini, OpenRouter, paket ChatGPT, xAI, Apple Intelligence, Sarashina, dan PLaMo sudah bawaan. OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq, dan banyak penyedia API lain tersedia melalui katalog models.dev, dan Anda dapat menambahkan endpoint kustom yang memakai format API yang didukung. Model yang tersedia bergantung pada masing-masing penyedia.

Bisakah saya memakai Claude dengan API key Anthropic?

Bisa. Tambahkan Anthropic dari katalog penyedia dengan API key Anda, atau siapkan endpoint kustom yang memakai Anthropic Messages API.

Bisakah saya membandingkan jawaban ChatGPT, Gemini, dan Claude berdampingan?

Bisa. Mode Dual mengirim prompt yang sama ke dua model dan menampilkan kedua jawaban berdampingan. Pilih dua model mana pun dari penyedia yang sudah Anda hubungkan.

Di mana percakapan dan API key saya disimpan?

Percakapan dan pengaturan disimpan di perangkat Anda. API key dan token akses disimpan di Keychain iOS. Prompt, konteks percakapan, dan lampiran yang Anda pilih hanya dikirim ke penyedia yang Anda pilih.

Apakah YamabikoChat berfungsi di iPad?

Ya. Ini aplikasi native untuk iPhone dan iPad, dengan Split View di iPad yang menampilkan daftar percakapan dan chat berdampingan.

Apa persyaratan sistemnya?

iOS 17 atau lebih baru di iPhone, dan iPadOS 17 atau lebih baru di iPad. Apple Intelligence memerlukan perangkat dan versi OS yang mendukungnya.

Apakah YamabikoChat sumber terbuka?

Ya. Kode sumbernya diterbitkan di GitHub di bawah MIT License. Perangkat lunak pihak ketiga yang disertakan tetap memakai lisensinya sendiri.

Masih ada pertanyaan? Kunjungi dukungan.
