Bawa AI Anda sendiri · iPhone & iPad

Chat AI dengan API key Anda sendiri. Bandingkan jawabannya.

YamabikoChat adalah aplikasi chat AI gratis untuk iPhone dan iPad. Hubungkan layanan AI yang sudah Anda gunakan — dengan API key atau akun yang didukung — lalu chat dengan satu model, bandingkan dua model berdampingan, atau biarkan dua model saling berbicara.

Sekilas

Apa itu YamabikoChat

Jenis
Klien chat AI native untuk iPhone dan iPad yang memakai API key atau akun Anda sendiri (BYOK)
Harga
Gratis. Tanpa iklan, tanpa pendaftaran, tanpa langganan atau pembelian token di aplikasi. Pemakaian layanan AI ditagih oleh penyedia.
Layanan AI
Google Gemini, OpenRouter, paket ChatGPT, xAI, Apple Intelligence, OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq, Sarashina, PLaMo, endpoint kustom, dan lainnya — lihat semua penyedia
Mode
Chat, Dual (dua model berdampingan), dan Percakapan otomatis (dua model saling berbicara), serta subagen yang mengambil sebagian tugas
Privasi
Percakapan tersimpan di perangkat Anda, API key disimpan di Keychain iOS, dan prompt hanya dikirim ke penyedia yang Anda pilih
Persyaratan
iOS 17 atau lebih baru (iPhone), iPadOS 17 atau lebih baru (iPad)
Pengembang
Pengembang independen porarrirr · sumber terbuka di bawah MIT License

Mode

Tiga mode percakapan, serta subagen

Pilih mode yang sesuai dengan pertanyaan, bukan sebaliknya.

01 / Chat

Bicara dengan satu model

Jawaban streaming dengan Markdown, sorotan kode, matematika, dan lampiran gambar. Edit, buat ulang, dan simpan varian jawaban.

02 / Dual

Bandingkan dua jawaban

Kirim prompt yang sama ke dua model dan baca kedua jawaban berdampingan. Cara kerja Dual

03 / Otomatis

Biarkan dua model berbicara

Pilih dua model, topik, dan jumlah giliran, lalu saksikan keduanya berdiskusi satu sama lain.

+ / Subagen

Delegasikan pekerjaan

Biarkan model menyerahkan sebagian permintaan ke subagen — masing-masing bisa memakai modelnya sendiri — dan ikuti kemajuannya di chat.

Fitur

Dibuat untuk pekerjaan sehari-hari

Menulis, ringkasan, terjemahan, kode, dan matematika — dengan alat yang dibutuhkan asisten sungguhan.

  • Lampirkan gambar, PDF, dan file teks (hingga 10 MB per file)
  • Pencarian web, Python lokal, dan grafik interaktif (GenUI) sebagai alat
  • Dikte suara dan ekstensi berbagi untuk Safari dan aplikasi lain
  • Aksi Shortcuts, pencarian Spotlight, dan percakapan rahasia
  • Proyek, pencarian riwayat, preset model, dan statistik penggunaan token
  • Split View iPad dan mode gelap

Untuk siapa

Untuk siapa

  • Anda sudah membayar untuk API key atau paket ChatGPT dan ingin aplikasi native iPhone dan iPad untuk memakainya.
  • Anda ingin memeriksa jawaban satu model dengan model lain sebelum mempercayainya.
  • Anda lebih suka membayar sesuai pemakaian daripada menumpuk beberapa langganan AI.
  • Anda memakai OpenRouter atau beberapa penyedia dan ingin semuanya di satu tempat.
  • Anda ingin riwayat chat tersimpan di perangkat Anda sendiri.
