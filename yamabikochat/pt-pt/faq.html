FAQ

Perguntas frequentes

Respostas curtas sobre preços, chaves de API, modelos suportados, privacidade e requisitos.

Última atualização: 2026-11-17

O YamabikoChat é gratuito?

Sim. O YamabikoChat é gratuito para transferir, sem anúncios, sem registo e sem subscrições nem compra de tokens na aplicação. Paga diretamente ao seu fornecedor de IA pela utilização que gerar, de acordo com os preços e termos desse fornecedor.

Preciso de uma chave de API?

Precisa de uma chave de API de um fornecedor de IA suportado ou de iniciar sessão numa conta suportada, como o plano ChatGPT ou a xAI. O Apple Intelligence funciona sem chave nos dispositivos que o suportam.

Posso usar a minha subscrição do ChatGPT em vez de uma chave de API?

Sim. A ligação do plano ChatGPT permite iniciar sessão com a sua conta ChatGPT e usar os modelos incluídos no seu plano, sem uma chave de API da OpenAI.

Que modelos de IA posso usar?

O Google Gemini, o OpenRouter, o plano ChatGPT, a xAI, o Apple Intelligence, o Sarashina e o PLaMo já vêm integrados. A OpenAI, a Anthropic (Claude), a DeepSeek, a Mistral, a Groq e muitos outros fornecedores de API estão disponíveis através do catálogo models.dev, e pode adicionar um endpoint personalizado que utilize um formato de API suportado. Os modelos disponíveis dependem de cada fornecedor.

Posso usar o Claude com a minha chave de API da Anthropic?

Sim. Adicione a Anthropic a partir do catálogo de fornecedores com a sua chave de API ou configure um endpoint personalizado que utilize a API Anthropic Messages.

Posso comparar as respostas do ChatGPT, do Gemini e do Claude lado a lado?

Sim. O modo Dual envia o mesmo prompt a dois modelos e mostra as duas respostas uma ao lado da outra. Escolha dois modelos quaisquer entre os fornecedores que ligou.

Onde ficam as minhas conversas e chaves de API?

As conversas e definições ficam no seu dispositivo. As chaves de API e os tokens de acesso ficam no Keychain do iOS. Os seus prompts, o contexto da conversa e os anexos que escolher são enviados apenas ao fornecedor selecionado.

O YamabikoChat funciona no iPad?

Sim. É uma aplicação nativa para iPhone e iPad, com Split View no iPad que mostra a lista de conversas e a conversa lado a lado.

Quais são os requisitos de sistema?

iOS 17 ou posterior no iPhone e iPadOS 17 ou posterior no iPad. O Apple Intelligence requer um dispositivo e uma versão do sistema que o suportem.

O YamabikoChat é de código aberto?

Sim. O código-fonte é publicado no GitHub com a licença MIT. O software de terceiros incluído mantém as suas próprias licenças.
