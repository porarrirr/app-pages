FAQ

Preguntes freqüents

Respostes curtes sobre el preu, les claus API, els models compatibles, la privadesa i els requisits.

Darrera actualització: 2026-11-17

YamabikoChat és gratuït?

Sí. YamabikoChat és gratuït de descarregar, sense anuncis, sense registre i sense subscripcions ni compres de tokens dins l'app. Pagues directament al teu proveïdor d'IA pel consum que generes, segons els seus preus i condicions.

Cal una clau API?

Necessites una clau API d'un proveïdor d'IA compatible o bé iniciar sessió en un compte compatible, com el pla de ChatGPT o xAI. Apple Intelligence funciona sense clau als dispositius compatibles.

Puc fer servir la meva subscripció de ChatGPT en lloc d'una clau API?

Sí. Amb la connexió del pla de ChatGPT pots iniciar sessió amb el teu compte de ChatGPT i fer servir els models inclosos al teu pla, sense cap clau API d'OpenAI.

Quins models d'IA puc fer servir?

Google Gemini, OpenRouter, el pla de ChatGPT, xAI, Apple Intelligence, Sarashina i PLaMo són integrats. OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq i molts altres proveïdors d'API estan disponibles a través del catàleg models.dev, i pots afegir un punt de connexió personalitzat amb un format d'API compatible. Els models disponibles depenen de cada proveïdor.

Puc fer servir Claude amb la meva clau API d'Anthropic?

Sí. Afegeix Anthropic des del catàleg de proveïdors amb la teva clau API, o configura un punt de connexió personalitzat que faci servir l'API Anthropic Messages.

Puc comparar les respostes de ChatGPT, Gemini i Claude costat a costat?

Sí. El mode Dual envia el mateix missatge a dos models i mostra les dues respostes costat a costat. Tria dos models dels proveïdors que hagis connectat.

On es desen les meves converses i les claus API?

Les converses i la configuració es desen al teu dispositiu. Les claus API i els tokens d'accés es desen al Clauer d'iOS. Els teus missatges, el context de la conversa i els adjunts que triïs només s'envien al proveïdor que hagis seleccionat.

YamabikoChat funciona a l'iPad?

Sí. És una app nativa per a iPhone i iPad, amb vista dividida a l'iPad que mostra la llista de converses i el xat costat a costat.

Quins són els requisits del sistema?

iOS 17 o posterior a l'iPhone i iPadOS 17 o posterior a l'iPad. Apple Intelligence requereix un dispositiu i una versió del sistema compatibles.

YamabikoChat és de codi obert?

Sí. El codi font es publica a GitHub amb la llicència MIT. El programari de tercers inclòs conserva les seves pròpies llicències.
