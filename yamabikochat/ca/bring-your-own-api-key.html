Porta la teva clau

Fes servir la teva pròpia clau API per al xat amb IA a l'iPhone i l'iPad

YamabikoChat és un client BYOK (porta la teva pròpia clau). Afegeixes una clau API —o inicies sessió en un compte compatible— i l'app envia els teus missatges directament a aquest proveïdor. No hi ha cap subscripció de YamabikoChat ni cap revenedor de tokens pel mig.

Darrera actualització: 2026-11-17

Què vol dir «portar la teva pròpia clau»?

Els proveïdors d'IA com OpenAI, Google, Anthropic i OpenRouter venen l'accés als seus models mitjançant claus API, normalment amb facturació per ús. Una app BYOK és un client per a aquestes claus: crees una clau al teu compte del proveïdor, l'afegeixes a l'app i el proveïdor et factura directament el que consumeixes.

Per què fer servir la teva pròpia clau

  • Paga pel que consumeixes. Els usuaris ocasionals sovint gasten menys que amb una subscripció mensual d'IA; els usuaris intensius veuen exactament d'on ve la despesa.
  • Tria el model. Fes servir els models que ofereix el teu proveïdor, no una llista fixa triada per una app.
  • Una app, molts proveïdors. Tingues Gemini, OpenRouter, OpenAI, Anthropic i d'altres al mateix lloc i compara'ls en mode Dual.
  • Consulta el teu consum. Les estadístiques d'ús de tokens mostren quant gastes.

Com configurar-ho

  1. Crea una clau API a la consola del teu proveïdor: per exemple, Google AI Studio per a Gemini, la plataforma d'OpenAI, la consola d'Anthropic o OpenRouter.
  2. Obre la configuració de YamabikoChat i tria el proveïdor als ajustos de connexió.
  3. Enganxa la clau. Es desa al Clauer d'iOS del teu dispositiu.
  4. Tria un model i comença a xatejar. Els models que l'app no pot executar de manera segura es mostren com a no disponibles, amb el motiu, en lloc d'endevinar-los.

No tens clau API? Inicia sessió

  • Pla de ChatGPT — inicia sessió amb el teu compte de ChatGPT per fer servir els models inclosos al teu pla.
  • xAI — inicia sessió amb el teu compte d'xAI.
  • Apple Intelligence — integrat als dispositius compatibles, al dispositiu o mitjançant Private Cloud Compute, sense cap clau.

Punts de connexió personalitzats

Si el teu servei no és a la llista, afegeix un punt de connexió personalitzat amb la seva URL base i la clau, i tria un dels formats d'API compatibles: OpenAI Chat Completions, OpenAI Responses, Anthropic Messages, Gemini (Google Generative AI) o Mistral.

Quant costa

L'app és gratuïta i no té compres integrades. El teu proveïdor cobra l'ús segons els seus preus, límits i condicions. El mode Dual i la conversa automàtica envien peticions a dos models, així que generen consum als dos.

Seguretat i privadesa

  • Les claus API i els tokens d'accés es desen al Clauer d'iOS, i l'app està dissenyada per no escriure'ls als seus registres de diagnòstic.
  • Els missatges, el context de la conversa i els adjunts que triïs s'envien directament al proveïdor que hagis seleccionat.
  • Les converses es desen al teu dispositiu. L'app no fa seguiment entre apps. Consulta la política de privadesa.
