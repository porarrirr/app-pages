Proveïdors d'IA compatibles

YamabikoChat es connecta als serveis d'IA següents amb la teva pròpia clau API o compte. Els proveïdors integrats es configuren directament a l'app; molts altres proveïdors d'API provenen del catàleg models.dev.

Més proveïdors d'API del catàleg models.dev

YamabikoChat llegeix el catàleg públic models.dev per oferir molts més proveïdors d'API, com ara OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq, xAI API, Moonshot AI (Kimi), MiniMax, Z.ai (GLM), Fireworks AI, Together AI i Hugging Face. Afegeix el proveïdor a la configuració amb la teva clau API i tria un model.

Cada model només s'executa quan el seu contracte d'API està verificat. Els models que no es poden executar de manera segura continuen visibles però desactivats, amb el motiu exacte: l'app mai no et canvia silenciosament a un altre model, punt de connexió o proveïdor.

Fer servir els models junts

Qualsevol model connectat es pot fer servir al xat, al mode Dual per comparar dues respostes i a la conversa automàtica per deixar que dos models parlin. L'entrada d'imatges, la configuració de raonament, les eines i la longitud del context depenen del model.

Les llistes de models canvien sovint. L'app sempre mostra la llista actual de cada proveïdor. Els noms de proveïdors i productes són marques dels seus propietaris; YamabikoChat no hi té cap afiliació.
