अपनी key साथ लाएँ

iPhone और iPad पर AI चैट के लिए अपनी API key इस्तेमाल करें

YamabikoChat एक bring-your-own-key (BYOK) क्लाइंट है। आप API key जोड़ते हैं—या किसी समर्थित अकाउंट में साइन इन करते हैं—और ऐप आपके प्रॉम्प्ट सीधे उसी प्रोवाइडर को भेजता है। बीच में कोई YamabikoChat सब्सक्रिप्शन या टोकन रीसेलर नहीं है।

अंतिम अपडेट: 2026-11-17

“अपनी key लाएँ” का क्या मतलब है

OpenAI, Google, Anthropic और OpenRouter जैसे AI प्रोवाइडर अपने मॉडलों तक पहुँच API key के ज़रिए बेचते हैं, और आम तौर पर इस्तेमाल के हिसाब से बिल भेजते हैं। BYOK ऐप उन key के लिए एक क्लाइंट है: आप प्रोवाइडर अकाउंट में key बनाते हैं, उसे ऐप में जोड़ते हैं, और प्रोवाइडर आपके इस्तेमाल का बिल सीधे आपको भेजता है।

अपनी key क्यों इस्तेमाल करें

  • जितना इस्तेमाल, उतना भुगतान। कम इस्तेमाल करने वाले अक्सर मासिक AI सब्सक्रिप्शन से कम खर्च करते हैं; ज़्यादा इस्तेमाल करने वालों को ठीक-ठीक पता रहता है कि खर्च कहाँ से आ रहा है।
  • मॉडल चुनें। ऐप की तय सूची के बजाय वही मॉडल इस्तेमाल करें जो आपका प्रोवाइडर देता है।
  • एक ऐप, कई प्रोवाइडर। Gemini, OpenRouter, OpenAI, Anthropic और अन्य को एक साथ रखें और डुअल मोड में उनकी तुलना करें।
  • अपना इस्तेमाल देखें। टोकन इस्तेमाल के आँकड़े बताते हैं कि आप कितना इस्तेमाल कर रहे हैं।

सेटअप कैसे करें

  1. API key बनाएँ अपने प्रोवाइडर के कंसोल में—जैसे Gemini के लिए Google AI Studio, OpenAI प्लेटफ़ॉर्म, Anthropic कंसोल या OpenRouter।
  2. YamabikoChat में सेटिंग्स खोलें और कनेक्शन सेटिंग्स में प्रोवाइडर चुनें।
  3. key पेस्ट करें। यह आपके डिवाइस की iOS कीचेन में सुरक्षित रहती है।
  4. मॉडल चुनें और चैट शुरू करें। जो मॉडल ऐप सुरक्षित रूप से नहीं चला सकता, वह अंदाज़ा लगाने के बजाय कारण के साथ अनुपलब्ध दिखाया जाता है।

API key नहीं है? साइन इन करें

  • ChatGPT प्लान — अपने प्लान में शामिल मॉडल इस्तेमाल करने के लिए ChatGPT अकाउंट से साइन इन करें।
  • xAI — अपने xAI अकाउंट से साइन इन करें।
  • Apple Intelligence — समर्थित डिवाइसों में पहले से मौजूद; डिवाइस पर या Private Cloud Compute के ज़रिए चलता है, किसी key की ज़रूरत नहीं।

कस्टम एंडपॉइंट

अगर आपकी सेवा सूची में नहीं है, तो उसका base URL और key देकर कस्टम एंडपॉइंट जोड़ें और इनमें से कोई समर्थित API फ़ॉर्मैट चुनें: OpenAI Chat Completions, OpenAI Responses, Anthropic Messages, Gemini (Google Generative AI) या Mistral।

इसका खर्च क्या है

ऐप मुफ़्त है और इसमें कोई इन-ऐप खरीद नहीं है। आपका प्रोवाइडर अपनी कीमत, सीमाओं और शर्तों के तहत इस्तेमाल का बिल भेजता है। डुअल मोड और ऑटो बातचीत दो मॉडलों को अनुरोध भेजते हैं, इसलिए दोनों पर इस्तेमाल बनता है।

सुरक्षा और गोपनीयता

  • API keys और एक्सेस टोकन iOS कीचेन में रहते हैं और ऐप उन्हें अपने डायग्नोस्टिक लॉग में न लिखने के लिए बनाया गया है।
  • प्रॉम्प्ट, बातचीत का कॉन्टेक्स्ट और आपके चुने हुए अटैचमेंट सीधे उसी प्रोवाइडर को भेजे जाते हैं जिसे आपने चुना है।
  • बातचीत आपके डिवाइस पर सुरक्षित रहती है। ऐप क्रॉस-ऐप ट्रैकिंग नहीं करता। गोपनीयता नीति देखें।

संबंधित गाइड

AI मॉडल की तुलना करें एक ही प्रॉम्प्ट दो मॉडलों को भेजें और दोनों जवाब साथ-साथ पढ़ें। समर्थित प्रोवाइडर Gemini, OpenRouter, ChatGPT प्लान, xAI, OpenAI, Anthropic और बहुत कुछ। सामान्य प्रश्न कीमत, ज़रूरी शर्तें, गोपनीयता और समर्थित मॉडल।

उसी AI के साथ आज़माएँ जिसे आप पहले से इस्तेमाल करते हैं।
