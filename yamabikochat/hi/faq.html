क्या YamabikoChat मुफ़्त है?

हाँ। YamabikoChat डाउनलोड करना मुफ़्त है, इसमें कोई विज्ञापन, साइन-अप, सब्सक्रिप्शन या ऐप के अंदर टोकन खरीद नहीं है। आप जो इस्तेमाल करते हैं, उसका भुगतान आप सीधे अपने AI प्रोवाइडर को उसकी कीमत और शर्तों के तहत करते हैं।

क्या मुझे API key चाहिए?

आपको किसी समर्थित AI प्रोवाइडर की API key चाहिए, या ChatGPT प्लान या xAI जैसे समर्थित अकाउंट में साइन-इन करना होगा। Apple Intelligence उन डिवाइसों पर बिना key के काम करता है जो इसे सपोर्ट करते हैं।

क्या API key के बजाय अपना ChatGPT सब्सक्रिप्शन इस्तेमाल कर सकता हूँ?

हाँ। ChatGPT प्लान कनेक्शन से आप ChatGPT अकाउंट से साइन इन करके अपने प्लान में शामिल मॉडल बिना OpenAI API key के इस्तेमाल कर सकते हैं।

मैं कौन से AI मॉडल इस्तेमाल कर सकता हूँ?

Google Gemini, OpenRouter, ChatGPT प्लान, xAI, Apple Intelligence, Sarashina और PLaMo बिल्ट-इन हैं। OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq और कई अन्य API प्रोवाइडर models.dev कैटलॉग से उपलब्ध हैं, और आप कोई समर्थित API फ़ॉर्मैट इस्तेमाल करने वाला कस्टम एंडपॉइंट भी जोड़ सकते हैं। उपलब्ध मॉडल हर प्रोवाइडर पर निर्भर करते हैं।

क्या मैं अपनी Anthropic API key से Claude इस्तेमाल कर सकता हूँ?

हाँ। प्रोवाइडर कैटलॉग से Anthropic को अपनी API key के साथ जोड़ें, या Anthropic Messages API इस्तेमाल करने वाला कस्टम एंडपॉइंट सेट करें।

क्या ChatGPT, Gemini और Claude के जवाब साथ-साथ तुलना कर सकता हूँ?

हाँ। डुअल मोड एक ही प्रॉम्प्ट दो मॉडलों को भेजता है और दोनों जवाब पास-पास दिखाता है। अपने जोड़े हुए प्रोवाइडर से कोई भी दो मॉडल चुनें।

मेरी बातचीत और API keys कहाँ सुरक्षित रहती हैं?

बातचीत और सेटिंग्स आपके डिवाइस पर रहती हैं। API keys और एक्सेस टोकन iOS कीचेन में रखे जाते हैं। आपके प्रॉम्प्ट, बातचीत का कॉन्टेक्स्ट और आपके चुने हुए अटैचमेंट सिर्फ़ उसी प्रोवाइडर को भेजे जाते हैं जिसे आपने चुना है।

क्या YamabikoChat iPad पर काम करता है?

हाँ। यह iPhone और iPad के लिए नेटिव ऐप है, और iPad पर स्प्लिट व्यू के साथ आपकी बातचीत की सूची और चैट पास-पास दिखती हैं।

सिस्टम की क्या ज़रूरतें हैं?

iPhone पर iOS 17 या बाद का संस्करण, और iPad पर iPadOS 17 या बाद का संस्करण। Apple Intelligence के लिए ऐसा डिवाइस और OS संस्करण चाहिए जो इसे सपोर्ट करे।

क्या YamabikoChat ओपन सोर्स है?

हाँ। सोर्स कोड GitHub पर MIT License के तहत प्रकाशित है। ऐप में शामिल तीसरे पक्ष का सॉफ़्टवेयर अपने अलग लाइसेंस बनाए रखता है।
