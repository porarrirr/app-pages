models.dev कैटलॉग से और API प्रोवाइडर

YamabikoChat कई और API प्रोवाइडर देने के लिए सार्वजनिक models.dev कैटलॉग पढ़ता है, जिनमें OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq, xAI API, Moonshot AI (Kimi), MiniMax, Z.ai (GLM), Fireworks AI, Together AI और Hugging Face शामिल हैं। सेटिंग्स में प्रोवाइडर जोड़ें, अपनी API key डालें और मॉडल चुनें।

हर मॉडल तभी चलता है जब उसका API कॉन्ट्रैक्ट सत्यापित हो। जो मॉडल सुरक्षित रूप से नहीं चल सकते, वे सटीक कारण के साथ दिखते तो हैं पर बंद रहते हैं—ऐप कभी चुपचाप आपको दूसरे मॉडल, एंडपॉइंट या प्रोवाइडर पर नहीं भेजता।

मॉडलों को साथ इस्तेमाल करें

हर जुड़ा हुआ मॉडल चैट में, दो जवाबों की तुलना के लिए डुअल मोड में और दो मॉडलों को बात कराने वाली ऑटो बातचीत में इस्तेमाल हो सकता है। इमेज इनपुट, रीज़निंग सेटिंग्स, टूल और कॉन्टेक्स्ट लंबाई मॉडल पर निर्भर करते हैं।

मॉडल की सूची अक्सर बदलती है। ऐप हर प्रोवाइडर की मौजूदा सूची दिखाता है। प्रोवाइडर और उत्पाद नाम उनके स्वामियों के ट्रेडमार्क हैं; YamabikoChat उनसे जुड़ा नहीं है।

संबंधित गाइड

AI मॉडल की तुलना करेंएक ही प्रॉम्प्ट दो मॉडलों को भेजें और दोनों जवाब साथ-साथ पढ़ें।अपनी API key इस्तेमाल करेंBYOK कैसे काम करता है, इसका खर्च क्या है और आपकी key कहाँ सुरक्षित रहती है।सामान्य प्रश्नकीमत, ज़रूरी शर्तें, गोपनीयता और समर्थित मॉडल।

उसी AI के साथ आज़माएँ जिसे आप पहले से इस्तेमाल करते हैं।
