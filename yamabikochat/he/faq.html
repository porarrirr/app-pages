שאלות נפוצות

תשובות קצרות על מחיר, מפתחות API, מודלים נתמכים, פרטיות ודרישות.

עדכון אחרון: 2026-11-17

האם YamabikoChat בחינם?

כן. YamabikoChat בחינם להורדה, בלי פרסומות, בלי הרשמה ובלי מינויים או רכישת טוקנים בתוך האפליקציה. אתם משלמים לספק ה-AI ישירות על השימוש שאתם יוצרים, לפי התמחור והתנאים של אותו ספק.

האם אני צריך מפתח API?

אתם צריכים מפתח API מספק AI נתמך או התחברות לחשבון נתמך, כמו תוכנית ChatGPT או xAI. Apple Intelligence פועל בלי מפתח במכשירים שתומכים בו.

אפשר להשתמש במנוי ChatGPT במקום במפתח API?

כן. חיבור תוכנית ChatGPT מאפשר להתחבר עם חשבון ChatGPT ולהשתמש במודלים הכלולים בתוכנית, בלי מפתח API של OpenAI.

באילו מודלי AI אפשר להשתמש?

Google Gemini, OpenRouter, תוכנית ChatGPT, xAI, Apple Intelligence, Sarashina ו-PLaMo מובנים. OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq ועוד ספקי API רבים זמינים דרך הקטלוג models.dev, ואפשר להוסיף נקודת קצה מותאמת שמשתמשת בתבנית API נתמכת. המודלים הזמינים תלויים בכל ספק.

אפשר להשתמש ב-Claude עם מפתח ה-API של Anthropic?

כן. הוסיפו את Anthropic מקטלוג הספקים עם מפתח ה-API, או הגדירו נקודת קצה מותאמת שמשתמשת ב-Anthropic Messages API.

אפשר להשוות את התשובות של ChatGPT, Gemini ו-Claude זו לצד זו?

כן. מצב Dual שולח את אותה בקשה לשני מודלים ומציג את שתי התשובות זו לצד זו. בחרו כל שני מודלים מבין הספקים שחיברתם.

איפה נשמרות השיחות ומפתחות ה-API שלי?

השיחות וההגדרות נשמרות במכשיר שלכם. מפתחות API וטוקני גישה נשמרים בצרור המפתחות של iOS. הבקשות, הקשר השיחה והקבצים המצורפים שבחרתם נשלחים רק לספק שבחרתם.

האם YamabikoChat עובד ב-iPad?

כן. זו אפליקציה מקורית ל-iPhone ול-iPad, עם תצוגה מפוצלת ב-iPad שמציגה את רשימת השיחות ואת הצ׳אט זה לצד זה.

מהן דרישות המערכת?

iOS 17 ואילך ב-iPhone, ו-iPadOS 17 ואילך ב-iPad. Apple Intelligence דורש מכשיר וגרסת מערכת שתומכים בו.

האם YamabikoChat הוא קוד פתוח?

כן. קוד המקור מפורסם ב-GitHub תחת MIT License. תוכנות צד שלישי המצורפות שומרות על הרישיונות שלהן.
