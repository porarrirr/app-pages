הביאו את המפתח שלכם

שימוש במפתח API משלכם לצ׳אט AI ב-iPhone וב-iPad

YamabikoChat הוא לקוח BYOK: אתם מוסיפים מפתח API — או מתחברים לחשבון נתמך — והאפליקציה שולחת את הבקשות ישירות לספק הזה. אין מינוי YamabikoChat ואין מתווך שמוכר טוקנים.

עדכון אחרון: 2026-11-17

מה המשמעות של „הביאו את המפתח שלכם”

ספקי AI כמו OpenAI, Google, Anthropic ו-OpenRouter מוכרים גישה למודלים שלהם באמצעות מפתחות API, בדרך כלל בחיוב לפי שימוש. אפליקציית BYOK היא לקוח למפתחות האלה: אתם יוצרים מפתח בחשבון הספק, מוסיפים אותו לאפליקציה, והספק מחייב אתכם ישירות על מה שאתם משתמשים בו.

למה להשתמש במפתח משלכם

  • לשלם על מה שמשתמשים. משתמשים מעטים מוציאים לעתים פחות ממינוי AI חודשי; משתמשים כבדים רואים בדיוק מאיפה מגיעה העלות.
  • לבחור את המודל. השתמשו במודלים שהספק מציע, ולא ברשימה קבועה שנבחרה על ידי אפליקציה.
  • אפליקציה אחת, ספקים רבים. החזיקו את Gemini, OpenRouter, OpenAI, Anthropic ואחרים במקום אחד, והשוו ביניהם במצב Dual.
  • לראות את השימוש. סטטיסטיקת השימוש בטוקנים מראה כמה אתם צורכים.

איך מגדירים

  1. צרו מפתח API בקונסולה של הספק — למשל Google AI Studio ל-Gemini, פלטפורמת OpenAI, הקונסולה של Anthropic או OpenRouter.
  2. פתחו את ההגדרות ב-YamabikoChat ובחרו את הספק בהגדרות החיבור.
  3. הדביקו את המפתח. הוא נשמר בצרור המפתחות של iOS במכשיר שלכם.
  4. בחרו מודל והתחילו שיחה. מודלים שהאפליקציה לא יכולה להריץ בבטחה מוצגים כלא זמינים, עם הסיבה, במקום לנחש.

אין לכם מפתח API? התחברו במקום

  • תוכנית ChatGPT — התחברו עם חשבון ChatGPT כדי להשתמש במודלים הכלולים בתוכנית שלכם.
  • xAI — התחברו עם חשבון xAI.
  • Apple Intelligence — מובנה במכשירים נתמכים, במכשיר או דרך Private Cloud Compute, בלי שום מפתח.

נקודות קצה מותאמות

אם השירות שלכם לא ברשימה, הוסיפו נקודת קצה מותאמת עם כתובת הבסיס שלה והמפתח, ובחרו אחת מתבניות ה-API הנתמכות: OpenAI Chat Completions, OpenAI Responses, Anthropic Messages, Gemini (Google Generative AI) או Mistral.

כמה זה עולה

האפליקציה בחינם, בלי רכישות בתוך האפליקציה. הספק שלכם גובה על השימוש לפי התמחור, המגבלות והתנאים שלו. מצב Dual ושיחה אוטומטית שולחים בקשות לשני מודלים, ולכן יוצרים שימוש בשניהם.

אבטחה ופרטיות

  • מפתחות API וטוקני גישה נשמרים בצרור המפתחות של iOS, והאפליקציה מתוכננת לא לכתוב אותם ביומני האבחון שלה.
  • בקשות, הקשר השיחה והקבצים המצורפים שאתם בוחרים נשלחים ישירות לספק שבחרתם.
  • השיחות נשמרות במכשיר שלכם. האפליקציה לא משתמשת במעקב בין אפליקציות. ראו מדיניות פרטיות.
