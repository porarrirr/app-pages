עוד ספקי API מקטלוג models.dev

YamabikoChat קורא את הקטלוג הציבורי models.dev כדי להציע עוד ספקי API רבים, ובהם OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq, xAI API, Moonshot AI (Kimi), MiniMax, Z.ai (GLM), Fireworks AI, Together AI ו-Hugging Face. הוסיפו את הספק בהגדרות עם מפתח ה-API ובחרו מודל.

כל מודל פועל רק לאחר אימות חוזה ה-API שלו. מודלים שאי אפשר להריץ בבטחה נשארים גלויים אך מושבתים, עם הסיבה המדויקת — האפליקציה לא מחליפה לכם מודל, נקודת קצה או ספק בשקט.

שימוש במודלים יחד

כל מודל מחובר יכול לשמש בצ׳אט, במצב Dual להשוואת שתי תשובות, ובשיחה אוטומטית כדי ששני מודלים ידברו. קלט תמונות, הגדרות חשיבה, כלים ואורך הקשר תלויים במודל.

רשימות המודלים משתנות לעתים קרובות. האפליקציה מציגה תמיד את הרשימה הנוכחית של כל ספק. שמות ספקים ומוצרים הם סימני מסחר של בעליהם; YamabikoChat אינה קשורה אליהם.

מדריכים קשורים

השוואת מודלי AIשלחו בקשה אחת לשני מודלים וקראו את שתי התשובות זו לצד זו.שימוש במפתח API משלכםאיך עובד BYOK, כמה זה עולה, ואיך המפתח שלכם נשמר.שאלות נפוצותמחיר, דרישות, פרטיות ומודלים נתמכים.
