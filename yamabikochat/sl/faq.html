Pogosta vprašanja

Pogosto zastavljena vprašanja

Kratki odgovori o ceni, API ključih, podprtih modelih, zasebnosti in zahtevah.

Zadnja posodobitev: 2026-11-17

Ali je YamabikoChat brezplačen?

Da. YamabikoChat je brezplačen za prenos, brez oglasov, registracije in brez naročnin ali nakupov žetonov v aplikaciji. Za uporabo, ki jo ustvarite, plačate neposredno svojemu ponudniku AI po njegovih cenah in pogojih.

Ali potrebujem API ključ?

Potrebujete API ključ podprtega ponudnika AI ali prijavo v podprt račun, na primer načrt ChatGPT ali xAI. Apple Intelligence deluje brez ključa v napravah, ki jo podpirajo.

Ali lahko uporabim svojo naročnino ChatGPT namesto API ključa?

Da. Povezava načrta ChatGPT vam omogoči prijavo z računom ChatGPT in uporabo modelov, vključenih v vaš načrt, brez API ključa OpenAI.

Katere modele AI lahko uporabljam?

Vgrajeni so Google Gemini, OpenRouter, načrt ChatGPT, xAI, Apple Intelligence, Sarashina in PLaMo. OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq in številni drugi ponudniki API so na voljo prek kataloga models.dev, dodate pa lahko tudi končno točko po meri s podprtim formatom API. Razpoložljivi modeli so odvisni od posameznega ponudnika.

Ali lahko uporabljam Claude s svojim API ključem Anthropic?

Da. Dodajte Anthropic iz kataloga ponudnikov s svojim API ključem ali nastavite končno točko po meri z API Anthropic Messages.

Ali lahko primerjam odgovore ChatGPT, Gemini in Claude drug ob drugem?

Da. Način Dual pošlje isti poziv dvema modeloma in prikaže oba odgovora drug ob drugem. Izberite katera koli dva modela pri ponudnikih, ki ste jih povezali.

Kje so shranjeni moji pogovori in API ključi?

Pogovori in nastavitve so shranjeni v vaši napravi. API ključi in dostopni žetoni so shranjeni v ključavnici iOS. Vaši pozivi, kontekst pogovora in priloge, ki jih izberete, se pošljejo le ponudniku, ki ste ga izbrali.

Ali YamabikoChat deluje na iPadu?

Da. To je nativna aplikacija za iPhone in iPad, na iPadu z razdeljenim pogledom, ki prikaže seznam pogovorov in klepet drug ob drugem.

Kakšne so sistemske zahteve?

iOS 17 ali novejši na iPhonu in iPadOS 17 ali novejši na iPadu. Apple Intelligence zahteva napravo in različico operacijskega sistema, ki jo podpirata.

Ali je YamabikoChat odprtokoden?

Da. Izvorna koda je objavljena na GitHubu pod licenco MIT. Priložena programska oprema tretjih oseb ohrani svoje licence.
