Podporovaní poskytovatelia AI

YamabikoChat sa pripája k nižšie uvedeným službám AI pomocou vášho vlastného API kľúča alebo účtu. Vstavaných poskytovateľov nastavíte priamo v aplikácii; mnoho ďalších poskytovateľov API pochádza z katalógu models.dev.

Ďalší poskytovatelia API z katalógu models.dev

YamabikoChat číta verejný katalóg models.dev a ponúka tak oveľa viac poskytovateľov API, vrátane OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq, xAI API, Moonshot AI (Kimi), MiniMax, Z.ai (GLM), Fireworks AI, Together AI a Hugging Face. Pridajte poskytovateľa v nastaveniach pomocou API kľúča a vyberte model.

Každý model beží len vtedy, keď je jeho API kontrakt overený. Modely, ktoré nemožno bezpečne spustiť, zostávajú viditeľné, ale vypnuté, s presným dôvodom – aplikácia vás nikdy potichu neprepne na iný model, koncový bod ani poskytovateľa.

Spoločné používanie modelov

Každý pripojený model možno použiť v chate, v režime Dual na porovnanie dvoch odpovedí a v automatickej konverzácii, kde sa rozprávajú dva modely. Vstup obrázkov, nastavenia uvažovania, nástroje a dĺžka kontextu závisia od modelu.

Zoznamy modelov sa často menia. Aplikácia vždy zobrazuje aktuálny zoznam pre každého poskytovateľa. Názvy poskytovateľov a produktov sú ochranné známky ich vlastníkov; YamabikoChat s nimi nie je spojený.
