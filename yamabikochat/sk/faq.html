Často kladené otázky

Krátke odpovede o cene, API kľúčoch, podporovaných modeloch, súkromí a požiadavkách.

Posledná aktualizácia: 2026-11-17

Je YamabikoChat zadarmo?

Áno. YamabikoChat je zadarmo na stiahnutie, bez reklám, bez registrácie a bez predplatného či nákupov tokenov v aplikácii. Za využitie, ktoré vytvoríte, platíte priamo svojmu poskytovateľovi AI podľa jeho cien a podmienok.

Potrebujem API kľúč?

Potrebujete buď API kľúč od podporovaného poskytovateľa AI, alebo prihlásenie do podporovaného účtu, napríklad plán ChatGPT alebo xAI. Apple Intelligence funguje bez kľúča na zariadeniach, ktoré ju podporujú.

Môžem namiesto API kľúča použiť svoje predplatné ChatGPT?

Áno. Pripojenie plánu ChatGPT vám umožní prihlásiť sa účtom ChatGPT a používať modely zahrnuté vo vašom pláne, bez API kľúča OpenAI.

Ktoré AI modely môžem použiť?

Vstavané sú Google Gemini, OpenRouter, plán ChatGPT, xAI, Apple Intelligence, Sarashina a PLaMo. OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq a mnohí ďalší poskytovatelia API sú dostupní cez katalóg models.dev a môžete pridať vlastný koncový bod s podporovaným formátom API. Dostupné modely závisia od jednotlivých poskytovateľov.

Môžem použiť Claude so svojím API kľúčom Anthropic?

Áno. Pridajte Anthropic z katalógu poskytovateľov pomocou svojho API kľúča, alebo nastavte vlastný koncový bod s API Anthropic Messages.

Môžem porovnať odpovede ChatGPT, Gemini a Claude vedľa seba?

Áno. Režim Dual pošle rovnakú výzvu dvom modelom a zobrazí obe odpovede vedľa seba. Vyberte ľubovoľné dva modely od poskytovateľov, ktorých máte pripojených.

Kde sú uložené moje konverzácie a API kľúče?

Konverzácie a nastavenia sú uložené vo vašom zariadení. API kľúče a prístupové tokeny sú uložené v zväzku kľúčov iOS. Vaše výzvy, kontext konverzácie a prílohy, ktoré vyberiete, sa odosielajú iba poskytovateľovi, ktorého ste zvolili.

Funguje YamabikoChat na iPade?

Áno. Je to natívna aplikácia pre iPhone a iPad, na iPade s rozdeleným zobrazením, ktoré ukazuje zoznam konverzácií a chat vedľa seba.

Aké sú systémové požiadavky?

iOS 17 alebo novší na iPhone a iPadOS 17 alebo novší na iPade. Apple Intelligence vyžaduje zariadenie a verziu operačného systému, ktoré ju podporujú.

Je YamabikoChat open source?

Áno. Zdrojový kód je zverejnený na GitHube pod licenciou MIT. Pribalený softvér tretích strán si zachováva vlastné licencie.
