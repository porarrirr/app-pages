તમારી કી લાવો

iPhone અને iPad પર AI ચેટ માટે તમારી પોતાની API કી વાપરો

YamabikoChat એ બ્રિંગ-યોર-ઓન-કી (BYOK) ક્લાયન્ટ છે. તમે API કી ઉમેરો — અથવા સપોર્ટેડ એકાઉન્ટમાં સાઇન ઇન કરો — અને એપ તમારા પ્રોમ્પ્ટ સીધા તે પ્રોવાઇડરને મોકલે છે. વચ્ચે YamabikoChatનું સબ્સ્ક્રિપ્શન કે ટોકન વેચનાર નથી.

છેલ્લે અપડેટ: 2026-11-17

“તમારી પોતાની કી વાપરો” એટલે શું

OpenAI, Google, Anthropic અને OpenRouter જેવા AI પ્રોવાઇડર તેમના મોડેલનો ઉપયોગ API કી દ્વારા વેચે છે, જેનું બિલ સામાન્ય રીતે વપરાશ પ્રમાણે થાય છે. BYOK એપ એ કીઓ માટેનું ક્લાયન્ટ છે: તમે તમારા પ્રોવાઇડર એકાઉન્ટમાં કી બનાવો, તેને એપમાં ઉમેરો, અને તમે જે વાપરો તેનું બિલ પ્રોવાઇડર તમને સીધું કરે છે.

તમારી પોતાની કી કેમ વાપરવી

  • વાપર્યા પ્રમાણે ચૂકવો. હલકા વપરાશકર્તાઓ ઘણી વાર માસિક AI સબ્સ્ક્રિપ્શન કરતાં ઓછું ખર્ચે છે; ભારે વપરાશકર્તાઓને ખર્ચ ક્યાંથી આવે છે તે સ્પષ્ટ દેખાય છે.
  • મોડેલ પસંદ કરો. એપ પસંદ કરેલી નિશ્ચિત સૂચિને બદલે તમારો પ્રોવાઇડર જે મોડેલ આપે તે વાપરો.
  • એક એપ, અનેક પ્રોવાઇડર. Gemini, OpenRouter, OpenAI, Anthropic વગેરેને સાથે રાખો અને ડ્યુઅલ મોડમાં તેમની સરખામણી કરો.
  • તમારો વપરાશ જુઓ. ટોકન વપરાશના આંકડા દર્શાવે છે કે તમે કેટલું વાપરો છો.

સેટઅપ કેવી રીતે કરવું

  1. API કી બનાવો તમારા પ્રોવાઇડરના કન્સોલમાં — ઉદાહરણ તરીકે Gemini માટે Google AI Studio, OpenAI પ્લેટફોર્મ, Anthropic કન્સોલ અથવા OpenRouter.
  2. YamabikoChatમાં સેટિંગ્સ ખોલો અને કનેક્શન સેટિંગ્સમાં પ્રોવાઇડર પસંદ કરો.
  3. કી પેસ્ટ કરો. તે તમારા ઉપકરણના iOS Keychainમાં સચવાય છે.
  4. મોડેલ પસંદ કરો અને ચેટ શરૂ કરો. એપ સુરક્ષિત રીતે ચલાવી ન શકે તેવા મોડેલ અનુમાન કરવાને બદલે કારણ સાથે અનુપલબ્ધ તરીકે દેખાય છે.

API કી નથી? સાઇન ઇન કરો

  • ChatGPT પ્લાન — તમારા ChatGPT એકાઉન્ટથી સાઇન ઇન કરો અને તમારા પ્લાનમાં સમાવિષ્ટ મોડેલ વાપરો.
  • xAI — તમારા xAI એકાઉન્ટથી સાઇન ઇન કરો.
  • Apple Intelligence — સપોર્ટેડ ઉપકરણો પર બિલ્ટ-ઇન, ઉપકરણ પર જ અથવા Private Cloud Compute દ્વારા, કોઈ કી વગર.

કસ્ટમ એન્ડપોઇન્ટ

તમારી સેવા સૂચિમાં ન હોય તો તેનું બેઝ URL અને કી સાથે કસ્ટમ એન્ડપોઇન્ટ ઉમેરો, અને સપોર્ટેડ API ફોર્મેટમાંથી એક પસંદ કરો: OpenAI Chat Completions, OpenAI Responses, Anthropic Messages, Gemini (Google Generative AI) અથવા Mistral.

ખર્ચ કેટલો છે

એપ મફત છે, એપમાં ખરીદી નથી. તમારો પ્રોવાઇડર તેની પોતાની કિંમત, મર્યાદા અને શરતો હેઠળ વપરાશનું બિલ કરે છે. ડ્યુઅલ મોડ અને ઓટો વાતચીત બે મોડેલને વિનંતી મોકલે છે, તેથી બંને પર વપરાશ થાય છે.

સુરક્ષા અને ગોપનીયતા

  • API કી અને એક્સેસ ટોકન iOS Keychainમાં સચવાય છે, અને એપ તેમને તેના ડાયગ્નોસ્ટિક લોગમાં લખે નહીં તે રીતે બનાવાઈ છે.
  • પ્રોમ્પ્ટ, વાતચીતનો સંદર્ભ અને તમે પસંદ કરેલા એટેચમેન્ટ તમે પસંદ કરેલા પ્રોવાઇડરને સીધા મોકલાય છે.
  • વાતચીત તમારા ઉપકરણ પર સચવાય છે. એપ ક્રોસ-એપ ટ્રેકિંગ વાપરતી નથી. ગોપનીયતા નીતિ જુઓ.

સંબંધિત માર્ગદર્શિકાઓ

AI મોડેલની સરખામણી કરોએક જ પ્રોમ્પ્ટ બે મોડેલને મોકલો અને બંને જવાબો સાથે સાથે વાંચો.સપોર્ટેડ પ્રોવાઇડરGemini, OpenRouter, ChatGPT પ્લાન, xAI, OpenAI, Anthropic અને વધુ.પ્રશ્નોકિંમત, જરૂરિયાતો, ગોપનીયતા અને સપોર્ટેડ મોડેલ.

તમે પહેલેથી જ વાપરો છો તે AI સાથે અજમાવો.
