છેલ્લે અપડેટ: 2026-11-17

YamabikoChat મફત છે?

હા. YamabikoChat ડાઉનલોડ કરવા મફત છે, જાહેરાત નથી, સાઇન-અપ નથી, અને એપની અંદર સબ્સ્ક્રિપ્શન કે ટોકન ખરીદી નથી. તમે જે વપરાશ કરો છો તેના માટે તમે તે પ્રોવાઇડરની કિંમત અને શરતો હેઠળ સીધું તમારા AI પ્રોવાઇડરને ચૂકવો છો.

મને API કીની જરૂર છે?

તમારે સપોર્ટેડ AI પ્રોવાઇડરની API કી અથવા ChatGPT પ્લાન કે xAI જેવા સપોર્ટેડ એકાઉન્ટથી સાઇન ઇનની જરૂર પડશે. Apple Intelligence તેને સપોર્ટ કરતા ઉપકરણો પર કી વગર કામ કરે છે.

શું હું API કીને બદલે મારું ChatGPT સબ્સ્ક્રિપ્શન વાપરી શકું?

હા. ChatGPT પ્લાન કનેક્શનથી તમે તમારા ChatGPT એકાઉન્ટથી સાઇન ઇન કરી શકો છો અને OpenAI API કી વગર તમારા પ્લાનમાં સમાવિષ્ટ મોડેલ વાપરી શકો છો.

કયા AI મોડેલ વાપરી શકાય?

Google Gemini, OpenRouter, ChatGPT પ્લાન, xAI, Apple Intelligence, Sarashina અને PLaMo બિલ્ટ-ઇન છે. OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq અને અન્ય ઘણા API પ્રોવાઇડર models.dev કેટલોગ દ્વારા ઉપલબ્ધ છે, અને તમે સપોર્ટેડ API ફોર્મેટ વાપરતું કસ્ટમ એન્ડપોઇન્ટ પણ ઉમેરી શકો છો. ઉપલબ્ધ મોડેલ દરેક પ્રોવાઇડર પર આધાર રાખે છે.

શું હું મારી Anthropic API કી સાથે Claude વાપરી શકું?

હા. પ્રોવાઇડર કેટલોગમાંથી તમારી API કી સાથે Anthropic ઉમેરો, અથવા Anthropic Messages API વાપરતું કસ્ટમ એન્ડપોઇન્ટ સેટ કરો.

શું હું ChatGPT, Gemini અને Claudeના જવાબો સાથે સાથે સરખાવી શકું?

હા. ડ્યુઅલ મોડ એક જ પ્રોમ્પ્ટ બે મોડેલને મોકલે છે અને બંને જવાબો બાજુમાં બતાવે છે. તમે જોડેલા પ્રોવાઇડરમાંથી કોઈપણ બે મોડેલ પસંદ કરો.

મારી વાતચીત અને API કી ક્યાં સચવાય છે?

વાતચીત અને સેટિંગ્સ તમારા ઉપકરણ પર સચવાય છે. API કી અને એક્સેસ ટોકન iOS Keychain માં સચવાય છે. તમારા પ્રોમ્પ્ટ, વાતચીતનો સંદર્ભ અને તમે પસંદ કરેલા એટેચમેન્ટ ફક્ત તમે પસંદ કરેલા પ્રોવાઇડરને મોકલાય છે.

YamabikoChat iPad પર કામ કરે છે?

હા. તે iPhone અને iPad માટેની નેટિવ એપ છે, જેમાં iPad પર સ્પ્લિટ વ્યૂ તમારી વાતચીતની સૂચિ અને ચેટ સાથે સાથે બતાવે છે.

સિસ્ટમની જરૂરિયાતો શું છે?

iPhone પર iOS 17 અથવા પછીનું અને iPad પર iPadOS 17 અથવા પછીનું. Apple Intelligence માટે તેને સપોર્ટ કરતું ઉપકરણ અને OS આવૃત્તિ જરૂરી છે.

YamabikoChat ઓપન સોર્સ છે?

હા. સોર્સ કોડ MIT License હેઠળ GitHub પર પ્રકાશિત છે. સાથે આવતું તૃતીય-પક્ષ સોફ્ટવેર તેના પોતાના લાઇસન્સ જાળવી રાખે છે.
