તમારું પોતાનું AI · iPhone & iPad

તમારી પોતાની API કી પર AI ચેટ. જવાબોની સરખામણી કરો.

YamabikoChat એ iPhone અને iPad માટેની મફત AI ચેટ એપ છે. તમે પહેલેથી જ વાપરો છો તે AI સેવાઓને API કી કે સપોર્ટેડ એકાઉન્ટથી જોડો, પછી એક મોડેલ સાથે ચેટ કરો, બે મોડેલની સાથે સાથે સરખામણી કરો અથવા બે મોડેલને એકબીજા સાથે વાત કરાવો.

મોડ

ત્રણ વાતચીત મોડ, ઉપરાંત સબ-એજન્ટ

પ્રશ્નને અનુરૂપ મોડ પસંદ કરો, ઊલટું નહીં.

01 / ચેટ

એક મોડેલ સાથે વાત કરો

Markdown, કોડ હાઇલાઇટિંગ, ગણિત અને ઇમેજ એટેચમેન્ટ સાથે સ્ટ્રીમિંગ જવાબો. સંપાદિત કરો, ફરી જનરેટ કરો અને જવાબની આવૃત્તિઓ રાખો.

02 / ડ્યુઅલ

બે જવાબોની સરખામણી કરો

એક જ પ્રોમ્પ્ટ બે મોડેલને મોકલો અને બંને જવાબો સાથે સાથે વાંચો. ડ્યુઅલ કેવી રીતે કામ કરે છે

03 / ઓટો

બે મોડેલને વાત કરવા દો

બે મોડેલ, એક વિષય અને વારાની સંખ્યા પસંદ કરો, પછી તેમને એકબીજા સાથે ચર્ચા કરતા જુઓ.

+ / સબ-એજન્ટ

કામ સોંપો

મોડેલને વિનંતીના ભાગ સબ-એજન્ટને સોંપવા દો — દરેક પોતાનું મોડેલ વાપરી શકે — અને ચેટમાં તેમની પ્રગતિ જુઓ.

સુવિધાઓ

રોજિંદા કામ માટે બનેલું

લેખન, સારાંશ, અનુવાદ, કોડ અને ગણિત — સાચા સહાયકને જરૂરી સાધનો સાથે.

  • ઇમેજ, PDF અને ટેક્સ્ટ ફાઇલો જોડો (દરેક 10 MB સુધી)
  • વેબ સર્ચ, લોકલ Python અને ઇન્ટરેક્ટિવ ચાર્ટ (GenUI) સાધનો તરીકે
  • વોઇસ ડિક્ટેશન અને Safari તથા અન્ય એપ માટે શેર એક્સ્ટેન્શન
  • Shortcuts એક્શન, Spotlight સર્ચ અને ગુપ્ત વાતચીત
  • પ્રોજેક્ટ, ઇતિહાસ સર્ચ, મોડેલ પ્રીસેટ અને ટોકન વપરાશના આંકડા
  • iPad સ્પ્લિટ વ્યૂ અને ડાર્ક મોડ

કોના માટે

આ એપ કોના માટે છે

  • તમે પહેલેથી API કી કે ChatGPT પ્લાન માટે ચૂકવો છો અને તેના માટે નેટિવ iPhone અને iPad એપ ઇચ્છો છો.
  • તમે એક મોડેલના જવાબ પર ભરોસો કરતા પહેલા બીજા મોડેલ સાથે તેની ચકાસણી કરવા માંગો છો.
  • તમે એક ઉપર એક એમ અનેક AI સબ્સ્ક્રિપ્શન લેવાને બદલે વાપર્યા પ્રમાણે ચૂકવવાનું પસંદ કરો છો.
  • તમે OpenRouter કે અનેક પ્રોવાઇડર વાપરો છો અને તેમને એક જ જગ્યાએ જોવા માંગો છો.
  • તમે તમારો ચેટ ઇતિહાસ તમારા પોતાના ડિવાઇસ પર રાખવા માંગો છો.

માર્ગદર્શિકા

વધુ જાણો

AI મોડેલની સરખામણી કરોએક જ પ્રોમ્પ્ટ બે મોડેલને મોકલો અને બંને જવાબો સાથે સાથે વાંચો.તમારી પોતાની API કી વાપરોBYOK કેવી રીતે કામ કરે છે, તેનો ખર્ચ કેટલો છે અને તમારી કી ક્યાં સચવાય છે.સપોર્ટેડ પ્રોવાઇડરGemini, OpenRouter, ChatGPT પ્લાન, xAI, OpenAI, Anthropic અને વધુ.પ્રશ્નોકિંમત, જરૂરિયાતો, ગોપનીયતા અને સપોર્ટેડ મોડેલ.

તમે પહેલેથી જ વાપરો છો તે AI સાથે અજમાવો.
