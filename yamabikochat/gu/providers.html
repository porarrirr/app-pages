સપોર્ટેડ AI પ્રોવાઇડર

YamabikoChat નીચેની AI સેવાઓ સાથે તમારી પોતાની API કી કે એકાઉન્ટથી જોડાય છે. બિલ્ટ-ઇન પ્રોવાઇડર એપમાં સીધા સેટ થાય છે; વધુ ઘણા API પ્રોવાઇડર models.dev કેટલોગમાંથી આવે છે.

છેલ્લે અપડેટ: 2026-11-17

બિલ્ટ-ઇન પ્રોવાઇડર

પ્રોવાઇડર કેવી રીતે જોડાવું નોંધ
Google Gemini API કી Google AI Studioના Gemini મોડેલ
OpenRouter API કી એપમાં OpenRouterની મોડેલ ડિરેક્ટરી જુઓ
ChatGPT પ્લાન ChatGPTથી સાઇન ઇન કરો તમારા ChatGPT પ્લાનમાં સમાવિષ્ટ મોડેલ વાપરે છે
xAI તમારા xAI એકાઉન્ટથી સાઇન ઇન કરો તમારા એકાઉન્ટ માટે ઉપલબ્ધ Grok મોડેલ
Apple Intelligence બિલ્ટ-ઇન, કી વગર સપોર્ટેડ ઉપકરણો પર, ઉપકરણ પર જ અને Private Cloud Compute દ્વારા
Sarashina API કી SB Intuitionsના જાપાની ભાષાના મોડેલ
PLaMo API કી Preferred Networksના જાપાની ભાષાના મોડેલ; PLaMo 3.1 Prime પર વેબ સર્ચ
કસ્ટમ એન્ડપોઇન્ટ બેઝ URL + API કી OpenAI Chat Completions, OpenAI Responses, Anthropic Messages, Gemini અથવા Mistral ફોર્મેટ

models.dev કેટલોગમાંથી વધુ API પ્રોવાઇડર

YamabikoChat વધુ API પ્રોવાઇડર ઓફર કરવા માટે જાહેર models.dev કેટલોગ વાંચે છે, જેમાં OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq, xAI API, Moonshot AI (Kimi), MiniMax, Z.ai (GLM), Fireworks AI, Together AI અને Hugging Face જેવા પ્રોવાઇડરનો સમાવેશ થાય છે. સેટિંગ્સમાં API કી સાથે પ્રોવાઇડર ઉમેરો અને મોડેલ પસંદ કરો.

દરેક મોડેલ ત્યારે જ ચાલે છે જ્યારે તેનો API કરાર ચકાસાયેલો હોય. જે મોડેલ સુરક્ષિત રીતે ચાલી શકે નહીં તે સચોટ કારણ સાથે દેખાય પણ નિષ્ક્રિય રહે — એપ કદી પણ તમને ચૂપચાપ બીજા મોડેલ, એન્ડપોઇન્ટ કે પ્રોવાઇડર પર ખસેડતી નથી.

મોડેલ સાથે મળીને વાપરવા

દરેક જોડાયેલું મોડેલ ચેટમાં, બે જવાબની સરખામણી કરતા ડ્યુઅલ મોડમાં, અને બે મોડેલને વાત કરાવતી ઓટો વાતચીતમાં વાપરી શકાય છે. ઇમેજ ઇનપુટ, રીઝનિંગ સેટિંગ, સાધનો અને કોન્ટેક્સ્ટ લંબાઈ મોડેલ પર આધાર રાખે છે.

મોડેલની સૂચિ વારંવાર બદલાય છે. એપ હંમેશા દરેક પ્રોવાઇડરની વર્તમાન સૂચિ બતાવે છે. પ્રોવાઇડર અને ઉત્પાદનોના નામ તેમના માલિકોના ટ્રેડમાર્ક છે; YamabikoChat તેમની સાથે જોડાયેલું નથી.

સંબંધિત માર્ગદર્શિકાઓ

AI મોડેલની સરખામણી કરો એક જ પ્રોમ્પ્ટ બે મોડેલને મોકલો અને બંને જવાબો સાથે સાથે વાંચો. તમારી પોતાની API કી વાપરો BYOK કેવી રીતે કામ કરે છે, તેનો ખર્ચ કેટલો છે અને તમારી કી ક્યાં સચવાય છે. પ્રશ્નો કિંમત, જરૂરિયાતો, ગોપનીયતા અને સપોર્ટેડ મોડેલ.

તમે પહેલેથી જ વાપરો છો તે AI સાથે અજમાવો.
