FAQ

Često postavljana pitanja

Kratki odgovori o cijeni, API ključevima, podržanim modelima, privatnosti i sistemskim zahtjevima.

Posljednje ažuriranje: 2026-11-17

Je li YamabikoChat besplatan?

Da. YamabikoChat je besplatan za preuzimanje, bez oglasa, bez registracije i bez pretplata ili kupnje tokena u aplikaciji. AI pružatelju plaćate izravno za potrošnju koju ostvarite, prema cijenama i uvjetima tog pružatelja.

Trebam li API ključ?

Potreban vam je API ključ podržanog AI pružatelja ili prijava podržanim računom, poput ChatGPT plana ili xAI računa. Apple Intelligence radi bez ključa na uređajima koji ga podržavaju.

Mogu li koristiti svoju ChatGPT pretplatu umjesto API ključa?

Da. Veza s ChatGPT planom omogućuje prijavu vašim ChatGPT računom i korištenje modela uključenih u vaš plan, bez OpenAI API ključa.

Koje AI modele mogu koristiti?

Google Gemini, OpenRouter, ChatGPT plan, xAI, Apple Intelligence, Sarashina i PLaMo ugrađeni su. OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq i mnogi drugi API pružatelji dostupni su putem kataloga models.dev, a možete dodati i prilagođenu krajnju točku koja koristi podržani API format. Dostupni modeli ovise o pojedinom pružatelju.

Mogu li koristiti Claude sa svojim Anthropic API ključem?

Da. Dodajte Anthropic iz kataloga pružatelja sa svojim API ključem ili postavite prilagođenu krajnju točku koja koristi Anthropic Messages API.

Mogu li usporediti odgovore ChatGPT-a, Gemini i Claudea jedan uz drugi?

Da. Dual način šalje isti upit dvama modelima i prikazuje oba odgovora jedan uz drugi. Odaberite bilo koja dva modela kod pružatelja koje ste povezali.

Gdje se čuvaju moji razgovori i API ključevi?

Razgovori i postavke čuvaju se na vašem uređaju. API ključevi i pristupni tokeni čuvaju se u iOS privjesku za ključeve. Vaši upiti, kontekst razgovora i odabrani privici šalju se samo pružatelju kojeg ste odabrali.

Radi li YamabikoChat na iPadu?

Da. To je nativna aplikacija za iPhone i iPad, a na iPadu ima podijeljeni prikaz koji istodobno pokazuje popis razgovora i razgovor.

Koji su sistemski zahtjevi?

iOS 17 ili noviji na iPhoneu te iPadOS 17 ili noviji na iPadu. Apple Intelligence zahtijeva uređaj i verziju sustava koji ga podržavaju.

Je li YamabikoChat otvorenog koda?

Da. Izvorni kod objavljen je na GitHubu pod MIT licencom. Uključeni softver trećih strana zadržava vlastite licence.
