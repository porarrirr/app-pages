Podržani AI pružatelji

Više API pružatelja iz kataloga models.dev

YamabikoChat čita javni katalog models.dev kako bi ponudio mnogo više API pružatelja, uključujući OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq, xAI API, Moonshot AI (Kimi), MiniMax, Z.ai (GLM), Fireworks AI, Together AI i Hugging Face. Dodajte pružatelja u postavkama sa svojim API ključem i odaberite model.

Svaki model pokreće se samo kada je njegov API ugovor provjeren. Modeli koji se ne mogu sigurno pokrenuti ostaju vidljivi, ali onemogućeni, s točnim razlogom — aplikacija vas nikada ne prebacuje potiho na drugi model, krajnju točku ili pružatelja.

Korištenje modela zajedno

Svaki povezani model može se koristiti u chatu, u Dual načinu za usporedbu dvaju odgovora i u automatskom razgovoru u kojem dva modela razgovaraju. Unos slika, postavke rezoniranja, alati i duljina konteksta ovise o modelu.

Popisi modela često se mijenjaju. Aplikacija uvijek prikazuje aktualni popis za svakog pružatelja. Nazivi pružatelja i proizvoda zaštitni su znakovi njihovih vlasnika; YamabikoChat nije povezan s njima.
