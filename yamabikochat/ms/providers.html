Penyedia AI yang disokong

YamabikoChat bersambung ke perkhidmatan AI di bawah dengan kunci API atau akaun anda sendiri. Penyedia terbina dalam disediakan terus dalam aplikasi; banyak lagi penyedia API datang daripada katalog models.dev.

Lebih banyak penyedia API daripada katalog models.dev

YamabikoChat membaca katalog awam models.dev untuk menawarkan lebih banyak penyedia API, termasuk OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq, xAI API, Moonshot AI (Kimi), MiniMax, Z.ai (GLM), Fireworks AI, Together AI dan Hugging Face. Tambah penyedia dalam Tetapan dengan kunci API anda dan pilih model.

Setiap model hanya berjalan apabila kontrak API-nya disahkan. Model yang tidak dapat berjalan dengan selamat kekal kelihatan tetapi dilumpuhkan, dengan sebab yang tepat — aplikasi tidak pernah menukar anda secara senyap kepada model, titik akhir atau penyedia lain.

Menggunakan model bersama-sama

Setiap model yang disambungkan boleh digunakan dalam Sembang, dalam mod Dual untuk membandingkan dua jawapan, dan dalam Perbualan auto untuk membiarkan dua model bercakap. Input imej, tetapan penaakulan, alat dan panjang konteks bergantung pada model.

Senarai model sering berubah. Aplikasi sentiasa menunjukkan senarai semasa bagi setiap penyedia. Nama penyedia dan produk ialah tanda dagangan pemiliknya; YamabikoChat tidak mempunyai kaitan dengan mereka.
