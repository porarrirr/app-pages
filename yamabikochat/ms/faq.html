Soalan lazim

Soalan lazim

Jawapan ringkas tentang harga, kunci API, model yang disokong, privasi dan keperluan.

Kemas kini terakhir: 2026-11-17

Adakah YamabikoChat percuma?

Ya. YamabikoChat percuma untuk dimuat turun, tanpa iklan, tanpa pendaftaran, dan tanpa langganan atau pembelian token dalam aplikasi. Anda membayar penyedia AI anda secara terus untuk penggunaan yang anda jana, mengikut harga dan terma penyedia tersebut.

Adakah saya perlukan kunci API?

Anda memerlukan kunci API daripada penyedia AI yang disokong atau log masuk akaun yang disokong, seperti pelan ChatGPT atau xAI. Apple Intelligence berfungsi tanpa kunci pada peranti yang menyokongnya.

Bolehkah saya guna langganan ChatGPT dan bukannya kunci API?

Boleh. Sambungan pelan ChatGPT membolehkan anda log masuk dengan akaun ChatGPT dan menggunakan model yang termasuk dalam pelan anda, tanpa kunci API OpenAI.

Model AI apa yang boleh saya gunakan?

Google Gemini, OpenRouter, pelan ChatGPT, xAI, Apple Intelligence, Sarashina dan PLaMo sudah terbina dalam. OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq dan banyak lagi penyedia API tersedia melalui katalog models.dev, dan anda boleh menambah titik akhir tersuai yang menggunakan format API yang disokong. Model yang tersedia bergantung pada setiap penyedia.

Bolehkah saya guna Claude dengan kunci API Anthropic saya?

Boleh. Tambah Anthropic daripada katalog penyedia dengan kunci API anda, atau sediakan titik akhir tersuai yang menggunakan Anthropic Messages API.

Bolehkah saya bandingkan jawapan ChatGPT, Gemini dan Claude bersebelahan?

Boleh. Mod Dual menghantar gesaan yang sama kepada dua model dan memaparkan kedua-dua jawapan bersebelahan. Pilih mana-mana dua model daripada penyedia yang telah anda sambungkan.

Di mana perbualan dan kunci API saya disimpan?

Perbualan dan tetapan disimpan pada peranti anda. Kunci API dan token akses disimpan dalam Keychain iOS. Gesaan, konteks perbualan dan lampiran yang anda pilih hanya dihantar kepada penyedia yang anda pilih.

Adakah YamabikoChat berfungsi pada iPad?

Ya. Ia aplikasi asli untuk iPhone dan iPad, dengan Split View pada iPad yang memaparkan senarai perbualan dan sembang bersebelahan.

Apakah keperluan sistem?

iOS 17 atau lebih baru pada iPhone, dan iPadOS 17 atau lebih baru pada iPad. Apple Intelligence memerlukan peranti dan versi OS yang menyokongnya.

Adakah YamabikoChat sumber terbuka?

Ya. Kod sumber diterbitkan di GitHub di bawah MIT License. Perisian pihak ketiga yang disertakan mengekalkan lesennya sendiri.
