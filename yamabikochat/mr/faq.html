YamabikoChat मोफत आहे का?

हो. YamabikoChat डाउनलोड करणे मोफत आहे; जाहिराती नाहीत, नोंदणी नाही, आणि ॲपमध्ये सदस्यता किंवा टोकन खरेदी नाही. तुम्ही केलेल्या वापरासाठी तुम्ही त्या प्रोव्हायडरच्या किंमती आणि अटींनुसार प्रोव्हायडरला थेट पैसे देता.

मला API की लागते का?

तुम्हाला समर्थित AI प्रोव्हायडरकडून API की, किंवा ChatGPT प्लॅन किंवा xAI सारख्या समर्थित खात्याने साइन इन — यापैकी एकाची गरज आहे. Apple Intelligence समर्थन असलेल्या डिव्हाइसेसवर कीशिवाय चालते.

API कीऐवजी मी माझी ChatGPT सदस्यता वापरू शकतो का?

हो. ChatGPT प्लॅन कनेक्शनमुळे तुम्ही ChatGPT खात्याने साइन इन करून तुमच्या प्लॅनमध्ये समाविष्ट मॉडेल्स OpenAI API कीशिवाय वापरू शकता.

कोणती AI मॉडेल्स वापरता येतात?

Google Gemini, OpenRouter, ChatGPT प्लॅन, xAI, Apple Intelligence, Sarashina आणि PLaMo अंगभूत आहेत. OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq आणि इतर अनेक API प्रोव्हायडर models.dev कॅटलॉगमधून उपलब्ध आहेत, आणि समर्थित API स्वरूप वापरणारा कस्टम एंडपॉइंटही तुम्ही जोडू शकता. उपलब्ध मॉडेल्स प्रत्येक प्रोव्हायडरवर अवलंबून असतात.

माझ्या Anthropic API कीने मी Claude वापरू शकतो का?

हो. प्रोव्हायडर कॅटलॉगमधून Anthropic जोडा आणि तुमची API की द्या, किंवा Anthropic Messages API वापरणारा कस्टम एंडपॉइंट सेट करा.

ChatGPT, Gemini आणि Claude ची उत्तरे शेजारी शेजारी तुलना करता येतात का?

हो. ड्युअल मोड एकच प्रॉम्प्ट दोन मॉडेल्सना पाठवतो आणि दोन्ही उत्तरे शेजारी शेजारी दाखवतो. तुम्ही जोडलेल्या प्रोव्हायडरमधून कोणतीही दोन मॉडेल्स निवडा.

माझी संभाषणे आणि API की कुठे साठवली जातात?

संभाषणे आणि सेटिंग्ज तुमच्या डिव्हाइसवर साठवली जातात. API की आणि प्रवेश टोकन iOS Keychain मध्ये साठवली जातात. तुमचे प्रॉम्प्ट, संभाषणाचा संदर्भ आणि तुम्ही निवडलेली अटॅचमेंट्स फक्त तुम्ही निवडलेल्या प्रोव्हायडरला पाठवली जातात.

YamabikoChat iPad वर चालते का?

हो. हे iPhone आणि iPad साठीचे नेटिव्ह ॲप आहे, आणि iPad वर स्प्लिट व्ह्यूमध्ये संभाषणांची यादी आणि चॅट शेजारी शेजारी दिसतात.

सिस्टमच्या आवश्यकता काय आहेत?

iPhone वर iOS 17 किंवा नंतरची आवृत्ती आणि iPad वर iPadOS 17 किंवा नंतरची आवृत्ती. Apple Intelligence साठी ते समर्थन करणारे डिव्हाइस आणि OS आवृत्ती लागते.

YamabikoChat ओपन सोर्स आहे का?

हो. स्रोत कोड MIT License अंतर्गत GitHub वर प्रकाशित आहे. समाविष्ट तृतीय-पक्ष सॉफ्टवेअरचे स्वतःचे परवाने टिकून राहतात.
