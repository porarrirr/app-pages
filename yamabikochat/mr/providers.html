समर्थित AI प्रोव्हायडर

models.dev कॅटलॉगमधील अधिक API प्रोव्हायडर

YamabikoChat सार्वजनिक models.dev कॅटलॉग वाचते आणि त्यामुळे अधिक API प्रोव्हायडर उपलब्ध होतात — OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq, xAI API, Moonshot AI (Kimi), MiniMax, Z.ai (GLM), Fireworks AI, Together AI आणि Hugging Face यासह. सेटिंग्जमध्ये प्रोव्हायडर जोडा, तुमची API की द्या आणि मॉडेल निवडा.

प्रत्येक मॉडेल फक्त त्याचा API करार पडताळल्यावरच चालते. सुरक्षितपणे चालवता न येणारी मॉडेल्स नेमक्या कारणासह दिसतात पण बंद असतात — ॲप तुम्हाला कधीही गुपचूप दुसऱ्या मॉडेल, एंडपॉइंट किंवा प्रोव्हायडरवर हलवत नाही.

मॉडेल्स एकत्र वापरणे

जोडलेले प्रत्येक मॉडेल चॅटमध्ये, दोन उत्तरांची तुलना करण्यासाठी ड्युअल मोडमध्ये आणि दोन मॉडेल्सना बोलू देण्यासाठी ऑटो संभाषणात वापरता येते. इमेज इनपुट, रिजनिंग सेटिंग्ज, साधने आणि संदर्भ लांबी मॉडेलनुसार बदलतात.

मॉडेल्सची यादी वारंवार बदलते. ॲप प्रत्येक प्रोव्हायडरची सध्याची यादी नेहमी दाखवते. प्रोव्हायडर आणि उत्पादनांची नावे त्यांच्या मालकांची ट्रेडमार्क आहेत; YamabikoChat त्यांच्याशी संलग्न नाही.

संबंधित मार्गदर्शक

AI मॉडेल्सची तुलना कराएकच प्रॉम्प्ट दोन मॉडेल्सना पाठवा आणि दोन्ही उत्तरे शेजारी शेजारी वाचा.तुमची स्वतःची API की वापराBYOK कसे काम करते, खर्च किती येतो आणि तुमची की कशी साठवली जाते.प्रश्नोत्तरेकिंमत, आवश्यकता, गोपनीयता आणि समर्थित मॉडेल्स.

तुम्ही आधीच वापरत असलेल्या AI सोबत वापरून पाहा.
