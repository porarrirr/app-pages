स्वतःची की आणा

iPhone आणि iPad वर तुमच्या स्वतःच्या API की सह AI चॅट करा

YamabikoChat हा ब्रिंग-युअर-ओन-की (BYOK) क्लायंट आहे. तुम्ही API की जोडता — किंवा समर्थित खात्यात साइन इन करता — आणि ॲप तुमचे प्रॉम्प्ट थेट त्या प्रोव्हायडरकडे पाठवते. यामध्ये YamabikoChat ची सदस्यता किंवा टोकन विक्रेता नाही.

शेवटचे अद्यतन: 2026-11-17

“स्वतःची की आणा” म्हणजे काय

OpenAI, Google, Anthropic आणि OpenRouter सारखे AI प्रोव्हायडर आपल्या मॉडेल्सचा वापर API कींद्वारे विकतात आणि बहुतेकदा वापरानुसार बिल आकारतात. BYOK ॲप हा त्या कींसाठीचा क्लायंट आहे: तुम्ही प्रोव्हायडर खात्यात की तयार करता, ती ॲपमध्ये जोडता आणि प्रोव्हायडर तुम्ही वापरलेल्याचे बिल थेट तुम्हाला करतो.

स्वतःची की का वापरावी

  • वापरलेल्याचेच पैसे. कमी वापरणाऱ्यांचा खर्च बऱ्याचदा मासिक AI सदस्यतेपेक्षा कमी असतो; जास्त वापरणाऱ्यांना खर्च कुठून येतो हे नेमके दिसते.
  • मॉडेल निवडा. ॲपने ठरवलेली निश्चित यादी नाही, तर तुमचा प्रोव्हायडर देत असलेली मॉडेल्स वापरा.
  • एक ॲप, अनेक प्रोव्हायडर. Gemini, OpenRouter, OpenAI, Anthropic आणि इतर शेजारी शेजारी ठेवा आणि ड्युअल मोडमध्ये त्यांची तुलना करा.
  • तुमचा वापर पहा. टोकन वापराची आकडेवारी तुम्ही किती वापरता हे दाखवते.

सेटअप कसा करावा

  1. API की तयार करा तुमच्या प्रोव्हायडरच्या कन्सोलमध्ये — उदाहरणार्थ Gemini साठी Google AI Studio, OpenAI प्लॅटफॉर्म, Anthropic कन्सोल किंवा OpenRouter.
  2. YamabikoChat मधील सेटिंग्ज उघडा आणि कनेक्शन सेटिंग्जमध्ये प्रोव्हायडर निवडा.
  3. की पेस्ट करा. ती तुमच्या डिव्हाइसवरील iOS Keychain मध्ये साठवली जाते.
  4. मॉडेल निवडा आणि चॅट सुरू करा. ॲप जी मॉडेल्स सुरक्षितपणे चालवू शकत नाही, ती अंदाज न लावता कारणासह उपलब्ध नसल्याचे दाखवते.

API की नाही? साइन इन करा

  • ChatGPT प्लॅन — तुमच्या ChatGPT खात्याने साइन इन करून तुमच्या प्लॅनमध्ये समाविष्ट मॉडेल्स वापरा.
  • xAI — तुमच्या xAI खात्याने साइन इन करा.
  • Apple Intelligence — समर्थित डिव्हाइसेसवर, डिव्हाइसवरच किंवा Private Cloud Compute द्वारे, कोणत्याही कीशिवाय.

कस्टम एंडपॉइंट

तुमची सेवा यादीत नसेल, तर तिचा बेस URL आणि की देऊन कस्टम एंडपॉइंट जोडा आणि समर्थित API स्वरूपांपैकी एक निवडा: OpenAI Chat Completions, OpenAI Responses, Anthropic Messages, Gemini (Google Generative AI) किंवा Mistral.

खर्च किती येतो

ॲप मोफत आहे आणि त्यात इन-ॲप खरेदी नाही. तुमचा प्रोव्हायडर त्याच्या किंमती, मर्यादा आणि अटींनुसार वापराचे बिल करतो. ड्युअल मोड आणि ऑटो संभाषण दोन मॉडेल्सना विनंत्या पाठवतात, त्यामुळे दोन्हींचा वापर होतो.

सुरक्षा आणि गोपनीयता

  • API की आणि प्रवेश टोकन iOS Keychain मध्ये साठवली जातात आणि ॲप त्यांना आपल्या डायग्नोस्टिक लॉगमध्ये लिहू नयेत अशा पद्धतीने बनवले आहे.
  • प्रॉम्प्ट, संभाषणाचा संदर्भ आणि तुम्ही निवडलेली अटॅचमेंट्स फक्त तुम्ही निवडलेल्या प्रोव्हायडरला थेट पाठवली जातात.
  • संभाषणे तुमच्या डिव्हाइसवर साठवली जातात. ॲप क्रॉस-ॲप ट्रॅकिंग वापरत नाही. गोपनीयता धोरण पहा.

संबंधित मार्गदर्शक

AI मॉडेल्सची तुलना करा एकच प्रॉम्प्ट दोन मॉडेल्सना पाठवा आणि दोन्ही उत्तरे शेजारी शेजारी वाचा. समर्थित प्रोव्हायडर Gemini, OpenRouter, ChatGPT प्लॅन, xAI, OpenAI, Anthropic आणि अधिक. प्रश्नोत्तरे किंमत, आवश्यकता, गोपनीयता आणि समर्थित मॉडेल्स.

तुम्ही आधीच वापरत असलेल्या AI सोबत वापरून पाहा.
