Providers

Supported AI providers

YamabikoChat connects to the AI services below with your own API key or account. Built-in providers are set up directly in the app; many more API providers come from the models.dev catalogue.

Last updated: 2026-11-17

Built-in providers

Provider How you connect Notes
Google Gemini API key Gemini models from Google AI Studio
OpenRouter API key Browse OpenRouter's model directory in the app
ChatGPT plan Sign in with ChatGPT Uses the models included in your ChatGPT plan
xAI Sign in with your xAI account Grok models available to your account
Apple Intelligence Built in, no key On-device and Private Cloud Compute, on supported devices
Sarashina API key Japanese language models by SB Intuitions
PLaMo API key Japanese language models by Preferred Networks; web search on PLaMo 3.1 Prime
Custom endpoint Base URL + API key OpenAI Chat Completions, OpenAI Responses, Anthropic Messages, Gemini or Mistral format

More API providers from the models.dev catalogue

YamabikoChat reads the public models.dev catalogue to offer many more API providers, including OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq, xAI API, Moonshot AI (Kimi), MiniMax, Z.ai (GLM), Fireworks AI, Together AI and Hugging Face. Add the provider in Settings with your API key and pick a model.

Each model runs only when its API contract is verified. Models that can't run safely stay visible but disabled, with the exact reason — the app never silently switches you to a different model, endpoint or provider.

Using the models together

Every connected model can be used in Chat, in Dual mode to compare two answers, and in Auto conversation to let two models talk. Image input, reasoning settings, tools and context length depend on the model.

Model lists change often. The app always shows the current list for each provider. Provider and product names are trademarks of their owners; YamabikoChat is not affiliated with them.
