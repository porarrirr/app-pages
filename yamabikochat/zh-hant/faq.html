常見問題

關於價格、API 金鑰、支援的模型、隱私權與系統需求的簡短解答。

最後更新：2026-11-17

YamabikoChat 免費嗎？

是的。YamabikoChat 可免費下載，沒有廣告、無需註冊，App 內也沒有訂閱或 Token 購買。你產生的使用費用，需依供應商的定價與條款直接支付給 AI 供應商。

我需要 API 金鑰嗎？

你需要支援的 AI 供應商提供的 API 金鑰，或使用 ChatGPT 訂閱方案、xAI 等支援的帳號登入。在支援的裝置上，Apple Intelligence 不需要金鑰即可使用。

可以用 ChatGPT 訂閱取代 API 金鑰嗎？

可以。使用 ChatGPT 訂閱方案連線時，你可以用 ChatGPT 帳號登入，無需 OpenAI API 金鑰即可使用方案中包含的模型。

可以使用哪些 AI 模型？

內建 Google Gemini、OpenRouter、ChatGPT 訂閱方案、xAI、Apple Intelligence、Sarashina 與 PLaMo。OpenAI、Anthropic（Claude）、DeepSeek、Mistral、Groq 等眾多 API 供應商可透過 models.dev 目錄使用，也可以新增採用支援 API 格式的自訂端點。可用模型取決於各供應商。

可以用 Anthropic API 金鑰使用 Claude 嗎？

可以。在供應商目錄中新增 Anthropic 並提供 API 金鑰，或設定使用 Anthropic Messages API 的自訂端點。

可以並排比較 ChatGPT、Gemini 與 Claude 的回答嗎？

可以。比較模式會把同一個提示詞送給兩個模型，並排顯示兩個回答。你可以從已連接的供應商中任選兩個模型。

我的對話和 API 金鑰保存在哪裡？

對話與設定保存在你的裝置上，API 金鑰與存取權杖保存在 iOS 鑰匙圈中。你的提示詞、對話上下文和你選擇的附件只會傳送給你選定的供應商。

YamabikoChat 支援 iPad 嗎？

支援。它是為 iPhone 與 iPad 打造的原生 App，在 iPad 上支援分割顯示，可並排顯示對話列表與聊天。

系統需求是什麼？

iPhone 需要 iOS 17 或以上版本，iPad 需要 iPadOS 17 或以上版本。Apple Intelligence 需要支援它的裝置與作業系統版本。

YamabikoChat 是開放原始碼嗎？

是的。原始碼以 MIT License 在 GitHub 上發布。隨附的第三方軟體保留各自的授權條款。
