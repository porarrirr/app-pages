自備金鑰

在 iPhone 與 iPad 上使用自己的 API 金鑰進行 AI 聊天

YamabikoChat 是自備金鑰（BYOK）的用戶端。你加入 API 金鑰或登入支援的帳號，App 就會把提示詞直接送給該供應商。中間沒有 YamabikoChat 訂閱，也沒有 Token 轉售。

最後更新：2026-11-17

什麼是自備金鑰（BYOK）

OpenAI、Google、Anthropic 與 OpenRouter 等 AI 供應商透過 API 金鑰販售模型存取權，通常按用量計費。BYOK App 就是使用這些金鑰的用戶端：你在供應商帳號中建立金鑰、加入 App，供應商就會依你的實際用量直接向你收費。

為什麼要使用自己的金鑰

  • 用多少付多少。輕度使用者的花費通常低於每月 AI 訂閱；重度使用者則能清楚看到費用來自哪裡。
  • 自由選擇模型。使用供應商提供的模型，而不是 App 固定的模型清單。
  • 一個 App，多家供應商。把 Gemini、OpenRouter、OpenAI、Anthropic 等放在一起使用，並在比較模式中比較它們。
  • 查看用量。Token 用量統計會顯示你用了多少。

如何設定

  1. 建立 API 金鑰——在供應商的主控台建立，例如 Gemini 使用 Google AI Studio，此外還有 OpenAI 平台、Anthropic 主控台或 OpenRouter。
  2. 開啟 YamabikoChat 的設定，在連線設定中選擇供應商。
  3. 貼上金鑰。金鑰會保存在你裝置上的 iOS 鑰匙圈中。
  4. 選擇模型並開始對話。App 無法安全執行的模型會顯示為無法使用並附上原因，而不會被猜測著執行。

沒有 API 金鑰？改用帳號登入

  • ChatGPT 訂閱方案 — 使用 ChatGPT 帳號登入，即可使用方案中包含的模型。
  • xAI — 使用 xAI 帳號登入。
  • Apple Intelligence — 在支援的裝置上內建，可在裝置端或透過 Private Cloud Compute 執行，完全不需要金鑰。

自訂端點

如果你的服務不在清單中，可以用基礎 URL 和金鑰新增自訂端點，並選擇一種支援的 API 格式：OpenAI Chat Completions、OpenAI Responses、Anthropic Messages、Gemini（Google Generative AI）或 Mistral。

費用如何計算

App 免費，沒有 App 內購買。供應商會依其定價、限制與條款收取使用費用。比較模式與自動對話會向兩個模型送出請求，因此兩邊都會產生用量。

安全性與隱私權

  • API 金鑰與存取權杖保存在 iOS 鑰匙圈中，App 的設計不會將它們寫入診斷記錄。
  • 提示詞、對話上下文和你選擇的附件會直接傳送給你選擇的供應商。
  • 對話保存在你的裝置上。App 不進行跨 App 追蹤。詳情請參閱隱私權政策。
