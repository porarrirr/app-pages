支援的 AI 供應商

YamabikoChat 透過你自己的 API 金鑰或帳號連接下列 AI 服務。內建供應商可直接在 App 中設定；更多 API 供應商來自 models.dev 目錄。

最後更新：2026-11-17

內建供應商

供應商 連接方式 說明
Google Gemini API 金鑰 來自 Google AI Studio 的 Gemini 模型
OpenRouter API 金鑰 在 App 中瀏覽 OpenRouter 的模型目錄
ChatGPT 訂閱方案 使用 ChatGPT 登入 使用 ChatGPT 訂閱方案中包含的模型
xAI 使用 xAI 帳號登入 你的帳號可用的 Grok 模型
Apple Intelligence 內建，無需金鑰 在支援的裝置上，透過裝置端與 Private Cloud Compute 執行
Sarashina API 金鑰 SB Intuitions 的日語模型
PLaMo API 金鑰 Preferred Networks 的日語模型；PLaMo 3.1 Prime 支援網頁搜尋
自訂端點 基礎 URL + API 金鑰 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages、Gemini 或 Mistral 格式

來自 models.dev 目錄的更多 API 供應商

YamabikoChat 會讀取公開的 models.dev 目錄，以提供更多 API 供應商，包括 OpenAI、Anthropic（Claude）、DeepSeek、Mistral、Groq、xAI API、Moonshot AI（Kimi）、MiniMax、Z.ai（GLM）、Fireworks AI、Together AI 與 Hugging Face。在設定中新增供應商與 API 金鑰，然後選擇模型即可。

每個模型只有在 API 介面約定經過驗證時才會執行。無法安全執行的模型會保持可見但停用，並顯示確切原因——App 絕不會悄悄切換到其他模型、端點或供應商。

搭配使用模型

每個已連接的模型都能用於聊天、用於並排比較兩個回答的比較模式，以及讓兩個模型對話的自動對話。圖片輸入、推理設定、工具與上下文長度取決於個別模型。

模型清單經常變動。App 一律顯示各供應商的最新清單。供應商與產品名稱是其所有者的商標；YamabikoChat 與它們沒有關聯。
