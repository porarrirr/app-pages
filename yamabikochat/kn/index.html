ನಿಮ್ಮದೇ API ಕೀಯಲ್ಲಿ AI ಚಾಟ್. ಉತ್ತರಗಳನ್ನು ಹೋಲಿಸಿ.

YamabikoChat iPhone ಮತ್ತು iPad ಗಾಗಿ ಒಂದು ಉಚಿತ AI ಚಾಟ್ ಆ್ಯಪ್. ನೀವು ಈಗಾಗಲೇ ಬಳಸುತ್ತಿರುವ AI ಸೇವೆಗಳನ್ನು API ಕೀ ಅಥವಾ ಬೆಂಬಲಿತ ಖಾತೆಯಿಂದ ಸಂಪರ್ಕಿಸಿ — ಒಂದು ಮಾದರಿಯೊಂದಿಗೆ ಚಾಟ್ ಮಾಡಿ, ಎರಡು ಮಾದರಿಗಳನ್ನು ಅಕ್ಕಪಕ್ಕದಲ್ಲಿ ಹೋಲಿಸಿ, ಅಥವಾ ಎರಡು ಮಾದರಿಗಳು ಪರಸ್ಪರ ಮಾತನಾಡಲಿ.

ಬೆಲೆ
ಉಚಿತ. ಜಾಹೀರಾತು, ಸೈನ್-ಅಪ್, ಚಂದಾದಾರಿಕೆಗಳು ಅಥವಾ ಆ್ಯಪ್‌ನಲ್ಲಿ ಟೋಕನ್ ಖರೀದಿಗಳು ಇಲ್ಲ. ಪ್ರೊವೈಡರ್ ಬಳಕೆಗೆ ಪ್ರೊವೈಡರ್‌ನಿಂದಲೇ ಬಿಲ್ ಆಗುತ್ತದೆ.
AI ಸೇವೆಗಳು
Google Gemini, OpenRouter, ChatGPT ಪ್ಲಾನ್, xAI, Apple Intelligence, OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq, Sarashina, PLaMo, ಕಸ್ಟಮ್ ಎಂಡ್‌ಪಾಯಿಂಟ್‌ಗಳು ಮತ್ತು ಹೆಚ್ಚು — ಎಲ್ಲ ಪ್ರೊವೈಡರ್‌ಗಳನ್ನು ನೋಡಿ
ಮೋಡ್‌ಗಳು
ಚಾಟ್, ಡ್ಯುಯಲ್ (ಎರಡು ಮಾದರಿಗಳು ಅಕ್ಕಪಕ್ಕದಲ್ಲಿ) ಮತ್ತು ಆಟೋ ಸಂಭಾಷಣೆ (ಎರಡು ಮಾದರಿಗಳು ಪರಸ್ಪರ ಮಾತನಾಡುತ್ತವೆ), ಜೊತೆಗೆ ಕೆಲಸದ ಭಾಗಗಳನ್ನು ಹೊತ್ತುಕೊಳ್ಳುವ ಸಬ್‌ಏಜೆಂಟ್‌ಗಳು

ಮೋಡ್‌ಗಳು

ಮೂರು ಸಂಭಾಷಣಾ ಮೋಡ್‌ಗಳು, ಜೊತೆಗೆ ಸಬ್‌ಏಜೆಂಟ್‌ಗಳು

ಪ್ರಶ್ನೆಗೆ ಹೊಂದುವ ಮೋಡ್ ಆಯ್ಕೆಮಾಡಿ, ಮೋಡ್‌ಗೆ ಹೊಂದುವ ಪ್ರಶ್ನೆಯಲ್ಲ.

01 / ಚಾಟ್

ಒಂದು ಮಾದರಿಯೊಂದಿಗೆ ಮಾತನಾಡಿ

Markdown, ಕೋಡ್ ಹೈಲೈಟಿಂಗ್, ಗಣಿತ ಮತ್ತು ಚಿತ್ರ ಲಗತ್ತುಗಳೊಂದಿಗೆ ಸ್ಟ್ರೀಮಿಂಗ್ ಉತ್ತರಗಳು. ಸಂಪಾದಿಸಿ, ಮತ್ತೆ ರಚಿಸಿ, ಉತ್ತರ ರೂಪಾಂತರಗಳನ್ನು ಉಳಿಸಿಕೊಳ್ಳಿ.

02 / ಡ್ಯುಯಲ್

ಎರಡು ಉತ್ತರಗಳನ್ನು ಹೋಲಿಸಿ

ಒಂದೇ ಪ್ರಾಂಪ್ಟ್ ಅನ್ನು ಎರಡು ಮಾದರಿಗಳಿಗೆ ಕಳುಹಿಸಿ, ಎರಡೂ ಉತ್ತರಗಳನ್ನು ಅಕ್ಕಪಕ್ಕದಲ್ಲಿ ಓದಿ. ಡ್ಯುಯಲ್ ಹೇಗೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ

03 / ಆಟೋ

ಎರಡು ಮಾದರಿಗಳು ಮಾತನಾಡಲಿ

ಎರಡು ಮಾದರಿಗಳು, ಒಂದು ವಿಷಯ ಮತ್ತು ಎಷ್ಟು ಸುತ್ತುಗಳು ಎಂದು ಆಯ್ಕೆಮಾಡಿ, ನಂತರ ಅವು ಪರಸ್ಪರ ಚರ್ಚಿಸುವುದನ್ನು ನೋಡಿ.

+ / ಸಬ್‌ಏಜೆಂಟ್‌ಗಳು

ಕೆಲಸವನ್ನು ವಹಿಸಿ

ಮಾದರಿಯು ವಿನಂತಿಯ ಕೆಲವು ಭಾಗಗಳನ್ನು ಸಬ್‌ಏಜೆಂಟ್‌ಗಳಿಗೆ ವಹಿಸಲಿ — ಪ್ರತಿಯೊಂದೂ ತನ್ನದೇ ಮಾದರಿ ಬಳಸಬಹುದು — ಅವುಗಳ ಪ್ರಗತಿಯನ್ನು ಚಾಟ್‌ನಲ್ಲಿ ಅನುಸರಿಸಿ.

ವೈಶಿಷ್ಟ್ಯಗಳು

ದಿನನಿತ್ಯದ ಕೆಲಸಕ್ಕಾಗಿ ನಿರ್ಮಿಸಲಾಗಿದೆ

ಬರವಣಿಗೆ, ಸಾರಾಂಶ, ಅನುವಾದ, ಕೋಡ್ ಮತ್ತು ಗಣಿತ — ನಿಜವಾದ ಸಹಾಯಕನಿಗೆ ಬೇಕಾದ ಪರಿಕರಗಳೊಂದಿಗೆ.

  • ಚಿತ್ರಗಳು, PDF ಮತ್ತು ಪಠ್ಯ ಫೈಲ್‌ಗಳನ್ನು ಲಗತ್ತಿಸಿ (ಪ್ರತಿಯೊಂದೂ 10 MB ವರೆಗೆ)
  • ವೆಬ್ ಹುಡುಕಾಟ, ಸ್ಥಳೀಯ Python ಮತ್ತು ಸಂವಾದಾತ್ಮಕ ಚಾರ್ಟ್‌ಗಳು (GenUI) ಪರಿಕರಗಳಾಗಿ
  • ಧ್ವನಿ ಡಿಕ್ಟೇಷನ್ ಮತ್ತು Safari ಸೇರಿದಂತೆ ಇತರ ಆ್ಯಪ್‌ಗಳಿಗಾಗಿ ಶೇರ್ ಎಕ್ಸ್‌ಟೆನ್ಷನ್
  • ಶಾರ್ಟ್‌ಕಟ್‌ಗಳ ಕ್ರಿಯೆಗಳು, Spotlight ಹುಡುಕಾಟ ಮತ್ತು ರಹಸ್ಯ ಸಂಭಾಷಣೆಗಳು
  • ಪ್ರಾಜೆಕ್ಟ್‌ಗಳು, ಇತಿಹಾಸ ಹುಡುಕಾಟ, ಮಾದರಿ ಪ್ರೀಸೆಟ್‌ಗಳು ಮತ್ತು ಟೋಕನ್ ಬಳಕೆಯ ಅಂಕಿಅಂಶಗಳು
  • iPad ಸ್ಪ್ಲಿಟ್ ವ್ಯೂ ಮತ್ತು ಡಾರ್ಕ್ ಮೋಡ್

ಯಾರಿಗಾಗಿ

ಯಾರಿಗಾಗಿ

  • ನೀವು ಈಗಾಗಲೇ API ಕೀ ಅಥವಾ ChatGPT ಪ್ಲಾನ್‌ಗೆ ಪಾವತಿಸುತ್ತಿದ್ದೀರಿ ಮತ್ತು ಅದಕ್ಕೆ ಸ್ಥಳೀಯ iPhone ಹಾಗೂ iPad ಆ್ಯಪ್ ಬೇಕು.
  • ಒಂದು ಮಾದರಿಯ ಉತ್ತರವನ್ನು ನಂಬುವ ಮೊದಲು ಇನ್ನೊಂದರೊಂದಿಗೆ ಹೋಲಿಸಿ ನೋಡಲು ಬಯಸುತ್ತೀರಿ.
  • ಹಲವು AI ಚಂದಾದಾರಿಕೆಗಳನ್ನು ಜೋಡಿಸುವ ಬದಲು ಬಳಸಿದಷ್ಟಕ್ಕೆ ಪಾವತಿಸಲು ಇಷ್ಟಪಡುತ್ತೀರಿ.
  • ನೀವು OpenRouter ಅಥವಾ ಹಲವು ಪ್ರೊವೈಡರ್‌ಗಳನ್ನು ಬಳಸುತ್ತೀರಿ ಮತ್ತು ಅವು ಒಂದೇ ಕಡೆ ಬೇಕು.
  • ನಿಮ್ಮ ಚಾಟ್ ಇತಿಹಾಸ ನಿಮ್ಮದೇ ಸಾಧನದಲ್ಲಿ ಇರಬೇಕೆಂದು ಬಯಸುತ್ತೀರಿ.

ಮಾರ್ಗದರ್ಶಿಗಳು

ಇನ್ನಷ್ಟು ತಿಳಿಯಿರಿ

AI ಮಾದರಿಗಳನ್ನು ಹೋಲಿಸಿ ಒಂದೇ ಪ್ರಾಂಪ್ಟ್ ಅನ್ನು ಎರಡು ಮಾದರಿಗಳಿಗೆ ಕಳುಹಿಸಿ, ಎರಡೂ ಉತ್ತರಗಳನ್ನು ಅಕ್ಕಪಕ್ಕದಲ್ಲಿ ಓದಿ. ನಿಮ್ಮದೇ API ಕೀ ಬಳಸಿ BYOK ಹೇಗೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ, ಎಷ್ಟು ಖರ್ಚಾಗುತ್ತದೆ, ನಿಮ್ಮ ಕೀ ಎಲ್ಲಿ ಸಂಗ್ರಹವಾಗುತ್ತದೆ. ಬೆಂಬಲಿತ ಪ್ರೊವೈಡರ್‌ಗಳು Gemini, OpenRouter, ChatGPT ಪ್ಲಾನ್, xAI, OpenAI, Anthropic ಮತ್ತು ಹೆಚ್ಚು. ಪ್ರಶ್ನೋತ್ತರ ಬೆಲೆ, ಅಗತ್ಯತೆಗಳು, ಗೋಪ್ಯತೆ ಮತ್ತು ಬೆಂಬಲಿತ ಮಾದರಿಗಳು.

ನೀವು ಈಗಾಗಲೇ ಬಳಸುತ್ತಿರುವ AI ಯೊಂದಿಗೆ ಪ್ರಯತ್ನಿಸಿ.
