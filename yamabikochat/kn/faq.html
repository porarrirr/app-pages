ಪದೇ ಪದೇ ಕೇಳುವ ಪ್ರಶ್ನೆಗಳು

ಬೆಲೆ, API ಕೀಗಳು, ಬೆಂಬಲಿತ ಮಾದರಿಗಳು, ಗೋಪ್ಯತೆ ಮತ್ತು ಅಗತ್ಯತೆಗಳ ಬಗ್ಗೆ ಚಿಕ್ಕ ಉತ್ತರಗಳು.

ಕೊನೆಯದಾಗಿ ನವೀಕರಿಸಲಾಗಿದೆ: 2026-11-17

YamabikoChat ಉಚಿತವೇ?

ಹೌದು. YamabikoChat ಡೌನ್‌ಲೋಡ್ ಉಚಿತ — ಜಾಹೀರಾತು ಇಲ್ಲ, ಸೈನ್-ಅಪ್ ಇಲ್ಲ, ಆ್ಯಪ್‌ನಲ್ಲಿ ಚಂದಾದಾರಿಕೆಗಳು ಅಥವಾ ಟೋಕನ್ ಖರೀದಿಗಳು ಇಲ್ಲ. ನೀವು ಮಾಡುವ ಬಳಕೆಗೆ ಆ ಪ್ರೊವೈಡರ್‌ನ ಬೆಲೆ ಮತ್ತು ನಿಯಮಗಳ ಪ್ರಕಾರ ನಿಮ್ಮ AI ಪ್ರೊವೈಡರ್‌ಗೆ ನೇರವಾಗಿ ಪಾವತಿಸುತ್ತೀರಿ.

ನನಗೆ API ಕೀ ಬೇಕೇ?

ಬೆಂಬಲಿತ AI ಪ್ರೊವೈಡರ್‌ನಿಂದ API ಕೀ ಅಥವಾ ಬೆಂಬಲಿತ ಖಾತೆ ಸೈನ್-ಇನ್ (ಉದಾ. ChatGPT ಪ್ಲಾನ್ ಅಥವಾ xAI) ಬೇಕು. Apple Intelligence ಬೆಂಬಲಿತ ಸಾಧನಗಳಲ್ಲಿ ಕೀ ಇಲ್ಲದೆಯೇ ಕೆಲಸ ಮಾಡುತ್ತದೆ.

API ಕೀ ಬದಲು ನನ್ನ ChatGPT ಚಂದಾದಾರಿಕೆ ಬಳಸಬಹುದೇ?

ಹೌದು. ChatGPT ಪ್ಲಾನ್ ಸಂಪರ್ಕದ ಮೂಲಕ ನಿಮ್ಮ ChatGPT ಖಾತೆಯಿಂದ ಸೈನ್-ಇನ್ ಮಾಡಿ, OpenAI API ಕೀ ಇಲ್ಲದೆಯೇ ನಿಮ್ಮ ಪ್ಲಾನ್‌ನಲ್ಲಿರುವ ಮಾದರಿಗಳನ್ನು ಬಳಸಬಹುದು.

ಯಾವ AI ಮಾದರಿಗಳನ್ನು ಬಳಸಬಹುದು?

Google Gemini, OpenRouter, ChatGPT ಪ್ಲಾನ್, xAI, Apple Intelligence, Sarashina ಮತ್ತು PLaMo ಆ್ಯಪ್‌ನಲ್ಲಿ ಒಳಗೊಂಡಿವೆ. OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq ಮತ್ತು ಇತರ API ಪ್ರೊವೈಡರ್‌ಗಳು models.dev ಕ್ಯಾಟಲಾಗ್ ಮೂಲಕ ಲಭ್ಯವಿವೆ, ಜೊತೆಗೆ ಬೆಂಬಲಿತ API ಸ್ವರೂಪ ಬಳಸುವ ಕಸ್ಟಮ್ ಎಂಡ್‌ಪಾಯಿಂಟ್ ಸೇರಿಸಬಹುದು. ಲಭ್ಯವಿರುವ ಮಾದರಿಗಳು ಪ್ರತಿ ಪ್ರೊವೈಡರ್ ಅನ್ನು ಅವಲಂಬಿಸಿವೆ.

ನನ್ನ Anthropic API ಕೀಯೊಂದಿಗೆ Claude ಬಳಸಬಹುದೇ?

ಹೌದು. ಪ್ರೊವೈಡರ್ ಕ್ಯಾಟಲಾಗ್‌ನಿಂದ Anthropic ಅನ್ನು ನಿಮ್ಮ API ಕೀಯೊಂದಿಗೆ ಸೇರಿಸಿ, ಅಥವಾ Anthropic Messages API ಬಳಸುವ ಕಸ್ಟಮ್ ಎಂಡ್‌ಪಾಯಿಂಟ್ ಸೆಟಪ್ ಮಾಡಿ.

ChatGPT, Gemini, Claude ಉತ್ತರಗಳನ್ನು ಅಕ್ಕಪಕ್ಕದಲ್ಲಿ ಹೋಲಿಸಬಹುದೇ?

ಹೌದು. ಡ್ಯುಯಲ್ ಮೋಡ್ ಒಂದೇ ಪ್ರಾಂಪ್ಟ್ ಅನ್ನು ಎರಡು ಮಾದರಿಗಳಿಗೆ ಕಳುಹಿಸಿ ಎರಡೂ ಉತ್ತರಗಳನ್ನು ಅಕ್ಕಪಕ್ಕದಲ್ಲಿ ತೋರಿಸುತ್ತದೆ. ನೀವು ಸಂಪರ್ಕಿಸಿದ ಪ್ರೊವೈಡರ್‌ಗಳಿಂದ ಯಾವುದೇ ಎರಡು ಮಾದರಿಗಳನ್ನು ಆಯ್ಕೆಮಾಡಿ.

ನನ್ನ ಸಂಭಾಷಣೆಗಳು ಮತ್ತು API ಕೀಗಳು ಎಲ್ಲಿ ಸಂಗ್ರಹವಾಗುತ್ತವೆ?

ಸಂಭಾಷಣೆಗಳು ಮತ್ತು ಸೆಟ್ಟಿಂಗ್‌ಗಳು ನಿಮ್ಮ ಸಾಧನದಲ್ಲಿ ಸಂಗ್ರಹವಾಗುತ್ತವೆ. API ಕೀಗಳು ಮತ್ತು ಆಕ್ಸೆಸ್ ಟೋಕನ್‌ಗಳು iOS ಕೀಚೇನ್‌ನಲ್ಲಿ ಇರುತ್ತವೆ. ನಿಮ್ಮ ಪ್ರಾಂಪ್ಟ್‌ಗಳು, ಸಂಭಾಷಣಾ ಸಂದರ್ಭ ಮತ್ತು ನೀವು ಆಯ್ಕೆಮಾಡುವ ಲಗತ್ತುಗಳು ನೀವು ಆಯ್ಕೆಮಾಡಿದ ಪ್ರೊವೈಡರ್‌ಗೆ ಮಾತ್ರ ಕಳುಹಿಸಲಾಗುತ್ತವೆ.

YamabikoChat iPad ನಲ್ಲಿ ಕೆಲಸ ಮಾಡುತ್ತದೆಯೇ?

ಹೌದು. ಇದು iPhone ಮತ್ತು iPad ಗಾಗಿ ಸ್ಥಳೀಯ ಆ್ಯಪ್; iPad ನಲ್ಲಿ ನಿಮ್ಮ ಸಂಭಾಷಣೆಗಳ ಪಟ್ಟಿ ಮತ್ತು ಚಾಟ್ ಅನ್ನು ಅಕ್ಕಪಕ್ಕದಲ್ಲಿ ತೋರಿಸುವ ಸ್ಪ್ಲಿಟ್ ವ್ಯೂ ಇದೆ.

ಸಿಸ್ಟಂ ಅಗತ್ಯತೆಗಳು ಯಾವುವು?

iPhone ನಲ್ಲಿ iOS 17 ಅಥವಾ ನಂತರ, iPad ನಲ್ಲಿ iPadOS 17 ಅಥವಾ ನಂತರ. Apple Intelligence ಗೆ ಅದನ್ನು ಬೆಂಬಲಿಸುವ ಸಾಧನ ಮತ್ತು OS ಆವೃತ್ತಿ ಬೇಕು.

YamabikoChat ಓಪನ್ ಸೋರ್ಸ್ ಆಗಿದೆಯೇ?

ಹೌದು. ಸೋರ್ಸ್ ಕೋಡ್ GitHub ನಲ್ಲಿ MIT License ಅಡಿಯಲ್ಲಿ ಪ್ರಕಟವಾಗಿದೆ. ಒಳಗೊಂಡಿರುವ ಮೂರನೇ ವ್ಯಕ್ತಿಯ ಸಾಫ್ಟ್‌ವೇರ್ ತನ್ನದೇ ಪರವಾನಗಿಗಳನ್ನು ಉಳಿಸಿಕೊಳ್ಳುತ್ತದೆ.

ಇನ್ನೂ ಪ್ರಶ್ನೆ ಇದೆಯೇ? ಸಹಾಯ ನೋಡಿ.
