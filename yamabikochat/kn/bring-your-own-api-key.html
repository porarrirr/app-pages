ನಿಮ್ಮ ಕೀ ನೀವೇ ತನ್ನಿ

iPhone ಮತ್ತು iPad ನಲ್ಲಿ AI ಚಾಟ್‌ಗೆ ನಿಮ್ಮದೇ API ಕೀ ಬಳಸಿ

YamabikoChat ಒಂದು ಬ್ರಿಂಗ್-ಯುವರ್-ಓನ್-ಕೀ (BYOK) ಕ್ಲೈಂಟ್. ನೀವು API ಕೀ ಸೇರಿಸಿ — ಅಥವಾ ಬೆಂಬಲಿತ ಖಾತೆಗೆ ಸೈನ್-ಇನ್ ಆಗಿ — ಆ್ಯಪ್ ನಿಮ್ಮ ಪ್ರಾಂಪ್ಟ್‌ಗಳನ್ನು ನೇರವಾಗಿ ಆ ಪ್ರೊವೈಡರ್‌ಗೆ ಕಳುಹಿಸುತ್ತದೆ. ಮಧ್ಯದಲ್ಲಿ YamabikoChat ಚಂದಾದಾರಿಕೆ ಅಥವಾ ಟೋಕನ್ ಮರುಮಾರಾಟಗಾರ ಇಲ್ಲ.

ಕೊನೆಯದಾಗಿ ನವೀಕರಿಸಲಾಗಿದೆ: 2026-11-17

“ನಿಮ್ಮದೇ ಕೀ ತನ್ನಿ” ಎಂದರೆ ಏನು

OpenAI, Google, Anthropic ಮತ್ತು OpenRouter ನಂತಹ AI ಪ್ರೊವೈಡರ್‌ಗಳು ತಮ್ಮ ಮಾದರಿಗಳಿಗೆ API ಕೀಗಳ ಮೂಲಕ ಪ್ರವೇಶ ನೀಡುತ್ತವೆ, ಸಾಮಾನ್ಯವಾಗಿ ಬಳಕೆಗೆ ಅನುಗುಣವಾಗಿ ಬಿಲ್ ಮಾಡುತ್ತವೆ. BYOK ಆ್ಯಪ್ ಆ ಕೀಗಳಿಗೆ ಒಂದು ಕ್ಲೈಂಟ್: ನೀವು ನಿಮ್ಮ ಪ್ರೊವೈಡರ್ ಖಾತೆಯಲ್ಲಿ ಕೀ ರಚಿಸಿ, ಅದನ್ನು ಆ್ಯಪ್‌ಗೆ ಸೇರಿಸಿ, ನೀವು ಬಳಸಿದ್ದಕ್ಕೆ ಪ್ರೊವೈಡರ್ ನೇರವಾಗಿ ನಿಮಗೆ ಬಿಲ್ ಮಾಡುತ್ತದೆ.

ನಿಮ್ಮದೇ ಕೀ ಏಕೆ ಬಳಸಬೇಕು

  • ಬಳಸಿದ್ದಕ್ಕೆ ಪಾವತಿಸಿ. ಕಡಿಮೆ ಬಳಸುವವರು ಮಾಸಿಕ AI ಚಂದಾದಾರಿಕೆಗಿಂತ ಕಡಿಮೆ ಖರ್ಚು ಮಾಡಬಹುದು; ಹೆಚ್ಚು ಬಳಸುವವರು ಖರ್ಚು ಎಲ್ಲಿಂದ ಬರುತ್ತದೆ ಎಂದು ಸ್ಪಷ್ಟವಾಗಿ ನೋಡಬಹುದು.
  • ಮಾದರಿ ಆಯ್ಕೆಮಾಡಿ. ಆ್ಯಪ್ ಆಯ್ಕೆ ಮಾಡಿದ ಸ್ಥಿರ ಪಟ್ಟಿಯನ್ನಲ್ಲ, ನಿಮ್ಮ ಪ್ರೊವೈಡರ್ ನೀಡುವ ಮಾದರಿಗಳನ್ನು ಬಳಸಿ.
  • ಒಂದು ಆ್ಯಪ್, ಹಲವು ಪ್ರೊವೈಡರ್‌ಗಳು. Gemini, OpenRouter, OpenAI, Anthropic ಮುಂತಾದವನ್ನು ಅಕ್ಕಪಕ್ಕದಲ್ಲಿ ಇರಿಸಿಕೊಂಡು, ಡ್ಯುಯಲ್ ಮೋಡ್‌ನಲ್ಲಿ ಹೋಲಿಸಿ ನೋಡಿ.
  • ನಿಮ್ಮ ಬಳಕೆ ನೋಡಿ. ಟೋಕನ್ ಬಳಕೆಯ ಅಂಕಿಅಂಶಗಳು ನೀವು ಎಷ್ಟು ಬಳಸುತ್ತೀರಿ ಎಂದು ತೋರಿಸುತ್ತವೆ.

ಹೇಗೆ ಸೆಟಪ್ ಮಾಡಬೇಕು

  1. API ಕೀ ರಚಿಸಿ — ನಿಮ್ಮ ಪ್ರೊವೈಡರ್ ಕನ್ಸೋಲ್‌ನಲ್ಲಿ. ಉದಾಹರಣೆಗೆ Gemini ಗಾಗಿ Google AI Studio, OpenAI ಪ್ಲಾಟ್‌ಫಾರ್ಮ್, Anthropic ಕನ್ಸೋಲ್ ಅಥವಾ OpenRouter.
  2. YamabikoChat ನಲ್ಲಿ ಸೆಟ್ಟಿಂಗ್‌ಗಳನ್ನು ತೆರೆಯಿರಿ ಮತ್ತು ಸಂಪರ್ಕ ಸೆಟ್ಟಿಂಗ್‌ಗಳಲ್ಲಿ ಪ್ರೊವೈಡರ್ ಆಯ್ಕೆಮಾಡಿ.
  3. ಕೀಯನ್ನು ಅಂಟಿಸಿ. ಅದು ನಿಮ್ಮ ಸಾಧನದ iOS ಕೀಚೇನ್‌ನಲ್ಲಿ ಉಳಿಯುತ್ತದೆ.
  4. ಮಾದರಿ ಆಯ್ಕೆಮಾಡಿ ಚಾಟ್ ಆರಂಭಿಸಿ. ಆ್ಯಪ್ ಸುರಕ್ಷಿತವಾಗಿ ಚಲಾಯಿಸಲಾಗದ ಮಾದರಿಗಳನ್ನು ಊಹಿಸದೆ, ಕಾರಣದೊಂದಿಗೆ ಲಭ್ಯವಿಲ್ಲ ಎಂದು ತೋರಿಸುತ್ತದೆ.

API ಕೀ ಇಲ್ಲವೇ? ಸೈನ್-ಇನ್ ಮಾಡಿ

  • ChatGPT ಪ್ಲಾನ್ — ನಿಮ್ಮ ಪ್ಲಾನ್‌ನಲ್ಲಿರುವ ಮಾದರಿಗಳನ್ನು ಬಳಸಲು ನಿಮ್ಮ ChatGPT ಖಾತೆಯಿಂದ ಸೈನ್-ಇನ್ ಮಾಡಿ.
  • xAI — ನಿಮ್ಮ xAI ಖಾತೆಯಿಂದ ಸೈನ್-ಇನ್ ಮಾಡಿ.
  • Apple Intelligence — ಬೆಂಬಲಿತ ಸಾಧನಗಳಲ್ಲಿ, ಸಾಧನದಲ್ಲೇ ಅಥವಾ Private Cloud Compute ಮೂಲಕ, ಕೀ ಇಲ್ಲದೆಯೇ ಲಭ್ಯ.

ಕಸ್ಟಮ್ ಎಂಡ್‌ಪಾಯಿಂಟ್‌ಗಳು

ನಿಮ್ಮ ಸೇವೆ ಪಟ್ಟಿಯಲ್ಲಿಲ್ಲದಿದ್ದರೆ, ಅದರ ಬೇಸ್ URL ಮತ್ತು ಕೀಯೊಂದಿಗೆ ಕಸ್ಟಮ್ ಎಂಡ್‌ಪಾಯಿಂಟ್ ಸೇರಿಸಿ, ಬೆಂಬಲಿತ API ಸ್ವರೂಪಗಳಲ್ಲಿ ಒಂದನ್ನು ಆಯ್ಕೆಮಾಡಿ: OpenAI Chat Completions, OpenAI Responses, Anthropic Messages, Gemini (Google Generative AI) ಅಥವಾ Mistral.

ಖರ್ಚು ಎಷ್ಟು

ಆ್ಯಪ್ ಉಚಿತ, ಆ್ಯಪ್‌ನೊಳಗಿನ ಖರೀದಿಗಳಿಲ್ಲ. ನಿಮ್ಮ ಪ್ರೊವೈಡರ್ ತಮ್ಮ ಬೆಲೆ, ಮಿತಿಗಳು ಮತ್ತು ನಿಯಮಗಳ ಪ್ರಕಾರ ಬಳಕೆಗೆ ಶುಲ್ಕ ವಿಧಿಸುತ್ತದೆ. ಡ್ಯುಯಲ್ ಮೋಡ್ ಮತ್ತು ಆಟೋ ಸಂಭಾಷಣೆ ಎರಡೂ ಮಾದರಿಗಳಿಗೆ ವಿನಂತಿಗಳನ್ನು ಕಳುಹಿಸುತ್ತವೆ, ಹಾಗಾಗಿ ಎರಡರಲ್ಲೂ ಬಳಕೆ ಉಂಟಾಗುತ್ತದೆ.

ಭದ್ರತೆ ಮತ್ತು ಗೋಪ್ಯತೆ

  • API ಕೀಗಳು ಮತ್ತು ಆಕ್ಸೆಸ್ ಟೋಕನ್‌ಗಳು iOS ಕೀಚೇನ್‌ನಲ್ಲಿ ಸಂಗ್ರಹವಾಗುತ್ತವೆ, ಆ್ಯಪ್ ಅವನ್ನು ತನ್ನ ಡಯಾಗ್ನಸ್ಟಿಕ್ ಲಾಗ್‌ಗಳಲ್ಲಿ ಬರೆಯದಂತೆ ವಿನ್ಯಾಸಗೊಳಿಸಲಾಗಿದೆ.
  • ಪ್ರಾಂಪ್ಟ್‌ಗಳು, ಸಂಭಾಷಣಾ ಸಂದರ್ಭ ಮತ್ತು ನೀವು ಆಯ್ಕೆಮಾಡುವ ಲಗತ್ತುಗಳು ನೇರವಾಗಿ ನೀವು ಆಯ್ಕೆಮಾಡಿದ ಪ್ರೊವೈಡರ್‌ಗೆ ಕಳುಹಿಸಲಾಗುತ್ತವೆ.
  • ಸಂಭಾಷಣೆಗಳು ನಿಮ್ಮ ಸಾಧನದಲ್ಲಿ ಸಂಗ್ರಹವಾಗುತ್ತವೆ. ಆ್ಯಪ್ ಆ್ಯಪ್‌ಗಳ ನಡುವಿನ ಟ್ರ್ಯಾಕಿಂಗ್ ಬಳಸುವುದಿಲ್ಲ. ಗೋಪ್ಯತಾ ನೀತಿ ನೋಡಿ.

ಸಂಬಂಧಿತ ಮಾರ್ಗದರ್ಶಿಗಳು

AI ಮಾದರಿಗಳನ್ನು ಹೋಲಿಸಿ ಒಂದೇ ಪ್ರಾಂಪ್ಟ್ ಅನ್ನು ಎರಡು ಮಾದರಿಗಳಿಗೆ ಕಳುಹಿಸಿ, ಎರಡೂ ಉತ್ತರಗಳನ್ನು ಅಕ್ಕಪಕ್ಕದಲ್ಲಿ ಓದಿ. ಬೆಂಬಲಿತ ಪ್ರೊವೈಡರ್‌ಗಳು Gemini, OpenRouter, ChatGPT ಪ್ಲಾನ್, xAI, OpenAI, Anthropic ಮತ್ತು ಹೆಚ್ಚು. ಪ್ರಶ್ನೋತ್ತರ ಬೆಲೆ, ಅಗತ್ಯತೆಗಳು, ಗೋಪ್ಯತೆ ಮತ್ತು ಬೆಂಬಲಿತ ಮಾದರಿಗಳು.
