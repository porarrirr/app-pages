ಬೆಂಬಲಿತ AI ಪ್ರೊವೈಡರ್‌ಗಳು

YamabikoChat ಕೆಳಗಿನ AI ಸೇವೆಗಳಿಗೆ ನಿಮ್ಮದೇ API ಕೀ ಅಥವಾ ಖಾತೆಯೊಂದಿಗೆ ಸಂಪರ್ಕಿಸುತ್ತದೆ. ಒಳಗೊಳ್ಳಲಾದ ಪ್ರೊವೈಡರ್‌ಗಳು ಆ್ಯಪ್‌ನಲ್ಲೇ ಸೆಟಪ್ ಆಗುತ್ತವೆ; ಇನ್ನಷ್ಟು API ಪ್ರೊವೈಡರ್‌ಗಳು models.dev ಕ್ಯಾಟಲಾಗ್‌ನಿಂದ ಬರುತ್ತವೆ.

models.dev ಕ್ಯಾಟಲಾಗ್‌ನಿಂದ ಇನ್ನಷ್ಟು API ಪ್ರೊವೈಡರ್‌ಗಳು

YamabikoChat ಇನ್ನಷ್ಟು API ಪ್ರೊವೈಡರ್‌ಗಳನ್ನು ನೀಡಲು ಸಾರ್ವಜನಿಕ models.dev ಕ್ಯಾಟಲಾಗ್ ಓದುತ್ತದೆ — OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq, xAI API, Moonshot AI (Kimi), MiniMax, Z.ai (GLM), Fireworks AI, Together AI ಮತ್ತು Hugging Face ಸೇರಿದಂತೆ. ಸೆಟ್ಟಿಂಗ್‌ಗಳಲ್ಲಿ ಪ್ರೊವೈಡರ್ ಅನ್ನು ನಿಮ್ಮ API ಕೀಯೊಂದಿಗೆ ಸೇರಿಸಿ, ಒಂದು ಮಾದರಿ ಆಯ್ಕೆಮಾಡಿ.

ಪ್ರತಿ ಮಾದರಿಯೂ ಅದರ API ಒಪ್ಪಂದ ಪರಿಶೀಲಿಸಲಾದಾಗ ಮಾತ್ರ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ. ಸುರಕ್ಷಿತವಾಗಿ ಚಲಾಯಿಸಲಾಗದ ಮಾದರಿಗಳು ಕಾಣುತ್ತವೆ ಆದರೆ ನಿಷ್ಕ್ರಿಯವಾಗಿರುತ್ತವೆ, ನಿಖರ ಕಾರಣದೊಂದಿಗೆ — ಆ್ಯಪ್ ಎಂದಿಗೂ ನಿಮಗೆ ತಿಳಿಯದಂತೆ ಬೇರೆ ಮಾದರಿ, ಎಂಡ್‌ಪಾಯಿಂಟ್ ಅಥವಾ ಪ್ರೊವೈಡರ್‌ಗೆ ಬದಲಾಯಿಸುವುದಿಲ್ಲ.

ಮಾದರಿಗಳನ್ನು ಒಟ್ಟಿಗೆ ಬಳಸುವುದು

ಸಂಪರ್ಕಿಸಿದ ಪ್ರತಿ ಮಾದರಿಯನ್ನು ಚಾಟ್‌ನಲ್ಲಿ, ಎರಡು ಉತ್ತರಗಳನ್ನು ಹೋಲಿಸಲು ಡ್ಯುಯಲ್ ಮೋಡ್‌ನಲ್ಲಿ, ಮತ್ತು ಎರಡು ಮಾದರಿಗಳು ಮಾತನಾಡುವ ಆಟೋ ಸಂಭಾಷಣೆಯಲ್ಲಿ ಬಳಸಬಹುದು. ಚಿತ್ರ ಇನ್‌ಪುಟ್, ರೀಜನಿಂಗ್ ಸೆಟ್ಟಿಂಗ್‌ಗಳು, ಪರಿಕರಗಳು ಮತ್ತು ಕಾಂಟೆಕ್ಸ್ಟ್ ಉದ್ದ ಮಾದರಿಯನ್ನು ಅವಲಂಬಿಸಿವೆ.

ಮಾದರಿ ಪಟ್ಟಿಗಳು ಆಗಾಗ್ಗೆ ಬದಲಾಗುತ್ತವೆ. ಆ್ಯಪ್ ಯಾವಾಗಲೂ ಪ್ರತಿ ಪ್ರೊವೈಡರ್‌ನ ಪ್ರಸ್ತುತ ಪಟ್ಟಿಯನ್ನು ತೋರಿಸುತ್ತದೆ. ಪ್ರೊವೈಡರ್ ಮತ್ತು ಉತ್ಪನ್ನ ಹೆಸರುಗಳು ಅವುಗಳ ಮಾಲೀಕರ ಟ್ರೇಡ್‌ಮಾರ್ಕ್‌ಗಳು; YamabikoChat ಅವರೊಂದಿಗೆ ಸಂಬಂಧ ಹೊಂದಿಲ್ಲ.

ಸಂಬಂಧಿತ ಮಾರ್ಗದರ್ಶಿಗಳು

AI ಮಾದರಿಗಳನ್ನು ಹೋಲಿಸಿಒಂದೇ ಪ್ರಾಂಪ್ಟ್ ಅನ್ನು ಎರಡು ಮಾದರಿಗಳಿಗೆ ಕಳುಹಿಸಿ, ಎರಡೂ ಉತ್ತರಗಳನ್ನು ಅಕ್ಕಪಕ್ಕದಲ್ಲಿ ಓದಿ.ನಿಮ್ಮದೇ API ಕೀ ಬಳಸಿBYOK ಹೇಗೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ, ಎಷ್ಟು ಖರ್ಚಾಗುತ್ತದೆ, ನಿಮ್ಮ ಕೀ ಎಲ್ಲಿ ಸಂಗ್ರಹವಾಗುತ್ತದೆ.ಪ್ರಶ್ನೋತ್ತರಬೆಲೆ, ಅಗತ್ಯತೆಗಳು, ಗೋಪ್ಯತೆ ಮತ್ತು ಬೆಂಬಲಿತ ಮಾದರಿಗಳು.
