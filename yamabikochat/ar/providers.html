المزيد من مزوّدي API من كتالوج models.dev

يقرأ YamabikoChat كتالوج models.dev العام لتقديم مزوّدين إضافيين كثيرين، منهم OpenAI وAnthropic (Claude) وDeepSeek وMistral وGroq وxAI API وMoonshot AI (Kimi) وMiniMax وZ.ai (GLM) وFireworks AI وTogether AI وHugging Face. أضف المزوّد من الإعدادات باستخدام مفتاح API واختر نموذجًا.

لا يعمل أي نموذج إلا بعد التحقق من عقد API الخاص به. تبقى النماذج التي لا يمكن تشغيلها بأمان ظاهرة لكن معطّلة، مع السبب الدقيق — ولا ينقلك التطبيق تلقائيًا إلى نموذج أو نقطة نهاية أو مزوّد آخر.

استخدام النماذج معًا

يمكن استخدام كل نموذج متصل في المحادثة، وفي الوضع الثنائي لمقارنة إجابتين، وفي المحادثة التلقائية ليتحدث نموذجان. يعتمد إدخال الصور وإعدادات الاستدلال والأدوات وطول السياق على النموذج.

تتغير قوائم النماذج كثيرًا. يعرض التطبيق دائمًا القائمة الحالية لكل مزوّد. أسماء المزوّدين والمنتجات علامات تجارية لأصحابها؛ وYamabikoChat غير تابع لهم.

أدلة ذات صلة
