الأسئلة الشائعة

إجابات قصيرة عن السعر ومفاتيح API والنماذج المدعومة والخصوصية والمتطلبات.

آخر تحديث: 2026-11-17

هل YamabikoChat مجاني؟

نعم. YamabikoChat مجاني للتنزيل، بلا إعلانات ولا تسجيل ولا اشتراكات أو شراء رموز داخل التطبيق. تدفع لمزوّد الذكاء الاصطناعي مباشرة مقابل الاستخدام الذي تنشئه، وفق تسعير ذلك المزوّد وشروطه.

هل أحتاج إلى مفتاح API؟

تحتاج إلى مفتاح API من مزوّد ذكاء اصطناعي مدعوم، أو إلى تسجيل دخول بحساب مدعوم مثل خطة ChatGPT أو xAI. يعمل Apple Intelligence دون مفتاح على الأجهزة التي تدعمه.

هل يمكنني استخدام اشتراك ChatGPT بدلًا من مفتاح API؟

نعم. يتيح اتصال خطة ChatGPT تسجيل الدخول بحساب ChatGPT واستخدام النماذج المشمولة في خطتك، دون مفتاح API من OpenAI.

ما نماذج الذكاء الاصطناعي التي يمكنني استخدامها؟

Google Gemini وOpenRouter وخطة ChatGPT وxAI وApple Intelligence وSarashina وPLaMo مدمجة. أما OpenAI وAnthropic (Claude) وDeepSeek وMistral وGroq وغيرها من مزوّدي API فتتوفر عبر كتالوج models.dev، ويمكنك إضافة نقطة نهاية مخصصة تستخدم صيغة API مدعومة. تعتمد النماذج المتاحة على كل مزوّد.

هل يمكنني استخدام Claude بمفتاح API الخاص بـ Anthropic؟

نعم. أضف Anthropic من كتالوج المزوّدين باستخدام مفتاح API، أو أعدّ نقطة نهاية مخصصة تستخدم Anthropic Messages API.

هل يمكنني مقارنة إجابات ChatGPT وGemini وClaude جنبًا إلى جنب؟

نعم. يرسل الوضع الثنائي الطلب نفسه إلى نموذجين ويعرض الإجابتين متجاورتين. اختر أي نموذجين من المزوّدين الذين ربطتهم.

أين تُخزَّن محادثاتي ومفاتيح API؟

تُخزَّن المحادثات والإعدادات على جهازك. تُحفظ مفاتيح API ورموز الوصول في سلسلة مفاتيح iOS. تُرسل طلباتك وسياق المحادثة والمرفقات التي تختارها إلى المزوّد الذي اخترته فقط.

هل يعمل YamabikoChat على iPad؟

نعم. إنه تطبيق أصلي لـ iPhone وiPad، مع عرض منقسم على iPad يعرض قائمة المحادثات والمحادثة جنبًا إلى جنب.

ما متطلبات النظام؟

iOS 17 أو أحدث على iPhone، وiPadOS 17 أو أحدث على iPad. يتطلب Apple Intelligence جهازًا وإصدار نظام يدعمه.

هل YamabikoChat مفتوح المصدر؟

نعم. يُنشر الكود المصدري على GitHub بموجب MIT License. ويحتفظ البرنامج الخارجي المضمَّن برخصه الخاصة.

لا تزال لديك سؤال؟ زُر الدعم.
