YamabikoChat ใช้ฟรีไหม

ใช่แล้ว YamabikoChat ดาวน์โหลดฟรี ไม่มีโฆษณา ไม่ต้องสมัครสมาชิก และไม่มีค่าสมาชิกหรือการซื้อโทเคนในแอป คุณชำระค่าการใช้งานให้ผู้ให้บริการ AI โดยตรงตามราคาและเงื่อนไขของผู้ให้บริการรายนั้น

ต้องมีคีย์ API ไหม

คุณต้องมีคีย์ API จากผู้ให้บริการ AI ที่รองรับ หรือลงชื่อเข้าใช้บัญชีที่รองรับ เช่น แพ็กเกจ ChatGPT หรือ xAI Apple Intelligence ใช้ได้โดยไม่ต้องมีคีย์บนอุปกรณ์ที่รองรับ

ใช้แพ็กเกจ ChatGPT แทนคีย์ API ได้ไหม

ได้ การเชื่อมต่อแพ็กเกจ ChatGPT ให้คุณลงชื่อเข้าใช้ด้วยบัญชี ChatGPT และใช้โมเดลที่รวมอยู่ในแพ็กเกจ โดยไม่ต้องใช้คีย์ API ของ OpenAI

ใช้โมเดล AI อะไรได้บ้าง

Google Gemini, OpenRouter, แพ็กเกจ ChatGPT, xAI, Apple Intelligence, Sarashina และ PLaMo เป็นผู้ให้บริการในตัว ส่วน OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq และผู้ให้บริการ API อีกหลายรายใช้ได้ผ่านแค็ตตาล็อก models.dev และคุณเพิ่มปลายทางที่กำหนดเองซึ่งใช้รูปแบบ API ที่รองรับได้ โมเดลที่ใช้ได้ขึ้นอยู่กับผู้ให้บริการแต่ละราย

ใช้ Claude กับคีย์ API ของ Anthropic ได้ไหม

ได้ เพิ่ม Anthropic จากแค็ตตาล็อกผู้ให้บริการด้วยคีย์ API ของคุณ หรือตั้งค่าปลายทางที่กำหนดเองซึ่งใช้ Anthropic Messages API

เปรียบเทียบคำตอบของ ChatGPT, Gemini และ Claude เคียงข้างกันได้ไหม

ได้ โหมดดูอัลส่งคำถามเดียวกันไปยังสองโมเดลและแสดงคำตอบทั้งสองเคียงข้างกัน เลือกสองโมเดลใดก็ได้จากผู้ให้บริการที่คุณเชื่อมต่อไว้

บทสนทนาและคีย์ API ถูกเก็บไว้ที่ไหน

บทสนทนาและการตั้งค่าถูกเก็บไว้บนอุปกรณ์ของคุณ คีย์ API และโทเคนการเข้าถึงถูกเก็บในพวงกุญแจของ iOS คำถาม บริบทของบทสนทนา และไฟล์แนบที่คุณเลือก จะถูกส่งไปยังผู้ให้บริการที่คุณเลือกเท่านั้น

YamabikoChat ใช้บน iPad ได้ไหม

ได้ เป็นแอปเนทีฟสำหรับ iPhone และ iPad พร้อมมุมมองแยกบน iPad ที่แสดงรายการบทสนทนากับแชทเคียงข้างกัน

ข้อกำหนดระบบคืออะไร

iPhone ต้องใช้ iOS 17 ขึ้นไป และ iPad ต้องใช้ iPadOS 17 ขึ้นไป Apple Intelligence ต้องใช้อุปกรณ์และเวอร์ชันระบบที่รองรับ
