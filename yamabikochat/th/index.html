YamabikoChat
หน้าแรกเปรียบเทียบโมเดลคีย์ API ของคุณผู้ให้บริการคำถามที่พบบ่อยภาษา

นำ AI ของคุณมาใช้ · iPhone & iPad

แชทกับ AI ด้วยคีย์ API ของคุณเอง แล้วเปรียบเทียบคำตอบ

YamabikoChat เป็นแอปแชท AI ฟรีสำหรับ iPhone และ iPad เชื่อมต่อบริการ AI ที่คุณใช้อยู่ด้วยคีย์ API หรือบัญชีที่รองรับ แล้วแชทกับโมเดลเดียว เปรียบเทียบคำตอบจากสองโมเดลเคียงข้างกัน หรือปล่อยให้สองโมเดลคุยกันก็ได้

iOS & iPadOS 17 ขึ้นไปฟรี · ไม่มีโฆษณาไม่ต้องสมัครสมาชิกคีย์เก็บในพวงกุญแจ
ดูซอร์สโค้ดบน GitHub ↗

ภาพรวม

YamabikoChat คืออะไร

ประเภท
ไคลเอนต์แชท AI แบบเนทีฟสำหรับ iPhone และ iPad ที่ใช้คีย์ API หรือบัญชีของคุณเอง (BYOK)
ราคา
ฟรี ไม่มีโฆษณา ไม่ต้องสมัครสมาชิก ไม่มีค่าสมาชิกรายเดือนหรือการซื้อโทเคนในแอป ส่วนการใช้งานจะถูกเรียกเก็บเงินโดยผู้ให้บริการ
บริการ AI
Google Gemini, OpenRouter, แพ็กเกจ ChatGPT, xAI, Apple Intelligence, OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq, Sarashina, PLaMo, ปลายทางที่กำหนดเอง และอื่น ๆ — ดูผู้ให้บริการทั้งหมด
โหมด
แชท, ดูอัล (สองโมเดลเคียงข้างกัน) และการสนทนาอัตโนมัติ (สองโมเดลคุยกัน) พร้อมซับเอเจนต์ที่รับงานบางส่วนไปทำ
ความเป็นส่วนตัว
บทสนทนาอยู่บนอุปกรณ์ของคุณ คีย์เก็บในพวงกุญแจของ iOS และคำถามจะถูกส่งไปยังผู้ให้บริการที่คุณเลือกเท่านั้น
ข้อกำหนดระบบ
iOS 17 ขึ้นไป (iPhone), iPadOS 17 ขึ้นไป (iPad)
นักพัฒนา

โหมด

สามโหมดการสนทนา พร้อมซับเอเจนต์

เลือกโหมดให้เข้ากับคำถาม ไม่ใช่ให้คำถามต้องเข้ากับโหมด

01 / แชท

คุยกับหนึ่งโมเดล

คำตอบสตรีมแบบเรียลไทม์พร้อม Markdown ไฮไลต์โค้ด สมการ และไฟล์แนบรูปภาพ แก้ไข สร้างใหม่ และเก็บคำตอบหลายเวอร์ชันได้

02 / ดูอัล

เปรียบเทียบสองคำตอบ

ส่งคำถามเดียวกันไปยังสองโมเดล แล้วอ่านคำตอบทั้งสองเคียงข้างกัน โหมดดูอัลทำงานอย่างไร

03 / อัตโนมัติ

ให้สองโมเดลคุยกัน

เลือกสองโมเดล หัวข้อ และจำนวนเทิร์น แล้วดูทั้งสองโมเดลถกกัน

+ / ซับเอเจนต์

มอบหมายงาน

ให้โมเดลแบ่งงานบางส่วนให้ซับเอเจนต์ ซึ่งแต่ละตัวใช้โมเดลของตัวเองได้ และติดตามความคืบหน้าได้ในแชท

ฟีเจอร์

สร้างมาเพื่องานทุกวัน

เขียน สรุป แปล โค้ด และคณิตศาสตร์ พร้อมเครื่องมือที่ผู้ช่วยตัวจริงต้องมี

  • แนบรูปภาพ PDF และไฟล์ข้อความ (ไฟล์ละไม่เกิน 10 MB)
  • ค้นหาเว็บ รัน Python ในเครื่อง และกราฟแบบโต้ตอบ (GenUI) เป็นเครื่องมือ
  • พิมพ์ด้วยเสียง และส่วนขยายแชร์สำหรับ Safari และแอปอื่น ๆ
  • คำสั่งในทางลัด ค้นหาด้วย Spotlight และบทสนทนาลับ
  • โปรเจกต์ ค้นหาประวัติ พรีเซ็ตโมเดล และสถิติการใช้โทเคน
  • มุมมองแยกบน iPad และโหมดมืด

เหมาะกับใคร

เหมาะกับใคร

  • คุณจ่ายเงินค่าคีย์ API หรือแพ็กเกจ ChatGPT อยู่แล้ว และอยากได้แอปเนทีฟบน iPhone และ iPad สำหรับการใช้งานนั้น
  • คุณอยากเทียบคำตอบของโมเดลหนึ่งกับอีกโมเดลก่อนจะเชื่อ
  • คุณอยากจ่ายตามการใช้งานมากกว่าสมัครสมาชิก AI หลายรายการซ้อนกัน
  • คุณใช้ OpenRouter หรือผู้ให้บริการหลายราย และอยากรวมไว้ในที่เดียว
  • คุณอยากเก็บประวัติแชทไว้บนอุปกรณ์ของคุณเอง

คู่มือ

อ่านเพิ่มเติม

เปรียบเทียบโมเดล AIส่งคำถามเดียวกันไปยังสองโมเดล แล้วอ่านคำตอบทั้งสองแบบเคียงข้างกันใช้คีย์ API ของคุณเองBYOK ทำงานอย่างไร มีค่าใช้จ่ายเท่าไร และเก็บคีย์ของคุณไว้ที่ไหนผู้ให้บริการที่รองรับGemini, OpenRouter, แพ็กเกจ ChatGPT, xAI, OpenAI, Anthropic และอื่น ๆคำถามที่พบบ่อยราคา ข้อกำหนดระบบ ความเป็นส่วนตัว และโมเดลที่รองรับ
