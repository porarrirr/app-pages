นำคีย์ของคุณมาใช้

ใช้คีย์ API ของคุณเองสำหรับแชท AI บน iPhone และ iPad

YamabikoChat เป็นไคลเอนต์แบบ bring-your-own-key (BYOK) คุณใส่คีย์ API หรือลงชื่อเข้าใช้บัญชีที่รองรับ แล้วแอปจะส่งคำถามของคุณตรงไปยังผู้ให้บริการรายนั้น ไม่มีค่าสมาชิก YamabikoChat หรือตัวแทนขายโทเคนคั่นกลาง

อัปเดตล่าสุด: 2026-11-17

“BYOK” หรือ “นำคีย์ของคุณมาใช้” หมายถึงอะไร

ผู้ให้บริการ AI อย่าง OpenAI, Google, Anthropic และ OpenRouter ขายการเข้าถึงโมเดลผ่านคีย์ API ซึ่งมักคิดค่าบริการตามการใช้งาน แอปแบบ BYOK คือไคลเอนต์ที่ใช้คีย์เหล่านั้น คุณสร้างคีย์ในบัญชีผู้ให้บริการ เพิ่มลงในแอป และผู้ให้บริการจะเรียกเก็บเงินจากคุณโดยตรงตามการใช้งาน

ทำไมต้องใช้คีย์ของคุณเอง

  • จ่ายตามที่ใช้จริง ผู้ใช้ไม่บ่อยมักจ่ายน้อยกว่าค่าสมาชิก AI รายเดือน และผู้ใช้หนักจะเห็นชัดว่าค่าใช้จ่ายมาจากไหน
  • เลือกโมเดลได้เอง ใช้โมเดลที่ผู้ให้บริการของคุณมี ไม่ใช่รายการตายตัวที่แอปกำหนด
  • แอปเดียว หลายผู้ให้บริการ เก็บ Gemini, OpenRouter, OpenAI, Anthropic และรายอื่นไว้ด้วยกัน แล้วเปรียบเทียบในโหมดดูอัล
  • เห็นการใช้งาน สถิติการใช้โทเคนแสดงว่าคุณใช้ไปเท่าไร

วิธีตั้งค่า

  1. สร้างคีย์ API ในคอนโซลของผู้ให้บริการ เช่น Google AI Studio สำหรับ Gemini, แพลตฟอร์ม OpenAI, คอนโซล Anthropic หรือ OpenRouter
  2. เปิดการตั้งค่าใน YamabikoChat แล้วเลือกผู้ให้บริการในการตั้งค่าการเชื่อมต่อ
  3. วางคีย์ คีย์จะถูกบันทึกไว้ในพวงกุญแจของ iOS บนอุปกรณ์ของคุณ
  4. เลือกโมเดลแล้วเริ่มแชท โมเดลที่แอปไม่สามารถรันได้อย่างปลอดภัยจะแสดงเป็นใช้ไม่ได้พร้อมเหตุผล แทนที่จะเดา

ไม่มีคีย์ API? ลงชื่อเข้าใช้แทนได้

  • แพ็กเกจ ChatGPT — ลงชื่อเข้าใช้ด้วยบัญชี ChatGPT เพื่อใช้โมเดลที่รวมอยู่ในแพ็กเกจของคุณ
  • xAI — ลงชื่อเข้าใช้ด้วยบัญชี xAI ของคุณ
  • Apple Intelligence — มาพร้อมในอุปกรณ์ที่รองรับ ทำงานบนอุปกรณ์หรือผ่าน Private Cloud Compute โดยไม่ต้องใช้คีย์

ปลายทางที่กำหนดเอง

หากบริการของคุณไม่อยู่ในรายการ ให้เพิ่มปลายทางที่กำหนดเองด้วย base URL และคีย์ แล้วเลือก API รูปแบบที่รองรับ: OpenAI Chat Completions, OpenAI Responses, Anthropic Messages, Gemini (Google Generative AI) หรือ Mistral

ค่าใช้จ่าย

แอปนี้ฟรีและไม่มีการซื้อในแอป ผู้ให้บริการของคุณคิดค่าการใช้งานตามราคา วงเงิน และเงื่อนไขของตน โหมดดูอัลและการสนทนาอัตโนมัติส่งคำขอไปยังสองโมเดล จึงเกิดการใช้งานทั้งสองฝั่ง

ความปลอดภัยและความเป็นส่วนตัว

  • คีย์ API และโทเคนการเข้าถึงถูกเก็บในพวงกุญแจของ iOS และแอปออกแบบมาไม่ให้บันทึกลงในบันทึกการวินิจฉัย
  • คำถาม บริบทของบทสนทนา และไฟล์แนบที่คุณเลือก จะถูกส่งตรงไปยังผู้ให้บริการที่คุณเลือก
  • บทสนทนาถูกเก็บไว้บนอุปกรณ์ของคุณ แอปไม่ใช้การติดตามข้ามแอป ดูนโยบายความเป็นส่วนตัว

คู่มือที่เกี่ยวข้อง

เปรียบเทียบโมเดล AIส่งคำถามเดียวกันไปยังสองโมเดล แล้วอ่านคำตอบทั้งสองแบบเคียงข้างกันผู้ให้บริการที่รองรับGemini, OpenRouter, แพ็กเกจ ChatGPT, xAI, OpenAI, Anthropic และอื่น ๆคำถามที่พบบ่อยราคา ข้อกำหนดระบบ ความเป็นส่วนตัว และโมเดลที่รองรับ
