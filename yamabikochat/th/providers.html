ผู้ให้บริการ AI ที่รองรับ

YamabikoChat เชื่อมต่อกับบริการ AI ด้านล่างด้วยคีย์ API หรือบัญชีของคุณเอง ผู้ให้บริการในตัวตั้งค่าได้โดยตรงในแอป และยังมีผู้ให้บริการ API อีกมากจากแค็ตตาล็อก models.dev

อัปเดตล่าสุด: 2026-11-17

ผู้ให้บริการในตัว

ผู้ให้บริการ วิธีเชื่อมต่อ หมายเหตุ
Google Gemini คีย์ API โมเดล Gemini จาก Google AI Studio
OpenRouter คีย์ API เลือกดูไดเรกทอรีโมเดลของ OpenRouter ได้ในแอป
แพ็กเกจ ChatGPT ลงชื่อเข้าใช้ด้วย ChatGPT ใช้โมเดลที่รวมอยู่ในแพ็กเกจ ChatGPT ของคุณ
xAI ลงชื่อเข้าใช้ด้วยบัญชี xAI ของคุณ โมเดล Grok ที่บัญชีของคุณใช้ได้
Apple Intelligence ในตัว ไม่ต้องใช้คีย์ ทำงานบนอุปกรณ์และผ่าน Private Cloud Compute เฉพาะอุปกรณ์ที่รองรับ
Sarashina คีย์ API โมเดลภาษาญี่ปุ่นจาก SB Intuitions
PLaMo คีย์ API โมเดลภาษาญี่ปุ่นจาก Preferred Networks ค้นหาเว็บได้บน PLaMo 3.1 Prime
ปลายทางที่กำหนดเอง Base URL + คีย์ API รูปแบบ OpenAI Chat Completions, OpenAI Responses, Anthropic Messages, Gemini หรือ Mistral

ผู้ให้บริการ API เพิ่มเติมจากแค็ตตาล็อก models.dev

YamabikoChat อ่านแค็ตตาล็อกสาธารณะ models.dev เพื่อให้มีผู้ให้บริการ API เพิ่มขึ้นอีกมาก รวมถึง OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq, xAI API, Moonshot AI (Kimi), MiniMax, Z.ai (GLM), Fireworks AI, Together AI และ Hugging Face เพียงเพิ่มผู้ให้บริการในการตั้งค่าด้วยคีย์ API ของคุณ แล้วเลือกโมเดล

แต่ละโมเดลจะทำงานเมื่อตรวจสอบสัญญา API ของโมเดลนั้นแล้วเท่านั้น โมเดลที่ไม่สามารถทำงานได้อย่างปลอดภัยจะยังแสดงอยู่แต่ปิดใช้งาน พร้อมเหตุผลที่ชัดเจน แอปจะไม่สลับไปใช้โมเดล ปลายทาง หรือผู้ให้บริการอื่นโดยที่คุณไม่รู้

ใช้โมเดลร่วมกัน

ทุกโมเดลที่เชื่อมต่อไว้ใช้ได้ในแชท ในโหมดดูอัลเพื่อเทียบสองคำตอบ และในการสนทนาอัตโนมัติเพื่อให้สองโมเดลคุยกัน การรับภาพ การตั้งค่าการให้เหตุผล เครื่องมือ และความยาวบริบทขึ้นอยู่กับโมเดล

รายการโมเดลเปลี่ยนบ่อย แอปจะแสดงรายการล่าสุดของผู้ให้บริการแต่ละรายเสมอ ชื่อผู้ให้บริการและผลิตภัณฑ์เป็นเครื่องหมายการค้าของเจ้าของ YamabikoChat ไม่ได้มีส่วนเกี่ยวข้องกับบริษัทเหล่านี้

คู่มือที่เกี่ยวข้อง

เปรียบเทียบโมเดล AI ส่งคำถามเดียวกันไปยังสองโมเดล แล้วอ่านคำตอบทั้งสองแบบเคียงข้างกัน ใช้คีย์ API ของคุณเอง BYOK ทำงานอย่างไร มีค่าใช้จ่ายเท่าไร และเก็บคีย์ของคุณไว้ที่ไหน คำถามที่พบบ่อย ราคา ข้อกำหนดระบบ ความเป็นส่วนตัว และโมเดลที่รองรับ

ลองใช้กับ AI ที่คุณใช้อยู่แล้ว
