Často kladené dotazy

Krátké odpovědi o ceně, API klíčích, podporovaných modelech, soukromí a požadavcích.

Poslední aktualizace: 2026-11-17

Je YamabikoChat zdarma?

Ano. YamabikoChat je zdarma ke stažení, bez reklam, bez registrace a bez předplatného či nákupů tokenů v aplikaci. Za využití, které vytvoříte, platíte přímo svému poskytovateli AI podle jeho cen a podmínek.

Potřebuji API klíč?

Potřebujete buď API klíč od podporovaného poskytovatele AI, nebo přihlášení k podporovanému účtu, například plán ChatGPT nebo xAI. Apple Intelligence funguje bez klíče na zařízeních, která ji podporují.

Mohu místo API klíče použít své předplatné ChatGPT?

Ano. Připojení plánu ChatGPT vám umožní přihlásit se účtem ChatGPT a používat modely zahrnuté ve vašem plánu, bez API klíče OpenAI.

Které AI modely mohu použít?

Vestavěné jsou Google Gemini, OpenRouter, plán ChatGPT, xAI, Apple Intelligence, Sarashina a PLaMo. OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq a mnoho dalších poskytovatelů API je dostupných přes katalog models.dev a můžete přidat vlastní koncový bod s podporovaným formátem API. Dostupné modely závisí na jednotlivých poskytovatelích.

Mohu použít Claude se svým API klíčem Anthropic?

Ano. Přidejte Anthropic z katalogu poskytovatelů pomocí svého API klíče, nebo nastavte vlastní koncový bod s API Anthropic Messages.

Mohu porovnat odpovědi ChatGPT, Gemini a Claude vedle sebe?

Ano. Režim Dual pošle stejný dotaz dvěma modelům a zobrazí obě odpovědi vedle sebe. Vyberte libovolné dva modely od poskytovatelů, které máte připojené.

Kde jsou uloženy mé konverzace a API klíče?

Konverzace a nastavení jsou uloženy ve vašem zařízení. API klíče a přístupové tokeny jsou uloženy v Klíčence iOS. Vaše dotazy, kontext konverzace a přílohy, které vyberete, se odesílají pouze poskytovateli, kterého jste zvolili.

Funguje YamabikoChat na iPadu?

Ano. Je to nativní aplikace pro iPhone a iPad, na iPadu s rozděleným zobrazením, které ukazuje seznam konverzací a chat vedle sebe.

Jaké jsou systémové požadavky?

iOS 17 nebo novější na iPhonu a iPadOS 17 nebo novější na iPadu. Apple Intelligence vyžaduje zařízení a verzi operačního systému, které ji podporují.

Je YamabikoChat open source?

Ano. Zdrojový kód je zveřejněn na GitHubu pod licencí MIT. Přibalený software třetích stran si zachovává vlastní licence.
