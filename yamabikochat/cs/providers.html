Podporovaní poskytovatelé AI

YamabikoChat se připojuje k níže uvedeným službám AI pomocí vašeho vlastního API klíče nebo účtu. Vestavěné poskytovatele nastavíte přímo v aplikaci; mnoho dalších poskytovatelů API pochází z katalogu models.dev.

Další poskytovatelé API z katalogu models.dev

YamabikoChat čte veřejný katalog models.dev a nabízí tak mnohem více poskytovatelů API, včetně OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq, xAI API, Moonshot AI (Kimi), MiniMax, Z.ai (GLM), Fireworks AI, Together AI a Hugging Face. Přidejte poskytovatele v nastavení pomocí API klíče a vyberte model.

Každý model běží jen tehdy, když je jeho API kontrakt ověřený. Modely, které nelze bezpečně spustit, zůstávají viditelné, ale vypnuté, s přesným důvodem – aplikace vás nikdy potichu nepřepne na jiný model, koncový bod ani poskytovatele.

Společné použití modelů

Každý připojený model lze použít v chatu, v režimu Dual pro porovnání dvou odpovědí a v automatické konverzaci, kde spolu mluví dva modely. Vstup obrázků, nastavení uvažování, nástroje a délka kontextu závisí na modelu.

Seznamy modelů se často mění. Aplikace vždy zobrazuje aktuální seznam pro každého poskytovatele. Názvy poskytovatelů a produktů jsou ochranné známky jejich vlastníků; YamabikoChat s nimi není spojen.

Související průvodci
