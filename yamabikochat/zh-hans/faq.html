最后更新：2026-11-17

YamabikoChat 免费吗？

是的。YamabikoChat 可免费下载，没有广告、无需注册，应用内也没有订阅或 Token 购买。你产生的使用费用需要按照提供商的定价和条款直接支付给 AI 提供商。

我需要 API 密钥吗？

你需要受支持的 AI 提供商提供的 API 密钥，或者使用 ChatGPT 订阅方案、xAI 等受支持的账户登录。在支持的设备上，Apple Intelligence 无需密钥即可使用。

可以用 ChatGPT 订阅代替 API 密钥吗？

可以。使用 ChatGPT 订阅方案连接时，你可以用 ChatGPT 账户登录，无需 OpenAI API 密钥即可使用方案中包含的模型。

可以使用哪些 AI 模型？

内置 Google Gemini、OpenRouter、ChatGPT 订阅方案、xAI、Apple Intelligence、Sarashina 和 PLaMo。OpenAI、Anthropic（Claude）、DeepSeek、Mistral、Groq 等众多 API 提供商可通过 models.dev 目录使用，也可以添加使用受支持 API 格式的自定义端点。可用模型取决于各提供商。

可以用 Anthropic API 密钥使用 Claude 吗？

可以。在提供商目录中添加 Anthropic 并提供 API 密钥，或设置使用 Anthropic Messages API 的自定义端点。

可以并排对比 ChatGPT、Gemini 和 Claude 的回答吗？

可以。对比模式会把同一个提示词发送给两个模型，并排显示两个回答。你可以从已连接的提供商中任选两个模型。

我的对话和 API 密钥保存在哪里？

对话和设置保存在你的设备上，API 密钥和访问令牌保存在 iOS 钥匙串中。你的提示词、对话上下文和你选择的附件只会发送给你选定的提供商。

YamabikoChat 支持 iPad 吗？

支持。它是为 iPhone 和 iPad 打造的原生应用，在 iPad 上支持分屏浏览，可并排显示对话列表和聊天。

系统要求是什么？

iPhone 需要 iOS 17 或更高版本，iPad 需要 iPadOS 17 或更高版本。Apple Intelligence 需要支持它的设备和操作系统版本。

YamabikoChat 是开源的吗？

是的。源代码以 MIT License 在 GitHub 上发布。随附的第三方软件保留各自的许可证。
