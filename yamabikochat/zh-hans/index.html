YamabikoChat 是什么

类型
使用自有 API 密钥或账户（BYOK）的 iPhone 和 iPad 原生 AI 聊天客户端
价格
免费。无广告、无需注册，应用内没有订阅或 Token 购买。使用费用由提供商计费。
AI 服务
Google Gemini、OpenRouter、ChatGPT 订阅方案、xAI、Apple Intelligence、OpenAI、Anthropic（Claude）、DeepSeek、Mistral、Groq、Sarashina、PLaMo、自定义端点等 — 查看所有提供商
模式
聊天、双模型对比（两个模型并排）、自动对话（两个模型互相对话），以及分担部分任务的子代理
隐私
对话保存在你的设备上，密钥保存在 iOS 钥匙串中，提示词只发送给你选择的提供商
系统要求
iOS 17 或更高版本（iPhone），iPadOS 17 或更高版本（iPad）
开发者
独立开发者 porarrirr · 以 MIT License 开源的软件

模式

三种对话模式，外加子代理

让模式配合问题，而不是反过来让问题配合模式。

01 / 聊天

与单个模型对话

流式回答支持 Markdown、代码高亮、数学公式和图片附件。可编辑、重新生成，并保留多个回答版本。

02 / 对比

对比两个回答

把同一个提示词发给两个模型，并排查看两个回答。对比模式如何运作

03 / 自动

让两个模型对话

选择两个模型、一个话题和对话轮数，然后观看它们彼此讨论。

+ / 子代理

把工作交给子代理

让模型把请求的一部分交给子代理处理——每个子代理可以使用不同的模型——并在聊天中查看进度。

功能

为日常工作打造

写作、摘要、翻译、代码和数学——配备真正助手所需的工具。

  • 添加图片、PDF 和文本文件（每个最大 10 MB）
  • 网页搜索、本地 Python 和交互式图表（GenUI）等工具
  • 语音听写，以及适用于 Safari 和其他应用的分享扩展
  • 快捷指令操作、Spotlight 搜索和私密对话
  • 项目、历史记录搜索、模型预设和 Token 用量统计
  • iPad 分屏浏览和深色模式

适合谁

适合哪些人

  • 已经有 API 密钥或 ChatGPT 订阅方案，想要一款原生 iPhone 和 iPad 应用来使用它们的人。
  • 在相信一个模型的回答之前，想先用另一个模型核对的人。
  • 宁愿按使用量付费，也不想叠加多个 AI 订阅的人。
  • 使用 OpenRouter 或多个提供商，想把它们集中在一个应用里的人。
  • 希望把聊天记录保存在自己设备上的人。
