自带密钥

在 iPhone 和 iPad 上使用自己的 API 密钥进行 AI 聊天

YamabikoChat 是一款自带密钥（BYOK）客户端。你添加 API 密钥或登录受支持的账户，应用就会把提示词直接发送给该提供商。中间没有 YamabikoChat 订阅，也没有 Token 转售。

最后更新：2026-11-17

什么是自带密钥（BYOK）

OpenAI、Google、Anthropic 和 OpenRouter 等 AI 提供商通过 API 密钥出售模型访问权限，通常按使用量计费。BYOK 应用就是使用这些密钥的客户端：你在提供商账户中创建密钥，添加到应用里，提供商就会按你的实际使用量直接向你收费。

为什么要使用自己的密钥

  • 用多少付多少。轻度用户的花费通常低于包月 AI 订阅；重度用户则能清楚看到费用来自哪里。
  • 自由选择模型。使用提供商提供的模型，而不是应用固定的模型列表。
  • 一个应用，多家提供商。把 Gemini、OpenRouter、OpenAI、Anthropic 等放在一起使用，并在对比模式中比较它们。
  • 查看用量。Token 用量统计会显示你用了多少。

如何设置

  1. 创建 API 密钥——在提供商的控制台中创建，例如 Gemini 使用 Google AI Studio，此外还有 OpenAI 平台、Anthropic 控制台或 OpenRouter。
  2. 打开 YamabikoChat 的设置，在连接设置中选择提供商。
  3. 粘贴密钥。密钥会保存在你设备上的 iOS 钥匙串中。
  4. 选择模型并开始聊天。应用无法安全运行的模型会显示为不可用并附上原因，而不会被猜测着运行。

没有 API 密钥？改用账户登录

  • ChatGPT 订阅方案 — 使用 ChatGPT 账户登录，即可使用方案中包含的模型。
  • xAI — 使用 xAI 账户登录。
  • Apple Intelligence — 在支持的设备上内置，可在设备端或通过 Private Cloud Compute 运行，完全不需要密钥。

自定义端点

如果你的服务不在列表中，可以用基础 URL 和密钥添加自定义端点，并选择一种受支持的 API 格式：OpenAI Chat Completions、OpenAI Responses、Anthropic Messages、Gemini（Google Generative AI）或 Mistral。

费用如何计算

应用免费，没有应用内购买。提供商按其定价、限额和条款收取使用费用。对比模式和自动对话会向两个模型发送请求，因此两边都会产生用量。

安全与隐私

  • API 密钥和访问令牌保存在 iOS 钥匙串中，应用的设计不会把它们写入诊断日志。
  • 提示词、对话上下文和你选择的附件会直接发送给你选择的提供商。
  • 对话保存在你的设备上。应用不进行跨应用跟踪。请参阅隐私政策。
