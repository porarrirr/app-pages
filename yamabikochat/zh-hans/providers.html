支持的 AI 提供商

YamabikoChat 通过你自己的 API 密钥或账户连接以下 AI 服务。内置提供商可直接在应用中设置；更多 API 提供商来自 models.dev 目录。

提供商连接方式说明

来自 models.dev 目录的更多 API 提供商

YamabikoChat 读取公开的 models.dev 目录，以提供更多 API 提供商，包括 OpenAI、Anthropic（Claude）、DeepSeek、Mistral、Groq、xAI API、Moonshot AI（Kimi）、MiniMax、Z.ai（GLM）、Fireworks AI、Together AI 和 Hugging Face。在设置中添加提供商和 API 密钥，然后选择模型即可。

每个模型只有在其 API 接口约定经过验证时才会运行。无法安全运行的模型会保持可见但处于禁用状态，并显示确切原因——应用绝不会悄悄切换到其他模型、端点或提供商。

组合使用模型

每个已连接的模型都可以用于聊天、用于并排对比两个回答的对比模式，以及让两个模型对话的自动对话。图片输入、推理设置、工具和上下文长度取决于具体模型。

模型列表经常变化。应用始终显示各提供商的最新列表。提供商和产品名称是其所有者的商标；YamabikoChat 与它们没有关联。
