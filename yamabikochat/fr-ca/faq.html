FAQ

Questions fréquentes

Des réponses courtes sur le prix, les clés API, les modèles compatibles, la confidentialité et la configuration requise.

Dernière mise à jour : 2026-11-17

YamabikoChat est-il gratuit ?

Oui. YamabikoChat est gratuit au téléchargement, sans publicité, sans inscription et sans abonnement ni achat de jetons dans l'appli. Vous payez directement votre fournisseur d'IA pour l'usage que vous générez, selon ses tarifs et conditions.

Faut-il une clé API ?

Il vous faut soit une clé API d'un fournisseur d'IA compatible, soit la connexion à un compte compatible, comme un forfait ChatGPT ou xAI. Apple Intelligence fonctionne sans clé sur les appareils compatibles.

Puis-je utiliser mon abonnement ChatGPT au lieu d'une clé API ?

Oui. La connexion au forfait ChatGPT permet de se connecter avec votre compte ChatGPT et d'utiliser les modèles inclus dans votre forfait, sans clé API OpenAI.

Quels modèles d'IA puis-je utiliser ?

Google Gemini, OpenRouter, forfait ChatGPT, xAI, Apple Intelligence, Sarashina et PLaMo sont intégrés. OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq et de nombreux autres fournisseurs d'API sont disponibles via le catalogue models.dev, et vous pouvez ajouter un point de terminaison personnalisé avec un format d'API pris en charge. Les modèles disponibles dépendent de chaque fournisseur.

Puis-je utiliser Claude avec ma clé API Anthropic ?

Oui. Ajoutez Anthropic depuis le catalogue de fournisseurs avec votre clé API, ou configurez un point de terminaison personnalisé qui utilise l'API Anthropic Messages.

Puis-je comparer les réponses de ChatGPT, Gemini et Claude côte à côte ?

Oui. Le mode Double envoie la même requête à deux modèles et affiche les deux réponses côte à côte. Choisissez deux modèles parmi ceux des fournisseurs connectés.

Où sont stockées mes conversations et mes clés API ?

Les conversations et les réglages sont stockés sur votre appareil. Les clés API et les jetons d'accès sont conservés dans le Trousseau iOS. Vos requêtes, le contexte de la conversation et les pièces jointes choisies ne sont envoyés qu'au fournisseur sélectionné.

YamabikoChat fonctionne-t-il sur iPad ?

Oui. C'est une appli native pour iPhone et iPad, avec Split View sur iPad pour afficher la liste des conversations et le clavardage côte à côte.

Quelle est la configuration requise ?

iOS 17 ou ultérieur sur iPhone, iPadOS 17 ou ultérieur sur iPad. Apple Intelligence nécessite un appareil et une version du système compatibles.

YamabikoChat est-il open source ?

Oui. Le code source est publié sur GitHub sous licence MIT. Les logiciels tiers inclus conservent leurs propres licences.
