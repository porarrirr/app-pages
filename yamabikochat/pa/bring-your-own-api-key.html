ਆਪਣੀ ਕੀ ਲਿਆਓ

iPhone ਅਤੇ iPad ਉੱਤੇ ਆਪਣੀ API ਕੀ ਨਾਲ AI ਚੈਟ ਕਰੋ

YamabikoChat ਆਪਣੀ ਕੀ ਲਿਆਉਣ ਵਾਲਾ (BYOK) ਕਲਾਇੰਟ ਹੈ। ਤੁਸੀਂ ਇੱਕ API ਕੀ ਜੋੜਦੇ ਹੋ — ਜਾਂ ਸਮਰਥਿਤ ਖਾਤੇ ਵਿੱਚ ਸਾਈਨ ਇਨ ਕਰਦੇ ਹੋ — ਅਤੇ ਐਪ ਤੁਹਾਡੇ ਪ੍ਰੋਂਪਟ ਸਿੱਧੇ ਉਸ ਪ੍ਰੋਵਾਈਡਰ ਨੂੰ ਭੇਜਦਾ ਹੈ। ਵਿਚਕਾਰ YamabikoChat ਦਾ ਕੋਈ ਸਬਸਕ੍ਰਿਪਸ਼ਨ ਜਾਂ ਟੋਕਨ ਵਿਕਰੇਤਾ ਨਹੀਂ ਹੈ।

ਆਖਰੀ ਅੱਪਡੇਟ: 2026-11-17

“ਆਪਣੀ ਕੀ ਲਿਆਓ” ਦਾ ਕੀ ਮਤਲਬ ਹੈ

OpenAI, Google, Anthropic ਅਤੇ OpenRouter ਵਰਗੇ AI ਪ੍ਰੋਵਾਈਡਰ API ਕੀਆਂ ਰਾਹੀਂ ਆਪਣੇ ਮਾਡਲਾਂ ਦੀ ਵਰਤੋਂ ਵੇਚਦੇ ਹਨ, ਆਮ ਤੌਰ ਉੱਤੇ ਵਰਤੋਂ ਅਨੁਸਾਰ ਬਿੱਲ ਭੇਜਦੇ ਹਨ। BYOK ਐਪ ਉਨ੍ਹਾਂ ਕੀਆਂ ਲਈ ਕਲਾਇੰਟ ਹੈ: ਤੁਸੀਂ ਪ੍ਰੋਵਾਈਡਰ ਖਾਤੇ ਵਿੱਚ ਕੀ ਬਣਾਉਂਦੇ ਹੋ, ਐਪ ਵਿੱਚ ਜੋੜਦੇ ਹੋ, ਅਤੇ ਪ੍ਰੋਵਾਈਡਰ ਤੁਹਾਡੀ ਵਰਤੋਂ ਦਾ ਬਿੱਲ ਸਿੱਧਾ ਤੁਹਾਨੂੰ ਭੇਜਦਾ ਹੈ।

ਆਪਣੀ ਕੀ ਕਿਉਂ ਵਰਤੋ

  • ਜਿੰਨੀ ਵਰਤੋਂ, ਉੱਨਾ ਖਰਚ। ਘੱਟ ਵਰਤਣ ਵਾਲਿਆਂ ਦਾ ਖਰਚ ਅਕਸਰ ਮਹੀਨਾਵਾਰ AI ਸਬਸਕ੍ਰਿਪਸ਼ਨ ਨਾਲੋਂ ਘੱਟ ਹੁੰਦਾ ਹੈ; ਵੱਧ ਵਰਤਣ ਵਾਲਿਆਂ ਨੂੰ ਸਾਫ਼ ਪਤਾ ਲੱਗਦਾ ਹੈ ਕਿ ਖਰਚ ਕਿੱਥੋਂ ਆ ਰਿਹਾ ਹੈ।
  • ਮਾਡਲ ਚੁਣੋ। ਕਿਸੇ ਐਪ ਦੀ ਬਣੀ-ਬਣਾਈ ਸੂਚੀ ਨਹੀਂ, ਸਗੋਂ ਤੁਹਾਡੇ ਪ੍ਰੋਵਾਈਡਰ ਵੱਲੋਂ ਦਿੱਤੇ ਮਾਡਲ ਵਰਤੋ।
  • ਇੱਕ ਐਪ, ਕਈ ਪ੍ਰੋਵਾਈਡਰ। Gemini, OpenRouter, OpenAI, Anthropic ਅਤੇ ਹੋਰ ਨਾਲ-ਨਾਲ ਰੱਖੋ, ਅਤੇ ਡਿਊਲ ਮੋਡ ਵਿੱਚ ਉਨ੍ਹਾਂ ਦੀ ਤੁਲਨਾ ਕਰੋ।
  • ਆਪਣੀ ਵਰਤੋਂ ਵੇਖੋ। ਟੋਕਨ ਵਰਤੋਂ ਦੇ ਅੰਕੜੇ ਦਿਖਾਉਂਦੇ ਹਨ ਕਿ ਤੁਸੀਂ ਕਿੰਨਾ ਵਰਤ ਰਹੇ ਹੋ।

ਇਸ ਨੂੰ ਕਿਵੇਂ ਸੈੱਟ ਕਰੀਏ

  1. API ਕੀ ਬਣਾਓ ਆਪਣੇ ਪ੍ਰੋਵਾਈਡਰ ਦੇ ਕੰਸੋਲ ਵਿੱਚ — ਉਦਾਹਰਨ ਲਈ Gemini ਲਈ Google AI Studio, OpenAI ਪਲੇਟਫਾਰਮ, Anthropic ਕੰਸੋਲ ਜਾਂ OpenRouter।
  2. YamabikoChat ਵਿੱਚ ਸੈਟਿੰਗਾਂ ਖੋਲ੍ਹੋ ਅਤੇ ਕਨੈਕਸ਼ਨ ਸੈਟਿੰਗਾਂ ਵਿੱਚ ਪ੍ਰੋਵਾਈਡਰ ਚੁਣੋ।
  3. ਕੀ ਪੇਸਟ ਕਰੋ। ਇਹ ਤੁਹਾਡੇ ਡਿਵਾਈਸ ਦੇ iOS Keychain ਵਿੱਚ ਸੰਭਾਲੀ ਜਾਂਦੀ ਹੈ।
  4. ਮਾਡਲ ਚੁਣੋ ਅਤੇ ਚੈਟ ਸ਼ੁਰੂ ਕਰੋ। ਜਿਹੜੇ ਮਾਡਲ ਐਪ ਸੁਰੱਖਿਅਤ ਢੰਗ ਨਾਲ ਨਹੀਂ ਚਲਾ ਸਕਦਾ, ਉਹ ਅੰਦਾਜ਼ਾ ਲਾਉਣ ਦੀ ਥਾਂ ਕਾਰਨ ਸਮੇਤ ਉਪਲਬਧ ਨਾ ਹੋਣ ਵਜੋਂ ਦਿਖਾਏ ਜਾਂਦੇ ਹਨ।

API ਕੀ ਨਹੀਂ? ਸਾਈਨ ਇਨ ਕਰੋ

  • ChatGPT ਪਲਾਨ — ਆਪਣੇ ChatGPT ਖਾਤੇ ਨਾਲ ਸਾਈਨ ਇਨ ਕਰਕੇ ਪਲਾਨ ਵਿੱਚ ਸ਼ਾਮਲ ਮਾਡਲ ਵਰਤੋ।
  • xAI — ਆਪਣੇ xAI ਖਾਤੇ ਨਾਲ ਸਾਈਨ ਇਨ ਕਰੋ।
  • Apple Intelligence — ਸਮਰਥਿਤ ਡਿਵਾਈਸਾਂ ਉੱਤੇ, ਡਿਵਾਈਸ ਉੱਤੇ ਹੀ ਜਾਂ Private Cloud Compute ਰਾਹੀਂ, ਕਿਸੇ ਕੀ ਤੋਂ ਬਿਨਾਂ।

ਕਸਟਮ ਐਂਡਪੌਇੰਟ

ਜੇ ਤੁਹਾਡੀ ਸੇਵਾ ਸੂਚੀ ਵਿੱਚ ਨਹੀਂ ਹੈ, ਤਾਂ ਉਸ ਦਾ ਬੇਸ URL ਅਤੇ ਕੀ ਦੇ ਕੇ ਕਸਟਮ ਐਂਡਪੌਇੰਟ ਜੋੜੋ, ਅਤੇ ਸਮਰਥਿਤ API ਫਾਰਮੈਟਾਂ ਵਿੱਚੋਂ ਇੱਕ ਚੁਣੋ: OpenAI Chat Completions, OpenAI Responses, Anthropic Messages, Gemini (Google Generative AI) ਜਾਂ Mistral.

ਖਰਚ ਕਿੰਨਾ

ਐਪ ਮੁਫ਼ਤ ਹੈ, ਐਪ ਦੇ ਅੰਦਰ ਕੋਈ ਖਰੀਦ ਨਹੀਂ। ਤੁਹਾਡਾ ਪ੍ਰੋਵਾਈਡਰ ਆਪਣੀਆਂ ਕੀਮਤਾਂ, ਸੀਮਾਵਾਂ ਅਤੇ ਸ਼ਰਤਾਂ ਅਨੁਸਾਰ ਵਰਤੋਂ ਦਾ ਬਿੱਲ ਭੇਜਦਾ ਹੈ। ਡਿਊਲ ਮੋਡ ਅਤੇ ਆਟੋ ਗੱਲਬਾਤ ਦੋ ਮਾਡਲਾਂ ਨੂੰ ਬੇਨਤੀਆਂ ਭੇਜਦੇ ਹਨ, ਇਸ ਲਈ ਦੋਵਾਂ ਦੀ ਵਰਤੋਂ ਬਣਦੀ ਹੈ।

ਸੁਰੱਖਿਆ ਅਤੇ ਪਰਦੇਦਾਰੀ

  • API ਕੀਆਂ ਅਤੇ ਐਕਸੈਸ ਟੋਕਨ iOS Keychain ਵਿੱਚ ਸੰਭਾਲੇ ਜਾਂਦੇ ਹਨ, ਅਤੇ ਐਪ ਇਸ ਤਰ੍ਹਾਂ ਬਣਾਇਆ ਗਿਆ ਹੈ ਕਿ ਇਹ ਉਨ੍ਹਾਂ ਨੂੰ ਆਪਣੇ ਡਾਇਗਨਸਟਿਕ ਲੌਗਾਂ ਵਿੱਚ ਨਾ ਲਿਖੇ।
  • ਪ੍ਰੋਂਪਟ, ਗੱਲਬਾਤ ਦਾ ਕਾਂਟੈਕਸਟ ਅਤੇ ਤੁਹਾਡੇ ਚੁਣੇ ਅਟੈਚਮੈਂਟ ਸਿੱਧੇ ਤੁਹਾਡੇ ਚੁਣੇ ਪ੍ਰੋਵਾਈਡਰ ਨੂੰ ਭੇਜੇ ਜਾਂਦੇ ਹਨ।
  • ਗੱਲਬਾਤਾਂ ਤੁਹਾਡੇ ਡਿਵਾਈਸ ਉੱਤੇ ਸੰਭਾਲੀਆਂ ਜਾਂਦੀਆਂ ਹਨ। ਐਪ ਕ੍ਰਾਸ-ਐਪ ਟ੍ਰੈਕਿੰਗ ਨਹੀਂ ਕਰਦਾ। ਪਰਦੇਦਾਰੀ ਨੀਤੀ ਵੇਖੋ।

ਸੰਬੰਧਿਤ ਗਾਈਡਾਂ

AI ਮਾਡਲਾਂ ਦੀ ਤੁਲਨਾ ਕਰੋਇੱਕ ਹੀ ਪ੍ਰੋਂਪਟ ਦੋ ਮਾਡਲਾਂ ਨੂੰ ਭੇਜੋ ਅਤੇ ਦੋਵੇਂ ਜਵਾਬ ਨਾਲ-ਨਾਲ ਪੜ੍ਹੋ।ਸਮਰਥਿਤ ਪ੍ਰੋਵਾਈਡਰGemini, OpenRouter, ChatGPT ਪਲਾਨ, xAI, OpenAI, Anthropic ਅਤੇ ਹੋਰ।ਸਵਾਲ-ਜਵਾਬਕੀਮਤ, ਲੋੜਾਂ, ਪਰਦੇਦਾਰੀ ਅਤੇ ਸਮਰਥਿਤ ਮਾਡਲ।

ਉਸੇ AI ਨਾਲ ਅਜ਼ਮਾਓ ਜੋ ਤੁਸੀਂ ਪਹਿਲਾਂ ਹੀ ਵਰਤਦੇ ਹੋ।
