models.dev ਕੈਟਾਲਾਗ ਤੋਂ ਹੋਰ API ਪ੍ਰੋਵਾਈਡਰ

YamabikoChat ਜਨਤਕ models.dev ਕੈਟਾਲਾਗ ਪੜ੍ਹਦਾ ਹੈ ਅਤੇ ਹੋਰ ਬਹੁਤ ਸਾਰੇ API ਪ੍ਰੋਵਾਈਡਰ ਦਿੰਦਾ ਹੈ, ਜਿਨ੍ਹਾਂ ਵਿੱਚ OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq, xAI API, Moonshot AI (Kimi), MiniMax, Z.ai (GLM), Fireworks AI, Together AI ਅਤੇ Hugging Face ਸ਼ਾਮਲ ਹਨ। ਸੈਟਿੰਗਾਂ ਵਿੱਚ ਪ੍ਰੋਵਾਈਡਰ ਜੋੜੋ, ਆਪਣੀ API ਕੀ ਦਿਓ ਅਤੇ ਮਾਡਲ ਚੁਣੋ।

ਹਰ ਮਾਡਲ ਸਿਰਫ਼ ਤਦ ਚੱਲਦਾ ਹੈ ਜਦੋਂ ਉਸ ਦਾ API ਇਕਰਾਰਨਾਮਾ ਜਾਂਚਿਆ ਗਿਆ ਹੋਵੇ। ਜਿਹੜੇ ਮਾਡਲ ਸੁਰੱਖਿਅਤ ਢੰਗ ਨਾਲ ਨਹੀਂ ਚੱਲ ਸਕਦੇ, ਉਹ ਸਹੀ ਕਾਰਨ ਸਮੇਤ ਦਿਸਦੇ ਹਨ ਪਰ ਬੰਦ ਰਹਿੰਦੇ ਹਨ — ਐਪ ਕਦੇ ਵੀ ਤੁਹਾਨੂੰ ਚੁੱਪ-ਚਾਪ ਕਿਸੇ ਹੋਰ ਮਾਡਲ, ਐਂਡਪੌਇੰਟ ਜਾਂ ਪ੍ਰੋਵਾਈਡਰ ਉੱਤੇ ਨਹੀਂ ਭੇਜਦਾ।

ਮਾਡਲਾਂ ਨੂੰ ਇਕੱਠੇ ਵਰਤਣਾ

ਜੋੜਿਆ ਹਰ ਮਾਡਲ ਚੈਟ ਵਿੱਚ, ਦੋ ਜਵਾਬਾਂ ਦੀ ਤੁਲਨਾ ਲਈ ਡਿਊਲ ਮੋਡ ਵਿੱਚ, ਅਤੇ ਦੋ ਮਾਡਲਾਂ ਨੂੰ ਗੱਲ ਕਰਾਉਣ ਲਈ ਆਟੋ ਗੱਲਬਾਤ ਵਿੱਚ ਵਰਤਿਆ ਜਾ ਸਕਦਾ ਹੈ। ਤਸਵੀਰ ਇਨਪੁੱਟ, ਰੀਜ਼ਨਿੰਗ ਸੈਟਿੰਗਾਂ, ਸੰਦ ਅਤੇ ਕਾਂਟੈਕਸਟ ਲੰਬਾਈ ਮਾਡਲ ਅਨੁਸਾਰ ਵੱਖਰੇ ਹੁੰਦੇ ਹਨ।

ਮਾਡਲਾਂ ਦੀ ਸੂਚੀ ਅਕਸਰ ਬਦਲਦੀ ਹੈ। ਐਪ ਹਰ ਪ੍ਰੋਵਾਈਡਰ ਦੀ ਮੌਜੂਦਾ ਸੂਚੀ ਹਮੇਸ਼ਾ ਦਿਖਾਉਂਦਾ ਹੈ। ਪ੍ਰੋਵਾਈਡਰ ਅਤੇ ਉਤਪਾਦਾਂ ਦੇ ਨਾਂ ਉਨ੍ਹਾਂ ਦੇ ਮਾਲਕਾਂ ਦੇ ਟ੍ਰੇਡਮਾਰਕ ਹਨ; YamabikoChat ਉਨ੍ਹਾਂ ਨਾਲ ਸੰਬੰਧਿਤ ਨਹੀਂ ਹੈ।

ਸੰਬੰਧਿਤ ਗਾਈਡਾਂ

AI ਮਾਡਲਾਂ ਦੀ ਤੁਲਨਾ ਕਰੋਇੱਕ ਹੀ ਪ੍ਰੋਂਪਟ ਦੋ ਮਾਡਲਾਂ ਨੂੰ ਭੇਜੋ ਅਤੇ ਦੋਵੇਂ ਜਵਾਬ ਨਾਲ-ਨਾਲ ਪੜ੍ਹੋ।ਆਪਣੀ API ਕੀ ਵਰਤੋBYOK ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ, ਖਰਚ ਕਿੰਨਾ ਆਉਂਦਾ ਹੈ, ਅਤੇ ਤੁਹਾਡੀ ਕੀ ਕਿੱਥੇ ਸੰਭਾਲੀ ਜਾਂਦੀ ਹੈ।ਸਵਾਲ-ਜਵਾਬਕੀਮਤ, ਲੋੜਾਂ, ਪਰਦੇਦਾਰੀ ਅਤੇ ਸਮਰਥਿਤ ਮਾਡਲ।

ਉਸੇ AI ਨਾਲ ਅਜ਼ਮਾਓ ਜੋ ਤੁਸੀਂ ਪਹਿਲਾਂ ਹੀ ਵਰਤਦੇ ਹੋ।
