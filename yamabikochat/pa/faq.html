ਸਵਾਲ-ਜਵਾਬ

ਆਮ ਪੁੱਛੇ ਜਾਂਦੇ ਸਵਾਲ

ਕੀਮਤ, API ਕੀ, ਸਮਰਥਿਤ ਮਾਡਲ, ਪਰਦੇਦਾਰੀ ਅਤੇ ਲੋੜਾਂ ਬਾਰੇ ਛੋਟੇ ਜਵਾਬ।

ਆਖਰੀ ਅੱਪਡੇਟ: 2026-11-17

ਕੀ YamabikoChat ਮੁਫ਼ਤ ਹੈ?

ਹਾਂ। YamabikoChat ਡਾਊਨਲੋਡ ਕਰਨਾ ਮੁਫ਼ਤ ਹੈ; ਕੋਈ ਵਿਗਿਆਪਨ ਨਹੀਂ, ਸਾਈਨ-ਅੱਪ ਨਹੀਂ, ਅਤੇ ਐਪ ਦੇ ਅੰਦਰ ਸਬਸਕ੍ਰਿਪਸ਼ਨ ਜਾਂ ਟੋਕਨ ਖਰੀਦ ਨਹੀਂ। ਤੁਸੀਂ ਜੋ ਵਰਤੋਂ ਬਣਾਉਂਦੇ ਹੋ, ਉਸ ਦਾ ਭੁਗਤਾਨ ਉਸ ਪ੍ਰੋਵਾਈਡਰ ਦੀਆਂ ਕੀਮਤਾਂ ਅਤੇ ਸ਼ਰਤਾਂ ਅਨੁਸਾਰ ਸਿੱਧਾ ਪ੍ਰੋਵਾਈਡਰ ਨੂੰ ਕਰਦੇ ਹੋ।

ਕੀ ਮੈਨੂੰ API ਕੀ ਦੀ ਲੋੜ ਹੈ?

ਤੁਹਾਨੂੰ ਸਮਰਥਿਤ AI ਪ੍ਰੋਵਾਈਡਰ ਤੋਂ API ਕੀ, ਜਾਂ ChatGPT ਪਲਾਨ ਜਾਂ xAI ਵਰਗੇ ਸਮਰਥਿਤ ਖਾਤੇ ਵਿੱਚ ਸਾਈਨ ਇਨ — ਇਨ੍ਹਾਂ ਵਿੱਚੋਂ ਇੱਕ ਦੀ ਲੋੜ ਹੈ। Apple Intelligence ਸਮਰਥਿਤ ਡਿਵਾਈਸਾਂ ਉੱਤੇ ਕਿਸੇ ਕੀ ਤੋਂ ਬਿਨਾਂ ਕੰਮ ਕਰਦਾ ਹੈ।

ਕੀ ਮੈਂ API ਕੀ ਦੀ ਥਾਂ ਆਪਣੀ ChatGPT ਸਬਸਕ੍ਰਿਪਸ਼ਨ ਵਰਤ ਸਕਦਾ ਹਾਂ?

ਹਾਂ। ChatGPT ਪਲਾਨ ਕਨੈਕਸ਼ਨ ਨਾਲ ਤੁਸੀਂ ChatGPT ਖਾਤੇ ਨਾਲ ਸਾਈਨ ਇਨ ਕਰਕੇ ਆਪਣੇ ਪਲਾਨ ਵਿੱਚ ਸ਼ਾਮਲ ਮਾਡਲ OpenAI API ਕੀ ਤੋਂ ਬਿਨਾਂ ਵਰਤ ਸਕਦੇ ਹੋ।

ਕਿਹੜੇ AI ਮਾਡਲ ਵਰਤ ਸਕਦਾ ਹਾਂ?

Google Gemini, OpenRouter, ChatGPT ਪਲਾਨ, xAI, Apple Intelligence, Sarashina ਅਤੇ PLaMo ਬਿਲਟ-ਇਨ ਹਨ। OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq ਅਤੇ ਹੋਰ ਬਹੁਤ ਸਾਰੇ API ਪ੍ਰੋਵਾਈਡਰ models.dev ਕੈਟਾਲਾਗ ਰਾਹੀਂ ਉਪਲਬਧ ਹਨ, ਅਤੇ ਤੁਸੀਂ ਸਮਰਥਿਤ API ਫਾਰਮੈਟ ਵਰਤਣ ਵਾਲਾ ਕਸਟਮ ਐਂਡਪੌਇੰਟ ਵੀ ਜੋੜ ਸਕਦੇ ਹੋ। ਉਪਲਬਧ ਮਾਡਲ ਹਰ ਪ੍ਰੋਵਾਈਡਰ ਉੱਤੇ ਨਿਰਭਰ ਕਰਦੇ ਹਨ।

ਕੀ ਮੈਂ ਆਪਣੀ Anthropic API ਕੀ ਨਾਲ Claude ਵਰਤ ਸਕਦਾ ਹਾਂ?

ਹਾਂ। ਪ੍ਰੋਵਾਈਡਰ ਕੈਟਾਲਾਗ ਵਿੱਚੋਂ Anthropic ਜੋੜੋ ਅਤੇ ਆਪਣੀ API ਕੀ ਦਿਓ, ਜਾਂ Anthropic Messages API ਵਰਤਣ ਵਾਲਾ ਕਸਟਮ ਐਂਡਪੌਇੰਟ ਸੈੱਟ ਕਰੋ।

ਕੀ ChatGPT, Gemini ਅਤੇ Claude ਦੇ ਜਵਾਬ ਨਾਲ-ਨਾਲ ਤੁਲਨਾ ਕਰ ਸਕਦਾ ਹਾਂ?

ਹਾਂ। ਡਿਊਲ ਮੋਡ ਇੱਕ ਹੀ ਪ੍ਰੋਂਪਟ ਦੋ ਮਾਡਲਾਂ ਨੂੰ ਭੇਜਦਾ ਹੈ ਅਤੇ ਦੋਵੇਂ ਜਵਾਬ ਨਾਲ-ਨਾਲ ਦਿਖਾਉਂਦਾ ਹੈ। ਤੁਹਾਡੇ ਜੋੜੇ ਪ੍ਰੋਵਾਈਡਰਾਂ ਵਿੱਚੋਂ ਕੋਈ ਵੀ ਦੋ ਮਾਡਲ ਚੁਣੋ।

ਮੇਰੀਆਂ ਗੱਲਬਾਤਾਂ ਅਤੇ API ਕੀਆਂ ਕਿੱਥੇ ਸੰਭਾਲੀਆਂ ਜਾਂਦੀਆਂ ਹਨ?

ਗੱਲਬਾਤਾਂ ਅਤੇ ਸੈਟਿੰਗਾਂ ਤੁਹਾਡੇ ਡਿਵਾਈਸ ਉੱਤੇ ਸੰਭਾਲੀਆਂ ਜਾਂਦੀਆਂ ਹਨ। API ਕੀਆਂ ਅਤੇ ਐਕਸੈਸ ਟੋਕਨ iOS Keychain ਵਿੱਚ ਸੰਭਾਲੇ ਜਾਂਦੇ ਹਨ। ਤੁਹਾਡੇ ਪ੍ਰੋਂਪਟ, ਗੱਲਬਾਤ ਦਾ ਕਾਂਟੈਕਸਟ ਅਤੇ ਤੁਹਾਡੇ ਚੁਣੇ ਅਟੈਚਮੈਂਟ ਸਿਰਫ਼ ਤੁਹਾਡੇ ਚੁਣੇ ਪ੍ਰੋਵਾਈਡਰ ਨੂੰ ਭੇਜੇ ਜਾਂਦੇ ਹਨ।

ਕੀ YamabikoChat iPad ਉੱਤੇ ਚੱਲਦਾ ਹੈ?

ਹਾਂ। ਇਹ iPhone ਅਤੇ iPad ਲਈ ਨੇਟਿਵ ਐਪ ਹੈ, ਅਤੇ iPad ਉੱਤੇ ਸਪਲਿਟ ਵਿਊ ਵਿੱਚ ਗੱਲਬਾਤਾਂ ਦੀ ਸੂਚੀ ਅਤੇ ਚੈਟ ਨਾਲ-ਨਾਲ ਦਿਸਦੇ ਹਨ।

ਸਿਸਟਮ ਦੀਆਂ ਲੋੜਾਂ ਕੀ ਹਨ?

iPhone ਉੱਤੇ iOS 17 ਜਾਂ ਨਵਾਂ, ਅਤੇ iPad ਉੱਤੇ iPadOS 17 ਜਾਂ ਨਵਾਂ। Apple Intelligence ਲਈ ਅਜਿਹਾ ਡਿਵਾਈਸ ਅਤੇ OS ਸੰਸਕਰਣ ਚਾਹੀਦਾ ਹੈ ਜੋ ਇਸ ਨੂੰ ਸਮਰਥਨ ਦੇਵੇ।

ਕੀ YamabikoChat ਓਪਨ ਸੋਰਸ ਹੈ?

ਹਾਂ। ਸੋਰਸ ਕੋਡ MIT License ਅਧੀਨ GitHub ਉੱਤੇ ਪ੍ਰਕਾਸ਼ਿਤ ਹੈ। ਨਾਲ ਦਿੱਤੇ ਤੀਜੀ ਧਿਰ ਦੇ ਸੌਫਟਵੇਅਰ ਦੇ ਆਪਣੇ ਲਾਇਸੰਸ ਬਰਕਰਾਰ ਰਹਿੰਦੇ ਹਨ।

ਹੋਰ ਸਵਾਲ ਹੈ? ਸਹਾਇਤਾ ਵੇਖੋ।

ਸੰਬੰਧਿਤ ਗਾਈਡਾਂ

AI ਮਾਡਲਾਂ ਦੀ ਤੁਲਨਾ ਕਰੋਇੱਕ ਹੀ ਪ੍ਰੋਂਪਟ ਦੋ ਮਾਡਲਾਂ ਨੂੰ ਭੇਜੋ ਅਤੇ ਦੋਵੇਂ ਜਵਾਬ ਨਾਲ-ਨਾਲ ਪੜ੍ਹੋ।ਆਪਣੀ API ਕੀ ਵਰਤੋBYOK ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ, ਖਰਚ ਕਿੰਨਾ ਆਉਂਦਾ ਹੈ, ਅਤੇ ਤੁਹਾਡੀ ਕੀ ਕਿੱਥੇ ਸੰਭਾਲੀ ਜਾਂਦੀ ਹੈ।ਸਮਰਥਿਤ ਪ੍ਰੋਵਾਈਡਰGemini, OpenRouter, ChatGPT ਪਲਾਨ, xAI, OpenAI, Anthropic ਅਤੇ ਹੋਰ।

ਉਸੇ AI ਨਾਲ ਅਜ਼ਮਾਓ ਜੋ ਤੁਸੀਂ ਪਹਿਲਾਂ ਹੀ ਵਰਤਦੇ ਹੋ।
