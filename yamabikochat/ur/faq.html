کیا YamabikoChat مفت ہے؟

جی ہاں۔ YamabikoChat ڈاؤن لوڈ کرنا مفت ہے، نہ کوئی اشتہار، نہ سائن اپ، اور نہ ایپ کے اندر کوئی سبسکرپشن یا ٹوکن کی خریداری۔ آپ جو استعمال بناتے ہیں اس کی ادائیگی براہ راست اپنے اے آئی فراہم کنندہ کو، اس کے نرخ اور شرائط کے تحت کرتے ہیں۔

کیا مجھے API کلید درکار ہے؟

آپ کو کسی معاون اے آئی فراہم کنندہ کی API کلید یا کسی معاون اکاؤنٹ سے سائن ان درکار ہوگا، جیسے ChatGPT پلان یا xAI۔ Apple Intelligence بغیر کلید کے ان ڈیوائسز پر کام کرتا ہے جو اسے سپورٹ کرتے ہیں۔

کیا میں API کلید کے بجائے اپنی ChatGPT سبسکرپشن استعمال کر سکتا ہوں؟

جی ہاں۔ ChatGPT پلان کنکشن آپ کو اپنے ChatGPT اکاؤنٹ سے سائن ان کرنے اور اپنے پلان میں شامل ماڈلز استعمال کرنے دیتا ہے، بغیر OpenAI API کلید کے۔

میں کون سے اے آئی ماڈلز استعمال کر سکتا ہوں؟

Google Gemini، OpenRouter، ChatGPT پلان، xAI، Apple Intelligence، Sarashina اور PLaMo پہلے سے شامل ہیں۔ OpenAI، Anthropic (Claude)، DeepSeek، Mistral، Groq اور بہت سے دیگر API فراہم کنندگان models.dev کیٹلاگ کے ذریعے دستیاب ہیں، اور آپ کوئی ایسا اپنا اینڈ پوائنٹ بھی شامل کر سکتے ہیں جو معاون API فارمیٹ استعمال کرے۔ دستیاب ماڈلز کا انحصار ہر فراہم کنندہ پر ہے۔

کیا میں اپنی Anthropic API کلید کے ساتھ Claude استعمال کر سکتا ہوں؟

جی ہاں۔ فراہم کنندگان کے کیٹلاگ سے Anthropic کو اپنی API کلید کے ساتھ شامل کریں، یا Anthropic Messages API استعمال کرنے والا اپنا اینڈ پوائنٹ ترتیب دیں۔

کیا میں ChatGPT، Gemini اور Claude کے جوابات ساتھ ساتھ موازنہ کر سکتا ہوں؟

جی ہاں۔ ڈوئل موڈ ایک ہی پرامپٹ دو ماڈلز کو بھیجتا ہے اور دونوں جوابات ایک دوسرے کے ساتھ دکھاتا ہے۔ اپنے جڑے ہوئے فراہم کنندگان میں سے کوئی بھی دو ماڈلز چنیں۔

میری گفتگو اور API کلیدیں کہاں محفوظ ہوتی ہیں؟

گفتگو اور سیٹنگز آپ کے ڈیوائس پر محفوظ ہوتی ہیں۔ API کلیدیں اور ایکسیس ٹوکنز iOS کی Keychain میں محفوظ ہوتے ہیں۔ آپ کے پرامپٹس، گفتگو کا سیاق اور آپ کے منتخب کردہ منسلکات صرف اسی فراہم کنندہ کو بھیجے جاتے ہیں جو آپ نے منتخب کیا۔

کیا YamabikoChat iPad پر کام کرتا ہے؟

جی ہاں۔ یہ iPhone اور iPad کے لیے نیٹیو ایپ ہے، جس میں iPad پر سپلٹ ویو آپ کی گفتگو کی فہرست اور چیٹ ساتھ ساتھ دکھاتا ہے۔

سسٹم کے تقاضے کیا ہیں؟

iPhone پر iOS 17 یا بعد کا ورژن، اور iPad پر iPadOS 17 یا بعد کا ورژن۔ Apple Intelligence کے لیے ایسا ڈیوائس اور OS ورژن درکار ہے جو اسے سپورٹ کرے۔
