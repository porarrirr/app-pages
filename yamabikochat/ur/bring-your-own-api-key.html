اپنی کلید ساتھ لائیں

iPhone اور iPad پر اے آئی چیٹ کے لیے اپنی API کلید استعمال کریں

YamabikoChat ایک BYOK (اپنی کلید ساتھ لائیں) کلائنٹ ہے۔ آپ API کلید شامل کرتے ہیں — یا کسی معاون اکاؤنٹ سے سائن ان کرتے ہیں — اور ایپ آپ کے پرامپٹس براہ راست اسی فراہم کنندہ کو بھیجتی ہے۔ درمیان میں نہ کوئی YamabikoChat سبسکرپشن ہے نہ ٹوکن بیچنے والا۔

آخری تازہ کاری: 2026-11-17

“اپنی کلید ساتھ لائیں” کا مطلب کیا ہے

OpenAI، Google، Anthropic اور OpenRouter جیسے اے آئی فراہم کنندگان اپنے ماڈلز تک رسائی API کلیدوں کے ذریعے فروخت کرتے ہیں، جس کا بل عام طور پر استعمال کے حساب سے ہوتا ہے۔ BYOK ایپ ان کلیدوں کے لیے ایک کلائنٹ ہے: آپ اپنے فراہم کنندہ کے اکاؤنٹ میں کلید بناتے ہیں، اسے ایپ میں شامل کرتے ہیں، اور فراہم کنندہ آپ کو براہ راست آپ کے استعمال کا بل دیتا ہے۔

اپنی کلید کیوں استعمال کریں

  • جتنا استعمال، اتنی ادائیگی۔ ہلکے صارفین اکثر ماہانہ اے آئی سبسکرپشن سے کم خرچ کرتے ہیں؛ زیادہ استعمال کرنے والوں کو بالکل معلوم ہوتا ہے کہ لاگت کہاں سے آ رہی ہے۔
  • ماڈل منتخب کریں۔ وہ ماڈلز استعمال کریں جو آپ کا فراہم کنندہ پیش کرتا ہے، نہ کہ کوئی ایپ کی مقرر کردہ فہرست۔
  • ایک ایپ، کئی فراہم کنندگان۔ Gemini، OpenRouter، OpenAI، Anthropic اور دیگر کو ایک جگہ رکھیں، اور ڈوئل موڈ میں ان کا موازنہ کریں۔
  • اپنا استعمال دیکھیں۔ ٹوکن استعمال کے اعداد و شمار بتاتے ہیں کہ آپ کتنا استعمال کرتے ہیں۔

اسے کیسے ترتیب دیں

  1. API کلید بنائیں اپنے فراہم کنندہ کے کنسول میں — مثلاً Gemini کے لیے Google AI Studio، OpenAI پلیٹ فارم، Anthropic کنسول، یا OpenRouter۔
  2. YamabikoChat میں سیٹنگز کھولیں اور کنکشن سیٹنگز میں فراہم کنندہ منتخب کریں۔
  3. کلید چسپاں کریں۔ یہ آپ کے ڈیوائس پر iOS کی Keychain میں محفوظ ہو جاتی ہے۔
  4. ماڈل چنیں اور چیٹ شروع کریں۔ وہ ماڈلز جنہیں ایپ محفوظ طریقے سے نہیں چلا سکتی، اندازے کے بجائے وجہ کے ساتھ غیر دستیاب دکھائے جاتے ہیں۔

API کلید نہیں ہے؟ سائن ان کریں

  • ChatGPT پلان — اپنے ChatGPT اکاؤنٹ سے سائن ان کریں اور اپنے پلان میں شامل ماڈلز استعمال کریں۔
  • xAI — اپنے xAI اکاؤنٹ سے سائن ان کریں۔
  • Apple Intelligence — معاون ڈیوائسز پر پہلے سے شامل، ڈیوائس پر یا Private Cloud Compute کے ذریعے، بغیر کسی کلید کے۔

اپنی مرضی کے اینڈ پوائنٹس

اگر آپ کی سروس فہرست میں نہیں ہے تو اس کے بیس URL اور کلید کے ساتھ اپنا اینڈ پوائنٹ شامل کریں، اور معاون API فارمیٹس میں سے ایک چنیں: OpenAI Chat Completions، OpenAI Responses، Anthropic Messages، Gemini (Google Generative AI) یا Mistral۔

اس کی لاگت کتنی ہے

ایپ مفت ہے اور اس میں کوئی خریداری نہیں۔ آپ کا فراہم کنندہ اپنے نرخ، حدود اور شرائط کے تحت استعمال کا بل وصول کرتا ہے۔ ڈوئل موڈ اور آٹو گفتگو دو ماڈلز کو درخواستیں بھیجتے ہیں، اس لیے دونوں پر استعمال بنتا ہے۔

سیکیورٹی اور رازداری

  • API کلیدیں اور ایکسیس ٹوکنز iOS کی Keychain میں محفوظ رہتے ہیں، اور ایپ کو اس طرح ڈیزائن کیا گیا ہے کہ وہ انہیں اپنے ڈائگناسٹک لاگز میں نہ لکھے۔
  • پرامپٹس، گفتگو کا سیاق اور آپ کے منتخب کردہ منسلکات براہ راست اسی فراہم کنندہ کو بھیجے جاتے ہیں جو آپ نے منتخب کیا۔
  • گفتگو آپ کے ڈیوائس پر محفوظ ہوتی ہے۔ ایپ ایپس کے درمیان ٹریکنگ استعمال نہیں کرتی۔ رازداری کی پالیسی دیکھیں۔

متعلقہ رہنمائیں

اے آئی ماڈلز کا موازنہ ایک ہی پرامپٹ دو ماڈلز کو بھیجیں اور دونوں جوابات ساتھ ساتھ پڑھیں۔ معاون فراہم کنندگان Gemini، OpenRouter، ChatGPT پلان، xAI، OpenAI، Anthropic اور مزید۔ عام سوالات قیمت، تقاضے، رازداری اور معاون ماڈلز۔
