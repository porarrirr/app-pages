ନିଜ କୀ ଆଣନ୍ତୁ

iPhone ଓ iPad ରେ AI ଚାଟ୍ ପାଇଁ ନିଜ API କୀ ବ୍ୟବହାର କରନ୍ତୁ

YamabikoChat ଏକ ବ୍ରିଙ୍ଗ୍-ୟୋର୍-ଓନ୍-କୀ (BYOK) କ୍ଲାଏଣ୍ଟ। ଆପଣ ଏକ API କୀ ଯୋଡ଼ନ୍ତି — କିମ୍ବା ସମର୍ଥିତ ଆକାଉଣ୍ଟରେ ସାଇନ୍ ଇନ୍ କରନ୍ତି — ଏବଂ ଆପ୍ ଆପଣଙ୍କ ପ୍ରମ୍ପ୍ଟ ସିଧାସଳଖ ସେହି ପ୍ରୋଭାଇଡର୍କୁ ପଠାଏ। ମଝିରେ YamabikoChat ର ସବସ୍କ୍ରିପ୍ସନ୍ କିମ୍ବା ଟୋକେନ୍ ବିକ୍ରେତା ନାହିଁ।

ଶେଷ ଅଦ୍ୟତନ: 2026-11-17

“ନିଜ କୀ ବ୍ୟବହାର କରନ୍ତୁ” ର ଅର୍ଥ

OpenAI, Google, Anthropic ଏବଂ OpenRouter ଭଳି AI ପ୍ରୋଭାଇଡର୍ API କୀ ମାଧ୍ୟମରେ ସେମାନଙ୍କ ମଡେଲର ଆକସେସ୍ ବିକ୍ରି କରନ୍ତି, ସାଧାରଣତଃ ବ୍ୟବହାର ଅନୁସାରେ ବିଲ୍ କରନ୍ତି। BYOK ଆପ୍ ସେହି କୀ ପାଇଁ ଏକ କ୍ଲାଏଣ୍ଟ: ଆପଣ ନିଜ ପ୍ରୋଭାଇଡର୍ ଆକାଉଣ୍ଟରେ ଏକ କୀ ତିଆରି କରନ୍ତି, ଏହାକୁ ଆପ୍ ରେ ଯୋଡ଼ନ୍ତି, ଏବଂ ଆପଣ ଯାହା ବ୍ୟବହାର କରନ୍ତି ତାର ବିଲ୍ ପ୍ରୋଭାଇଡର୍ ସିଧାସଳଖ ଆପଣଙ୍କୁ କରେ।

ନିଜ କୀ କାହିଁକି ବ୍ୟବହାର କରିବେ

  • ଯାହା ବ୍ୟବହାର କରନ୍ତି ତାର ଦେୟ ଦିଅନ୍ତୁ। ହାଲୁକା ବ୍ୟବହାରକାରୀମାନେ ପ୍ରାୟତଃ ମାସିକ AI ସବସ୍କ୍ରିପ୍ସନ୍ ଠାରୁ କମ୍ ଖର୍ଚ୍ଚ କରନ୍ତି; ଭାରୀ ବ୍ୟବହାରକାରୀମାନେ ଖର୍ଚ୍ଚ କେଉଁଠୁ ଆସୁଛି ତାହା ସ୍ପଷ୍ଟ ଦେଖନ୍ତି।
  • ମଡେଲ ବାଛନ୍ତୁ। ଏକ ଆପ୍ ବାଛିଥିବା ସ୍ଥିର ତାଲିକା ନୁହେଁ, ଆପଣଙ୍କ ପ୍ରୋଭାଇଡର୍ ଯୋଗାଉଥିବା ମଡେଲ ବ୍ୟବହାର କରନ୍ତୁ।
  • ଏକ ଆପ୍, ଅନେକ ପ୍ରୋଭାଇଡର୍। Gemini, OpenRouter, OpenAI, Anthropic ଆଦିକୁ ପାଶ୍ୱରେ ପାଶ୍ୱରେ ରଖନ୍ତୁ ଏବଂ ଡୁଆଲ୍ ମୋଡ୍ ରେ ସେଗୁଡ଼ିକୁ ତୁଳନା କରନ୍ତୁ।
  • ନିଜ ବ୍ୟବହାର ଦେଖନ୍ତୁ। ଟୋକେନ୍ ବ୍ୟବହାର ପରିସଂଖ୍ୟାନ ଦେଖାଏ ଯେ ଆପଣ କେତେ ବ୍ୟବହାର କରୁଛନ୍ତି।

ଏହାକୁ କିପରି ସେଟ୍ ଅପ୍ କରିବେ

  1. API କୀ ତିଆରି କରନ୍ତୁ ଆପଣଙ୍କ ପ୍ରୋଭାଇଡର୍ କନସୋଲରେ — ଉଦାହରଣ ସ୍ୱରୂପ Gemini ପାଇଁ Google AI Studio, OpenAI ପ୍ଲାଟଫର୍ମ, Anthropic କନସୋଲ କିମ୍ବା OpenRouter।
  2. YamabikoChat ରେ ସେଟିଂସ୍ ଖୋଲନ୍ତୁ ଏବଂ ସଂଯୋଗ ସେଟିଂସ୍ ରେ ପ୍ରୋଭାଇଡର୍ ବାଛନ୍ତୁ।
  3. କୀ ପେଷ୍ଟ କରନ୍ତୁ। ଏହା ଆପଣଙ୍କ ଡିଭାଇସର iOS Keychain ରେ ସେଭ୍ ହୁଏ।
  4. ମଡେଲ ବାଛି ଚାଟ୍ ଆରମ୍ଭ କରନ୍ତୁ। ଆପ୍ ଯେଉଁ ମଡେଲକୁ ସୁରକ୍ଷିତ ଭାବରେ ଚଲାଇପାରିବ ନାହିଁ, ସେଗୁଡ଼ିକ ଅନୁମାନ କରିବା ପରିବର୍ତ୍ତେ କାରଣ ସହିତ ଅକ୍ଷମ ଭାବରେ ଦେଖାଯାଏ।

API କୀ ନାହିଁ? ସାଇନ୍ ଇନ୍ କରନ୍ତୁ

  • ChatGPT ପ୍ଲାନ୍ — ଆପଣଙ୍କ ChatGPT ଆକାଉଣ୍ଟରେ ସାଇନ୍ ଇନ୍ କରି ଆପଣଙ୍କ ପ୍ଲାନ୍ ରେ ଅନ୍ତର୍ଭୁକ୍ତ ମଡେଲ ବ୍ୟବହାର କରନ୍ତୁ।
  • xAI — ଆପଣଙ୍କ xAI ଆକାଉଣ୍ଟରେ ସାଇନ୍ ଇନ୍ କରନ୍ତୁ।
  • Apple Intelligence — ସମର୍ଥିତ ଡିଭାଇସରେ ବିଲ୍ଟ-ଇନ୍, ଡିଭାଇସରେ ହିଁ କିମ୍ବା Private Cloud Compute ମାଧ୍ୟମରେ, କୌଣସି କୀ ବିନା।

କଷ୍ଟମ୍ ଏଣ୍ଡପଏଣ୍ଟ

ଆପଣଙ୍କ ସେବା ତାଲିକାରେ ନ ଥିଲେ, ଏହାର ବେସ୍ URL ଏବଂ କୀ ସହିତ ଏକ କଷ୍ଟମ୍ ଏଣ୍ଡପଏଣ୍ଟ ଯୋଡ଼ନ୍ତୁ, ଏବଂ ସମର୍ଥିତ API ଫର୍ମାଟ୍ ମଧ୍ୟରୁ ଗୋଟିଏ ବାଛନ୍ତୁ: OpenAI Chat Completions, OpenAI Responses, Anthropic Messages, Gemini (Google Generative AI) କିମ୍ବା Mistral।

ଏହାର ଖର୍ଚ୍ଚ କେତେ

ଆପ୍ ମାଗଣା, ଆପ୍ ଭିତରେ କୌଣସି କ୍ରୟ ନାହିଁ। ଆପଣଙ୍କ ପ୍ରୋଭାଇଡର୍ ନିଜ ମୂଲ୍ୟ, ସୀମା ଏବଂ ସର୍ତ୍ତାବଳୀ ଅଧୀନରେ ବ୍ୟବହାରର ବିଲ୍ କରେ। ଡୁଆଲ୍ ମୋଡ୍ ଏବଂ ଅଟୋ ବାର୍ତ୍ତାଳାପ ଦୁଇଟି ମଡେଲକୁ ଅନୁରୋଧ ପଠାନ୍ତି, ତେଣୁ ଉଭୟଙ୍କ ଉପରେ ବ୍ୟବହାର ସୃଷ୍ଟି ହୁଏ।

ସୁରକ୍ଷା ଏବଂ ଗୋପନୀୟତା

  • API କୀ ଏବଂ ଆକସେସ୍ ଟୋକେନ୍ iOS Keychain ରେ ସେଭ୍ ହୁଏ, ଏବଂ ଆପ୍ ସେଗୁଡ଼ିକୁ ନିଜ ଡାଇଗ୍ନୋଷ୍ଟିକ୍ ଲଗ୍ ରେ ଲେଖିବ ନାହିଁ ବୋଲି ଡିଜାଇନ୍ କରାଯାଇଛି।
  • ପ୍ରମ୍ପ୍ଟ, ବାର୍ତ୍ତାଳାପର ପ୍ରସଙ୍ଗ ଏବଂ ଆପଣ ବାଛିଥିବା ସଂଲଗ୍ନ ସିଧାସଳଖ ଆପଣ ବାଛିଥିବା ପ୍ରୋଭାଇଡର୍କୁ ପଠାଯାଏ।
  • ବାର୍ତ୍ତାଳାପ ଆପଣଙ୍କ ଡିଭାଇସରେ ସେଭ୍ ହୁଏ। ଆପ୍ କ୍ରସ୍-ଆପ୍ ଟ୍ରାକିଂ ବ୍ୟବହାର କରେ ନାହିଁ। ଗୋପନୀୟତା ନୀତି ଦେଖନ୍ତୁ।

ସଂପୃକ୍ତ ଗାଇଡ୍

AI ମଡେଲ ତୁଳନା କରନ୍ତୁ ଗୋଟିଏ ପ୍ରମ୍ପ୍ଟ ଦୁଇଟି ମଡେଲକୁ ପଠାନ୍ତୁ ଏବଂ ଦୁଇଟି ଉତ୍ତର ପାଶ୍ୱରେ ପାଶ୍ୱରେ ପଢ଼ନ୍ତୁ। ସମର୍ଥିତ ପ୍ରୋଭାଇଡର୍ Gemini, OpenRouter, ChatGPT ପ୍ଲାନ୍, xAI, OpenAI, Anthropic ଏବଂ ଅଧିକ। ପ୍ରଶ୍ନୋତ୍ତର ମୂଲ୍ୟ, ଆବଶ୍ୟକତା, ଗୋପନୀୟତା ଏବଂ ସମର୍ଥିତ ମଡେଲ।

ଆପଣ ପୂର୍ବରୁ ବ୍ୟବହାର କରୁଥିବା AI ସହିତ ଏହାକୁ ଚେଷ୍ଟା କରନ୍ତୁ।
