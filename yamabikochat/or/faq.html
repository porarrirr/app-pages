ବାରମ୍ବାର ପଚରାଯାଉଥିବା ପ୍ରଶ୍ନ

ମୂଲ୍ୟ, API କୀ, ସମର୍ଥିତ ମଡେଲ, ଗୋପନୀୟତା ଏବଂ ଆବଶ୍ୟକତା ବିଷୟରେ ସଂକ୍ଷିପ୍ତ ଉତ୍ତର।

ଶେଷ ଅଦ୍ୟତନ: 2026-11-17

YamabikoChat ମାଗଣା କି?

ହଁ। YamabikoChat ଡାଉନଲୋଡ୍ କରିବା ମାଗଣା, କୌଣସି ବିଜ୍ଞାପନ ନାହିଁ, ସାଇନ୍-ଅପ୍ ନାହିଁ, ଏବଂ ଆପ୍ ଭିତରେ ସବସ୍କ୍ରିପ୍ସନ୍ କିମ୍ବା ଟୋକେନ୍ କ୍ରୟ ନାହିଁ। ଆପଣ ଯେଉଁ ବ୍ୟବହାର କରନ୍ତି, ତାର ଦେୟ ସେହି ପ୍ରୋଭାଇଡର୍ ର ମୂଲ୍ୟ ଏବଂ ସର୍ତ୍ତାବଳୀ ଅଧୀନରେ ସିଧାସଳଖ ଆପଣଙ୍କ AI ପ୍ରୋଭାଇଡର୍କୁ ଦିଅନ୍ତି।

ମୋତେ API କୀ ଆବଶ୍ୟକ କି?

ଆପଣଙ୍କୁ ସମର୍ଥିତ AI ପ୍ରୋଭାଇଡର୍ ର API କୀ କିମ୍ବା ChatGPT ପ୍ଲାନ୍ କିମ୍ବା xAI ଭଳି ସମର୍ଥିତ ଆକାଉଣ୍ଟରେ ସାଇନ୍ ଇନ୍ ଆବଶ୍ୟକ। Apple Intelligence ଏହାକୁ ସମର୍ଥନ କରୁଥିବା ଡିଭାଇସରେ କୀ ବିନା କାମ କରେ।

API କୀ ବଦଳେ ମୁଁ ମୋର ChatGPT ସବସ୍କ୍ରିପ୍ସନ୍ ବ୍ୟବହାର କରିପାରିବି କି?

ହଁ। ChatGPT ପ୍ଲାନ୍ ସଂଯୋଗ ଦ୍ୱାରା ଆପଣ ନିଜ ChatGPT ଆକାଉଣ୍ଟରେ ସାଇନ୍ ଇନ୍ କରିପାରିବେ ଏବଂ OpenAI API କୀ ବିନା ନିଜ ପ୍ଲାନ୍ ରେ ଅନ୍ତର୍ଭୁକ୍ତ ମଡେଲ ବ୍ୟବହାର କରିପାରିବେ।

କେଉଁ AI ମଡେଲ ବ୍ୟବହାର କରିପାରିବି?

Google Gemini, OpenRouter, ChatGPT ପ୍ଲାନ୍, xAI, Apple Intelligence, Sarashina ଏବଂ PLaMo ବିଲ୍ଟ-ଇନ୍। OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq ଏବଂ ଅନେକ ଅନ୍ୟ API ପ୍ରୋଭାଇଡର୍ models.dev କ୍ୟାଟାଲଗ୍ ମାଧ୍ୟମରେ ଉପଲବ୍ଧ, ଏବଂ ଆପଣ ସମର୍ଥିତ API ଫର୍ମାଟ୍ ବ୍ୟବହାର କରୁଥିବା ଏକ କଷ୍ଟମ୍ ଏଣ୍ଡପଏଣ୍ଟ ମଧ୍ୟ ଯୋଡ଼ିପାରିବେ। ଉପଲବ୍ଧ ମଡେଲ ପ୍ରତ୍ୟେକ ପ୍ରୋଭାଇଡର୍ ଉପରେ ନିର୍ଭର କରେ।

ମୁଁ ମୋର Anthropic API କୀ ସହିତ Claude ବ୍ୟବହାର କରିପାରିବି କି?

ହଁ। ପ୍ରୋଭାଇଡର୍ କ୍ୟାଟାଲଗ୍ ରୁ ଆପଣଙ୍କ API କୀ ସହିତ Anthropic ଯୋଡ଼ନ୍ତୁ, କିମ୍ବା Anthropic Messages API ବ୍ୟବହାର କରୁଥିବା ଏକ କଷ୍ଟମ୍ ଏଣ୍ଡପଏଣ୍ଟ ସେଟ୍ କରନ୍ତୁ।

ମୁଁ ChatGPT, Gemini ଏବଂ Claude ର ଉତ୍ତର ପାଶ୍ୱରେ ପାଶ୍ୱରେ ତୁଳନା କରିପାରିବି କି?

ହଁ। ଡୁଆଲ୍ ମୋଡ୍ ଏକା ପ୍ରମ୍ପ୍ଟ ଦୁଇଟି ମଡେଲକୁ ପଠାଏ ଏବଂ ଦୁଇଟି ଉତ୍ତର ପାଖାପାଖି ଦେଖାଏ। ଆପଣ ସଂଯୋଗ କରିଥିବା ପ୍ରୋଭାଇଡର୍ ରୁ ଯେକୌଣସି ଦୁଇଟି ମଡେଲ ବାଛନ୍ତୁ।

ମୋର ବାର୍ତ୍ତାଳାପ ଏବଂ API କୀ କେଉଁଠି ସେଭ୍ ହୁଏ?

ବାର୍ତ୍ତାଳାପ ଏବଂ ସେଟିଂସ୍ ଆପଣଙ୍କ ଡିଭାଇସରେ ସେଭ୍ ହୁଏ। API କୀ ଏବଂ ଆକସେସ୍ ଟୋକେନ୍ iOS Keychain ରେ ସେଭ୍ ହୁଏ। ଆପଣଙ୍କ ପ୍ରମ୍ପ୍ଟ, ବାର୍ତ୍ତାଳାପର ପ୍ରସଙ୍ଗ ଏବଂ ଆପଣ ବାଛିଥିବା ସଂଲଗ୍ନ କେବଳ ଆପଣ ବାଛିଥିବା ପ୍ରୋଭାଇଡର୍କୁ ପଠାଯାଏ।

YamabikoChat iPad ରେ କାମ କରେ କି?

ହଁ। ଏହା iPhone ଓ iPad ପାଇଁ ଏକ ନେଟିଭ୍ ଆପ୍, ଯେଉଁଥିରେ iPad ରେ ସ୍ପ୍ଲିଟ୍ ଭ୍ୟୁ ଆପଣଙ୍କ ବାର୍ତ୍ତାଳାପ ତାଲିକା ଏବଂ ଚାଟ୍ ପାଶ୍ୱରେ ପାଶ୍ୱରେ ଦେଖାଏ।

ସିଷ୍ଟମ୍ ଆବଶ୍ୟକତା କଣ?

iPhone ରେ iOS 17 କିମ୍ବା ପରେ, ଏବଂ iPad ରେ iPadOS 17 କିମ୍ବା ପରେ। Apple Intelligence ପାଇଁ ଏହାକୁ ସମର୍ଥନ କରୁଥିବା ଡିଭାଇସ୍ ଏବଂ OS ସଂସ୍କରଣ ଆବଶ୍ୟକ।

YamabikoChat ଓପନ୍ ସୋର୍ସ କି?

ହଁ। ସୋର୍ସ କୋଡ୍ MIT License ଅଧୀନରେ GitHub ରେ ପ୍ରକାଶିତ। ସହିତ ଆସୁଥିବା ତୃତୀୟ-ପକ୍ଷ ସଫ୍ଟୱେର୍ ନିଜର ଲାଇସେନ୍ସ ବଜାୟ ରଖେ।

ଆହୁରି ପ୍ରଶ୍ନ ଅଛି? ସହାୟତା ଦେଖନ୍ତୁ।
