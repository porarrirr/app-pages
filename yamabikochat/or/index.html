ହୋମ୍ମଡେଲ ତୁଳନାଆପଣଙ୍କ API କୀପ୍ରୋଭାଇଡର୍ପ୍ରଶ୍ନୋତ୍ତର ଭାଷା

ନିଜ AI ଆଣନ୍ତୁ · iPhone & iPad

ନିଜ API କୀରେ AI ଚାଟ୍। ଉତ୍ତରଗୁଡ଼ିକୁ ତୁଳନା କରନ୍ତୁ।

YamabikoChat ହେଉଛି iPhone ଓ iPad ପାଇଁ ଏକ ମାଗଣା AI ଚାଟ୍ ଆପ୍। ଆପଣ ପୂର୍ବରୁ ବ୍ୟବହାର କରୁଥିବା AI ସେବାଗୁଡ଼ିକୁ API କୀ କିମ୍ବା ସମର୍ଥିତ ଆକାଉଣ୍ଟ ସହିତ ସଂଯୋଗ କରନ୍ତୁ, ତାପରେ ଗୋଟିଏ ମଡେଲ ସହିତ ଚାଟ୍ କରନ୍ତୁ, ଦୁଇଟି ମଡେଲର ଉତ୍ତର ପାଶ୍ୱରେ ପାଶ୍ୱରେ ତୁଳନା କରନ୍ତୁ, କିମ୍ବା ଦୁଇଟି ମଡେଲକୁ ପରସ୍ପର ସହିତ କଥା କରାନ୍ତୁ।

ମୋଡ୍

ତିନୋଟି ବାର୍ତ୍ତାଳାପ ମୋଡ୍, ସହିତ ସବ୍ଏଜେଣ୍ଟ

ପ୍ରଶ୍ନ ଅନୁସାରେ ମୋଡ୍ ବାଛନ୍ତୁ, ଓଲଟା ନୁହେଁ।

01 / ଚାଟ୍

ଗୋଟିଏ ମଡେଲ ସହିତ କଥା ହୁଅନ୍ତୁ

Markdown, କୋଡ୍ ହାଇଲାଇଟିଂ, ଗଣିତ ଏବଂ ଇମେଜ୍ ସଂଲଗ୍ନ ସହିତ ଷ୍ଟ୍ରିମିଂ ଉତ୍ତର। ସମ୍ପାଦନ କରନ୍ତୁ, ପୁନଃ ଜେନେରେଟ୍ କରନ୍ତୁ ଏବଂ ଉତ୍ତରର ଭିନ୍ନ ସଂସ୍କରଣ ରଖନ୍ତୁ।

02 / ଡୁଆଲ୍

ଦୁଇଟି ଉତ୍ତର ତୁଳନା କରନ୍ତୁ

ଏକା ପ୍ରମ୍ପ୍ଟ ଦୁଇଟି ମଡେଲକୁ ପଠାନ୍ତୁ ଏବଂ ଦୁଇଟି ଉତ୍ତର ପାଶ୍ୱରେ ପାଶ୍ୱରେ ପଢ଼ନ୍ତୁ। ଡୁଆଲ୍ କିପରି କାମ କରେ

03 / ଅଟୋ

ଦୁଇଟି ମଡେଲକୁ କଥା କରିବାକୁ ଦିଅନ୍ତୁ

ଦୁଇଟି ମଡେଲ, ଏକ ବିଷୟ ଏବଂ କେତେ ଥର ଉତ୍ତର ଦେବେ ବାଛନ୍ତୁ, ତାପରେ ସେମାନେ ପରସ୍ପର ସହିତ ଆଲୋଚନା କରୁଥିବା ଦେଖନ୍ତୁ।

+ / ସବ୍ଏଜେଣ୍ଟ

କାମ ଦାୟିତ୍ୱ ଦିଅନ୍ତୁ

ମଡେଲକୁ ଅନୁରୋଧର ଅଂଶ ସବ୍ଏଜେଣ୍ଟକୁ ଦେବାକୁ ଦିଅନ୍ତୁ — ପ୍ରତ୍ୟେକେ ନିଜ ମଡେଲ ବ୍ୟବହାର କରିପାରିବେ — ଏବଂ ଚାଟ୍ ରେ ସେମାନଙ୍କ ଅଗ୍ରଗତି ଦେଖନ୍ତୁ।

ବୈଶିଷ୍ଟ୍ୟ

ପ୍ରତିଦିନର କାମ ପାଇଁ ତିଆରି

ଲେଖା, ସାରାଂଶ, ଅନୁବାଦ, କୋଡ୍ ଏବଂ ଗଣିତ — ପ୍ରକୃତ ସହାୟକ ପାଇଁ ଆବଶ୍ୟକ ସାଧନ ସହିତ।

  • ଇମେଜ୍, PDF ଏବଂ ଟେକ୍ସଟ୍ ଫାଇଲ୍ ସଂଲଗ୍ନ କରନ୍ତୁ (ପ୍ରତ୍ୟେକଟି 10 MB ପର୍ଯ୍ୟନ୍ତ)
  • ୱେବ୍ ସର୍ଚ୍ଚ, ସ୍ଥାନୀୟ Python ଏବଂ ଇଣ୍ଟରାକ୍ଟିଭ୍ ଚାର୍ଟ (GenUI) ଉପକରଣ ଭାବରେ
  • ଭଏସ୍ ଡିକ୍ଟେସନ୍ ଏବଂ Safari ତଥା ଅନ୍ୟ ଆପ୍ ପାଇଁ ସେୟାର୍ ଏକ୍ସଟେନ୍ସନ୍
  • Shortcuts କ୍ରିୟା, Spotlight ସର୍ଚ୍ଚ ଏବଂ ଗୋପନ ବାର୍ତ୍ତାଳାପ
  • ପ୍ରୋଜେକ୍ଟ, ଇତିହାସ ସର୍ଚ୍ଚ, ମଡେଲ ପ୍ରିସେଟ୍ ଏବଂ ଟୋକେନ୍ ବ୍ୟବହାର ପରିସଂଖ୍ୟାନ
  • iPad ସ୍ପ୍ଲିଟ୍ ଭ୍ୟୁ ଏବଂ ଡାର୍କ ମୋଡ୍

କାହା ପାଇଁ

ଏହା କାହା ପାଇଁ

  • ଆପଣ ପୂର୍ବରୁ API କୀ କିମ୍ବା ChatGPT ପ୍ଲାନ୍ ପାଇଁ ଦେୟ ଦିଅନ୍ତି ଏବଂ ଏହା ପାଇଁ ଏକ ନେଟିଭ୍ iPhone ଓ iPad ଆପ୍ ଚାହାନ୍ତି।
  • ଆପଣ ଏକ ମଡେଲର ଉତ୍ତରକୁ ବିଶ୍ୱାସ କରିବା ପୂର୍ବରୁ ଅନ୍ୟ ମଡେଲ ସହିତ ତାହା ଯାଞ୍ଚ କରିବାକୁ ଚାହାନ୍ତି।
  • ଆପଣ ଏକାଧିକ AI ସବସ୍କ୍ରିପ୍ସନ୍ ଯୋଡ଼ିବା ପରିବର୍ତ୍ତେ ବ୍ୟବହାର ଅନୁସାରେ ଦେୟ ଦେବାକୁ ପସନ୍ଦ କରନ୍ତି।
  • ଆପଣ OpenRouter କିମ୍ବା ଏକାଧିକ ପ୍ରୋଭାଇଡର୍ ବ୍ୟବହାର କରନ୍ତି ଏବଂ ସେଗୁଡ଼ିକୁ ଏକ ସ୍ଥାନରେ ରଖିବାକୁ ଚାହାନ୍ତି।
  • ଆପଣ ନିଜ ଚାଟ୍ ଇତିହାସ ନିଜ ଡିଭାଇସରେ ରଖିବାକୁ ଚାହାନ୍ତି।

ଗାଇଡ୍

ଅଧିକ ଜାଣନ୍ତୁ

AI ମଡେଲ ତୁଳନା କରନ୍ତୁ ଗୋଟିଏ ପ୍ରମ୍ପ୍ଟ ଦୁଇଟି ମଡେଲକୁ ପଠାନ୍ତୁ ଏବଂ ଦୁଇଟି ଉତ୍ତର ପାଶ୍ୱରେ ପାଶ୍ୱରେ ପଢ଼ନ୍ତୁ। ନିଜ API କୀ ବ୍ୟବହାର କରନ୍ତୁ BYOK କିପରି କାମ କରେ, ଏହାର ଖର୍ଚ୍ଚ କେତେ, ଏବଂ ଆପଣଙ୍କ କୀ କେଉଁଠି ରହେ। ସମର୍ଥିତ ପ୍ରୋଭାଇଡର୍ Gemini, OpenRouter, ChatGPT ପ୍ଲାନ୍, xAI, OpenAI, Anthropic ଏବଂ ଅଧିକ। ପ୍ରଶ୍ନୋତ୍ତର ମୂଲ୍ୟ, ଆବଶ୍ୟକତା, ଗୋପନୀୟତା ଏବଂ ସମର୍ଥିତ ମଡେଲ।

ଆପଣ ପୂର୍ବରୁ ବ୍ୟବହାର କରୁଥିବା AI ସହିତ ଏହାକୁ ଚେଷ୍ଟା କରନ୍ତୁ।
