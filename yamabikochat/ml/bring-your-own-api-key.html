നിങ്ങളുടെ കീ നിങ്ങൾ കൊണ്ടുവരിക

iPhone, iPad-ൽ AI ചാറ്റിന് നിങ്ങളുടെ സ്വന്തം API കീ ഉപയോഗിക്കുക

YamabikoChat ഒരു ബ്രിംഗ്-യുവർ-ഓൺ-കീ (BYOK) ക്ലയന്റാണ്. നിങ്ങൾ ഒരു API കീ ചേർക്കുന്നു — അല്ലെങ്കിൽ പിന്തുണയുള്ള അക്കൗണ്ടിൽ സൈൻ ഇൻ ചെയ്യുന്നു — ആപ്പ് നിങ്ങളുടെ പ്രോംപ്റ്റുകൾ നേരിട്ട് ആ പ്രൊവൈഡർക്ക് അയക്കുന്നു. ഇടയിൽ YamabikoChat സബ്സ്ക്രിപ്ഷനോ ടോക്കൺ വിൽപ്പനക്കാരനോ ഇല്ല.

അവസാനം അപ്ഡേറ്റ് ചെയ്തത്: 2026-11-17

“നിങ്ങളുടെ സ്വന്തം കീ കൊണ്ടുവരിക” എന്നതിന്റെ അർത്ഥം

OpenAI, Google, Anthropic, OpenRouter തുടങ്ങിയ AI പ്രൊവൈഡർമാർ തങ്ങളുടെ മോഡലുകളിലേക്കുള്ള പ്രവേശനം API കീകൾ വഴി വിൽക്കുന്നു, സാധാരണയായി ഉപയോഗത്തിന് അനുസരിച്ച് ബിൽ ചെയ്യുന്നു. BYOK ആപ്പ് ആ കീകൾക്കുള്ള ഒരു ക്ലയന്റാണ്: നിങ്ങൾ പ്രൊവൈഡർ അക്കൗണ്ടിൽ ഒരു കീ ഉണ്ടാക്കി, അത് ആപ്പിൽ ചേർക്കുന്നു, നിങ്ങൾ ഉപയോഗിച്ചതിന് പ്രൊവൈഡർ നേരിട്ട് നിങ്ങൾക്ക് ബിൽ ചെയ്യുന്നു.

നിങ്ങളുടെ സ്വന്തം കീ എന്തിന് ഉപയോഗിക്കണം

  • ഉപയോഗിച്ചതിന് മാത്രം പണം നൽകുക. കുറച്ച് ഉപയോഗിക്കുന്നവർ പ്രതിമാസ AI സബ്സ്ക്രിപ്ഷനെക്കാൾ കുറവ് ചെലവാക്കാം; കൂടുതൽ ഉപയോഗിക്കുന്നവർ ചെലവ് എവിടെ നിന്ന് വരുന്നു എന്ന് വ്യക്തമായി കാണാം.
  • മോഡൽ തിരഞ്ഞെടുക്കുക. ആപ്പ് തിരഞ്ഞെടുത്ത സ്ഥിരമായ പട്ടികയല്ല, നിങ്ങളുടെ പ്രൊവൈഡർ നൽകുന്ന മോഡലുകൾ ഉപയോഗിക്കുക.
  • ഒരു ആപ്പ്, പല പ്രൊവൈഡർമാർ. Gemini, OpenRouter, OpenAI, Anthropic തുടങ്ങിയവ അടുത്തടുത്ത് സൂക്ഷിച്ച്, ഡ്യുവൽ മോഡിൽ താരതമ്യം ചെയ്യുക.
  • നിങ്ങളുടെ ഉപയോഗം കാണുക. ടോക്കൺ ഉപയോഗ സ്ഥിതിവിവരങ്ങൾ നിങ്ങൾ എത്ര ഉപയോഗിക്കുന്നു എന്ന് കാണിക്കുന്നു.

എങ്ങനെ സെറ്റപ്പ് ചെയ്യാം

  1. API കീ ഉണ്ടാക്കുക — നിങ്ങളുടെ പ്രൊവൈഡർ കൺസോളിൽ. ഉദാഹരണത്തിന് Gemini-ക്ക് Google AI Studio, OpenAI പ്ലാറ്റ്ഫോം, Anthropic കൺസോൾ അല്ലെങ്കിൽ OpenRouter.
  2. YamabikoChat-ൽ ക്രമീകരണങ്ങൾ തുറക്കുക, കണക്ഷൻ ക്രമീകരണങ്ങളിൽ പ്രൊവൈഡർ തിരഞ്ഞെടുക്കുക.
  3. കീ പേസ്റ്റ് ചെയ്യുക. അത് നിങ്ങളുടെ ഉപകരണത്തിലെ iOS കീച്ചെയിനിൽ സൂക്ഷിക്കുന്നു.
  4. മോഡൽ തിരഞ്ഞെടുത്ത് ചാറ്റ് തുടങ്ങുക. ആപ്പിന് സുരക്ഷിതമായി പ്രവർത്തിപ്പിക്കാനാകാത്ത മോഡലുകൾ ഊഹിക്കാതെ, കാരണത്തോടെ ലഭ്യമല്ല എന്ന് കാണിക്കും.

API കീ ഇല്ലേ? സൈൻ ഇൻ ചെയ്യുക

  • ChatGPT പ്ലാൻ — നിങ്ങളുടെ പ്ലാനിൽ ഉൾപ്പെട്ട മോഡലുകൾ ഉപയോഗിക്കാൻ നിങ്ങളുടെ ChatGPT അക്കൗണ്ടിൽ സൈൻ ഇൻ ചെയ്യുക.
  • xAI — നിങ്ങളുടെ xAI അക്കൗണ്ടിൽ സൈൻ ഇൻ ചെയ്യുക.
  • Apple Intelligence — പിന്തുണയുള്ള ഉപകരണങ്ങളിൽ, ഉപകരണത്തിൽ തന്നെയോ Private Cloud Compute വഴിയോ, കീ ഒട്ടും ഇല്ലാതെ ലഭ്യമാണ്.

കസ്റ്റം എൻഡ്പോയിന്റുകൾ

നിങ്ങളുടെ സേവനം പട്ടികയിലില്ലെങ്കിൽ, അതിന്റെ ബേസ് URL-ഉം കീയും ഉപയോഗിച്ച് ഒരു കസ്റ്റം എൻഡ്പോയിന്റ് ചേർത്ത്, പിന്തുണയുള്ള API ഫോർമാറ്റുകളിൽ ഒന്ന് തിരഞ്ഞെടുക്കുക: OpenAI Chat Completions, OpenAI Responses, Anthropic Messages, Gemini (Google Generative AI) അല്ലെങ്കിൽ Mistral.

ചെലവ് എത്ര

ആപ്പ് സൗജന്യമാണ്, ഇൻ-ആപ്പ് വാങ്ങലുകൾ ഇല്ല. നിങ്ങളുടെ പ്രൊവൈഡർ അവരുടെ വില, പരിധികൾ, നിബന്ധനകൾ എന്നിവ അനുസരിച്ച് ഉപയോഗത്തിന് ചാർജ് ചെയ്യും. ഡ്യുവൽ മോഡും ഓട്ടോ സംഭാഷണവും രണ്ട് മോഡലുകൾക്ക് അഭ്യർത്ഥനകൾ അയക്കുന്നു, അതിനാൽ രണ്ടിലും ഉപയോഗം ഉണ്ടാകും.

സുരക്ഷയും സ്വകാര്യതയും

  • API കീകളും ആക്സസ് ടോക്കണുകളും iOS കീച്ചെയിനിൽ സൂക്ഷിക്കുന്നു, ആപ്പ് അവ തന്റെ ഡയഗ്നോസ്റ്റിക് ലോഗുകളിൽ എഴുതാതിരിക്കാൻ രൂപകൽപ്പന ചെയ്തിട്ടുണ്ട്.
  • പ്രോംപ്റ്റുകളും സംഭാഷണ സന്ദർഭവും നിങ്ങൾ തിരഞ്ഞെടുക്കുന്ന അറ്റാച്ച്മെന്റുകളും നേരിട്ട് നിങ്ങൾ തിരഞ്ഞെടുത്ത പ്രൊവൈഡർക്ക് അയക്കുന്നു.
  • സംഭാഷണങ്ങൾ നിങ്ങളുടെ ഉപകരണത്തിൽ സൂക്ഷിക്കുന്നു. ആപ്പ് ആപ്പുകൾക്കിടയിലുള്ള ട്രാക്കിംഗ് ഉപയോഗിക്കുന്നില്ല. സ്വകാര്യതാ നയം കാണുക.

അനുബന്ധ ഗൈഡുകൾ

AI മോഡലുകൾ താരതമ്യം ചെയ്യുകഒരേ പ്രോംപ്റ്റ് രണ്ട് മോഡലുകൾക്ക് അയച്ച് രണ്ട് ഉത്തരങ്ങളും അടുത്തടുത്ത് വായിക്കുക.പിന്തുണയുള്ള പ്രൊവൈഡർമാർGemini, OpenRouter, ChatGPT പ്ലാൻ, xAI, OpenAI, Anthropic തുടങ്ങി കൂടുതൽ.ചോദ്യോത്തരങ്ങൾവില, ആവശ്യകതകൾ, സ്വകാര്യത, പിന്തുണയുള്ള മോഡലുകൾ.

നിങ്ങൾ ഇപ്പോൾ ഉപയോഗിക്കുന്ന AI ഉപയോഗിച്ച് പരീക്ഷിക്കുക.
