ചോദ്യോത്തരങ്ങൾ

പതിവായി ചോദിക്കുന്ന ചോദ്യങ്ങൾ

വില, API കീകൾ, പിന്തുണയുള്ള മോഡലുകൾ, സ്വകാര്യത, ആവശ്യകതകൾ എന്നിവയെക്കുറിച്ചുള്ള ചെറിയ ഉത്തരങ്ങൾ.

അവസാനം അപ്ഡേറ്റ് ചെയ്തത്: 2026-11-17

YamabikoChat സൗജന്യമാണോ?

അതെ. YamabikoChat ഡൗൺലോഡ് ചെയ്യാൻ സൗജന്യമാണ് — പരസ്യങ്ങളില്ല, സൈൻ-അപ്പില്ല, ആപ്പിനുള്ളിൽ സബ്സ്ക്രിപ്ഷനുകളോ ടോക്കൺ വാങ്ങലുകളോ ഇല്ല. നിങ്ങൾ സൃഷ്ടിക്കുന്ന ഉപയോഗത്തിന് ആ പ്രൊവൈഡറുടെ വിലയും നിബന്ധനകളും അനുസരിച്ച് നിങ്ങളുടെ AI പ്രൊവൈഡർക്ക് നേരിട്ട് പണം നൽകണം.

എനിക്ക് API കീ വേണോ?

പിന്തുണയുള്ള AI പ്രൊവൈഡറിൽ നിന്നുള്ള API കീയോ പിന്തുണയുള്ള അക്കൗണ്ട് സൈൻ ഇന്നോ (ഉദാ. ChatGPT പ്ലാൻ അല്ലെങ്കിൽ xAI) വേണം. Apple Intelligence പിന്തുണയുള്ള ഉപകരണങ്ങളിൽ കീ ഇല്ലാതെ പ്രവർത്തിക്കും.

API കീയ്ക്ക് പകരം എന്റെ ChatGPT സബ്സ്ക്രിപ്ഷൻ ഉപയോഗിക്കാമോ?

അതെ. ChatGPT പ്ലാൻ കണക്ഷൻ വഴി നിങ്ങളുടെ ChatGPT അക്കൗണ്ട് ഉപയോഗിച്ച് സൈൻ ഇൻ ചെയ്ത്, OpenAI API കീ ഇല്ലാതെ തന്നെ നിങ്ങളുടെ പ്ലാനിൽ ഉൾപ്പെട്ട മോഡലുകൾ ഉപയോഗിക്കാം.

ഏത് AI മോഡലുകൾ ഉപയോഗിക്കാം?

Google Gemini, OpenRouter, ChatGPT പ്ലാൻ, xAI, Apple Intelligence, Sarashina, PLaMo എന്നിവ ആപ്പിൽ ഉൾപ്പെടുത്തിയിട്ടുണ്ട്. OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq തുടങ്ങി മറ്റ് API പ്രൊവൈഡർമാർ models.dev കാറ്റലോഗിലൂടെ ലഭ്യമാണ്, കൂടാതെ പിന്തുണയുള്ള API ഫോർമാറ്റ് ഉപയോഗിക്കുന്ന കസ്റ്റം എൻഡ്പോയിന്റും ചേർക്കാം. ലഭ്യമായ മോഡലുകൾ ഓരോ പ്രൊവൈഡറിനെ ആശ്രയിച്ചിരിക്കും.

എന്റെ Anthropic API കീ ഉപയോഗിച്ച് Claude ഉപയോഗിക്കാമോ?

അതെ. പ്രൊവൈഡർ കാറ്റലോഗിൽ നിന്ന് Anthropic നിങ്ങളുടെ API കീ ഉപയോഗിച്ച് ചേർക്കുക, അല്ലെങ്കിൽ Anthropic Messages API ഉപയോഗിക്കുന്ന കസ്റ്റം എൻഡ്പോയിന്റ് സെറ്റപ്പ് ചെയ്യുക.

ChatGPT, Gemini, Claude എന്നിവയുടെ ഉത്തരങ്ങൾ അടുത്തടുത്ത് താരതമ്യം ചെയ്യാമോ?

അതെ. ഡ്യുവൽ മോഡ് ഒരേ പ്രോംപ്റ്റ് രണ്ട് മോഡലുകൾക്ക് അയച്ച് രണ്ട് ഉത്തരങ്ങളും അടുത്തടുത്ത് കാണിക്കുന്നു. നിങ്ങൾ ബന്ധിപ്പിച്ച പ്രൊവൈഡർമാരിൽ നിന്ന് ഏതെങ്കിലും രണ്ട് മോഡലുകൾ തിരഞ്ഞെടുക്കുക.

എന്റെ സംഭാഷണങ്ങളും API കീകളും എവിടെ സൂക്ഷിക്കുന്നു?

സംഭാഷണങ്ങളും ക്രമീകരണങ്ങളും നിങ്ങളുടെ ഉപകരണത്തിൽ സൂക്ഷിക്കുന്നു. API കീകളും ആക്സസ് ടോക്കണുകളും iOS കീച്ചെയിനിൽ സൂക്ഷിക്കുന്നു. നിങ്ങളുടെ പ്രോംപ്റ്റുകളും സംഭാഷണ സന്ദർഭവും നിങ്ങൾ തിരഞ്ഞെടുക്കുന്ന അറ്റാച്ച്മെന്റുകളും നിങ്ങൾ തിരഞ്ഞെടുത്ത പ്രൊവൈഡർക്ക് മാത്രമേ അയക്കൂ.

YamabikoChat iPad-ൽ പ്രവർത്തിക്കുമോ?

അതെ. ഇത് iPhone, iPad എന്നിവയ്ക്കുള്ള നേറ്റീവ് ആപ്പാണ്; iPad-ൽ നിങ്ങളുടെ സംഭാഷണ പട്ടികയും ചാറ്റും അടുത്തടുത്ത് കാണിക്കുന്ന സ്പ്ലിറ്റ് വ്യൂ ഉണ്ട്.

സിസ്റ്റം ആവശ്യകതകൾ എന്തൊക്കെയാണ്?

iPhone-ൽ iOS 17 അല്ലെങ്കിൽ അതിന് ശേഷമുള്ള പതിപ്പ്, iPad-ൽ iPadOS 17 അല്ലെങ്കിൽ അതിന് ശേഷമുള്ള പതിപ്പ്. Apple Intelligence-ന് അതിനെ പിന്തുണയ്ക്കുന്ന ഉപകരണവും OS പതിപ്പും വേണം.

YamabikoChat ഓപ്പൺ സോഴ്സ് ആണോ?

അതെ. സോഴ്സ് കോഡ് GitHub-ൽ MIT License പ്രകാരം പ്രസിദ്ധീകരിച്ചിട്ടുണ്ട്. ഉൾപ്പെടുത്തിയ മൂന്നാം കക്ഷി സോഫ്റ്റ്വെയർ അതിന്റെ സ്വന്തം ലൈസൻസുകൾ നിലനിർത്തുന്നു.

ഇനിയും സംശയമുണ്ടോ? പിന്തുണ സന്ദർശിക്കുക.

അനുബന്ധ ഗൈഡുകൾ

AI മോഡലുകൾ താരതമ്യം ചെയ്യുക ഒരേ പ്രോംപ്റ്റ് രണ്ട് മോഡലുകൾക്ക് അയച്ച് രണ്ട് ഉത്തരങ്ങളും അടുത്തടുത്ത് വായിക്കുക. നിങ്ങളുടെ സ്വന്തം API കീ ഉപയോഗിക്കുക BYOK എങ്ങനെ പ്രവർത്തിക്കുന്നു, ചെലവ് എത്ര, നിങ്ങളുടെ കീ എവിടെ സൂക്ഷിക്കുന്നു. പിന്തുണയുള്ള പ്രൊവൈഡർമാർ Gemini, OpenRouter, ChatGPT പ്ലാൻ, xAI, OpenAI, Anthropic തുടങ്ങി കൂടുതൽ.

നിങ്ങൾ ഇപ്പോൾ ഉപയോഗിക്കുന്ന AI ഉപയോഗിച്ച് പരീക്ഷിക്കുക.
