നിങ്ങളുടെ സ്വന്തം API കീയിൽ AI ചാറ്റ്. ഉത്തരങ്ങൾ താരതമ്യം ചെയ്യുക.

YamabikoChat iPhone, iPad എന്നിവയ്ക്കുള്ള സൗജന്യ AI ചാറ്റ് ആപ്പാണ്. നിങ്ങൾ ഇപ്പോൾ ഉപയോഗിക്കുന്ന AI സേവനങ്ങൾ API കീയോ പിന്തുണയുള്ള അക്കൗണ്ടോ ഉപയോഗിച്ച് ബന്ധിപ്പിക്കുക — ഒരു മോഡലുമായി ചാറ്റ് ചെയ്യുക, രണ്ട് മോഡലുകളെ അടുത്തടുത്ത് താരതമ്യം ചെയ്യുക, അല്ലെങ്കിൽ രണ്ട് മോഡലുകൾ പരസ്പരം സംസാരിക്കാൻ അനുവദിക്കുക.

തരം
നിങ്ങളുടെ സ്വന്തം API കീകളോ അക്കൗണ്ടുകളോ ഉപയോഗിക്കുന്ന (BYOK), iPhone, iPad എന്നിവയ്ക്കുള്ള നേറ്റീവ് AI ചാറ്റ് ക്ലയന്റ്
വില
സൗജന്യം. പരസ്യങ്ങളില്ല, സൈൻ-അപ്പില്ല, ആപ്പിനുള്ളിൽ സബ്സ്ക്രിപ്ഷനുകളോ ടോക്കൺ വാങ്ങലുകളോ ഇല്ല. പ്രൊവൈഡറുടെ ഉപയോഗത്തിന് പ്രൊവൈഡർ തന്നെ ബിൽ ചെയ്യും.
AI സേവനങ്ങൾ
Google Gemini, OpenRouter, ChatGPT പ്ലാൻ, xAI, Apple Intelligence, OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq, Sarashina, PLaMo, കസ്റ്റം എൻഡ്പോയിന്റുകൾ തുടങ്ങി കൂടുതൽ — എല്ലാ പ്രൊവൈഡർമാരെയും കാണുക
മോഡുകൾ
ചാറ്റ്, ഡ്യുവൽ (രണ്ട് മോഡലുകൾ അടുത്തടുത്ത്), ഓട്ടോ സംഭാഷണം (രണ്ട് മോഡലുകൾ പരസ്പരം സംസാരിക്കുന്നു), കൂടാതെ ജോലിയുടെ ഭാഗങ്ങൾ ഏറ്റെടുക്കുന്ന സബ്ഏജന്റുകൾ
സ്വകാര്യത
സംഭാഷണങ്ങൾ നിങ്ങളുടെ ഉപകരണത്തിൽ തന്നെ നിലനിൽക്കും, കീകൾ iOS കീച്ചെയിനിൽ സൂക്ഷിക്കും, പ്രോംപ്റ്റുകൾ നിങ്ങൾ തിരഞ്ഞെടുത്ത പ്രൊവൈഡർക്ക് മാത്രം പോകും

മോഡുകൾ

മൂന്ന് സംഭാഷണ മോഡുകൾ, കൂടെ സബ്ഏജന്റുകൾ

ചോദ്യത്തിന് യോജിക്കുന്ന മോഡ് തിരഞ്ഞെടുക്കുക; മോഡിന് യോജിക്കുന്ന ചോദ്യമല്ല.

01 / ചാറ്റ്

ഒരു മോഡലുമായി സംസാരിക്കുക

Markdown, കോഡ് ഹൈലൈറ്റിംഗ്, ഗണിതം, ചിത്ര അറ്റാച്ച്മെന്റുകൾ എന്നിവയോടെ സ്ട്രീമിംഗ് ഉത്തരങ്ങൾ. എഡിറ്റ് ചെയ്യുക, വീണ്ടും ജനറേറ്റ് ചെയ്യുക, ഉത്തര വകഭേദങ്ങൾ സൂക്ഷിക്കുക.

02 / ഡ്യുവൽ

രണ്ട് ഉത്തരങ്ങൾ താരതമ്യം ചെയ്യുക

ഒരേ പ്രോംപ്റ്റ് രണ്ട് മോഡലുകൾക്ക് അയച്ച് രണ്ട് ഉത്തരങ്ങളും അടുത്തടുത്ത് വായിക്കുക. ഡ്യുവൽ എങ്ങനെ പ്രവർത്തിക്കുന്നു

03 / ഓട്ടോ

രണ്ട് മോഡലുകൾ സംസാരിക്കട്ടെ

രണ്ട് മോഡലുകൾ, ഒരു വിഷയം, എത്ര റൗണ്ടുകൾ എന്നിവ തിരഞ്ഞെടുത്ത് അവ പരസ്പരം ചർച്ച ചെയ്യുന്നത് കാണുക.

+ / സബ്ഏജന്റുകൾ

ജോലി ഏൽപ്പിക്കുക

ഒരു അഭ്യർത്ഥനയുടെ ഭാഗങ്ങൾ മോഡൽ സബ്ഏജന്റുകൾക്ക് ഏൽപ്പിക്കാൻ അനുവദിക്കുക — ഓരോന്നിനും സ്വന്തം മോഡൽ ഉപയോഗിക്കാം — അവയുടെ പുരോഗതി ചാറ്റിൽ തന്നെ കാണുക.

സവിശേഷതകൾ

ദൈനംദിന ജോലിക്കായി നിർമ്മിച്ചത്

എഴുത്ത്, സംഗ്രഹങ്ങൾ, വിവർത്തനം, കോഡ്, ഗണിതം — ഒരു യഥാർത്ഥ അസിസ്റ്റന്റിന് വേണ്ട ഉപകരണങ്ങളോടെ.

  • ചിത്രങ്ങൾ, PDF, ടെക്സ്റ്റ് ഫയലുകൾ അറ്റാച്ച് ചെയ്യുക (ഓരോന്നും 10 MB വരെ)
  • വെബ് തിരയൽ, ലോക്കൽ Python, ഇന്ററാക്ടീവ് ചാർട്ടുകൾ (GenUI) ഉപകരണങ്ങളായി
  • വോയ്സ് ഡിക്ടേഷനും Safari ഉൾപ്പെടെയുള്ള ആപ്പുകൾക്കുള്ള ഷെയർ എക്സ്റ്റൻഷനും
  • Shortcuts ആക്ഷനുകൾ, Spotlight തിരയൽ, രഹസ്യ സംഭാഷണങ്ങൾ
  • പ്രോജക്ടുകൾ, ചരിത്ര തിരയൽ, മോഡൽ പ്രീസെറ്റുകൾ, ടോക്കൺ ഉപയോഗ സ്ഥിതിവിവരങ്ങൾ
  • iPad സ്പ്ലിറ്റ് വ്യൂവും ഡാർക്ക് മോഡും

ആർക്കുവേണ്ടി

ആർക്കുവേണ്ടി

  • നിങ്ങൾ ഇപ്പോൾ തന്നെ API കീക്കോ ChatGPT പ്ലാനിനോ പണം നൽകുന്നു, അതിന് ഒരു നേറ്റീവ് iPhone, iPad ആപ്പ് വേണം.
  • ഒരു മോഡലിന്റെ ഉത്തരം വിശ്വസിക്കും മുൻപ് മറ്റൊന്നുമായി താരതമ്യം ചെയ്യാൻ ആഗ്രഹിക്കുന്നു.
  • നിരവധി AI സബ്സ്ക്രിപ്ഷനുകൾ കൂട്ടിച്ചേർക്കുന്നതിനെക്കാൾ ഉപയോഗിച്ചതിന് പണം നൽകുന്നതാണ് ഇഷ്ടം.
  • നിങ്ങൾ OpenRouter അല്ലെങ്കിൽ നിരവധി പ്രൊവൈഡർമാരെ ഉപയോഗിക്കുന്നു, അവ ഒരിടത്ത് വേണം.
  • നിങ്ങളുടെ ചാറ്റ് ചരിത്രം നിങ്ങളുടെ സ്വന്തം ഉപകരണത്തിൽ സൂക്ഷിക്കാൻ ആഗ്രഹിക്കുന്നു.

ഗൈഡുകൾ

കൂടുതൽ അറിയുക

AI മോഡലുകൾ താരതമ്യം ചെയ്യുകഒരേ പ്രോംപ്റ്റ് രണ്ട് മോഡലുകൾക്ക് അയച്ച് രണ്ട് ഉത്തരങ്ങളും അടുത്തടുത്ത് വായിക്കുക.നിങ്ങളുടെ സ്വന്തം API കീ ഉപയോഗിക്കുകBYOK എങ്ങനെ പ്രവർത്തിക്കുന്നു, ചെലവ് എത്ര, നിങ്ങളുടെ കീ എവിടെ സൂക്ഷിക്കുന്നു.പിന്തുണയുള്ള പ്രൊവൈഡർമാർGemini, OpenRouter, ChatGPT പ്ലാൻ, xAI, OpenAI, Anthropic തുടങ്ങി കൂടുതൽ.ചോദ്യോത്തരങ്ങൾവില, ആവശ്യകതകൾ, സ്വകാര്യത, പിന്തുണയുള്ള മോഡലുകൾ.

നിങ്ങൾ ഇപ്പോൾ ഉപയോഗിക്കുന്ന AI ഉപയോഗിച്ച് പരീക്ഷിക്കുക.

iPhone, iPad എന്നിവയ്ക്കായി YamabikoChat ഡൗൺലോഡ് ചെയ്യുക.
