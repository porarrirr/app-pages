പ്രൊവൈഡർമാർ

പിന്തുണയുള്ള AI പ്രൊവൈഡർമാർ

YamabikoChat താഴെയുള്ള AI സേവനങ്ങളുമായി നിങ്ങളുടെ സ്വന്തം API കീയോ അക്കൗണ്ടോ ഉപയോഗിച്ച് ബന്ധിപ്പിക്കുന്നു. ഉൾപ്പെടുത്തിയ പ്രൊവൈഡർമാർ ആപ്പിൽ തന്നെ സെറ്റപ്പ് ചെയ്യുന്നു; കൂടുതൽ API പ്രൊവൈഡർമാർ models.dev കാറ്റലോഗിൽ നിന്ന് വരുന്നു.

അവസാനം അപ്ഡേറ്റ് ചെയ്തത്: 2026-11-17

ഉൾപ്പെടുത്തിയ പ്രൊവൈഡർമാർ

പ്രൊവൈഡർഎങ്ങനെ ബന്ധിപ്പിക്കാംകുറിപ്പുകൾ
Google GeminiAPI കീGoogle AI Studio-യിൽ നിന്നുള്ള Gemini മോഡലുകൾ
OpenRouterAPI കീആപ്പിൽ OpenRouter മോഡൽ ഡയറക്ടറി ബ്രൗസ് ചെയ്യുക
ChatGPT പ്ലാൻChatGPT ഉപയോഗിച്ച് സൈൻ ഇൻനിങ്ങളുടെ ChatGPT പ്ലാനിൽ ഉൾപ്പെട്ട മോഡലുകൾ ഉപയോഗിക്കുന്നു
xAIനിങ്ങളുടെ xAI അക്കൗണ്ട് ഉപയോഗിച്ച് സൈൻ ഇൻനിങ്ങളുടെ അക്കൗണ്ടിന് ലഭ്യമായ Grok മോഡലുകൾ
Apple Intelligenceഉൾപ്പെടുത്തിയത്, കീ ആവശ്യമില്ലപിന്തുണയുള്ള ഉപകരണങ്ങളിൽ ഉപകരണത്തിൽ തന്നെയും Private Cloud Compute വഴിയും
SarashinaAPI കീSB Intuitions-ന്റെ ജാപ്പനീസ് ഭാഷാ മോഡലുകൾ
PLaMoAPI കീPreferred Networks-ന്റെ ജാപ്പനീസ് ഭാഷാ മോഡലുകൾ; PLaMo 3.1 Prime-ൽ വെബ് തിരയൽ
കസ്റ്റം എൻഡ്പോയിന്റ്ബേസ് URL + API കീOpenAI Chat Completions, OpenAI Responses, Anthropic Messages, Gemini അല്ലെങ്കിൽ Mistral ഫോർമാറ്റ്

models.dev കാറ്റലോഗിൽ നിന്ന് കൂടുതൽ API പ്രൊവൈഡർമാർ

കൂടുതൽ API പ്രൊവൈഡർമാരെ നൽകാൻ YamabikoChat പൊതു models.dev കാറ്റലോഗ് വായിക്കുന്നു — OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq, xAI API, Moonshot AI (Kimi), MiniMax, Z.ai (GLM), Fireworks AI, Together AI, Hugging Face എന്നിവ ഉൾപ്പെടെ. ക്രമീകരണങ്ങളിൽ പ്രൊവൈഡർ നിങ്ങളുടെ API കീ ഉപയോഗിച്ച് ചേർത്ത് ഒരു മോഡൽ തിരഞ്ഞെടുക്കുക.

ഓരോ മോഡലും അതിന്റെ API കരാർ പരിശോധിച്ച് ഉറപ്പാക്കിയാൽ മാത്രമേ പ്രവർത്തിക്കൂ. സുരക്ഷിതമായി പ്രവർത്തിപ്പിക്കാനാകാത്ത മോഡലുകൾ കാണാം പക്ഷേ നിഷ്ക്രിയമായിരിക്കും, കൃത്യമായ കാരണത്തോടെ — ആപ്പ് ഒരിക്കലും നിങ്ങൾ അറിയാതെ മറ്റൊരു മോഡലിലേക്കോ എൻഡ്പോയിന്റിലേക്കോ പ്രൊവൈഡറിലേക്കോ മാറ്റില്ല.

മോഡലുകൾ ഒരുമിച്ച് ഉപയോഗിക്കൽ

ബന്ധിപ്പിച്ച ഏത് മോഡലും ചാറ്റിലും, രണ്ട് ഉത്തരങ്ങൾ താരതമ്യം ചെയ്യാൻ ഡ്യുവൽ മോഡിലും, രണ്ട് മോഡലുകൾ സംസാരിക്കുന്ന ഓട്ടോ സംഭാഷണത്തിലും ഉപയോഗിക്കാം. ചിത്ര ഇൻപുട്ട്, റീസണിംഗ് ക്രമീകരണങ്ങൾ, ഉപകരണങ്ങൾ, കോൺടെക്സ്റ്റ് നീളം എന്നിവ മോഡലിനെ ആശ്രയിച്ചിരിക്കും.

മോഡൽ പട്ടികകൾ പലപ്പോഴും മാറുന്നു. ആപ്പ് എപ്പോഴും ഓരോ പ്രൊവൈഡറിന്റെയും നിലവിലെ പട്ടിക കാണിക്കുന്നു. പ്രൊവൈഡർ, ഉൽപ്പന്ന നാമങ്ങൾ അവരുടെ ഉടമകളുടെ ട്രേഡ്മാർക്കുകളാണ്; YamabikoChat അവരുമായി ബന്ധപ്പെട്ടിട്ടില്ല.

അനുബന്ധ ഗൈഡുകൾ

AI മോഡലുകൾ താരതമ്യം ചെയ്യുകഒരേ പ്രോംപ്റ്റ് രണ്ട് മോഡലുകൾക്ക് അയച്ച് രണ്ട് ഉത്തരങ്ങളും അടുത്തടുത്ത് വായിക്കുക.നിങ്ങളുടെ സ്വന്തം API കീ ഉപയോഗിക്കുകBYOK എങ്ങനെ പ്രവർത്തിക്കുന്നു, ചെലവ് എത്ര, നിങ്ങളുടെ കീ എവിടെ സൂക്ഷിക്കുന്നു.ചോദ്യോത്തരങ്ങൾവില, ആവശ്യകതകൾ, സ്വകാര്യത, പിന്തുണയുള്ള മോഡലുകൾ.

നിങ്ങൾ ഇപ്പോൾ ഉപയോഗിക്കുന്ന AI ഉപയോഗിച്ച് പരീക്ഷിക്കുക.

iPhone, iPad എന്നിവയ്ക്കായി YamabikoChat ഡൗൺലോഡ് ചെയ്യുക.
