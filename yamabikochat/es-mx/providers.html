Proveedores de IA compatibles

YamabikoChat se conecta a los servicios de IA de abajo con tu propia clave API o cuenta. Los proveedores integrados se configuran directamente en la app; muchos otros proveedores de API llegan del catálogo models.dev.

Más proveedores de API del catálogo models.dev

YamabikoChat lee el catálogo público models.dev para ofrecer muchos más proveedores de API, incluidos OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq, xAI API, Moonshot AI (Kimi), MiniMax, Z.ai (GLM), Fireworks AI, Together AI y Hugging Face. Agrega el proveedor en Ajustes con tu clave API y elige un modelo.

Cada modelo se ejecuta solo cuando su contrato de API está verificado. Los modelos que no se pueden ejecutar de forma segura siguen visibles pero desactivados, con el motivo exacto: la app nunca te cambia a otro modelo, endpoint o proveedor sin avisarte.

Usar los modelos juntos

Cada modelo conectado se puede usar en Chat, en el modo Dual para comparar dos respuestas y en la conversación Auto para que dos modelos hablen. La entrada de imágenes, los ajustes de razonamiento, las herramientas y la longitud del contexto dependen del modelo.

Las listas de modelos cambian a menudo. La app muestra siempre la lista actual de cada proveedor. Los nombres de proveedores y productos son marcas de sus propietarios; YamabikoChat no está afiliada a ellos.
