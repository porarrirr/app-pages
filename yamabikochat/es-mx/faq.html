FAQ

Preguntas frecuentes

Respuestas breves sobre precio, claves API, modelos compatibles, privacidad y requisitos.

Última actualización: 2026-11-17

¿YamabikoChat es gratis?

Sí. YamabikoChat se puede descargar gratis, sin anuncios, sin registro y sin suscripciones ni compra de tokens en la app. Pagas directamente a tu proveedor de IA el uso que generas, según los precios y las condiciones de ese proveedor.

¿Necesito una clave API?

Necesitas una clave API de un proveedor de IA compatible, o iniciar sesión con una cuenta compatible, como el plan de ChatGPT o xAI. Apple Intelligence funciona sin clave en los dispositivos que la admiten.

¿Puedo usar mi suscripción de ChatGPT en lugar de una clave API?

Sí. La conexión con el plan de ChatGPT te permite iniciar sesión con tu cuenta de ChatGPT y usar los modelos incluidos en tu plan, sin una clave API de OpenAI.

¿Qué modelos de IA puedo usar?

Google Gemini, OpenRouter, plan de ChatGPT, xAI, Apple Intelligence, Sarashina y PLaMo vienen integrados. OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq y muchos otros proveedores de API están disponibles a través del catálogo models.dev, y puedes agregar un endpoint personalizado con un formato de API compatible. Los modelos disponibles dependen de cada proveedor.

¿Puedo usar Claude con mi clave API de Anthropic?

Sí. Agrega Anthropic desde el catálogo de proveedores con tu clave API, o configura un endpoint personalizado que use la API Anthropic Messages.

¿Puedo comparar las respuestas de ChatGPT, Gemini y Claude en paralelo?

Sí. El modo Dual envía el mismo prompt a dos modelos y muestra ambas respuestas una al lado de la otra. Elige dos modelos cualesquiera de los proveedores que tengas conectados.

¿Dónde se guardan mis conversaciones y claves API?

Las conversaciones y los ajustes se guardan en tu dispositivo. Las claves API y los tokens de acceso se guardan en el Llavero de iOS. Tus prompts, el contexto de la conversación y los archivos adjuntos que elijas se envían solo al proveedor que hayas seleccionado.

¿YamabikoChat funciona en iPad?

Sí. Es una app nativa para iPhone y iPad, con una vista dividida en iPad que muestra la lista de conversaciones y el chat en paralelo.

¿Cuáles son los requisitos del sistema?

iOS 17 o posterior en iPhone, y iPadOS 17 o posterior en iPad. Apple Intelligence requiere un dispositivo y una versión del sistema operativo que lo admitan.

¿YamabikoChat es de código abierto?

Sí. El código fuente está publicado en GitHub con la licencia MIT. El software de terceros incluido conserva sus propias licencias.
