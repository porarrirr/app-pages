FAQ

Întrebări frecvente

Răspunsuri scurte despre preț, chei API, modele acceptate, confidențialitate și cerințe.

Ultima actualizare: 2026-11-17

YamabikoChat este gratuit?

Da. YamabikoChat este gratuit la descărcare, fără reclame, fără cont și fără abonamente sau achiziții de tokenuri în aplicație. Plătești direct furnizorului de AI pentru utilizarea pe care o generezi, conform prețurilor și termenilor acelui furnizor.

Am nevoie de o cheie API?

Ai nevoie fie de o cheie API de la un furnizor AI acceptat, fie de conectarea la un cont acceptat, cum ar fi abonamentul ChatGPT sau xAI. Apple Intelligence funcționează fără cheie pe dispozitivele care îl acceptă.

Pot folosi abonamentul ChatGPT în loc de o cheie API?

Da. Conexiunea prin abonamentul ChatGPT îți permite să te conectezi cu contul tău ChatGPT și să folosești modelele incluse în abonament, fără o cheie API OpenAI.

Ce modele AI pot folosi?

Google Gemini, OpenRouter, abonamentul ChatGPT, xAI, Apple Intelligence, Sarashina și PLaMo sunt integrate. OpenAI, Anthropic (Claude), DeepSeek, Mistral, Groq și mulți alți furnizori API sunt disponibili prin catalogul models.dev, iar tu poți adăuga un endpoint personalizat care folosește un format API acceptat. Modelele disponibile depind de fiecare furnizor.

Pot folosi Claude cu cheia mea API Anthropic?

Da. Adaugă Anthropic din catalogul de furnizori cu cheia ta API sau configurează un endpoint personalizat care folosește API-ul Anthropic Messages.

Pot compara răspunsurile ChatGPT, Gemini și Claude alături?

Da. Modul Dual trimite același prompt la două modele și afișează ambele răspunsuri unul lângă altul. Alege oricare două modele dintre furnizorii la care te-ai conectat.

Unde sunt stocate conversațiile și cheile mele API?

Conversațiile și setările sunt stocate pe dispozitivul tău. Cheile API și tokenurile de acces sunt stocate în Keychain-ul iOS. Prompturile, contextul conversației și fișierele atașate pe care le alegi sunt trimise doar furnizorului selectat.

YamabikoChat funcționează pe iPad?

Da. Este o aplicație nativă pentru iPhone și iPad, cu Split view pe iPad, care arată lista de conversații și chatul alături.

Care sunt cerințele de sistem?

iOS 17 sau mai nou pe iPhone și iPadOS 17 sau mai nou pe iPad. Apple Intelligence necesită un dispozitiv și o versiune de sistem care îl acceptă.

YamabikoChat este open source?

Da. Codul sursă este publicat pe GitHub sub licența MIT. Software-ul terț inclus păstrează propriile licențe.
