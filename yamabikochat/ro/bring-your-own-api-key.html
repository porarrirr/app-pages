Adu-ți propria cheie

Folosește-ți propria cheie API pentru chat AI pe iPhone și iPad

YamabikoChat este un client BYOK (bring your own key). Adaugi o cheie API — sau te conectezi la un cont acceptat — iar aplicația trimite prompturile direct la acel furnizor. Nu există niciun abonament YamabikoChat și nicio revânzare de tokenuri între.

Ultima actualizare: 2026-11-17

Ce înseamnă „bring your own key”

Furnizorii de AI precum OpenAI, Google, Anthropic și OpenRouter vând acces la modelele lor prin chei API, de obicei facturate pe utilizare. O aplicație BYOK este un client pentru aceste chei: creezi o cheie în contul furnizorului, o adaugi în aplicație, iar furnizorul te facturează direct pentru ce folosești.

De ce să folosești propria cheie

  • Plătești pentru ce folosești. Cei care folosesc puțin cheltuie de obicei mai puțin decât pe un abonament lunar de AI; cei care folosesc intens văd exact de unde vin costurile.
  • Alegi modelul. Folosești modelele oferite de furnizorul tău, nu o listă fixă aleasă de aplicație.
  • O aplicație, mai mulți furnizori. Ține Gemini, OpenRouter, OpenAI, Anthropic și alții unul lângă altul și compară-i în modul Dual.
  • Vezi consumul. Statisticile de utilizare a tokenurilor arată cât folosești.

Cum îl configurezi

  1. Creează o cheie API în consola furnizorului tău — de exemplu Google AI Studio pentru Gemini, platforma OpenAI, consola Anthropic sau OpenRouter.
  2. Deschide Setările din YamabikoChat și alege furnizorul în setările de conectare.
  3. Lipește cheia. Este salvată în Keychain-ul iOS de pe dispozitivul tău.
  4. Alege un model și începe conversația. Modelele pe care aplicația nu le poate rula în siguranță apar ca indisponibile, împreună cu motivul, în loc să fie ghicite.

Fără cheie API? Conectează-te cu un cont

  • Abonament ChatGPT — conectează-te cu contul tău ChatGPT pentru a folosi modelele incluse în abonament.
  • xAI — conectează-te cu contul tău xAI.
  • Apple Intelligence — integrat pe dispozitivele acceptate, pe dispozitiv sau prin Private Cloud Compute, fără nicio cheie.

Endpointuri personalizate

Dacă serviciul tău nu apare în listă, adaugă un endpoint personalizat cu URL-ul de bază și cheia, apoi alege unul dintre formatele API acceptate: OpenAI Chat Completions, OpenAI Responses, Anthropic Messages, Gemini (Google Generative AI) sau Mistral.

Cât costă

Aplicația este gratuită, fără achiziții în aplicație. Furnizorul îți facturează utilizarea conform propriilor prețuri, limite și termeni. Modul Dual și conversația automată trimit cereri la două modele, deci generează utilizare la ambele.

Securitate și confidențialitate

  • Cheile API și tokenurile de acces sunt păstrate în Keychain-ul iOS, iar aplicația este proiectată să nu le scrie în jurnalele sale de diagnosticare.
  • Prompturile, contextul conversației și fișierele atașate pe care le alegi sunt trimise direct furnizorului selectat.
  • Conversațiile sunt stocate pe dispozitivul tău. Aplicația nu folosește urmărire între aplicații. Vezi politica de confidențialitate.
