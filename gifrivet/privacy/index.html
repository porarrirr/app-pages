プライバシーポリシー

GifRivetは「あなたのメディアはあなたの端末から一歩も外に出さない」という設計原則に基づき、個人情報の収集・追跡・広告配信を一切行いません。

01

完全オンデバイス処理

動画・画像の変換、Metalレンダリング、AI背景透過・超解像・補間・物体追従、音声文字起こしはすべて端末内で完結します。

02

追跡・広告・解析SDKゼロ

アクセス解析、広告SDK、クラッシュ自動送信ツール、ユーザー行動トラッキング、アカウント登録は一切組み込んでいません。

03

自社サーバー非保有

開発者が運営するバックエンドサーバーは存在せず、ユーザーのメディアや編集データが開発者へ送信されることはありません。

04

EXIF・メタデータ削除対応

書き出しスタジオおよびバッチスタジオに「メタデータを保持」切替スイッチを搭載し、位置情報等のEXIFを除去して出力できます。

01

基本方針と収集しない情報

GifRivet（以下「本アプリ」）は、利用者のプライバシーを最優先に設計されています。本アプリは氏名、メールアドレス、位置情報、端末識別子（IDFA等）、利用履歴、クラッシュログ、ならびに利用者が取り込んだ写真・動画・GIF・音声データを、開発者または第三者のサーバーへ自動送信・収集しません。

本アプリには広告SDK、アナリティクスSDK、SNSトラッキングSDKなどの第三者データ収集モジュールは一切含まれていません。

02

端末内に保存されるデータとApp Groupの扱い

本アプリは編集作業の継続、クラッシュ復旧、カスタム資産管理のため、以下のデータを利用者の端末内アプリ専用保護領域（サンドボックス）および同一端末内の共有App Groupにのみ保存します。

  • ▪ 作成・編集中のプロジェクトデータ、自動保存ジャーナル、ゴミ箱内のプロジェクト
  • ▪ サムネイル・フレームキャッシュ（設定画面からいつでも一括消去可能）
  • ▪ 利用者が登録したカスタムフォント（.ttf / .otf）、3D LUT（.cube）、カスタムステッカー、書き出しプリセット
  • ▪ 共有拡張（GifRivet Share Extension）からの受け渡しメディアおよび iMessage ステッカー拡張（GifRivet Stickers）へ保存したステッカー素材

これらのデータは端末内にとどまり、開発者へ送信されません。不要なプロジェクトやキャッシュはアプリ内からいつでも削除でき、本アプリをアンインストールすると端末内のアプリ保存領域のデータも通常は削除されます。

利用者がiOSのiCloudバックアップまたはMac/PCへのバックアップを有効にしている場合、OSの仕組みによりローカルデータがバックアップ対象となる場合があります。その管理と暗号化はAppleの仕様に従います。

03

使用するOS権限とオンデバイス機能

本アプリは、利用者が該当機能を明示的に操作した場合に限り、最小限のiOS / iPadOS権限を要求します。

  • ▪ 写真ライブラリ（読み取り／追加）：写真・動画・Live Photos・GIFの取り込み、および書き出し結果の写真Appへの保存のためだけに使用します。
  • ▪ カメラ：アプリ内のカメラキャプチャ機能で動画・連写撮影を行う場合のみ使用します。
  • ▪ 音声認識（SFSpeechRecognizer）：自動字幕生成機能を利用する場合のみ使用します。本アプリは requiresOnDeviceRecognition = true を強制しており、音声データが外部サーバーへ送信されることはありません。
  • ▪ クリップボード：ホーム画面またはエディタで利用者がクリップボード取り込み・コピーを操作した際にのみ読み書きします。
  • ▪ 画面収録（ReplayKit）および Apple Image Playground：利用者が明示的に起動した場合のみOS標準フレームワークを通じて動作します。
04

任意機能「URLから取り込み」における通信について

本アプリは原則として完全オフラインで動作しますが、ホーム画面メニューの「URLから取り込み」機能を利用者が手動で実行し、http:// または https:// のURLを入力した場合に限り、端末から入力されたURL先へ直接ダウンロード通信（URLSession）を行います。

この通信は開発者のサーバーを経由せず、利用者の端末と指定先ホスト間で直接行われます。接続先サーバーでのアクセスログ（IPアドレス等）の取り扱いは、当該接続先のプライバシーポリシーに従います。

05

書き出し・メタデータ管理・共有機能

書き出し、ファイル保存、AirDrop、他アプリへの共有は、すべて利用者の明示的な操作によってのみ開始されます。書き出し設定およびバッチ設定の「メタデータを保持」をオフにすることで、EXIFや撮影情報などのメタデータを含めずにファイルを生成できます。

iOS標準の共有シート等を通じて外部サービスへファイルを受け渡した後のデータ取り扱いは、共有先サービス各社のプライバシーポリシーに従います。

06

お問い合わせにより受領する情報

利用者がサポート窓口（support@rarari.org）またはプライバシー窓口（privacy@rarari.org）へメールでお問い合わせいただいた場合、送信元メールアドレス、本文、および任意で添付された情報を受領します。

受領した情報は、お問い合わせへの返信、不具合調査、サポート対応および必要な記録保管のみに利用し、広告目的の利用や第三者への販売・提供は一切行いません。過去の問い合わせ内容の削除をご希望の場合はプライバシー窓口までご連絡ください。

07

本Webサイトおよびホスティング基盤について

本公式サイト（マーケティングページ・サポートページ・プライバシーポリシー）には、開発者が設置したアクセス解析ツール、広告タグ、トラッキング用Cookieは一切ありません（ライト/ダーク表示設定の保存にのみブラウザの localStorage を使用します）。

本サイトは GitHub Pages 上で公開されています。GitHubは配信およびセキュリティ維持のためアクセス元のIPアドレス等の技術ログを処理する場合があります。詳細は GitHub General Privacy Statement および Apple プライバシーポリシーをご確認ください。

08

お子様のプライバシーおよびポリシーの変更

本アプリは年齢を問わず個人情報を収集する機能を持たないため、お子様が利用する場合も個人情報は収集されません。

本アプリの機能追加や法令改正に伴い本ポリシーを改定する場合は、本ページを更新し最終更新日を明記します。
