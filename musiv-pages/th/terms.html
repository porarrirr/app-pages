ข้อกำหนดและข้อจำกัดความรับผิดชอบ

อัปเดตล่าสุด: 22 พฤษภาคม 2026

หน้านี้กำหนดเงื่อนไขการใช้งานสำหรับ Musiv ("แอป") และเว็บไซต์ที่เกี่ยวข้อง การดาวน์โหลด ติดตั้ง หรือใช้งานแอปถือเป็นการยอมรับข้อกำหนดเหล่านี้ หากคุณไม่ยอมรับ อย่าใช้แอป

1. ลักษณะของแอป

  • แอปเป็นเครื่องมือที่อ้างอิงข้อมูลที่เปิดเผยต่อสาธารณะจาก URL เพลงที่ผู้ใช้ระบุ และสร้างการค้นหาและลิงก์สำหรับบริการเพลงอื่นๆ
  • แอปไม่เล่น ไม่สตรีม ไม่ดาวน์โหลด ไม่ให้บริการ และไม่เผยแพร่เพลงซ้ำ
  • แอปไม่ใช่แอปอย่างเป็นทางการ บริการอย่างเป็นทางการ หรือบริการที่เกี่ยวข้องของ Spotify, Apple, Google, Amazon ฯลฯ

2. ไม่มีการรับประกัน

แอปและข้อมูลที่เกี่ยวข้องให้บริการตาม"สภาพที่เป็นอยู่" (AS IS) ผู้ดำเนินการไม่ให้การรับประกันใดๆ ไม่ว่าโดยชัดแจ้งหรือโดยนัย รวมถึงแต่ไม่จำกัดเพียง:

  • ความถูกต้อง ความสมบูรณ์ หรือความเป็นปัจจุบันของการแปลงลิงก์ หรือการตรงกับเพลงหรือศิลปินเฉพาะ
  • ความพร้อมใช้งานอย่างต่อเนื่อง หรือการไม่มีข้อผิดพลาดและข้อบกพร่อง
  • ความเหมาะสมกับวัตถุประสงค์หรือความคาดหวังของผู้ใช้
  • ความเข้ากันได้อย่างต่อเนื่องกับบริการของบุคคลที่สาม (การสตรีมเพลง เบราว์เซอร์ OS ฯลฯ)

3. บริการของบุคคลที่สาม

  • ปลายทางที่เปิดผ่านแอปอยู่ภายใต้เงื่อนไขการใช้งาน ค่าธรรมเนียม และข้อจำกัดตามภูมิภาคของบริการเพลง เว็บไซต์ และแอปที่เกี่ยวข้อง คุณต้องปฏิบัติตามและใช้งานด้วยความรับผิดชอบและค่าใช้จ่ายของคุณเอง
  • การเปลี่ยนแปลงข้อกำหนด API ข้อจำกัดการเข้าถึง การบำรุงรักษา ฯลฯ ของบุคคลที่สามอาจทำให้ฟีเจอร์ของแอปหยุดทำงาน ผู้ดำเนินการไม่มีภาระผูกพันในการกู้คืนหรือชดเชย
  • เมทาดาทา เช่น ชื่อเพลงและชื่อศิลปิน ที่แอปได้รับจากหน้าและ API ที่อ้างอิงให้บริการโดยบุคคลที่สาม และอาจมีข้อผิดพลาดหรือข้อบกพร่อง

4. เครื่องหมายการค้าและทรัพย์สินทางปัญญา

ชื่อ โลโก้ และเครื่องหมายการค้าของ Spotify, Apple Music, YouTube, YouTube Music, Amazon Music ฯลฯ เป็นของเจ้าของแต่ละราย แอปไม่ได้แสดงความเกี่ยวข้อง การรับรอง หรือใบอนุญาตใดๆ จากเจ้าของเหล่านั้น ผู้ใช้ควรเคารพแนวทางและนโยบายเครื่องหมายการค้าของเจ้าของแต่ละราย

5. การจำกัดความรับผิดชอบ

ในขอบเขตสูงสุดที่กฎหมายอนุญาต ผู้ดำเนินการไม่รับผิดชอบต่อความเสียหายที่เกิดจากการใช้งานหรือไม่สามารถใช้งานแอปได้ (รวมถึงแต่ไม่จำกัดเพียง ความเสียหายทางอ้อม ความเสียหายพิเศษ ความเสียหายเชิงลงโทษ ผลกำไรที่เสียหาย การสูญหายของข้อมูล ความล้มเหลวของอุปกรณ์ หรือข้อพิพาทเกี่ยวกับการเรียกเก็บเงินและสัญญากับบริการของบุคคลที่สาม) ยกเว้นกรณีมีการกระทำโดยเจตนาหรือความประมาทอย่างร้ายแรงในการดำเนินงาน

แม้ว่าผู้ดำเนินการจะถือว่ารับผิดชอบจากเหตุผลใดก็ตาม ความรับผิดชอบถูกจำกัดอยู่ที่จำนวนเงิน ที่ผู้ใช้จ่ายสำหรับแอปในช่วง 12 เดือนที่ผ่านมา (หรือศูนย์หากแอปให้บริการฟรี)

6. หน้าที่ของผู้ใช้

  • อย่าใช้แอปเพื่อแปลงหรือแชร์ URL หรือเนื้อหาที่ผิดกฎหมาย ฉ้อโกง หรือละเมิดสิทธิ์
  • เข้าใจว่าการใช้คลิปบอร์ดและฟีเจอร์การแชร์อาจประมวลผล URL ที่ไม่ตั้งใจ
  • จัดการอุปกรณ์ เครือข่าย และบัญชีของคุณเอง

7. การเปลี่ยนแปลงและการยุติบริการ

ผู้ดำเนินการอาจเปลี่ยนแปลง จำกัด หรือยุติฟีเจอร์ทั้งหมดหรือบางส่วนของแอปโดยไม่ต้องแจ้งล่วงหน้า ผู้ดำเนินการไม่รับผิดชอบต่อความเสียหายที่เกิดขึ้นกับผู้ใช้จากเรื่องนี้

8. ความเป็นส่วนตัว

การประมวลผลข้อมูลอยู่ภายใต้ นโยบายความเป็นส่วนตัว ในกรณีที่ข้อกำหนดเหล่านี้ขัดแย้งกับนโยบายความเป็นส่วนตัว นโยบายความเป็นส่วนตัวมีผลบังคับในเรื่องความเป็นส่วนตัว

9. การเปลี่ยนแปลงข้อกำหนดเหล่านี้

ผู้ดำเนินการอาจเปลี่ยนแปลงข้อกำหนดเหล่านี้ได้ตลอดเวลา การใช้งานต่อหลังจากการเปลี่ยนแปลงถือเป็นการยอมรับ การเปลี่ยนแปลงที่สำคัญจะประกาศผ่านวันที่อัปเดตในหน้านี้หรือในแอปหรือบนเว็บ

10. กฎหมายที่ใช้บังคับและความสามารถในการแยกส่วน

ข้อกำหนดเหล่านี้อยู่ภายใต้กฎหมายญี่ปุ่น ข้อพิพาทที่เกี่ยวข้องกับแอปอยู่ภายใต้เขตอำนาจศาลแต่เพียงผู้เดียว ของศาลในสถานที่ที่ตั้งของผู้ดำเนินการ (ยกเว้นกรณีที่ผู้ดำเนินการและผู้ใช้ตกลงเป็นอย่างอื่น) หากส่วนใดส่วนหนึ่งของข้อกำหนดเหล่านี้เป็นโมฆะ ข้อกำหนดที่เหลือยังคงมีผลบังคับใช้
