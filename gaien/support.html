はじめかた

アカウントを作らずに使えますか？

はい。学習タイマー、教材管理、自動復習、カレンダー、時間割、集中制限などの基本機能をすべてアカウントなし・広告なしで使えます。複数端末で記録を共有したいときだけ、設定の「クラウド同期」からアカウントを作成してください。

最初の学習記録をつけるには？

「タイマー」タブを開いて科目（および任意で教材）を選び、計測を開始します。勉強が終わったら「終了して記録」を押すと、学習時間・評価・問題進捗が自動集計されます。ホーム画面の「学習をはじめる」ボタンからもすぐ開始できます。

ダークモードや対応OS・対応言語は？

設定からライト／ダーク／システム設定に合わせる表示を選べます。iPhone・iPad（iOS 16以降、Split View・サイドバー対応）および Android（8.0以降）に対応しており、アプリは50言語にネイティブ対応しています。

タイマー・集中表示・見守りペット

ストップウォッチ・カウントダウン・手動入力の違いは？

経過時間を測る「ストップウォッチ」、25分ポモドーロなど時間を決める「カウントダウン」、あとから勉強時間を追加できる「手動入力」の3方式に対応しています。計測中でも「問題の進捗を記録」から正誤をつけられます。

アプリを閉じてもタイマーは続きますか？

はい。別のアプリに切り替えたり画面をロックしたりしても計測は継続します。iOS版では対応端末のロック画面や Dynamic Island にライブアクティビティとして進行状況を表示できます。端末を横向きにすると集中用の全画面表示・置き時計モードも使えます。

「見守りペット」はカメラ映像を録画・送信しますか？

いいえ、一切ありません。見守りペットは端末内（オンデバイス）での人物検出のみを行い、カメラ映像の表示・保存・外部サーバーへの送信は一切行いません。機能自体も任意でオフのまま利用できます。

削除した学習記録を元に戻せますか？

削除前に作成したバックアップがあれば、設定の「バックアップ」から復元できます。復元を実行すると現在のデータも事前に自動バックアップされるため安心です。

教材・問題集・自動復習

問題集グリッドの5段階の色分けと自動復習はどう動きますか？

問題集を登録して各問題の正解・不正解を記録すると、誤答履歴のある問題は「1日後 → 3日後 → 7日後 → 14日後」の間隔で復習対象として自動スケジュールされ、ホーム画面の「次の一歩（今日の復習）」に表示されます。連続正解に応じて色が赤から黄・緑へと変化し、定着度が一目でわかります。

バーコードを読み取れないときはどうすればいいですか？

端末の設定で StudyTrail のカメラアクセスが許可されているか確認し、明るい場所で上段のISBNバーコード（978または979から始まる13桁）を枠内に合わせてください。読み取れない場合は検索画面からISBN番号や書名を直接入力して登録できます。

科目のアイコンや色を変更できますか？

はい。「科目」タブから各科目の編集メニューを開くと、科目名・アイコン・カラーを自由に変更できます。設定した色はレポートグラフや時間割にも自動で反映されます。

スマホの集中制限（iOS スクリーンタイム）

集中制限ではどんなルールを組み合わせられますか？

「タイマー計測中」「指定した時間帯（使用禁止・無料開放）」「1日の学習目標未達成の間」「地図で指定した場所（学校・図書館など）」の4つのルールを独立してオン／オフできます。さらに、勉強した分だけスマホの持ち時間が増える交換レート・目標達成ボーナス・時間制解除チケットにも対応しています。

場所ルールで使う位置情報は外部に送信されますか？

いいえ。場所ルールのジオフェンス判定は端末内のみで完結し、位置情報が開発者のサーバーや Firebase へ送信されることはありません。アプリを閉じた状態でエリアの出入りを検知するため、iOS の設定で「位置情報を常に許可」にする必要があります。

「設定の期間固定ロック」を有効にすると解除できますか？

期間固定ロックは、自分でルールを緩めてしまうのを防ぐための機能です。指定した期限までは集中制限の設定変更や無効化ができなくなりますので、必要な連絡アプリや学習アプリを「許可するアプリ」に登録してから有効にしてください。

時間割・試験カウントダウン・目標

時間割の授業復習機能はどう使いますか？

「学習管理」→「時間割」から学期と時限を設定し、各コマに授業を登録します。画面上部の「復習」タブへ切り替えると授業ごとの復習状況を確認でき、未復習の授業があるときに通知でリマインドすることもできます。

曜日によって1日の目標時間を変えられますか？

はい。「学習管理」→「目標」から、月〜日それぞれ別の1日目標時間と週間目標を設定できます。平日は短め、休日は長めといった無理のないスケジュール設定が可能です。

ウィジェット＆ライブアクティビティ

iPhone・iPadでウィジェットを追加するには？

ホーム画面の空いている場所を長押しし、「編集」→「ウィジェットを追加」を選びます。「StudyTrail」を検索すると、今日の学習・目標・連続学習・試験カウントダウンなど9種類のウィジェットから選んで配置できます。ロック画面のカスタマイズからも追加可能です。

Androidでウィジェットを追加するには？

ホーム画面の空いている場所を長押しして「ウィジェット」一覧を開き、StudyTrail のウィジェットを選んでホーム画面へドラッグして配置してください。

クラウド同期とアカウント

クラウド同期を使い始めるには？

設定の「クラウド同期」にある「サインイン / アカウント作成」を選びます。iPhone・iPad・Android など別の端末でも同じアカウントでサインインすると、差分同期でデータを共有できます。万一オフライン編集で競合が起きた場合は、競合解決画面で残す内容を選択できます。

機種変更したら何をすればいいですか？

クラウド同期を使っていた場合は、新しい端末で同じアカウントにサインインするだけで引き継げます。ローカルのみで使っていた場合は、古い端末の設定から JSON 形式でバックアップを書き出し、新しい端末でインポートしてください。

アカウントを削除するには？

サインインした状態で設定を開き、「クラウド同期」の「アカウントを削除」を選びます。確認画面で現在のパスワードを入力すると、クラウド同期アカウント・クラウド上の同期データ・この端末の学習データが完全に削除されます。残したい記録は事前に JSON で書き出してください。

アプリから手続きできない場合は、お問い合わせ窓口へご連絡ください。

バックアップと書き出し

学習記録を JSON / CSV に書き出すには？

設定の「バックアップ」で「エクスポート」を選び、形式を指定します。完全なバックアップ・別端末への移行には JSON を、Excel や Google スプレッドシートでの集計には CSV を選んでください。

書き出した JSON データを読み込むには？

設定の「バックアップ」で「インポート」を選び、保存しておいた JSON ファイルを指定してください。復元前には現在の状態が自動バックアップされるため、万一間違えた場合も復元画面から元に戻せます。
