プライバシーポリシー Privacy Policy

1. 取得する情報および利用目的 1. Information We Collect & Purposes of Use

開発者は、以下の情報を取得し、それぞれ記載の目的の範囲内で利用します（個人情報保護法第17条・第18条）。

We collect and process the following information strictly within the stated purposes:

  • アカウント情報（メールアドレス・パスワード）: クラウド同期機能をご利用の場合、Firebase Authentication を通じたユーザー認証およびクラウド同期機能の提供に利用します。パスワードは Firebase のサーバー上でハッシュ化され、開発者が直接閲覧・取得することはありません。
  • 学習記録データ（科目、教材名、問題進捗、タイマー記録、時間割、学習目標、テスト日程等）: アプリ内での学習記録の保存・表示、およびクラウド同期機能をご利用の場合はサーバーへの保管に利用します。
  • カメラ（ISBN バーコード読取・見守りペット機能をご利用の場合）: 教材登録時のバーコード読み取り、および見守りペット機能におけるオンデバイス人物検出のみに使用します。カメラ映像の表示（見守りペット時）・録画・保存・外部送信は一切行いません。
  • 位置情報（iOS の集中制限・場所ルールをご利用の場合）: ユーザーが指定した場所（学校・図書館等）にいるあいだ、許可したアプリ以外を制限するために、端末上でジオフェンス判定を行います。位置情報は端末内のみで処理し、開発者のサーバーおよび Firebase へ送信しません。この機能はユーザーが明示的に有効にした場合に限り動作し、バックグラウンドでの判定には OS の「位置情報の常に許可」が必要です。
  • スクリーンタイム設定（iOS の集中制限機能をご利用の場合）: Apple Family Controls を用いて、選択されたアプリ・カテゴリの使用制限を端末内のみで実行します。制限対象アプリの一覧や使用状況が開発者のサーバーへ送信されることはありません。
  • 書籍検索クエリ（ISBN・書名検索をご利用の場合）: 教材の書誌情報を自動入力する目的で、入力または読み取った ISBN やキーワードを Google Books API へ送信する場合があります。
  • 匿名利用統計情報: アプリの品質向上および不具合調査のため、Google Analytics for Firebase を通じて、個人を特定できない形での匿名統計情報（画面遷移、機能利用状況等）を収集することがあります。
  • クラッシュログ: アプリの不具合調査・改善のため、Firebase Crashlytics を通じて、クラッシュ発生時の匿名技術情報（端末機種、OSバージョン、スタックトレース等）を自動収集することがあります。
  • Account Credentials (Email & Password): Used via Firebase Authentication only when you opt into Cloud Sync. Passwords are hashed by Firebase and are never accessible to the Developer.
  • Study Records (Subjects, textbooks, problem progress, timer sessions, timetable, goals, exams): Stored locally on-device, and synced to Cloud Firestore only if you enable Cloud Sync.
  • Camera (ISBN Scanner & Optional Study Pet): Used solely for reading ISBN barcodes and on-device person detection for Study Pet. Study Pet never displays, records, saves, or uploads camera video.
  • Location (Optional iOS Location Focus Zones): Used strictly for on-device geofencing to apply focus rules at user-selected places (such as school or a library). Location is never sent to our servers or Firebase.
  • Screen Time Controls (Optional iOS Family Controls): Managed strictly on-device through Apple's Screen Time APIs; selected apps and usage data are never sent to external servers.
  • Book Lookup Queries (Optional ISBN / Title Search): Sent to Google Books API solely to autofill book metadata when you search for a textbook.
  • Anonymous Usage Analytics & Crash Logs: Google Analytics for Firebase and Firebase Crashlytics may collect anonymized diagnostics (device model, OS version, stack traces) to improve app stability.

5. 安全管理措置（個人情報保護法第23条） 5. Security Measures

開発者は、取り扱う個人データの漏えい、滅失または毀損の防止その他の安全管理のため、以下の措置を講じています。

  • 通信の暗号化: アプリとサーバー間の通信は SSL/TLS により暗号化されています。
  • アクセス制御: Firebase Security Rules により、ユーザーは自身のデータにのみアクセスできるよう制御しています。
  • 認証情報の保護: パスワードは Firebase Authentication によりハッシュ化して保管され、開発者が平文のパスワードにアクセスすることはありません。
  • データ保管: クラウドデータは Google LLC が運営するデータセンターに保管され、同社の物理的・技術的セキュリティ措置により保護されています。
  • Encrypted Transit: All client-server traffic is encrypted with SSL/TLS.
  • Strict Access Control: Firebase Security Rules restrict access strictly to each authenticated user's own data.
  • Credential Protection: Passwords are hashed by Firebase Authentication and never visible in plaintext.

7. データの保管・削除 7. Data Retention & Deletion

クラウド同期機能をご利用の場合、データは Firebase（Google LLC）のサーバーに保管されます。ユーザーはアプリ内の設定画面からいつでもご自身のアカウントおよび登録されたデータを完全に削除することができます。アカウント削除後、サーバー上のデータは速やかに削除されます（ただし、バックアップからの完全消去には一定期間を要する場合があります）。

Cloud-synced data is stored on Firebase servers until you delete your account. You can permanently delete your account and all synced records anytime inside Settings → Cloud Sync → Delete Account.

8. Cookie・端末識別子等の利用 8. Cookies & Device Identifiers

当アプリは Web ブラウザベースのサービスではないため、Cookie は使用しません。ただし、Google Analytics for Firebase および Firebase Crashlytics は、端末を識別するための匿名識別子（Instance ID 等）を利用します。これらの識別子は個人を特定するものではなく、統計分析およびクラッシュ分析の目的にのみ使用されます。

The mobile app does not use browser cookies. Firebase Analytics and Crashlytics use anonymous instance identifiers solely for aggregate analytics and crash diagnosis.
