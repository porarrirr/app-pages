સહાય

એપ વાપરવામાં મદદની જરૂર હોય કે કોઈ સમસ્યા મળી હોય, તો અહીંથી શરૂ કરો.

અમારો સંપર્ક કરો

પ્રશ્નો, બગ રિપોર્ટ અને સૂચનો GitHub Issues દ્વારા મોકલો. અમે દરેકને જોઈએ છીએ અને શક્ય તેટલી વહેલી તકે જવાબ આપીએ છીએ.

GitHub પર અમારો સંપર્ક કરો

પોસ્ટ કરવા માટે GitHub એકાઉન્ટ જરૂરી છે. પોસ્ટ જાહેર થાય છે, તેથી કૃપા કરીને તમારા ફોટા કે કોઈ પણ અંગત માહિતી સાથે મૂકશો નહીં.

કૃપા કરીને આનો સમાવેશ કરો

  • તમારા ઉપકરણનું મોડેલ (ઉદાહરણ તરીકે, iPhone 15 કે iPad Air)
  • તમારું iOS કે iPadOS વર્ઝન
  • એપનું વર્ઝન
  • શું થયું અને તે સુધી લઈ જનારા પગલાં

જરૂરિયાતો

  • iOS 17 કે પછીના વર્ઝનવાળું iPhone કે iPad
  • તમારી ફોટા લાઇબ્રેરીમાં ઍક્સેસની પરવાનગી (બધા ફોટા કે કેટલાક ફોટા)
  • કોઈ એકાઉન્ટની જરૂર નથી

વારંવાર પૂછાતા પ્રશ્નો

10
01“બરાબર સરખા ફોટા” અને “સમાન ફોટા” વચ્ચે શું ફરક છે?

બરાબર સરખા ફોટા એ છે જેની ફાઇલો સંપૂર્ણપણે સરખી હોય. સમાન ફોટા એ છે જે ઇમેજના નાના વર્ઝનની સરખામણી કરતાં લગભગ એક જ જેવા દેખાય, જેમ કે બર્સ્ટ અને ફરી પાડેલા ફોટા.

02“ડિલીટ” પસંદ કરતાં જ ફોટા ડિલીટ થઈ જાય છે?

ના. તમે ડિલીટ કરવા પસંદ કરેલા ફોટા ફક્ત ડિલીટ લિસ્ટમાં ભેગા થાય છે; તે હજી ડિલીટ થયા નથી. તમે ડિલીટ લિસ્ટ ફરી જુઓ, ડિલીટ કરવાનું શરૂ કરો અને તમારા iPhone ની પુષ્ટિ સ્ક્રીન પર “ડિલીટ” દબાવો, ત્યારે જ તે ડિલીટ થાય છે.

03ભૂલથી ડિલીટ કરેલો ફોટો પાછો મેળવી શકાય?

હા, થોડા સમય માટે, ફોટા એપના “તાજેતરમાં ડિલીટ કરેલા” માંથી. એ સમય પછી ફોટા કાયમ માટે ડિલીટ થઈ જાય છે, તેથી જલદી તપાસો.

04હું iCloud ફોટા વાપરું છું. ડિલીટ કરું ત્યારે શું થાય?

જો તમે iCloud ફોટા વાપરતા હો, તો ડિલીટ કરેલા ફોટા એ જ Apple એકાઉન્ટથી સાઇન ઇન હોય એવા તમારા અન્ય ઉપકરણો — જેમ કે તમારું iPad કે Mac — પરથી પણ દૂર થાય છે.

05મારા iPhone પર સેવ ન હોય એવા ફોટા પણ એપ ચેક કરી શકે?

iCloud માં સેવ થયેલા ફોટા લોડ કરીને ચેક કરવા માટે સેટિંગ્સમાં “iCloud ફોટા પણ લોડ કરો” ચાલુ કરો. લોડ કરવામાં મોબાઇલ ડેટા વપરાઈ શકે છે. આ ફેરફાર આગલા ચેકથી લાગુ થાય છે.

06હું જે ફોટા ક્યારેય ડિલીટ ન કરવા માંગતો હોય તેમને કેવી રીતે સુરક્ષિત કરું?

ફોટોને મોટા કદમાં ખોલો અને “સુરક્ષિત કરો” પસંદ કરો. પછી એ ફોટો ડિલીટ કરી શકાતો નથી. ફોટા એપમાં તમે પ્રિય તરીકે ચિહ્નિત કરેલા ફોટા આપોઆપ સુરક્ષિત થાય છે.

07ચેકમાં ઘણો સમય લાગે છે.

ઘણા ફોટા હોય તો ચેકમાં થોડો સમય લાગી શકે. એપ બંધ કરવાથી ચેક અટકે છે, પણ તમે ગમે ત્યારે જ્યાં છોડ્યું ત્યાંથી ચાલુ કરી શકો છો. તમે તેને થોભાવી પણ શકો છો.

08મારા ફક્ત કેટલાક ફોટા જ દેખાય છે.

જો ફોટા ઍક્સેસ “કેટલાક ફોટા” પર સેટ હોય, તો ફક્ત તમે પસંદ કરેલા ફોટા દેખાય છે. એપની સેટિંગ્સમાં “પસંદ કરેલા ફોટા બદલો” વાપરો, અથવા સેટિંગ્સ એપમાં ઍક્સેસને “બધા ફોટા” પર બદલો.

09“લોડ ન થઈ શકેલા ફોટા” દેખાય છે.

આ iCloud માં સેવ થયેલા ફોટા છે અથવા ચેક દરમિયાન લોડ ન થઈ શકેલા ફોટા છે. ઇન્ટરનેટ સાથે જોડાઓ, “iCloud ફોટા પણ લોડ કરો” ચાલુ કરો અને તેમને ફરી લોડ કરો — તે સફળતાપૂર્વક લોડ થઈ શકે છે.

10મારા ફોટા ક્યારેય ક્યાંય મોકલાય છે?

ના. બધી ફોટા સરખામણી તમારા ઉપકરણ પર જ થાય છે, અને ફોટા તથા ચેકના પરિણામ ક્યારેય ક્યાંય મોકલાતા નથી. વિગતો માટે ગોપનીયતા નીતિ જુઓ.

જો કોઈ ફોટા દેખાય નહીં

જો ફોટા ઍક્સેસ બંધ હોય, તો એપ તમારા ફોટા બતાવી શકતી નથી. સેટિંગ્સ એપ ખોલો અને આ એપ માટે “ફોટા” ચાલુ કરો. તમે એપની સેટિંગ્સ સ્ક્રીન પર “સેટિંગ્સ એપ ખોલો” થી પણ ત્યાં પહોંચી શકો છો.
