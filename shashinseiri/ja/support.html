サポート

使い方で困ったときや、不具合を見つけたときはこちらをご覧ください。

お問い合わせ

ご質問・不具合のご報告・ご要望は、GitHub の Issue からお送りください。内容を確認のうえ、順次対応します。

GitHub で問い合わせる

投稿には GitHub アカウントが必要です。投稿内容は公開されるため、写真そのものや個人情報は添付しないでください。

お問い合わせの際に書いていただきたいこと

  • お使いの機種（例：iPhone 15、iPad Air）
  • iOS / iPadOS のバージョン
  • アプリのバージョン
  • 起きたことと、そのときの操作手順

動作環境

  • iOS 17 以降の iPhone・iPad
  • 写真ライブラリへのアクセス許可（「すべての写真」または「一部の写真」）
  • アカウント登録は不要です

よくある質問

10
01「まったく同じ写真」と「よく似た写真」は何が違いますか？

「まったく同じ写真」は、ファイルの中身が完全に一致する写真です。「よく似た写真」は、縮小した画像を比べて見た目がよく似ていると判断した写真で、連写や撮り直しなどが当てはまります。

02「削除」を選んだら、すぐに写真が消えますか？

いいえ。「削除」を選んだ写真は削除リストに集まるだけで、まだ削除されていません。削除リストで内容を確認して削除を実行し、iPhoneの確認画面で「削除」を押したときにはじめて削除されます。

03まちがえて削除した写真は戻せますか？

写真アプリの「最近削除した項目」から、しばらくの間は戻せます。期間を過ぎると完全に削除されるため、早めに確認してください。

04iCloud写真を使っています。削除するとどうなりますか？

iCloud写真を使っている場合、削除した写真は iPad や Mac など、同じ Apple アカウントのほかの端末からも削除されます。

05iPhoneに保存されていない写真もチェックできますか？

設定の「iCloudの写真も読み込む」をオンにすると、iCloud にある写真も読み込んでチェックできます。読み込みにはモバイル通信を使うことがあります。設定の変更は次のチェックから使われます。

06削除したくない写真を守るには？

写真を大きく表示して「保護」を選ぶと、その写真は削除できなくなります。写真アプリでお気に入りにした写真も、自動で保護されます。

07チェックに時間がかかります。

写真が多いと、チェックに少し時間がかかります。アプリを閉じるとチェックは止まりますが、続きからいつでも再開できます。一時停止することもできます。

08一部の写真しか表示されません。

写真へのアクセスが「一部の写真」になっていると、選んだ写真だけが表示されます。アプリの設定にある「選ぶ写真を変更する」か、設定アプリでアクセスを「すべての写真」に変更してください。

09「読み込めなかった写真」と表示されます。

iCloud にある写真や、途中で読み込めなかった写真です。インターネットに接続した状態で「iCloudの写真も読み込む」をオンにし、もう一度読み込むと、読み込める場合があります。

10写真が外部に送信されることはありますか？

ありません。写真の比較はすべて端末の中で行い、写真やチェック結果を外部に送信することはありません。詳しくはプライバシーポリシーをご覧ください。

写真が表示されないとき

写真へのアクセスがオフになっていると、アプリは写真を表示できません。設定アプリを開き、このアプリの「写真」をオンにしてください。アプリの設定画面にある「設定アプリを開く」からも移動できます。
