지원

앱을 사용하다 도움이 필요하거나 문제를 발견했다면 여기에서 시작하세요.

문의하기

질문, 버그 신고, 기능 제안은 GitHub 이슈로 보내 주세요. 하나하나 확인하고 가능한 한 빨리 답변드리겠습니다.

GitHub에서 문의하기

게시하려면 GitHub 계정이 필요합니다. 게시 내용은 공개되므로 사진이나 개인정보는 첨부하지 마세요.

문의할 때 함께 알려 주세요

  • 사용 중인 기기 모델(예: iPhone 15, iPad Air)
  • iOS 또는 iPadOS 버전
  • 앱 버전
  • 무슨 일이 있었는지와 그때까지의 작업 순서

실행 환경

  • iOS 17 이상이 설치된 iPhone 또는 iPad
  • 사진 보관함 접근 권한(모든 사진 또는 선택한 사진)
  • 계정 가입 불필요

자주 묻는 질문

11
01사진을 탭하면 “남기기”와 “삭제” 중 어떻게 되나요?+

사진을 탭하면 “남기기”와 “삭제”가 전환됩니다

02“삭제”를 선택하면 사진이 바로 지워지나요?+

아니요. 삭제하기로 선택한 사진은 삭제 목록에 모일 뿐 아직 삭제되지 않습니다. 삭제 목록에서 내용을 확인하고 삭제를 실행한 뒤 iPhone 확인 화면에서 “삭제”를 눌러야 비로소 삭제됩니다. 사진 앱의 “최근 삭제된 항목”에서도 삭제한 후에 저장 공간이 늘어납니다.

03지우고 싶지 않은 사진은 어떻게 보호하나요?+

사진을 크게 보기로 열고 “보호”를 선택하세요. 그러면 그 사진은 더 이상 삭제할 수 없습니다. 사진 앱에서 즐겨찾기로 표시한 사진은 자동으로 보호됩니다.

04실수로 삭제한 사진을 되돌릴 수 있나요?+

사진 선택 또는 보호 설정에 마지막으로 저장한 변경을 취소합니다. 네, 사진 앱의 “최근 삭제된 항목”에서 한동안 되돌릴 수 있습니다. 기간이 지나면 완전히 삭제되므로 되도록 빨리 확인하세요.

05iCloud 사진을 사용하고 있습니다. 삭제하면 어떻게 되나요?+

iCloud 사진을 사용하는 경우 삭제한 사진은 iPad나 Mac 등 같은 Apple 계정으로 로그인한 다른 기기에서도 삭제됩니다. iCloud 공유 사진 보관함의 사진을 삭제하면 모든 참여자의 보관함에서 삭제됩니다. 설정에서 “iCloud 사진도 불러오기”를 켜면 iCloud에 있는 사진도 불러와 확인할 수 있습니다. 확인 중에는 Wi‑Fi에 연결되어 있을 때만 사진을 다운로드합니다(저데이터 모드 제외). 사진을 전체 화면으로 볼 때는 모바일 데이터를 사용할 수 있습니다. 다음 확인부터 적용됩니다. 남은 공간이 2 GB보다 적은 동안에는 iCloud에서 다운로드하지 않습니다.

06이용 요금이 있나요?+

무료입니다. 앱 내 구입, 구독, 광고, 추적이 없으며 계정도 필요하지 않습니다.

07“완전히 같은 사진”과 “비슷한 사진”은 어떻게 다른가요?+

완전히 같은 사진은 파일 내용이 완전히 일치하는 사진입니다. 비슷한 사진은 이미지를 축소해 비교했을 때 거의 똑같아 보이는 사진으로, 연사나 다시 찍은 사진 등이 여기에 해당합니다.

08확인하는 데 시간이 오래 걸립니다.+

사진이 많으면 확인에 조금 시간이 걸릴 수 있습니다. 앱을 닫으면 확인이 멈추지만 언제든지 하던 곳에서 이어서 다시 시작할 수 있습니다. 일시 정지할 수도 있습니다.

09사진이 일부만 표시됩니다.+

사진 접근 권한이 “선택한 사진”으로 설정되어 있으면 직접 고른 사진만 표시됩니다. 앱 설정의 “선택할 사진 변경”을 사용하거나 설정 앱에서 접근 권한을 “모든 사진”으로 변경하세요.

10“불러오지 못한 사진”이 표시됩니다.+

iCloud에 있는 사진이거나 확인 중에 불러오지 못한 사진입니다. 인터넷에 연결한 상태에서 “iCloud 사진도 불러오기”를 켜고 다시 불러오면 성공할 수 있습니다.

11사진이 외부로 전송되는 일이 있나요?+

없습니다. 모든 사진 비교는 기기 안에서 이루어지며 사진과 확인 결과는 어디에도 전송되지 않습니다. 자세한 내용은 개인정보 처리방침을 확인하세요.

사진이 표시되지 않을 때

사진 접근 권한이 꺼져 있으면 앱에서 사진을 표시할 수 없습니다. 설정 앱을 열고 이 앱의 “사진”을 켜세요. 앱 설정 화면의 “설정 앱 열기”를 통해서도 이동할 수 있습니다.
