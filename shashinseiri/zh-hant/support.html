支援

使用 App 時需要協助，或發現了問題，請先從這裡開始。

聯絡我們

問題、錯誤回報與功能建議，歡迎透過 GitHub Issues 告訴我們。我們會逐一確認，並儘快回覆。

在 GitHub 上聯絡我們

發文需要 GitHub 帳號。發文內容會公開，請勿附上照片或任何個人資料。

請提供以下資訊

  • 你的裝置機型（例如 iPhone 15、iPad Air）
  • 你的 iOS 或 iPadOS 版本
  • App 版本
  • 發生的狀況與操作步驟

系統需求

  • 搭載 iOS 17 或以上版本的 iPhone 或 iPad
  • 照片圖庫的取用權限（「所有照片」或「部分照片」）
  • 不需要帳號

常見問題

10
01「完全相同的照片」和「相似的照片」有什麼不同？

「完全相同的照片」是指檔案內容完全一致的照片。「相似的照片」則是把圖片縮小後互相比對，看起來幾乎一樣的照片，例如連拍和重拍。

02選了「刪除」之後，照片會馬上消失嗎？

不會。選了「刪除」的照片只會集中在刪除清單，還沒有真的被刪除。必須在刪除清單確認內容、執行刪除，並在 iPhone 的確認畫面點一下「刪除」，照片才會被刪除。

03不小心刪掉的照片可以救回來嗎？

可以，在一段時間內可從「照片」App 的「最近刪除」復原。超過期限後，照片就會永久刪除，請盡早確認。

04我有使用 iCloud 照片，刪除後會怎樣？

如果你使用 iCloud 照片，刪除的照片也會從登入同一個 Apple 帳號的其他裝置上移除，例如 iPad 或 Mac。

05沒有存在 iPhone 上的照片也能檢查嗎？

在設定中開啟「同時載入 iCloud 照片」，就能載入並檢查儲存在 iCloud 的照片。載入時可能會使用行動數據。這項變更會從下次檢查開始生效。

06要怎麼保護絕對不想刪除的照片？

把照片放大顯示，然後選擇「保護」，那張照片就無法再被刪除。你在「照片」App 標記為我的最愛的照片，也會自動受到保護。

07檢查要花很久的時間。

照片較多時，檢查會需要一些時間。關閉 App 後檢查就會停止，但隨時都能從上次的位置繼續。你也可以暫停檢查。

08只顯示了一部分照片。

如果照片取用權限設為「部分照片」，就只會顯示你選取的照片。請使用 App 設定中的「更改所選照片」，或在「設定」App 中把取用權限改為「所有照片」。

09畫面顯示「無法載入的照片」。

這些是儲存在 iCloud 的照片，或檢查過程中無法載入的照片。連上網路、開啟「同時載入 iCloud 照片」後重新載入，或許就能順利載入。

10照片會被傳送到外部嗎？

不會。所有照片比對都在你的裝置上進行，照片和檢查結果絕不會傳送到任何地方。詳情請參閱隱私權政策。

沒有顯示照片時

如果照片取用權限已關閉，App 就無法顯示你的照片。請打開「設定」App，為這個 App 開啟「照片」。你也可以從 App 設定畫面中的『打開「設定」App』前往。

隱私權政策

照片只會在你的 iPhone 或 iPad 上檢查。
