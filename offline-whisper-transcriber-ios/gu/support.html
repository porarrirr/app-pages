સહાય

મદદ અને સહાય

iPhone અને iPad માટે Whisper: Offline Transcription ના સેટઅપ પગલાં, ટિપ્સ અને સામાન્ય સમસ્યાઓના જવાબો.

આ પેજ પર
  1. આવશ્યકતાઓ
  2. પ્રથમ વખત સેટઅપ
  3. વધુ સારા પરિણામો માટે ટિપ્સ
  4. સમસ્યા નિવારણ
  5. સ્ટોરેજ અને ડેટા મેનેજમેન્ટ
  6. સંપર્ક

આવશ્યકતાઓ

  • iPhone અથવા iPad પર iOS / iPadOS 17.0 કે ત્યારબાદનું વર્ઝન.
  • Live Transcribe, Apple નું ઓન-ડિવાઇસ સ્પીચ એન્જિન અને ઓન-ડિવાઇસ Apple Intelligence ચેટ માટે iOS 26 કે ત્યારબાદનું (સમર્થિત ડિવાઇસ પર).
  • વૈકલ્પિક Private Cloud Compute મોડ માટે iOS 27 કે ત્યારબાદનું.
  • મોડેલ ડાઉનલોડ કરવા માટે ઇન્ટરનેટ કનેક્શન અને ખાલી સ્ટોરેજ (મોડેલ પ્રમાણે લગભગ 15 MB થી 1.5 GB).
  • રેકોર્ડિંગ માટે માઇક્રોફોનની પરવાનગી.

પ્રથમ વખત સેટઅપ

  1. એપ ખોલો. મોડેલ ડાઉનલોડ સ્ક્રીન દેખાશે.
  2. કોઈ Whisper મોડેલ ડાઉનલોડ કરો. Base (લગભગ 142 MB) ડિફોલ્ટ છે અને શરૂઆત માટે યોગ્ય વિકલ્પ છે.
  3. ડાઉનલોડ પૂર્ણ થાય ત્યારે રેકોર્ડ બટન ટૅપ કરો અથવા શરૂ કરવા માટે Select File / Select Video from Photos પસંદ કરો.
  4. વૈકલ્પિક: Settings માં તમે VAD મોડેલ (શાંત ભાગો છોડવા માટે) અથવા Core ML એન્કોડર (જે સમર્થિત ડિવાઇસ પર પ્રોસેસિંગ ઝડપી કરી શકે છે) ડાઉનલોડ કરી શકો છો.

મોડેલ ડાઉનલોડ થયા પછી, તે મોડેલથી ટ્રાન્સક્રિપ્શન સામાન્ય રીતે ઇન્ટરનેટ કનેક્શન વગર ચાલી શકે છે.

વધુ સારા પરિણામો માટે ટિપ્સ

  • જો ઓટો-ડિટેક્શન ખોટી ભાષા પસંદ કરે તો Settings માં ભાષા સેટ કરો.
  • જો શબ્દો વારંવાર છૂટી જતા હોય તો મોટું મોડેલ અજમાવો (Small, Medium અથવા Large v3 Turbo).
  • વારંવાર આવતા નામો, પ્રોડક્ટ નામો અથવા તકનીકી શબ્દો માટે શબ્દભંડોળ સંકેતો ઉમેરો.
  • ઘોંઘાટવાળા રેકોર્ડિંગ્સ માટે ઓડિયો ક્લીનઅપ અને લાંબા વિરામ વાળા રેકોર્ડિંગ્સ માટે Skip Silent Sections ચાલુ કરો.
  • માઇક્રોફોનને બોલનાર વ્યક્તિની નજીક રાખો અને શક્ય હોય ત્યાં સુધી બેકગ્રાઉન્ડ ઘોંઘાટ ઓછો રાખો.

સમસ્યા નિવારણ

મોડેલ ડાઉનલોડ નિષ્ફળ જાય છે અથવા અટકી જાય છે

તમારું નેટવર્ક કનેક્શન તપાસો અને મોડેલ માટે પૂરતું ખાલી સ્ટોરેજ છે તેની ખાતરી કરો. તમે ફરી પ્રયાસ કરી શકો છો અથવા Settings → Model & Downloads માંથી અલગ મોડેલ પસંદ કરી શકો છો. ધીમા કનેક્શન પર મોટા મોડેલ્સને સમય લાગી શકે છે.

માઇક્રોફોન કામ કરતો નથી

iOS Settings એપ → Privacy & Security → Microphone ખોલો અને ખાતરી કરો કે એપને પરવાનગી આપેલી છે. જો બીજી કોઈ એપ માઇક્રોફોન વાપરી રહી હોય, તો તેને બંધ કરીને ફરી પ્રયાસ કરો. તમે માઇક્રોફોન સ્વિચરથી અલગ ઇનપુટ પણ પસંદ કરી શકો છો.

ટ્રાન્સક્રિપ્શન ધીમું છે, અથવા એપની મેમરી પૂરી થઈ જાય છે

નાનું મોડેલ (Tiny, Base અથવા Q5 વેરિઅન્ટ) અજમાવો અને એડવાન્સ્ડ સેટિંગ્સમાં Flash Attention ચાલુ કરો. ખૂબ લાંબી ફાઇલોને વધુ મેમરી અને સમય લાગે છે; લાંબા રેકોર્ડિંગને નાના ભાગોમાં વહેંચવાથી મદદ મળી શકે છે.

પરિણામ ખોટી ભાષામાં આવે છે અથવા વિચિત્ર ટેક્સ્ટ દેખાય છે

Auto-Detect ને બદલે Settings માં બોલાયેલી ભાષા પસંદ કરો. જો તમને અંગ્રેજી અનુવાદ ન જોઈતો હોય, તો "Translate to English" બંધ છે તેની ખાતરી કરો. લાંબી શાંતિ ક્યારેક પુનરાવર્તિત શબ્દસમૂહો બનાવી શકે છે; Skip Silent Sections ચાલુ કરવાથી તે ઘટી શકે છે.

Live Transcribe અથવા Apple નું સ્પીચ એન્જિન ઉપલબ્ધ નથી

આ સુવિધાઓ માટે iOS 26 કે ત્યારબાદનું વર્ઝન જરૂરી છે, અને તમારી ભાષા માટેનું ભાષા મોડેલ પહેલા તૈયાર કરવું પડી શકે છે. iOS સ્પીચ મોડેલ્સ મેનેજ કરવા માટે એપમાં Settings ખોલો.

Apple Intelligence ચેટ ઉપલબ્ધ નથી

ચેટ માટે Apple Intelligence ને સપોર્ટ કરતા ડિવાઇસ પર iOS 26 કે ત્યારબાદનું વર્ઝન જરૂરી છે, અને iOS Settings એપમાં Apple Intelligence ચાલુ હોવું જોઈએ. ઉપલબ્ધતા પ્રદેશ અને ભાષા પર પણ આધારિત હોઈ શકે છે.

ઇમ્પોર્ટ કરેલી વિડિયો કે ઓડિયો ફાઇલ ટ્રાન્સક્રાઇબ થઈ શકતી નથી

કેટલીક ફાઇલો એવા ફોર્મેટ કે સુરક્ષાનો ઉપયોગ કરી શકે છે જેને iOS વાંચી શકતું નથી. ફાઇલને M4A, MP3, WAV, MP4 અથવા MOV તરીકે ફરીથી એક્સપોર્ટ કરવાનો પ્રયાસ કરો, અથવા તપાસો કે ફાઇલ Files એપમાં ચાલે છે કે નહીં.

સ્ટોરેજ અને ડેટા મેનેજમેન્ટ

  • ટ્રાન્સક્રિપ્ટ્સ અને રેકોર્ડિંગ્સ: History માંથી અલગ-અલગ આઇટમ્સ ડિલીટ કરો.
  • ટૅગ્સ: Manage Tags માંથી નામ બદલો, મર્જ કરો અથવા ડિલીટ કરો.
  • મોડેલ્સ: જગ્યા ખાલી કરવા માટે Settings માં ડાઉનલોડ કરેલા મોડેલ્સ ડિલીટ કરો.
  • બધું જ: એપ ડિલીટ કરવાથી તેનો ડેટા ડિવાઇસમાંથી દૂર થઈ જાય છે.

સંપર્ક

બગ રિપોર્ટ્સ, પ્રશ્નો અથવા સુવિધાની વિનંતીઓ માટે કૃપા કરીને GitHub પર એક ઇશ્યૂ ખોલો. GitHub એકાઉન્ટ જરૂરી છે.

GitHub પર ઇશ્યૂ ખોલો

ઇશ્યૂઝ સાર્વજનિક હોય છે. કૃપા કરીને વ્યક્તિગત માહિતી, ખાનગી રેકોર્ડિંગ્સ કે ટ્રાન્સક્રિપ્ટ્સ સામેલ ન કરો. જો મદદરૂપ થાય, તો Settings → Diagnostics → Share Logs માંથી લોગ્સ જોડી શકો છો, પરંતુ પહેલા તેમની સામગ્રી તપાસી લો.
