帮助与支持

适用于 iPhone 和 iPad 的 Whisper 离线语音转文字：设置步骤、使用技巧与常见问题解答。

系统要求

  • iPhone 或 iPad 上运行 iOS / iPadOS 17.0 或更高版本。
  • 使用实时转写、Apple 的设备端语音引擎和设备端 Apple Intelligence 对话需要 iOS 26 或更高版本（需设备支持）。
  • 使用可选的私有云计算模式需要 iOS 27 或更高版本。
  • 下载模型需要网络连接和可用存储空间（视模型不同，约 15 MB 到 1.5 GB）。
  • 录音需要麦克风权限。

首次设置

  1. 打开 App，会出现模型下载界面。
  2. 下载一个 Whisper 模型。Base（约 142 MB）是默认选项，也是比较合适的起点。
  3. 下载完成后，轻点录音按钮，或选择“选择文件” / “从照片选择视频”开始使用。
  4. 可选：在“设置”中，你还可以下载 VAD 模型（用于跳过静音片段）或 Core ML 编码器（在支持的设备上可能加快处理速度）。

模型下载完成后，使用该模型进行转写通常无需网络连接。

获得更好结果的技巧

  • 如果自动检测选错了语言，请在“设置”中手动指定语言。
  • 如果经常漏词，请试试更大的模型（Small、Medium 或 Large v3 Turbo）。
  • 为经常出现的人名、产品名或专业术语添加词汇提示。
  • 录音噪音较大时开启音频清理；录音中有长时间停顿时开启“跳过静音片段”。
  • 尽量让麦克风靠近说话者，并在条件允许时减少背景噪音。

故障排查

模型下载失败或中断

请检查网络连接，并确认有足够的可用存储空间放下该模型。你可以重试，或在“设置”→“模型与下载”中选择其他模型。网络较慢时，大模型可能需要较长时间。

麦克风无法使用

打开 iOS 的“设置”App →“隐私与安全性”→“麦克风”，确认已允许本 App 使用。如果其他 App 正在占用麦克风，请先关闭它再重试。你也可以用麦克风切换器选择其他输入设备。

转写速度很慢，或 App 提示内存不足

可以试试较小的模型（Tiny、Base 或 Q5 变体），并在高级设置中开启 Flash Attention。超长文件需要更多内存和时间，把长录音拆分成几段可能会更顺利。

结果语言不对，或出现了奇怪的文字

请在“设置”中选择实际说的语言，而不是使用自动检测。除非你需要英文译文，否则请确认“翻译为英文”已关闭。长时间的静音有时会导致重复语句，开启“跳过静音片段”可能会减少这种情况。

实时转写或 Apple 的语音引擎不可用

这些功能需要 iOS 26 或更高版本，并且可能需要先准备对应语言的语音模型。你可以打开 App 内的“设置”管理 iOS 语音模型。

Apple Intelligence 对话不可用

对话功能需要在支持 Apple Intelligence 的设备上运行 iOS 26 或更高版本，并在 iOS 的“设置”App 中开启 Apple Intelligence。可用性也可能因地区和语言而异。

导入的视频或音频文件无法转写

部分文件使用的格式或保护机制可能无法被 iOS 读取。可以尝试将文件重新导出为 M4A、MP3、WAV、MP4 或 MOV，或确认该文件能在“文件”App 中播放。

管理存储空间与数据

  • 转写文本和录音：在“历史记录”中删除单条项目。
  • 标签：在“管理标签”中重命名、合并或删除。
  • 模型：在“设置”中删除已下载的模型以释放空间。
  • 全部数据：删除 App 即可从设备上移除其数据。

联系方式

如需报告问题、提问或提出功能建议，请在 GitHub 上提交 Issue。你需要一个 GitHub 账户。

在 GitHub 上提交 Issue

Issue 是公开的，请不要包含个人信息、私人录音或转写文本。如果有帮助，你可以在确认内容后，附上来自“设置”→“诊断”→“分享日志”的日志。
