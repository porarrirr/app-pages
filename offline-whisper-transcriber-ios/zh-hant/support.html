說明與支援

iPhone 與 iPad 版 Whisper 離線語音轉文字的設定步驟、使用技巧，以及常見問題的解答。

系統需求

  • iPhone 或 iPad，需搭載 iOS / iPadOS 17.0 或以上版本。
  • iOS 26 或以上版本才能使用即時轉寫、Apple 的裝置端語音引擎，以及在支援裝置上的裝置端 Apple Intelligence 對話。
  • 選用的 Private Cloud Compute 模式需要 iOS 27 或以上版本。
  • 下載模型需要網路連線與可用儲存空間（依模型不同，約 15 MB 到 1.5 GB）。
  • 錄音需要麥克風權限。

初次設定

  1. 開啟 App，會出現模型下載畫面。
  2. 下載一個 Whisper 模型。Base（約 142 MB）是預設模型，也是合理的起點。
  3. 下載完成後，點一下錄音按鈕，或選擇選擇檔案 / 從「照片」選擇影片即可開始。
  4. 選用：在「設定」中可以下載 VAD 模型（用來略過靜音片段），或 Core ML 編碼器（在支援的裝置上可能加快處理速度）。

下載模型後，使用該模型進行轉寫時，通常不需要網路連線。

提升結果品質的技巧

  • 如果自動偵測選錯語言，請在「設定」中指定語言。
  • 如果經常漏字，可以試試較大的模型（Small、Medium 或 Large v3 Turbo）。
  • 針對經常出現的人名、產品名稱或技術術語，加入詞彙提示。
  • 錄音環境吵雜時，開啟音訊清理；錄音中有長時間停頓時，開啟略過靜音片段。
  • 盡量讓麥克風靠近說話者，並減少背景噪音。

疑難排解

模型下載失敗或中斷

請檢查網路連線，並確認有足夠的可用儲存空間容納該模型。你可以在「設定」→「模型與下載」中重試或改選其他模型。大型模型在較慢的網路上可能需要一些時間。

麥克風沒有作用

開啟 iOS 的「設定」App →「隱私權與安全性」→「麥克風」，確認已允許此 App 使用麥克風。如果有其他 App 正在使用麥克風，請先關閉再試一次。你也可以用麥克風切換器選擇其他輸入裝置。

轉寫速度很慢，或 App 記憶體不足

可以改用較小的模型（Tiny、Base 或 Q5 版本），並在進階設定中開啟 Flash Attention。非常長的檔案需要更多記憶體與時間；將長錄音分成幾段處理可能會有幫助。

結果語言錯誤，或出現奇怪的文字

在「設定」中直接指定說話語言，不要使用自動偵測。除非你想要英文翻譯，否則請確認「翻譯為英文」已關閉。長時間的靜音有時會產生重複的句子；開啟「略過靜音片段」可能可以改善。

即時轉寫或 Apple 的語音引擎無法使用

這些功能需要 iOS 26 或以上版本，而且可能需要先準備你所使用語言的語言模型。請在 App 的「設定」中管理 iOS 語音模型。

Apple Intelligence 對話無法使用

對話功能需要 iOS 26 或以上版本，且裝置需支援 Apple Intelligence，並已在 iOS 的「設定」App 中開啟 Apple Intelligence。可用性也可能因地區與語言而異。

匯入的影片或音訊檔無法轉寫

有些檔案的格式或保護機制是 iOS 無法讀取的。可以試著將檔案重新匯出成 M4A、MP3、WAV、MP4 或 MOV，或確認該檔案能在「檔案」App 中播放。

管理儲存空間與資料

  • 逐字稿與錄音：在歷史記錄中刪除個別項目。
  • 標籤：在「管理標籤」中重新命名、合併或刪除。
  • 模型：在「設定」中刪除已下載的模型，以釋放空間。
  • 全部資料：刪除 App 就會將其資料從裝置上移除。

聯絡方式

如要回報問題、提出疑問或功能建議，請在 GitHub 上建立 issue。需要 GitHub 帳號。

在 GitHub 建立 issue

GitHub 上的 issue 是公開的。請勿包含個人資訊、私人錄音或逐字稿。如有助於排查，你可以在確認內容後，附上從「設定」→「診斷」→「分享記錄」取得的記錄檔。
