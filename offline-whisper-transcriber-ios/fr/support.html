Aide et assistance

Étapes de configuration, conseils et réponses aux problèmes courants avec Whisper: Transcription vocale pour iPhone et iPad.

Prérequis

  • iOS / iPadOS 17.0 ou version ultérieure sur iPhone ou iPad.
  • iOS 26 ou version ultérieure pour Transcription en direct, le moteur vocal d’Apple sur l’appareil et la conversation Apple Intelligence sur l’appareil (sur les appareils compatibles).
  • iOS 27 ou version ultérieure pour le mode facultatif Private Cloud Compute.
  • Une connexion Internet et de l’espace de stockage libre pour télécharger un modèle (d’environ 15 MB à 1,5 GB selon le modèle).
  • L’autorisation d’accès au microphone pour l’enregistrement.

Première configuration

  1. Ouvrez l’app. Un écran de téléchargement de modèle s’affiche.
  2. Téléchargez un modèle Whisper. Base (environ 142 MB) est le modèle par défaut et un bon point de départ.
  3. Une fois le téléchargement terminé, touchez le bouton d’enregistrement ou choisissez Sélectionner un fichier / Sélectionner une vidéo dans Photos pour commencer.
  4. Facultatif : dans Réglages, vous pouvez télécharger le modèle VAD (pour ignorer les passages silencieux) ou un encodeur Core ML (qui peut accélérer le traitement sur les appareils compatibles).

Une fois un modèle téléchargé, la transcription avec ce modèle peut généralement fonctionner sans connexion Internet.

Conseils pour de meilleurs résultats

  • Définissez la langue dans Réglages si la détection automatique choisit la mauvaise.
  • Essayez un modèle plus grand (Small, Medium ou Large v3 Turbo) si des mots sont souvent manqués.
  • Ajoutez des indices de vocabulaire pour les noms, les noms de produits ou les termes techniques qui reviennent souvent.
  • Activez le nettoyage audio pour les enregistrements bruyants, et Ignorer les passages silencieux pour les enregistrements comportant de longues pauses.
  • Gardez le microphone près de la personne qui parle et réduisez le bruit ambiant lorsque c’est possible.

Dépannage

Le téléchargement du modèle échoue ou s’arrête

Vérifiez votre connexion réseau et assurez-vous que l’espace de stockage libre est suffisant pour le modèle. Vous pouvez réessayer ou choisir un autre modèle dans Réglages → Modèle et téléchargements. Les grands modèles peuvent prendre du temps sur une connexion lente.

Le microphone ne fonctionne pas

Ouvrez l’app Réglages d’iOS → Confidentialité et sécurité → Microphone et vérifiez que l’app est autorisée. Si une autre app utilise le microphone, fermez-la et réessayez. Vous pouvez aussi choisir une autre entrée avec le sélecteur de microphone.

La transcription est lente ou l’app manque de mémoire

Essayez un modèle plus petit (Tiny, Base ou une variante Q5) et activez Flash Attention dans les réglages avancés. Les fichiers très longs demandent plus de mémoire et de temps ; diviser un long enregistrement en parties plus courtes peut aider.

Le résultat est dans la mauvaise langue ou contient un texte étrange

Choisissez la langue parlée dans Réglages plutôt que la Détection automatique. Vérifiez que « Traduire en anglais » est désactivé, sauf si vous voulez une traduction en anglais. Les longs silences peuvent parfois produire des phrases répétées ; activer Ignorer les passages silencieux peut réduire ce phénomène.

Transcription en direct ou le moteur vocal d’Apple n’est pas disponible

Ces fonctionnalités nécessitent iOS 26 ou version ultérieure, et le modèle de langue correspondant à votre langue peut devoir être préparé au préalable. Ouvrez Réglages dans l’app pour gérer les modèles vocaux d’iOS.

La conversation Apple Intelligence n’est pas disponible

La conversation nécessite iOS 26 ou version ultérieure sur un appareil compatible avec Apple Intelligence, avec Apple Intelligence activé dans l’app Réglages d’iOS. La disponibilité peut aussi dépendre de la région et de la langue.

Un fichier vidéo ou audio importé ne peut pas être transcrit

Certains fichiers peuvent utiliser des formats ou une protection que iOS ne sait pas lire. Essayez de réexporter le fichier en M4A, MP3, WAV, MP4 ou MOV, ou vérifiez que le fichier s’ouvre dans l’app Fichiers.

Gestion du stockage et des données

  • Transcriptions et enregistrements : supprimez les éléments un par un depuis l’historique.
  • Tags : renommez-les, fusionnez-les ou supprimez-les depuis Gérer les tags.
  • Modèles : supprimez les modèles téléchargés dans Réglages pour libérer de l’espace.
  • Tout : supprimer l’app efface ses données de l’appareil.

Contact

Pour signaler un bug, poser une question ou proposer une fonctionnalité, ouvrez un ticket sur GitHub. Un compte GitHub est nécessaire.

Ouvrir un ticket sur GitHub

Les tickets sont publics. N’y joignez pas d’informations personnelles, d’enregistrements privés ni de transcriptions. Si cela peut aider, vous pouvez joindre les journaux depuis Réglages → Diagnostics → Partager les journaux, après en avoir vérifié le contenu.
