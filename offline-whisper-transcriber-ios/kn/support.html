ಸಹಾಯ ಮತ್ತು ಬೆಂಬಲ

iPhone ಮತ್ತು iPad ಗಾಗಿ Whisper: Offline Transcription ಕುರಿತ ಸೆಟಪ್ ಹಂತಗಳು, ಸಲಹೆಗಳು ಮತ್ತು ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳಿಗೆ ಉತ್ತರಗಳು.

ಈ ಪುಟದಲ್ಲಿ
  1. ಅಗತ್ಯತೆಗಳು
  2. ಮೊದಲ ಬಾರಿಯ ಸೆಟಪ್
  3. ಉತ್ತಮ ಫಲಿತಾಂಶಗಳಿಗಾಗಿ ಸಲಹೆಗಳು
  4. ಸಮಸ್ಯೆ ಪರಿಹಾರ
  5. ಸಂಗ್ರಹಣೆ ಮತ್ತು ಡೇಟಾ ನಿರ್ವಹಣೆ
  6. ಸಂಪರ್ಕ

ಅಗತ್ಯತೆಗಳು

  • iPhone ಅಥವಾ iPad ನಲ್ಲಿ iOS / iPadOS 17.0 ಅಥವಾ ನಂತರದ ಆವೃತ್ತಿ.
  • Live Transcribe, Apple ನ ಸಾಧನದಲ್ಲೇ ಇರುವ ಸ್ಪೀಚ್ ಎಂಜಿನ್ ಮತ್ತು ಸಾಧನದಲ್ಲೇ Apple Intelligence ಚಾಟ್‌ಗಾಗಿ iOS 26 ಅಥವಾ ನಂತರದ ಆವೃತ್ತಿ (ಬೆಂಬಲಿತ ಸಾಧನಗಳಲ್ಲಿ).
  • ಐಚ್ಛಿಕ Private Cloud Compute ಮೋಡ್‌ಗಾಗಿ iOS 27 ಅಥವಾ ನಂತರದ ಆವೃತ್ತಿ.
  • ಮಾದರಿಯನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡಲು ಇಂಟರ್ನೆಟ್ ಸಂಪರ್ಕ ಮತ್ತು ಖಾಲಿ ಸಂಗ್ರಹಣೆ (ಮಾದರಿಯನ್ನು ಅವಲಂಬಿಸಿ ಸುಮಾರು 15 MB ಯಿಂದ 1.5 GB).
  • ರೆಕಾರ್ಡಿಂಗ್‌ಗಾಗಿ ಮೈಕ್ರೊಫೋನ್ ಅನುಮತಿ.

ಮೊದಲ ಬಾರಿಯ ಸೆಟಪ್

  1. ಆ್ಯಪ್ ತೆರೆಯಿರಿ. ಮಾದರಿ ಡೌನ್‌ಲೋಡ್ ಪರದೆ ಕಾಣಿಸುತ್ತದೆ.
  2. Whisper ಮಾದರಿಯನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ. Base (ಸುಮಾರು 142 MB) ಡೀಫಾಲ್ಟ್ ಆಗಿದ್ದು, ಪ್ರಾರಂಭಿಸಲು ಸೂಕ್ತವಾದ ಆಯ್ಕೆಯಾಗಿದೆ.
  3. ಡೌನ್‌ಲೋಡ್ ಪೂರ್ಣಗೊಂಡಾಗ, ಪ್ರಾರಂಭಿಸಲು ರೆಕಾರ್ಡ್ ಬಟನ್ ಟ್ಯಾಪ್ ಮಾಡಿ ಅಥವಾ Select File / Select Video from Photos ಆಯ್ಕೆಮಾಡಿ.
  4. ಐಚ್ಛಿಕ: Settings ನಲ್ಲಿ ನೀವು VAD ಮಾದರಿಯನ್ನು (ಮೌನ ವಿಭಾಗಗಳನ್ನು ಬಿಟ್ಟುಬಿಡಲು) ಅಥವಾ Core ML ಎನ್‌ಕೋಡರ್ ಅನ್ನು (ಬೆಂಬಲಿತ ಸಾಧನಗಳಲ್ಲಿ ಪ್ರಕ್ರಿಯೆಯನ್ನು ವೇಗಗೊಳಿಸಬಹುದು) ಡೌನ್‌ಲೋಡ್ ಮಾಡಬಹುದು.

ಮಾದರಿಯನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡಿದ ನಂತರ, ಆ ಮಾದರಿಯೊಂದಿಗೆ ಟ್ರಾನ್ಸ್‌ಕ್ರಿಪ್ಷನ್ ಸಾಮಾನ್ಯವಾಗಿ ಇಂಟರ್ನೆಟ್ ಸಂಪರ್ಕವಿಲ್ಲದೆಯೂ ನಡೆಯುತ್ತದೆ.

ಉತ್ತಮ ಫಲಿತಾಂಶಗಳಿಗಾಗಿ ಸಲಹೆಗಳು

  • ಸ್ವಯಂ-ಗುರುತಿಸುವಿಕೆ ತಪ್ಪಾದ ಭಾಷೆಯನ್ನು ಆರಿಸಿದರೆ Settings ನಲ್ಲಿ ಭಾಷೆಯನ್ನು ಹೊಂದಿಸಿ.
  • ಪದಗಳು ಆಗಾಗ್ಗೆ ಬಿಟ್ಟುಹೋಗುತ್ತಿದ್ದರೆ ದೊಡ್ಡ ಮಾದರಿಯನ್ನು ಪ್ರಯತ್ನಿಸಿ (Small, Medium ಅಥವಾ Large v3 Turbo).
  • ಆಗಾಗ್ಗೆ ಬರುವ ಹೆಸರುಗಳು, ಉತ್ಪನ್ನದ ಹೆಸರುಗಳು ಅಥವಾ ತಾಂತ್ರಿಕ ಪದಗಳಿಗಾಗಿ ಶಬ್ದಕೋಶ ಸುಳಿವುಗಳನ್ನು ಸೇರಿಸಿ.
  • ಶಬ್ದವಿರುವ ರೆಕಾರ್ಡಿಂಗ್‌ಗಳಿಗಾಗಿ ಆಡಿಯೊ ಸ್ವಚ್ಛಗೊಳಿಸುವಿಕೆಯನ್ನು ಆನ್ ಮಾಡಿ, ಮತ್ತು ದೀರ್ಘ ವಿರಾಮಗಳಿರುವ ರೆಕಾರ್ಡಿಂಗ್‌ಗಳಿಗಾಗಿ Skip Silent Sections ಆನ್ ಮಾಡಿ.
  • ಮೈಕ್ರೊಫೋನ್ ಅನ್ನು ಮಾತನಾಡುವವರಿಗೆ ಹತ್ತಿರದಲ್ಲಿ ಇರಿಸಿ ಮತ್ತು ಸಾಧ್ಯವಾದಷ್ಟು ಹಿನ್ನೆಲೆ ಶಬ್ದವನ್ನು ಕಡಿಮೆ ಮಾಡಿ.

ಸಮಸ್ಯೆ ಪರಿಹಾರ

ಮಾದರಿ ಡೌನ್‌ಲೋಡ್ ವಿಫಲವಾಗುತ್ತದೆ ಅಥವಾ ನಿಲ್ಲುತ್ತದೆ

ನಿಮ್ಮ ನೆಟ್‌ವರ್ಕ್ ಸಂಪರ್ಕವನ್ನು ಪರಿಶೀಲಿಸಿ ಮತ್ತು ಮಾದರಿಗಾಗಿ ಸಾಕಷ್ಟು ಖಾಲಿ ಸಂಗ್ರಹಣೆ ಇದೆ ಎಂದು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ. ನೀವು ಮತ್ತೆ ಪ್ರಯತ್ನಿಸಬಹುದು ಅಥವಾ Settings → Model & Downloads ನಿಂದ ಬೇರೆ ಮಾದರಿಯನ್ನು ಆಯ್ಕೆಮಾಡಬಹುದು. ನಿಧಾನವಾದ ಸಂಪರ್ಕಗಳಲ್ಲಿ ದೊಡ್ಡ ಮಾದರಿಗಳಿಗೆ ಸ್ವಲ್ಪ ಸಮಯ ತೆಗೆದುಕೊಳ್ಳಬಹುದು.

ಮೈಕ್ರೊಫೋನ್ ಕೆಲಸ ಮಾಡುತ್ತಿಲ್ಲ

iOS Settings ಆ್ಯಪ್ → Privacy & Security → Microphone ತೆರೆಯಿರಿ ಮತ್ತು ಆ್ಯಪ್‌ಗೆ ಅನುಮತಿ ಇದೆ ಎಂದು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ. ಬೇರೆ ಆ್ಯಪ್ ಮೈಕ್ರೊಫೋನ್ ಬಳಸುತ್ತಿದ್ದರೆ, ಅದನ್ನು ಮುಚ್ಚಿ ಮತ್ತೆ ಪ್ರಯತ್ನಿಸಿ. ಮೈಕ್ರೊಫೋನ್ ಸ್ವಿಚರ್ ಮೂಲಕ ನೀವು ಬೇರೆ ಇನ್‌ಪುಟ್ ಅನ್ನೂ ಆಯ್ಕೆಮಾಡಬಹುದು.

ಟ್ರಾನ್ಸ್‌ಕ್ರಿಪ್ಷನ್ ನಿಧಾನವಾಗಿದೆ, ಅಥವಾ ಆ್ಯಪ್‌ನ ಮೆಮೊರಿ ಮುಗಿಯುತ್ತದೆ

ಚಿಕ್ಕ ಮಾದರಿಯನ್ನು (Tiny, Base ಅಥವಾ Q5 ರೂಪಾಂತರ) ಪ್ರಯತ್ನಿಸಿ ಮತ್ತು ಸುಧಾರಿತ ಸೆಟ್ಟಿಂಗ್‌ಗಳಲ್ಲಿ Flash Attention ಆನ್ ಮಾಡಿ. ಬಹಳ ಉದ್ದದ ಫೈಲ್‌ಗಳಿಗೆ ಹೆಚ್ಚು ಮೆಮೊರಿ ಮತ್ತು ಸಮಯ ಬೇಕಾಗುತ್ತದೆ; ಉದ್ದದ ರೆಕಾರ್ಡಿಂಗ್ ಅನ್ನು ಚಿಕ್ಕ ಭಾಗಗಳಾಗಿ ವಿಭಜಿಸುವುದು ಸಹಾಯ ಮಾಡಬಹುದು.

ಫಲಿತಾಂಶ ತಪ್ಪು ಭಾಷೆಯಲ್ಲಿದೆ ಅಥವಾ ವಿಚಿತ್ರ ಪಠ್ಯವನ್ನು ಹೊಂದಿದೆ

Auto-Detect ಬದಲಿಗೆ Settings ನಲ್ಲಿ ಮಾತನಾಡಿದ ಭಾಷೆಯನ್ನು ಆಯ್ಕೆಮಾಡಿ. ನಿಮಗೆ ಇಂಗ್ಲಿಷ್ ಅನುವಾದ ಬೇಡದಿದ್ದರೆ "Translate to English" ಆಫ್ ಆಗಿದೆ ಎಂದು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ. ದೀರ್ಘ ಮೌನಗಳು ಕೆಲವೊಮ್ಮೆ ಪುನರಾವರ್ತಿತ ಪದಗುಚ್ಛಗಳನ್ನು ಉಂಟುಮಾಡಬಹುದು; Skip Silent Sections ಆನ್ ಮಾಡುವುದರಿಂದ ಇದನ್ನು ಕಡಿಮೆ ಮಾಡಬಹುದು.

Live Transcribe ಅಥವಾ Apple ನ ಸ್ಪೀಚ್ ಎಂಜಿನ್ ಲಭ್ಯವಿಲ್ಲ

ಈ ವೈಶಿಷ್ಟ್ಯಗಳಿಗೆ iOS 26 ಅಥವಾ ನಂತರದ ಆವೃತ್ತಿ ಅಗತ್ಯವಿದೆ, ಮತ್ತು ನಿಮ್ಮ ಭಾಷೆಯ ಭಾಷಾ ಮಾದರಿಯನ್ನು ಮೊದಲು ಸಿದ್ಧಪಡಿಸಬೇಕಾಗಬಹುದು. iOS ಸ್ಪೀಚ್ ಮಾದರಿಗಳನ್ನು ನಿರ್ವಹಿಸಲು ಆ್ಯಪ್‌ನಲ್ಲಿ Settings ತೆರೆಯಿರಿ.

Apple Intelligence ಚಾಟ್ ಲಭ್ಯವಿಲ್ಲ

ಚಾಟ್‌ಗೆ Apple Intelligence ಬೆಂಬಲಿಸುವ ಸಾಧನದಲ್ಲಿ iOS 26 ಅಥವಾ ನಂತರದ ಆವೃತ್ತಿ ಅಗತ್ಯವಿದೆ, ಮತ್ತು iOS Settings ಆ್ಯಪ್‌ನಲ್ಲಿ Apple Intelligence ಆನ್ ಆಗಿರಬೇಕು. ಲಭ್ಯತೆಯು ಪ್ರದೇಶ ಮತ್ತು ಭಾಷೆಯ ಮೇಲೂ ಅವಲಂಬಿತವಾಗಿರಬಹುದು.

ಆಮದು ಮಾಡಿದ ವೀಡಿಯೊ ಅಥವಾ ಆಡಿಯೊ ಫೈಲ್ ಅನ್ನು ಟ್ರಾನ್ಸ್‌ಕ್ರೈಬ್ ಮಾಡಲು ಸಾಧ್ಯವಾಗುತ್ತಿಲ್ಲ

ಕೆಲವು ಫೈಲ್‌ಗಳು iOS ಓದಲಾಗದ ಫಾರ್ಮ್ಯಾಟ್‌ಗಳು ಅಥವಾ ರಕ್ಷಣೆಯನ್ನು ಬಳಸಬಹುದು. ಫೈಲ್ ಅನ್ನು M4A, MP3, WAV, MP4 ಅಥವಾ MOV ಆಗಿ ಮತ್ತೆ ರಫ್ತು ಮಾಡಲು ಪ್ರಯತ್ನಿಸಿ, ಅಥವಾ Files ಆ್ಯಪ್‌ನಲ್ಲಿ ಫೈಲ್ ಪ್ಲೇ ಆಗುತ್ತದೆಯೇ ಎಂದು ಪರಿಶೀಲಿಸಿ.

ಸಂಗ್ರಹಣೆ ಮತ್ತು ಡೇಟಾ ನಿರ್ವಹಣೆ

  • ಟ್ರಾನ್ಸ್‌ಕ್ರಿಪ್ಟ್‌ಗಳು ಮತ್ತು ರೆಕಾರ್ಡಿಂಗ್‌ಗಳು: History ನಿಂದ ಪ್ರತ್ಯೇಕ ಅಂಶಗಳನ್ನು ಅಳಿಸಿ.
  • ಟ್ಯಾಗ್‌ಗಳು: Manage Tags ನಿಂದ ಮರುಹೆಸರಿಸಿ, ವಿಲೀನಗೊಳಿಸಿ ಅಥವಾ ಅಳಿಸಿ.
  • ಮಾದರಿಗಳು: ಜಾಗವನ್ನು ಮುಕ್ತಗೊಳಿಸಲು Settings ನಲ್ಲಿ ಡೌನ್‌ಲೋಡ್ ಮಾಡಿದ ಮಾದರಿಗಳನ್ನು ಅಳಿಸಿ.
  • ಎಲ್ಲವೂ: ಆ್ಯಪ್ ಅನ್ನು ಅಳಿಸುವುದರಿಂದ ಅದರ ಡೇಟಾ ಸಾಧನದಿಂದ ತೆಗೆದುಹಾಕಲ್ಪಡುತ್ತದೆ.

ಸಂಪರ್ಕ

ಬಗ್ ವರದಿಗಳು, ಪ್ರಶ್ನೆಗಳು ಅಥವಾ ವೈಶಿಷ್ಟ್ಯ ವಿನಂತಿಗಳಿಗಾಗಿ, ದಯವಿಟ್ಟು GitHub ನಲ್ಲಿ ಇಶ್ಯೂ ತೆರೆಯಿರಿ. GitHub ಖಾತೆ ಅಗತ್ಯವಿದೆ.

GitHub ನಲ್ಲಿ ಇಶ್ಯೂ ತೆರೆಯಿರಿ

ಇಶ್ಯೂಗಳು ಸಾರ್ವಜನಿಕವಾಗಿರುತ್ತವೆ. ದಯವಿಟ್ಟು ವೈಯಕ್ತಿಕ ಮಾಹಿತಿ, ಖಾಸಗಿ ರೆಕಾರ್ಡಿಂಗ್‌ಗಳು ಅಥವಾ ಟ್ರಾನ್ಸ್‌ಕ್ರಿಪ್ಟ್‌ಗಳನ್ನು ಸೇರಿಸಬೇಡಿ. ಸಹಾಯಕವಾಗಿದ್ದರೆ, Settings → Diagnostics → Share Logs ನಿಂದ ಲಾಗ್‌ಗಳ ವಿಷಯವನ್ನು ಪರಿಶೀಲಿಸಿದ ನಂತರ ಅವುಗಳನ್ನು ಲಗತ್ತಿಸಬಹುದು.
