ସହାୟତା

ସାହାଯ୍ୟ ଓ ସହାୟତା

iPhone ଏବଂ iPad ପାଇଁ Whisper: Offline Transcription ର ସେଟଅପ୍ ପଦକ୍ଷେପ, ଟିପ୍ସ୍ ଏବଂ ସାଧାରଣ ସମସ୍ୟାର ଉତ୍ତର।

ଏହି ପୃଷ୍ଠାରେ
  1. ଆବଶ୍ୟକତା
  2. ପ୍ରଥମ ଥର ସେଟଅପ୍
  3. ଭଲ ଫଳାଫଳ ପାଇଁ ଟିପ୍ସ୍
  4. ସମସ୍ୟା ସମାଧାନ
  5. ଷ୍ଟୋରେଜ୍ ଓ ଡାଟା ପରିଚାଳନା
  6. ଯୋଗାଯୋଗ

ଆବଶ୍ୟକତା

  • iPhone କିମ୍ବା iPad ରେ iOS / iPadOS 17.0 କିମ୍ବା ପରବର୍ତ୍ତୀ ସଂସ୍କରଣ।
  • Live Transcribe, Apple ର ଅନ୍-ଡିଭାଇସ୍ ସ୍ପିଚ୍ ଇଞ୍ଜିନ୍ ଏବଂ ଅନ୍-ଡିଭାଇସ୍ Apple Intelligence ଚାଟ୍ ପାଇଁ iOS 26 କିମ୍ବା ପରବର୍ତ୍ତୀ (ସମର୍ଥିତ ଡିଭାଇସ୍‌ରେ)।
  • ବୈକଳ୍ପିକ Private Cloud Compute ମୋଡ୍ ପାଇଁ iOS 27 କିମ୍ବା ପରବର୍ତ୍ତୀ।
  • ମଡେଲ୍ ଡାଉନଲୋଡ୍ କରିବାକୁ ଇଣ୍ଟରନେଟ୍ ସଂଯୋଗ ଏବଂ ଖାଲି ଷ୍ଟୋରେଜ୍ (ମଡେଲ୍ ଅନୁସାରେ ପ୍ରାୟ 15 MB ରୁ 1.5 GB)।
  • ରେକର୍ଡିଂ ପାଇଁ ମାଇକ୍ରୋଫୋନ୍ ଅନୁମତି।

ପ୍ରଥମ ଥର ସେଟଅପ୍

  1. ଆପ୍ ଖୋଲନ୍ତୁ। ଏକ ମଡେଲ୍ ଡାଉନଲୋଡ୍ ସ୍କ୍ରିନ୍ ଦେଖାଯିବ।
  2. ଏକ Whisper ମଡେଲ୍ ଡାଉନଲୋଡ୍ କରନ୍ତୁ। Base (ପ୍ରାୟ 142 MB) ଡିଫଲ୍ଟ୍ ଏବଂ ଆରମ୍ଭ କରିବା ପାଇଁ ଏକ ଉପଯୁକ୍ତ ବିକଳ୍ପ।
  3. ଡାଉନଲୋଡ୍ ଶେଷ ହେଲେ, ଆରମ୍ଭ କରିବାକୁ ରେକର୍ଡ ବଟନ୍ ଟ୍ୟାପ୍ କରନ୍ତୁ କିମ୍ବା Select File / Select Video from Photos ବାଛନ୍ତୁ।
  4. ବୈକଳ୍ପିକ: Settings ରେ ଆପଣ VAD ମଡେଲ୍ (ନିରବ ଅଂଶ ଛାଡ଼ିବା ପାଇଁ) କିମ୍ବା Core ML ଏନକୋଡର୍ (ଯାହା ସମର୍ଥିତ ଡିଭାଇସ୍‌ରେ ପ୍ରକ୍ରିୟାକରଣକୁ ଦ୍ରୁତ କରିପାରେ) ଡାଉନଲୋଡ୍ କରିପାରିବେ।

ମଡେଲ୍ ଡାଉନଲୋଡ୍ ହେବା ପରେ, ସେହି ମଡେଲ୍ ସହିତ ଟ୍ରାନ୍ସକ୍ରିପ୍ସନ୍ ସାଧାରଣତଃ ଇଣ୍ଟରନେଟ୍ ସଂଯୋଗ ବିନା ଚାଲିପାରେ।

ଭଲ ଫଳାଫଳ ପାଇଁ ଟିପ୍ସ୍

  • ଅଟୋ-ଡିଟେକ୍ସନ୍ ଭୁଲ୍ ଭାଷା ବାଛିଲେ Settings ରେ ଭାଷା ସେଟ୍ କରନ୍ତୁ।
  • ଶବ୍ଦ ବାରମ୍ବାର ଛାଡ଼ିଯାଉଥିଲେ ବଡ଼ ମଡେଲ୍ ଚେଷ୍ଟା କରନ୍ତୁ (Small, Medium କିମ୍ବା Large v3 Turbo)।
  • ବାରମ୍ବାର ଆସୁଥିବା ନାମ, ପ୍ରଡକ୍ଟ ନାମ କିମ୍ବା ବୈଷୟିକ ଶବ୍ଦ ପାଇଁ ଶବ୍ଦକୋଷ ସଙ୍କେତ ଯୋଗ କରନ୍ତୁ।
  • ଶବ୍ଦଯୁକ୍ତ ରେକର୍ଡିଂ ପାଇଁ ଅଡିଓ ସଫା କରିବା ଏବଂ ଦୀର୍ଘ ବିରାମ ଥିବା ରେକର୍ଡିଂ ପାଇଁ Skip Silent Sections ଚାଲୁ କରନ୍ତୁ।
  • ମାଇକ୍ରୋଫୋନ୍‌କୁ ବକ୍ତାଙ୍କ ନିକଟରେ ରଖନ୍ତୁ ଏବଂ ସମ୍ଭବ ହେଲେ ପୃଷ୍ଠଭୂମି ଶବ୍ଦ କମାନ୍ତୁ।

ସମସ୍ୟା ସମାଧାନ

ମଡେଲ୍ ଡାଉନଲୋଡ୍ ବିଫଳ ହୁଏ କିମ୍ବା ଅଟକିଯାଏ

ଆପଣଙ୍କ ନେଟୱାର୍କ ସଂଯୋଗ ଯାଞ୍ଚ କରନ୍ତୁ ଏବଂ ମଡେଲ୍ ପାଇଁ ଯଥେଷ୍ଟ ଖାଲି ଷ୍ଟୋରେଜ୍ ଅଛି କି ନାହିଁ ନିଶ୍ଚିତ କରନ୍ତୁ। ଆପଣ ପୁଣି ଚେଷ୍ଟା କରିପାରିବେ କିମ୍ବା Settings → Model & Downloads ରୁ ଅନ୍ୟ ମଡେଲ୍ ବାଛିପାରିବେ। ଧୀର ସଂଯୋଗରେ ବଡ଼ ମଡେଲ୍ ଡାଉନଲୋଡ୍‌ରେ ସମୟ ଲାଗିପାରେ।

ମାଇକ୍ରୋଫୋନ୍ କାମ କରୁନାହିଁ

iOS Settings ଆପ୍ → Privacy & Security → Microphone ଖୋଲନ୍ତୁ ଏବଂ ଆପ୍‌କୁ ଅନୁମତି ଅଛି କି ନାହିଁ ନିଶ୍ଚିତ କରନ୍ତୁ। ଯଦି ଅନ୍ୟ କୌଣସି ଆପ୍ ମାଇକ୍ରୋଫୋନ୍ ବ୍ୟବହାର କରୁଛି, ତେବେ ତାହାକୁ ବନ୍ଦ କରି ପୁଣି ଚେଷ୍ଟା କରନ୍ତୁ। ମାଇକ୍ରୋଫୋନ୍ ସ୍ୱିଚର୍ ସାହାଯ୍ୟରେ ଆପଣ ଅନ୍ୟ ଇନ୍‌ପୁଟ୍ ମଧ୍ୟ ବାଛିପାରିବେ।

ଟ୍ରାନ୍ସକ୍ରିପ୍ସନ୍ ଧୀର ହେଉଛି, କିମ୍ବା ଆପ୍‌ର ମେମୋରି ସରିଯାଉଛି

ଛୋଟ ମଡେଲ୍ (Tiny, Base କିମ୍ବା Q5 ଭାରିଆଣ୍ଟ୍) ଚେଷ୍ଟା କରନ୍ତୁ ଏବଂ ଆଡଭାନ୍ସଡ୍ ସେଟିଂରେ Flash Attention ଚାଲୁ କରନ୍ତୁ। ବହୁତ ଲମ୍ବା ଫାଇଲ୍‌ରେ ଅଧିକ ମେମୋରି ଓ ସମୟ ଲାଗେ; ଲମ୍ବା ରେକର୍ଡିଂକୁ ଛୋଟ ଅଂଶରେ ଭାଗ କଲେ ସାହାଯ୍ୟ ମିଳିପାରେ।

ଫଳାଫଳ ଭୁଲ୍ ଭାଷାରେ ଆସୁଛି କିମ୍ବା ଅଜବ ଟେକ୍ସଟ୍ ଦେଖାଉଛି

Auto-Detect ବଦଳରେ Settings ରେ କୁହାଯାଇଥିବା ଭାଷା ବାଛନ୍ତୁ। ଆପଣ ଇଂରାଜୀ ଅନୁବାଦ ଚାହୁଁନଥିଲେ "Translate to English" ବନ୍ଦ ଅଛି କି ନାହିଁ ନିଶ୍ଚିତ କରନ୍ତୁ। ଦୀର୍ଘ ନିରବତା କେବେକେବେ ପୁନରାବୃତ୍ତ ବାକ୍ୟାଂଶ ସୃଷ୍ଟି କରିପାରେ; Skip Silent Sections ଚାଲୁ କଲେ ଏହା କମିପାରେ।

Live Transcribe କିମ୍ବା Apple ର ସ୍ପିଚ୍ ଇଞ୍ଜିନ୍ ଉପଲବ୍ଧ ନାହିଁ

ଏହି ବୈଶିଷ୍ଟ୍ୟଗୁଡ଼ିକ ପାଇଁ iOS 26 କିମ୍ବା ପରବର୍ତ୍ତୀ ସଂସ୍କରଣ ଆବଶ୍ୟକ, ଏବଂ ଆପଣଙ୍କ ଭାଷା ପାଇଁ ଭାଷା ମଡେଲ୍ ପ୍ରଥମେ ପ୍ରସ୍ତୁତ କରିବାକୁ ପଡ଼ିପାରେ। iOS ସ୍ପିଚ୍ ମଡେଲ୍ ପରିଚାଳନା କରିବାକୁ ଆପ୍‌ରେ Settings ଖୋଲନ୍ତୁ।

Apple Intelligence ଚାଟ୍ ଉପଲବ୍ଧ ନାହିଁ

ଚାଟ୍ ପାଇଁ Apple Intelligence ସମର୍ଥନ କରୁଥିବା ଡିଭାଇସ୍‌ରେ iOS 26 କିମ୍ବା ପରବର୍ତ୍ତୀ ସଂସ୍କରଣ ଆବଶ୍ୟକ, ଏବଂ iOS Settings ଆପ୍‌ରେ Apple Intelligence ଚାଲୁ ଥିବା ଦରକାର। ଉପଲବ୍ଧତା ଅଞ୍ଚଳ ଏବଂ ଭାଷା ଉପରେ ମଧ୍ୟ ନିର୍ଭର କରିପାରେ।

ଇମ୍ପୋର୍ଟ କରାଯାଇଥିବା ଭିଡିଓ କିମ୍ବା ଅଡିଓ ଫାଇଲ୍ ଟ୍ରାନ୍ସକ୍ରାଇବ୍ ହେଉନାହିଁ

କିଛି ଫାଇଲ୍ ଏପରି ଫର୍ମାଟ୍ କିମ୍ବା ସୁରକ୍ଷା ବ୍ୟବହାର କରିପାରେ ଯାହା iOS ପଢ଼ିପାରିବ ନାହିଁ। ଫାଇଲ୍‌କୁ M4A, MP3, WAV, MP4 କିମ୍ବା MOV ଭାବେ ପୁଣି ଏକ୍ସପୋର୍ଟ କରି ଚେଷ୍ଟା କରନ୍ତୁ, କିମ୍ବା Files ଆପ୍‌ରେ ଫାଇଲ୍ ଚାଲୁଛି କି ନାହିଁ ଯାଞ୍ଚ କରନ୍ତୁ।

ଷ୍ଟୋରେଜ୍ ଓ ଡାଟା ପରିଚାଳନା

  • ଟ୍ରାନ୍ସକ୍ରିପ୍ଟ ଓ ରେକର୍ଡିଂ: History ରୁ ଗୋଟିଏ ଗୋଟିଏ ଆଇଟମ୍ ଡିଲିଟ୍ କରନ୍ତୁ।
  • ଟ୍ୟାଗ୍: Manage Tags ରୁ ନାମ ବଦଳାନ୍ତୁ, ମିଶାନ୍ତୁ କିମ୍ବା ଡିଲିଟ୍ କରନ୍ତୁ।
  • ମଡେଲ୍: ଜାଗା ଖାଲି କରିବାକୁ Settings ରେ ଡାଉନଲୋଡ୍ ହୋଇଥିବା ମଡେଲ୍ ଡିଲିଟ୍ କରନ୍ତୁ।
  • ସବୁକିଛି: ଆପ୍ ଡିଲିଟ୍ କଲେ ଡିଭାଇସ୍‌ରୁ ଏହାର ଡାଟା ହଟିଯାଏ।

ଯୋଗାଯୋଗ

ବଗ୍ ରିପୋର୍ଟ, ପ୍ରଶ୍ନ କିମ୍ବା ବୈଶିଷ୍ଟ୍ୟ ଅନୁରୋଧ ପାଇଁ ଦୟାକରି GitHub ରେ ଏକ ଇସ୍ୟୁ ଖୋଲନ୍ତୁ। GitHub ଆକାଉଣ୍ଟ ଆବଶ୍ୟକ।

GitHub ରେ ଇସ୍ୟୁ ଖୋଲନ୍ତୁ

ଇସ୍ୟୁଗୁଡ଼ିକ ସାର୍ବଜନୀନ। ଦୟାକରି ବ୍ୟକ୍ତିଗତ ତଥ୍ୟ, ବ୍ୟକ୍ତିଗତ ରେକର୍ଡିଂ କିମ୍ବା ଟ୍ରାନ୍ସକ୍ରିପ୍ଟ ସାମିଲ କରନ୍ତୁ ନାହିଁ। ସାହାଯ୍ୟ ହେଲେ Settings → Diagnostics → Share Logs ରୁ ଲଗ୍‌ଗୁଡ଼ିକର ବିଷୟବସ୍ତୁ ଯାଞ୍ଚ କରିବା ପରେ ସଂଲଗ୍ନ କରିପାରିବେ।
