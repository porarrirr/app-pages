隐私政策

ABC Studio 尊重您的隐私，坚持零不必要信息收集的设计原则。

最后更新：2026年11月25日

隐私基本原则

完全本地处理 乐谱解析、渲染和音频合成均在您的设备本地完成，绝不会发送至外部服务器。
零追踪与零广告 应用内未集成任何广告、行为追踪 SDK 或访问分析库。
分享去向由您指定 导出的乐谱与音频仅在您主动选择分享目标时，才会传递至您指定的存储位置或应用。

porari（以下称“运营者”）就 ABC Studio（以下称“本应用”）及 ABC Studio 介绍网站（以下称“本网站”）的信息处理方式说明如下：

1. 本应用的信息处理

本应用运行于 iOS 17 或 iPadOS 17 及更高版本。ABC、MusicXML 与 LilyPond 乐谱的解析、显示、播放和导出均在设备本地处理。LilyPond 处理使用应用内置编译器。本应用无账号注册、广告、分析 SDK、追踪功能或向开发者自动发送崩溃报告的功能，绝不会将乐谱或使用情况发送至运营者。

2. 存储在设备本地的信息

为提供相关功能并在下次启动时恢复状态，本应用会在设备的应用专属存储区保存以下信息。这些数据绝不会发送给运营者。

  • 上次打开乐谱的源码、文件名、编辑内容及导入的相关文件
  • 乐谱缩放比例、播放位置自动跟随及耳机定位设置
  • 乐谱库中保存的乐谱及相关文件，以及各曲目的显示名称、创建日期、曲目数等管理信息

乐谱库中的曲目可在应用内单独删除。编辑中的文本可通过编辑器中的“清除所有输入”清空。在设备上选择“删除 App”会删除应用的本地存储数据；选择“卸载 App”则会保留文稿与数据。

导出乐谱源码、MusicXML、MXL、PDF、PNG、MIDI、WAV 等文件时，可能会在设备内生成临时文件。保存至分享目标的文件将受该目标的管理策略约束。

若您启用了 iCloud 或 Mac/PC 备份，本应用的本地数据可能会包含在备份中。备份加密与管理遵循您的设备设置及 Apple 服务规范。详情请参阅 Apple 的“iCloud 云备份内容” 。

3. 文件与剪贴板

本应用会读取您打开的乐谱文件以及所选项目中包含的相关文件。LilyPond 引用文件仅在操作系统允许访问的范围内读取。剪贴板文本用于“从剪贴板导入”及编辑器中的粘贴操作。仅当您主动执行复制操作时，诊断结果、错误信息或作曲技能资料才会写入剪贴板。

4. 导出、分享与外部链接

导出与分享仅由您的明确轻点操作触发。本应用会调用 iOS 标准分享面板，并将文件传递至您选择的应用（如邮件、隔空投送、文件、各类云盘等）。接收方对数据的处理遵循各自服务的隐私政策。

当您打开支持页面等网页链接时，会与该网站建立通信连接。当您通过邮件应用发送咨询邮件时，邮件会送达运营者。

5. 通过咨询收到的信息

若您通过电子邮件联系我们，您的发件人邮箱地址、邮件正文、附件及其中包含的信息将送达运营者的收件服务器。运营者仅将这些信息用于回复、技术支持、故障排查及必要的对应记录，绝不用于向第三方销售或投放广告。

如需查询或删除过往咨询记录，请联系我们的隐私联系窗口 。请勿在邮件中包含机密信息或与咨询无关的个人信息。

6. 本网站与外部服务

本介绍网站未安装任何由运营者设置的访问分析工具、广告标签或用于写入 Cookie 的追踪脚本。本网站托管于 GitHub Pages。为确保内容分发与基础设施安全，GitHub 可能会处理访问来源 IP 地址和请求日志。详情请参阅 GitHub 隐私声明 。

App Store、iOS 诊断共享设置、iCloud 云备份等 Apple 平台基础服务的数据处理方式遵循Apple 隐私政策 。

7. 儿童信息

本应用不具备向运营者发送个人信息的功能。即使儿童使用本应用，也不会收集任何个人信息。若咨询邮件中包含儿童信息，仅在提供支持所需的范围内处理。请家长注意避免在邮件中填写不必要的个人信息。

8. 政策变更

因本应用或本网站功能调整、法律法规修订等原因变更本政策时，我们将更新本页面并修订顶部的最后更新日期。
