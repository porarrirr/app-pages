ABC Studio നിങ്ങളുടെ സ്വകാര്യതയെ മാനിക്കുന്നു, അനാവശ്യ ഡാറ്റാ ശേഖരണം ഒഴിവാക്കുന്ന തരത്തിലാണ് രൂപകൽപ്പന ചെയ്തിരിക്കുന്നത്.

സ്വകാര്യതാ തത്വങ്ങൾ

പൂർണ്ണമായും പ്രാദേശിക പ്രോസസ്സിംഗ് സ്കോർ പാഴ്സിംഗ്, റെൻഡറിംഗ്, ഓഡിയോ സിന്തസിസ് എന്നിവയെല്ലാം നിങ്ങളുടെ ഉപകരണത്തിൽ നടക്കുന്നു, ഒരിക്കലും ബാഹ്യ സെർവറുകളിലേക്ക് അയയ്ക്കുന്നില്ല.
സീറോ ട്രാക്കിംഗും പരസ്യങ്ങളുമില്ല ആപ്പിനുള്ളിൽ പരസ്യങ്ങളോ പെരുമാറ്റ ട്രാക്കിംഗ് SDK-കളോ അനലിറ്റിക്സ് ലൈബ്രറികളോ ഉൾപ്പെടുത്തിയിട്ടില്ല.
ലക്ഷ്യസ്ഥാനം നിങ്ങൾ തിരഞ്ഞെടുക്കുന്നു എക്സ്പോർട്ട് ചെയ്ത സ്കോറുകളും ഓഡിയോയും നിങ്ങൾ പങ്കിടുമ്പോൾ തിരഞ്ഞെടുക്കുന്ന സ്റ്റോറേജ് സ്ഥലത്തേക്കോ ആപ്പിലേക്കോ മാത്രമേ നൽകുന്നുള്ളൂ.
ഉള്ളടക്കം
1. ഈ ആപ്പ് കൈകാര്യം ചെയ്യുന്ന ഡാറ്റ 2. ഉപകരണത്തിൽ സംഭരിച്ച വിവരങ്ങൾ 3. ഫയലുകളും ക്ലിപ്പ്ബോർഡും 4. എക്സ്പോർട്ടും പങ്കിടലും 5. ബന്ധപ്പെടുക 6. ഈ വെബ്സൈറ്റും ബാഹ്യ സേവനങ്ങളും 7. കുട്ടികളുടെ വിവരങ്ങൾ 8. നയത്തിലെ മാറ്റങ്ങൾ 9. ഓപ്പറേറ്ററും ബന്ധപ്പെടാനുള്ള വിവരങ്ങളും

ABC Studio ("ആപ്പ്"), ABC Studio വിവര സൈറ്റ് ("സൈറ്റ്") എന്നിവയിൽ വിവരങ്ങൾ എങ്ങനെ കൈകാര്യം ചെയ്യപ്പെടുന്നു എന്ന് porari ("ഓപ്പറേറ്റർ") താഴെ വിശദീകരിക്കുന്നു.

1. ഈ ആപ്പ് കൈകാര്യം ചെയ്യുന്ന ഡാറ്റ

ഈ ആപ്പ് iOS 17 അല്ലെങ്കിൽ iPadOS 17 ഉം അതിനുശേഷമുള്ളവയിലും പ്രവർത്തിക്കുന്നു. ABC, MusicXML, LilyPond സ്കോറുകളുടെ പാഴ്സിംഗ്, പ്രദർശനം, പ്ലേബാക്ക്, എക്സ്പോർട്ട് എന്നിവ ഉപകരണത്തിൽ തന്നെയാണ് പ്രോസസ്സ് ചെയ്യുന്നത്. LilyPond പ്രോസസ്സിംഗ് ആപ്പിനൊപ്പം ബണ്ടിൽ ചെയ്ത കമ്പൈലർ ഉപയോഗിക്കുന്നു. ആപ്പിൽ അക്കൗണ്ട് രജിസ്ട്രേഷനോ പരസ്യങ്ങളോ അനലിറ്റിക്സ് SDK-കളോ ട്രാക്കിംഗ് ഫീച്ചറുകളോ ഡെവലപ്പർക്ക് സ്വയമേവയുള്ള ക്രാഷ് റിപ്പോർട്ടിംഗോ ഇല്ല. സ്കോറുകളോ ഉപയോഗ വിവരങ്ങളോ ആപ്പിൽ നിന്ന് ഓപ്പറേറ്റർക്ക് അയയ്ക്കുന്നില്ല.

2. നിങ്ങളുടെ ഉപകരണത്തിൽ സംഭരിച്ചിരിക്കുന്ന വിവരങ്ങൾ

സവിശേഷതകൾ നൽകാനും അടുത്ത തവണ തുറക്കുമ്പോൾ അവസ്ഥ പുനഃസ്ഥാപിക്കാനും, ഈ ആപ്പ് താഴെ പറയുന്ന വിവരങ്ങൾ നിങ്ങളുടെ ഉപകരണത്തിലെ പ്രാദേശിക ആപ്പ് സ്റ്റോറേജിൽ സൂക്ഷിക്കുന്നു. ഇതിലൊന്നും ആപ്പിൽ നിന്ന് ഓപ്പറേറ്റർക്ക് അയയ്ക്കുന്നില്ല.

  • അവസാനമായി തുറന്ന സ്കോറിന്റെ സോഴ്സ്, ഫയൽ നാമം, എഡിറ്റുകൾ, ഇറക്കുമതി ചെയ്ത അനുബന്ധ ഫയലുകൾ
  • സ്കോർ സൂം നില, പ്ലേബാക്ക് സ്ഥാനം ഓട്ടോ-ഫോളോ, ഇയർഫോൺ പാനിംഗ് ക്രമീകരണങ്ങൾ
  • ലൈബ്രറിയിൽ സംരക്ഷിച്ച സ്കോറുകളും അനുബന്ധ ഫയലുകളും, കൂടാതെ പ്രദർശന നാമം, നിർമ്മാണ തീയതി, കൃതികളുടെ എണ്ണം തുടങ്ങിയ മാനേജ്മെന്റ് വിവരങ്ങൾ

ലൈബ്രറിയിലെ കൃതികൾ ആപ്പിനുള്ളിൽ വെവ്വേറെ ഇല്ലാതാക്കാം. എഡിറ്റ് ചെയ്തുകൊണ്ടിരിക്കുന്ന ടെക്സ്റ്റ് എഡിറ്ററിലെ "എല്ലാ ഇൻപുട്ടും ഇല്ലാതാക്കുക" ഉപയോഗിച്ച് മായ്ക്കാം. ഉപകരണത്തിൽ നിന്ന് ആപ്പ് നീക്കം ചെയ്താൽ ("ആപ്പ് ഇല്ലാതാക്കുക") അതിന്റെ പ്രാദേശിക സ്റ്റോറേജ് മായ്ക്കപ്പെടും; "ആപ്പ് ഓഫ്‌ലോഡ് ചെയ്യുക" (Offload App) ഡോക്യുമെന്റുകളും ഡാറ്റയും സൂക്ഷിക്കുന്നു.

സ്കോർ സോഴ്സുകൾ, MusicXML, MXL, PDF, PNG, MIDI, WAV മുതലായവ എക്സ്പോർട്ട് ചെയ്യുമ്പോൾ നിങ്ങളുടെ ഉപകരണത്തിൽ താൽക്കാലിക ഫയലുകൾ സൃഷ്ടിക്കപ്പെട്ടേക്കാം. പങ്കിട്ട ലക്ഷ്യസ്ഥാനത്ത് സംരക്ഷിച്ച ഫയലുകൾ ആ ലക്ഷ്യസ്ഥാനം കൈകാര്യം ചെയ്യുന്നു.

നിങ്ങൾ iCloud അല്ലെങ്കിൽ Mac/PC ബാക്കപ്പ് പ്രവർത്തനക്ഷമമാക്കിയിട്ടുണ്ടെങ്കിൽ, ഈ ആപ്പിന്റെ പ്രാദേശിക ഡാറ്റ ബാക്കപ്പുകളിൽ ഉൾപ്പെട്ടേക്കാം. ബാക്കപ്പ് എൻക്രിപ്ഷനും മാനേജ്മെന്റും നിങ്ങളുടെ ഉപകരണ ക്രമീകരണങ്ങളും Apple-ന്റെ സേവന നിബന്ധനകളും പാലിക്കുന്നു. വിശദാംശങ്ങൾക്ക് Apple-ന്റെ "iCloud ബാക്കപ്പ് കവറേജ്" പേജ് കാണുക.

3. ഫയലുകളും ക്ലിപ്പ്ബോർഡും

നിങ്ങൾ തുറക്കുന്ന സ്കോർ ഫയലുകളും തിരഞ്ഞെടുത്ത പ്രോജക്റ്റിൽ ഉൾപ്പെട്ട അനുബന്ധ ഫയലുകളും ആപ്പ് വായിക്കുന്നു. LilyPond റഫറൻസ് ഫയലുകൾ OS അനുവദിക്കുന്ന ആക്സസ് പരിധിക്കുള്ളിൽ മാത്രമേ വായിക്കുന്നുള്ളൂ. "ക്ലിപ്പ്ബോർഡിൽ നിന്ന് ലോഡ് ചെയ്യുക" എന്നതിനും എഡിറ്ററിലെ പേസ്റ്റ് പ്രവർത്തനങ്ങൾക്കും ക്ലിപ്പ്ബോർഡ് ടെക്സ്റ്റ് ഉപയോഗിക്കുന്നു. നിങ്ങൾ കോപ്പി ചെയ്യുമ്പോൾ ഡയഗ്നോസ്റ്റിക്സ്, പിശക് സന്ദേശങ്ങൾ, കംപോസിഷൻ സ്കിൽ സാമഗ്രികൾ എന്നിവ ക്ലിപ്പ്ബോർഡിലേക്ക് എഴുതപ്പെടുന്നു.

4. എക്സ്പോർട്ട്, പങ്കിടൽ, ബാഹ്യ ലിങ്കുകൾ

എക്സ്പോർട്ടും പങ്കിടലും നിങ്ങളുടെ വ്യക്തമായ ടാപ്പിലൂടെ മാത്രമേ ആരംഭിക്കൂ. ആപ്പ് സാധാരണ iOS ഷെയർ ഷീറ്റ് കാണിച്ച് നിങ്ങൾ തിരഞ്ഞെടുക്കുന്ന ആപ്പിന് (Mail, AirDrop, Files, വിവിധ ക്ലൗഡുകൾ മുതലായവ) ഫയലുകൾ നൽകുന്നു. സ്വീകർത്താക്കൾ ഡാറ്റ എങ്ങനെ കൈകാര്യം ചെയ്യുന്നു എന്നത് ഓരോ സേവനത്തിന്റെയും സ്വകാര്യതാ നയത്തിന് വിധേയമാണ്.

സഹായ പേജുകൾ പോലുള്ള വെബ് ലിങ്കുകൾ തുറക്കുമ്പോൾ, ആ സൈറ്റുമായി ഒരു കണക്ഷൻ ഉണ്ടാകുന്നു. നിങ്ങളുടെ മെയിൽ ആപ്പിൽ നിന്ന് അയയ്ക്കുമ്പോൾ അന്വേഷണ ഇമെയിലുകൾ ഓപ്പറേറ്ററിലേക്ക് എത്തുന്നു.

5. അന്വേഷണങ്ങൾ വഴി ലഭിക്കുന്ന വിവരങ്ങൾ

നിങ്ങൾ ഇമെയിൽ വഴി ഞങ്ങളെ ബന്ധപ്പെടുകയാണെങ്കിൽ, അയയ്ക്കുന്നയാളുടെ വിലാസം, സന്ദേശ ഉള്ളടക്കം, അറ്റാച്ച്മെന്റുകൾ, അവയിൽ അടങ്ങിയ വിവരങ്ങൾ എന്നിവ ഓപ്പറേറ്ററുടെ ഇൻകമിംഗ് മെയിൽ സെർവറിൽ എത്തും. മറുപടി നൽകാനും സഹായം നൽകാനും ബഗ് അന്വേഷണത്തിനും ആവശ്യമായ രേഖകൾക്കും മാത്രമാണ് ഓപ്പറേറ്റർ ഇവ ഉപയോഗിക്കുന്നത് — മൂന്നാം കക്ഷികൾക്ക് വിൽപ്പനയ്ക്കോ പരസ്യത്തിനോ ഒരിക്കലും ഉപയോഗിക്കില്ല.

മുൻകാല അന്വേഷണ ചരിത്രം പരിശോധിക്കാനോ ഇല്ലാതാക്കാനോ ദയവായി ഞങ്ങളുടെ സ്വകാര്യതാ ടീമിനെ ബന്ധപ്പെടുക. ഇമെയിലുകളിൽ രഹസ്യ വിവരങ്ങളോ അന്വേഷണത്തിന് ആവശ്യമില്ലാത്ത വ്യക്തിഗത വിവരങ്ങളോ ഉൾപ്പെടുത്തരുത്.

6. ഈ വെബ്സൈറ്റും ബാഹ്യ സേവനങ്ങളും

ഈ വിവര സൈറ്റിൽ ഓപ്പറേറ്റർ സ്ഥാപിച്ച അനലിറ്റിക്സ് ടൂളുകളോ പരസ്യ ടാഗുകളോ കുക്കികൾ സജ്ജമാക്കുന്ന ട്രാക്കിംഗ് സ്ക്രിപ്റ്റുകളോ അടങ്ങിയിട്ടില്ല. സൈറ്റ് GitHub Pages-ലാണ് ഹോസ്റ്റ് ചെയ്തിരിക്കുന്നത്. ഉള്ളടക്ക വിതരണത്തിനും അടിസ്ഥാന സൗകര്യ സുരക്ഷയ്ക്കുമായി GitHub സോഴ്സ് IP വിലാസങ്ങളും അഭ്യർത്ഥന ലോഗുകളും പ്രോസസ്സ് ചെയ്തേക്കാം. വിശദാംശങ്ങൾക്ക് GitHub സ്വകാര്യതാ പ്രസ്താവന കാണുക.

App Store, iOS ഡയഗ്നോസ്റ്റിക് പങ്കിടൽ ക്രമീകരണങ്ങൾ, iCloud ബാക്കപ്പ്, മറ്റ് Apple പ്ലാറ്റ്‌ഫോം സേവനങ്ങൾ എന്നിവ ഡാറ്റ കൈകാര്യം ചെയ്യുന്ന രീതി Apple-ന്റെ സ്വകാര്യതാ നയം അനുസരിച്ചാണ്.

7. കുട്ടികളുടെ വിവരങ്ങൾ

ഓപ്പറേറ്റർക്ക് വ്യക്തിഗത വിവരങ്ങൾ അയയ്ക്കുന്ന ഒരു ഫീച്ചറും ആപ്പിലില്ല. കുട്ടികൾ ആപ്പ് ഉപയോഗിക്കുമ്പോഴും വ്യക്തിഗത വിവരങ്ങളൊന്നും ശേഖരിക്കപ്പെടുന്നില്ല. ഒരു അന്വേഷണത്തിൽ കുട്ടിയുടെ വിവരങ്ങൾ ഉൾപ്പെട്ടിട്ടുണ്ടെങ്കിൽ, സഹായത്തിന് ആവശ്യമായ അളവിൽ മാത്രമേ അത് കൈകാര്യം ചെയ്യുകയുള്ളൂ. മാതാപിതാക്കൾ ഇമെയിലുകളിൽ അനാവശ്യ വ്യക്തിഗത വിവരങ്ങൾ ഉൾപ്പെടുത്തുന്നത് ഒഴിവാക്കണം.

8. ഈ നയത്തിലെ മാറ്റങ്ങൾ

ആപ്പ് അല്ലെങ്കിൽ സൈറ്റ് സവിശേഷതകളിലെ മാറ്റങ്ങൾ, നിയമപരമായ പരിഷ്കാരങ്ങൾ മുതലായവ കാരണം ഈ നയത്തിൽ മാറ്റമുണ്ടായാൽ, ഈ പേജ് അപ്ഡേറ്റ് ചെയ്യുകയും മുകളിലുള്ള അവസാന അപ്ഡേറ്റ് തീയതി പുതുക്കുകയും ചെയ്യും.
