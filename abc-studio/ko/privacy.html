개인정보 처리방침

ABC Studio는 사용자의 개인정보를 존중하며, 불필요한 정보를 수집하지 않도록 철저히 설계되었습니다.

최종 업데이트: 2026년 11월 25일

개인정보 보호 원칙

완전한 로컬 처리 악보 파싱, 렌더링, 오디오 합성은 모두 기기 내부에서 이루어지며 외부 서버로 전송되지 않습니다.
추적·광고 제로 앱 내부에 광고, 행태 추적 SDK, 접속 분석 라이브러리가 일절 포함되어 있지 않습니다.
공유 대상은 사용자가 직접 선택 내보낸 악보와 오디오는 사용자가 공유 대상을 직접 선택할 때만 해당 저장 위치나 앱으로 전달됩니다.
목차
1. 앱에서의 정보 처리 2. 기기 내 저장 정보 3. 파일·클립보드 4. 내보내기·공유 5. 문의하기 6. 본 사이트 및 외부 서비스 7. 아동 정보 8. 방침 변경 9. 운영자·문의처

porari(이하 ‘운영자’)는 ABC Studio(이하 ‘본 앱’) 및 ABC Studio 안내 사이트(이하 ‘본 사이트’)에서의 정보 처리 방침을 다음과 같이 설명합니다.

1. 본 앱에서의 정보 처리

본 앱은 iOS 17 또는 iPadOS 17 이상에서 동작합니다. ABC, MusicXML, LilyPond 악보의 분석, 표시, 재생, 내보내기는 모두 기기 내에서 처리됩니다. LilyPond 처리는 앱에 내장된 컴파일러를 사용합니다. 본 앱에는 계정 등록, 광고, 접속 분석 SDK, 추적 기능, 개발자 자동 오류 보고 기능이 없습니다. 악보나 이용 현황 등이 앱에서 운영자에게 전송되는 일은 일절 없습니다.

2. 기기 내에 저장되는 정보

본 앱은 기능 제공과 다음 실행 시 상태 복원을 위해 아래 정보를 기기 내 앱 전용 저장 공간에 저장합니다. 이 정보는 운영자에게 전송되지 않습니다.

  • 마지막으로 연 악보의 소스, 파일 이름, 편집 내용 및 가져온 관련 파일
  • 악보 표시 배율, 재생 위치 자동 따라가기, 이어폰 음향 위치 설정
  • 라이브러리에 저장한 악보와 관련 파일, 각 곡의 표시 이름, 생성 일시, 곡 수 등의 관리 정보

라이브러리의 곡은 앱 내에서 개별 삭제할 수 있습니다. 편집 중인 텍스트는 편집기의 ‘입력 내용 모두 지우기’로 삭제할 수 있습니다. 기기에서 ‘앱 삭제’를 선택하면 기기의 앱 저장 공간이 삭제됩니다. ‘앱 정리하기’를 선택하면 문서와 데이터가 유지됩니다.

악보 소스, MusicXML, MXL, PDF, PNG, MIDI, WAV 등을 내보낼 때 기기 내에 임시 파일이 생성될 수 있습니다. 공유 대상에 저장된 파일은 해당 대상의 관리 정책을 따릅니다.

iCloud 또는 Mac/PC 백업을 활성화한 경우 본 앱의 로컬 데이터가 백업에 포함될 수 있습니다. 백업 암호화 및 대상 관리는 기기 설정과 Apple의 서비스 사양을 따릅니다. 자세한 내용은 Apple의 ‘iCloud 백업 대상’을 확인해 주세요.

3. 파일 및 클립보드 처리

사용자가 연 악보 파일과 선택한 프로젝트에 포함된 관련 파일을 읽습니다. LilyPond 참조 파일은 OS가 접근을 허용한 범위 내에서만 읽습니다. 클립보드 텍스트는 ‘클립보드에서 불러오기’나 편집기 붙여넣기 시 사용됩니다. 진단 결과, 오류 메시지, 작곡 스킬 자료 등은 사용자가 복사를 실행할 때 클립보드에 기록됩니다.

4. 내보내기, 공유 및 외부 링크

내보내기와 공유는 사용자의 명시적인 탭 동작에 의해서만 시작됩니다. 본 앱은 표준 iOS 공유 시트를 표시하고 사용자가 선택한 앱(Mail, AirDrop, 파일, 각종 클라우드 등)으로 파일을 전달합니다. 수신 측의 데이터 처리는 각 서비스의 개인정보 처리방침을 따릅니다.

지원 페이지 등 웹 링크를 열면 해당 사이트와 통신이 발생합니다. 문의 이메일은 사용자가 메일 앱에서 전송할 때 운영자에게 전달됩니다.

5. 문의를 통해 수집되는 정보

이메일로 문의하시면 발신자 이메일 주소, 본문, 첨부 파일 및 포함된 정보가 운영자의 수신 메일 서버에 도달합니다. 운영자는 이를 회신, 지원, 오류 조사 및 대응 기록 목적에만 사용하며, 판매나 광고 목적으로 제3자에게 제공하거나 이용하지 않습니다.

과거 문의 내역을 확인하거나 삭제하려면 개인정보 문의처로 연락해 주세요. 기밀 정보나 문의에 불필요한 개인정보는 이메일에 포함하지 마시기 바랍니다.

6. 본 사이트 및 외부 서비스

본 안내 사이트에는 운영자가 설치한 접속 분석 도구, 광고 태그, 쿠키를 발행하는 추적 스크립트가 전혀 없습니다. 본 사이트는 GitHub Pages에서 호스팅됩니다. GitHub는 콘텐츠 전송과 인프라 보안 유지를 위해 접속자의 IP 주소와 요청 로그를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보 처리방침을 확인해 주세요.

App Store, iOS 진단 공유 설정, iCloud 백업 등 Apple이 제공하는 기반 서비스의 데이터 처리는 Apple 개인정보 처리방침을 따릅니다.

7. 아동의 개인정보

본 앱에는 운영자에게 개인정보를 전송하는 기능이 없습니다. 어린이가 본 앱을 이용하더라도 개인정보는 수집되지 않습니다. 문의 내용에 아동의 정보가 포함된 경우 지원에 필요한 범위 내에서만 처리합니다. 보호자께서는 불필요한 개인정보를 이메일에 기재하지 않도록 유의해 주시기 바랍니다.

8. 방침의 변경

본 앱이나 본 사이트의 사양 변경, 법령 개정 등에 따라 본 방침을 변경하는 경우 이 페이지를 업데이트하고 상단의 최종 업데이트 날짜를 갱신합니다.
