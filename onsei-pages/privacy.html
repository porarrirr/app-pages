2. 基本方針

本アプリは、テキストの音声合成、任意の声クローン、ポッドキャスト対話生成を、原則として利用者の端末内（オンデバイス）で行います。提供者は、本アプリを通じて利用者の入力テキスト、参照音声、生成音声、アカウント情報などを、提供者が管理するサーバーへ送信・収集する機能を実装していません。

個人情報の保護に関する法律（個人情報保護法）その他の適用法令を遵守するよう努めます。本アプリの実装上、提供者が保有する利用者の個人データは原則として存在しません（サポートメールで任意に送られた情報を除く。第12条参照）。

任意の「プロンプトを最適化」操作は Apple Intelligence を利用します。iOS 27 以降で利用可能な場合、声の説明文と参照音声の有無を Apple の Private Cloud Compute へ送信します（第6.4節参照）。

3. 収集する情報

3.1 提供者がサーバーで収集しないもの

本アプリの通常利用において、提供者は氏名・住所・電話番号・メールアドレス（アカウント機能なし）、合成用に入力したテキスト、マイクで録音した参照音声や読み込んだ音声・動画ファイル、生成された音声ファイル、位置情報・連絡先・写真ライブラリ一括アクセス、広告識別子やトラッキング用永続IDをサーバーへ収集しません。

3.2 サポート経由で任意に提供される情報

利用者がサポート窓口（メール）に問い合わせた場合、送信されたメールアドレス、本文、添付ファイル等を、問い合わせ対応の目的で取り扱います。不要になった時点で削除するよう努めますが、法令上の保存義務がある場合はその限りではありません。

4. 端末内で扱うデータ

本アプリは機能提供のために次のデータを利用者の端末上で扱います。本アプリでは「ファイル共有」が有効な場合があり、端末を PC 等に接続したときに Documents 内のファイルが見えることがあります。参照音声など機微なファイルの管理は利用者ご自身で行ってください。

入力テキスト・台本音声合成やポッドキャスト作成のためにアプリ内で処理し、必要に応じて端末内に保存します。提供者が運営するサーバーへ送信しません。
参照音声・埋め込み等声クローン等のため、録音または音声・動画ファイルから取り込んだデータを端末内（Documents 配下等）に保存することがあります。
生成音声・ライブラリ端末内のライブラリ領域・一時領域に WAV / MP3 等として書き出し、再生・共有に利用します。利用者が共有シートで他アプリへ送った場合は、送信先の取扱いに従います。
モデルデータ日本語および多言語音声合成用のモデルパックを端末内（Application Support 等・iCloud バックアップ除外設定）に保存します。公開配布されているモデルファイルであり、利用者の個人情報そのものではありません。
診断ログ診断用のログを端末上のシステムログ等に出力することがあります。提供者のサーバーへ自動送信する仕組みはありません。

5. マイクへのアクセス

本アプリは、声クローン用の参照音声（3〜10秒）の録音のためにマイクへアクセスすることがあります。用途は参照録音に限られ、常時録音やバックグラウンドでの秘密録音を目的としません。

許可は iOS の「設定」からいつでも変更できます。許可しない場合でも、録音以外の機能（参照なしの合成やファイル読込）は利用できます。

6. 通信・第三者

6.1 モデルのダウンロード

初回起動時や多言語モデルの追加取得時など、対象モデルが端末にない場合、利用者の明示的なサイズ同意のうえ、本アプリは Hugging Face（huggingface.co）上の配布リポジトリからモデルファイルおよびマニフェストを HTTPS で取得し、SHA-256 ハッシュ検証を行います。この通信はモデル配布のためのダウンロードであり、利用者の合成テキストや参照音声をアップロードするものではありません。

モデル取得時、通信の性質上、接続先のサーバーは IP アドレス、User-Agent、アクセス日時、要求した URL 等の通信メタデータを処理し得ます。これらは提供者ではなく Hugging Face その他の配信インフラの管理下にあり、その取扱いは各事業者のポリシーに従います。

6.2 利用者が自ら開く外部リンク

アプリ内のライセンス画面等からモデルの出典ページや OSS のリポジトリを開くと、Safari 等を通じて第三者のサイトにアクセスします。その場合の取扱いは各サイトのポリシーに従います。

6.3 利用者が行う共有

生成音声を共有シート等で他アプリ・他サービスに送った場合、送信先のサービスがデータを処理します。提供者は当該送信先の取扱いを管理できません。

6.4 プロンプトの最適化（Apple Intelligence）

利用者が任意で「プロンプトを最適化」を押した場合、声・話し方の説明文を Apple Intelligence で編集します。iOS 27 以降で Private Cloud Compute が利用可能な場合は、入力した説明文、参照音声の有無、および編集用の指示を Apple の Private Cloud Compute に送信します。クラウド処理を利用できない場合や処理に失敗した場合は、対応端末のオンデバイスモデルで処理を試みます。

Private Cloud Compute での処理は Apple が提供するサービスです。Apple は、この処理に送信されたデータをリクエストの処理にのみ使用し、応答を返した後には保持しないと説明しています。

7. 利用目的

端末内データおよびサポート経由の情報は、次の目的の範囲で扱います。下記以外の目的で、提供者が端末外にデータを持ち出して利用することはありません（サポートメールの内容を除く）。

  • 本アプリの音声合成・ボイスクローン・ポッドキャスト作成・再生・設定等の機能提供
  • モデルの取得・検証（サイズ・SHA-256 ハッシュ照合等）
  • お問い合わせへの対応、不具合調査
  • 利用規約違反への対応、権利保護、法令に基づく対応

8. 第三者提供・共同利用

本アプリから外部サービスへ送信する情報は、第6節に記載したモデル取得時の通信情報、利用者が任意に共有する音声、およびプロンプト最適化で送信する説明文等です。提供者は、利用者の音声・テキストを第三者に販売・譲渡しません。

モデル配信事業者（Hugging Face 等）への通信メタデータの到達は利用者がモデルを取得する過程で生じるものであり、プロンプト最適化時に Apple が処理する説明文等については第6.4節のとおりです。法令に基づく開示請求等がある場合は、これに応じることがあります。

9. トラッキング・広告・分析

  • App Tracking Transparency（ATT）によるクロスアプリ追跡は行いません。
  • 広告 SDK、分析 SDK、クラッシュレポートの外部送信 SDK は、現バージョンでは組み込んでいません。
  • Apple のプライバシーマニフェスト（PrivacyInfo.xcprivacy）上、トラッキングは行わず、収集データ種別の申告は空としています（実装の変更があった場合は本ポリシーを更新します）。

10. 保存期間・削除

  • 端末内データ: 利用者が本アプリを削除するまで、または利用者がライブラリやファイルを削除するまで端末に残ることがあります。OS の一時領域のファイルは OS やアプリの都合で削除されることがあります。
  • サポートメール: 対応に必要な期間保持し、不要になれば削除するよう努めます。
  • 提供者のサーバー上に、本アプリの利用ログや音声を蓄積するデータベースはありません（現バージョン）。

11. 安全管理

提供者は、サポートメールで受け取った情報について、不正アクセスや漏えいを防ぐため合理的な範囲で注意を払います。端末内データの安全は、主に Apple の iOS セキュリティと利用者自身の端末管理（パスコード、OS 更新、端末共有の有無等）に依存します。機微な参照音声を端末に残す場合は、利用者ご自身でアクセス管理に注意してください。

12. 開示等の請求

個人情報保護法に基づく開示、訂正、利用停止等の請求については、onsei@rarari.org までご連絡ください。

なお、本アプリの設計上、提供者が保有する「本アプリ利用に伴う個人データ」は原則として存在しません。端末内データの削除は、アプリの削除または端末上のファイル操作により行ってください。本人確認が必要な場合は、合理的な範囲で確認を求めることがあります。

13. 子どもの利用

本アプリは特定の年齢層のみを対象とした「子ども向け」アプリとして設計されていません。児童からオンラインで個人情報を積極的に収集する機能はありません。保護者の方は、お子さまの端末利用と声クローン機能の扱いについてご監督ください。

14. 海外への転送

モデル取得のため、利用者が所在する国・地域から Hugging Face 等の国外サーバーへ HTTPS 通信が行われることがあります。これはモデルファイルのダウンロードに伴うものであり、提供者による利用者音声・テキストの国外サーバーへのアップロードではありません。

プロンプト最適化で利用する Apple の Private Cloud Compute への通信で送信するデータと利用目的は、第6.4節のとおりです。

15. 改定

提供者は、法令の改正、機能変更、運営上の必要に応じて本ポリシーを改定することがあります。重要な変更がある場合は、本ページの更新日の変更その他適切な方法で周知します。改定後に本アプリを利用した場合、改定後のポリシーに同意したものとみなすことがあります。

16. 準拠法

本ポリシーの解釈および適用は、日本法に準拠します。
